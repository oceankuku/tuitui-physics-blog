## 题型一：位移公式计算——直代卡

![位移公式问题模型](/blog-images/k006-displacement-time-formula/K006-匀变速直线运动的位移与时间的关系-05-位移公式-问题模型.png)

### 如何识别

题目给（或可求）$v_0$、a、t 求位移 x；或给 x 反求其中一个量。情境：探测器减速下落、高铁启动、升降机、闸机减速。

### 为什么用这个方法

公式一行：

:::formula
x = v_0 t + \frac{1}{2} a t^2
:::

读法照旧：前一半匀速打底，后一半加速加成。动作四步：定正方向 → 列已知带符号 → 代入 → 检查结果正负与物理意义。三条纪律从速度公式延续并加码：

1. 符号纪律：减速段 a 代负；x 为负表示终点在正方向反侧（如上抛落回原点以下）。
2. 时间只代一次：t 是"本段"的总时长，"加速 8 s 后又匀速 5 s"必须分段，各段各用各的时间。
3. 单位统一：先换 m/s 再动笔。

适用条件：匀变速直线运动专用。变加速、拐弯全失效。配套工具：知三求二——x、$v_0$、a、t 四量知三求一，与 $v = v_0 + at$ 联立可解更复杂的组合。

### 完整示范

:::problem
示范 1（2021 福建卷 T13 同型，主讲篇第 1 题）：探测器 96 m/s 匀减速到 0 历时 80 s（向下为正）。$a = -1.2$ m/s²，$x = 96 \times 80 + 0.5 \times (-1.2) \times 80^2 = 7680 - 3840 = 3840$ m。平均速度法验算：$x = \frac{96 + 0}{2} \times 80 = 3840$ m。两条路同答案，考试时一正一验，稳。
:::

:::problem
示范 2（反求型，2017 海南卷 T3 同型，主讲篇第 5 题）：刹车线长 25 m、$a = 8$ m/s²，求刹车前速度。车停：$0 = v_0^2 - 2 \times 8 \times 25$（这是 $v^2 = v_0^2 + 2ax$ 的应用——"没有 t 的公式"，主讲篇知识点三已引入），$v_0^2 = 400$，$v_0 = 20$ m/s。刹车线长就是刹车位移，生活情境与物理量的翻译先行。
:::

### 条件变化后怎么调整

- 变式 1：多段接力。加速—匀速—减速的行程问题。应对：切段，各段选各自的公式（匀速段 $x = vt$），段间末速接初速，位移相加。
- 变式 2：过零反向。求出的 x 为负或某时刻速度反向。应对：以 v = 0 时刻为界切段，正负号交给公式，图景交给检查。
- 变式 3：比例条件反求。"第 1 s 内与第 3 s 内位移之比"——进题型三。

### 常见错误与适用边界

- 错因（数学）：$\frac{1}{2}at^2$ 项漏乘 0.5 或漏平方。推荐固定书写顺序：先写公式原形，再代数。
- 错因（概念）：把 x 当路程用。往返或减速过头时两者不同。
- 边界：单段匀变速内使用；跨段问题切段处理；本单元不用面积微元做非匀变速。

## 题型二：平均速度法——中间时刻钥匙卡

![平均速度法问题模型](/blog-images/k006-displacement-time-formula/K006-匀变速直线运动的位移与时间的关系-07-平均速度法-问题模型.png)

### 如何识别

匀变速段里出现"中间时刻的速度""首末速度已知""位移与时间的搭配"类问题；或题目结构让你预感"直接代位移公式会算很久"。

### 为什么用这个方法

匀变速直线运动有一条漂亮的推论：中间时刻的瞬时速度等于这段的平均速度：

:::formula
v_{\frac{t}{2}}\,(\text{中点}) = \bar{v} = \frac{v_0 + v_{\text{末}}}{2}
:::

于是位移多了一条快路：

:::formula
x = \bar{v} t = \frac{v_0 + v_{\text{末}}}{2}\, t
:::

为什么成立：v–t 图是倾斜直线，梯形面积 = 中位线 × 高。中位线恰好立在时间中点上。"为什么选它当钥匙"：它把"带 $t^2$ 的计算"换成"首末速度平均后乘时间"，数字漂亮时口算都行；2023 山东卷 T6（公交 RST）那一整类难题，钥匙就是它。

适用条件：只在匀变速段成立（v–t 必须是直线）。变加速不能用；跨段（先减速后匀速）不能整段套，切开后各段各用。

### 完整示范

:::problem
示范 1（对称感应门型，2024 海南卷 T5，主讲篇第 16 题）：每扇门先匀加速再匀减速、末速 0、各 2 s、共 2 m。两段平均速度都是 $\frac{v_{max}}{2}$，总位移 = $\frac{v_{max}}{2} \times 4 = 2$ m → $v_{max} = 1$ m/s。对称结构里平均速度法一步出答案，比联立方程快一倍。
:::

:::problem
示范 2（2023 山东卷 T6 同型，主讲篇第 9 题）：匀减速过 R、S、T，RS 位移 20 m 用时 2 s、ST 位移 20 m 用时 4 s，求 S 点速度。设 RS 中间时刻速度 = 10 m/s、ST 中间时刻速度 = 5 m/s；两个中间时刻相隔 1 s（$\frac{2 + 4}{2}$ 对上），所以 $a = \frac{5 - 10}{1} = -5$ m/s²；S 点速度 = $10 + (-5) \times 1 = 5$ m/s。全程没有列一个方程组——中间时刻的链条接起来就完了。
:::

### 条件变化后怎么调整

- 变式 1：首末速度不齐。已知 $v_0$ 和 a、t：先 $v_{\text{末}} = v_0 + at$，再平均。应对：两步合一步写。
- 变式 2：位移中点速度。位移中点的速度是另一条推论 $v_{\frac{x}{2}} = \sqrt{\frac{v_0^2 + v^2}{2}}$，与中间时刻不同（减速时 $v_{\frac{x}{2}} > v_{\frac{t}{2}}$）。本单元认识即可，不展开推导。
- 变式 3：非匀变速段。平均速度法只剩定义式 $\bar{v} = \frac{\Delta x}{\Delta t}$ 可用，推论失效。识别标志：v–t 图是否直线。

### 常见错误与适用边界

- 错因（条件）：在变加速段用 $\frac{v_0 + v}{2}$。先确认匀变速再上钥匙。
- 错因（混淆）：中间时刻与位移中点当成同一个点。减速时两者不重合。
- 边界：本卡解决匀变速段的 x、$\bar{v}$、$v_{\frac{t}{2}}$ 互求；不处理变加速与曲线。

## 题型三：比例关系与逐差——1:3:5 卡

![逐差关系问题模型](/blog-images/k006-displacement-time-formula/K006-匀变速直线运动的位移与时间的关系-09-逐差关系-问题模型.png)

### 如何识别

题目出现"初速度为零""连续相等时间间隔""第 n 个 T 内位移""连续相等位移""纸带连续相等间隔数据"。这是初速为零匀加速的专属赛道。

### 为什么用这个方法

初速为零的匀加速直线运动，从静止起按相等时间 T 切段，四条比例关系（主讲篇已逐条推导）：

1. 速度比：1 s 末、2 s 末、3 s 末……速度之比 = 1 : 2 : 3 : …
2. 位移比：前 1、前 2、前 3 个 T 内位移之比 = 1 : 4 : 9 : …（$x \propto t^2$）
3. 逐段比：第 1、第 2、第 3 个 T 内位移之比 = 1 : 3 : 5 : …（连续奇数比）
4. 逐差恒定：相邻相等时间间隔位移差 $\Delta x = aT^2$（对任意匀变速成立，不限初速为零）

适用条件：前三条必须初速为零（或能"逆向"化为初速为零——见变式 2）；第四条 $aT^2$ 是匀变速通吃。比例是有条件的结论，条件丢了就错。

### 完整示范

:::problem
示范 1（2016 全国卷同型，主讲篇第 17 题）：初速为零匀加速，前 3 s 位移 18 m。$x = \frac{1}{2}at^2$ → $a = \frac{2 \times 18}{9} = 4$ m/s²；第 3 s 内位移 = 前 3 s 减前 2 s = $18 - 0.5 \times 4 \times 4 = 10$ m。用 1:3:5 心算版：前 3 s 含 1:3:5 三段，总 9 份，每份 2 m，第 3 s 内占 5 份 = 10 m。比例一摆，不用算 $t^2$。
:::

:::problem
示范 2（2019 全国Ⅰ卷 T18 原题，主讲篇第 14 题）：竖直上抛到最高点 H，逆向看是初速为零的匀加速下落：从顶往下第一个 $\frac{H}{4}$、第二个……时间之比 $1 : (\sqrt{2}-1) : (\sqrt{3}-\sqrt{2}) : (2-\sqrt{3})$。所以最后一段（扣篮问的"上升第一个 $\frac{H}{4}$"）与最前一段之比 $t_1 : t_2 = (2-\sqrt{3}) : 1 > 1$。逆向思维是这张卡的标配：上抛的"最后一段"倒过来读就是下落的"第一段"。
:::

:::problem
示范 3（逐差版，2021 福建卷 T13 同型，主讲篇第 15 题）：纸带 T = 0.1 s，连续三段 6.0、8.0、10.0 cm。$\Delta x = 2.0$ cm 恒定 → $a = \frac{\Delta x}{T^2} = \frac{0.02}{0.01} = 2$ m/s²。逐差法是实验题（第五组实验单元）与计算题两栖的必点技能。
:::

### 条件变化后怎么调整

- 变式 1：等时间但非从静止。先算第一段末速，或用 $\Delta x = aT^2$ 只求 a。应对：比例 1:3:5 不可用，逐差仍可用。
- 变式 2：逆向化归。减速到停的问题倒过来读成"初速为零的加速"（刹车倒放、上抛倒放）。应对：末态当初态，时间轴翻转。
- 变式 3：等位移切段。通过连续相等位移（2024 山东卷 T3 木板型）：各段末速比 = $1 : \sqrt{2} : \sqrt{3}$，时间用 $t = \sqrt{\frac{2x}{a}}$ 逐段差。应对：回到 $x \propto t^2$ 的原始关系解。
- 变式 4：纸带缺段。连续六段用逐差法分组求 a（$(x_4+x_5+x_6) - (x_1+x_2+x_3) = 9aT^2$）。应对：实验单元正式推，本单元先记结构。

### 常见错误与适用边界

- 错因（条件）：初速不为零硬套 1:3:5。比例前先查 $v_0$。
- 错因（概念）："前 n 秒位移比"与"第 n 秒位移比"混用（1:4:9 对 1:3:5）。
- 错因（数学）：$\sqrt{2}-1 \approx 0.41$、$2-\sqrt{3} \approx 0.27$ 这些数值要熟，考场现推费时间。
- 边界：比例只服务初速为零的匀加速（或其逆过程）；$\Delta x = aT^2$ 服务一切匀变速。

## 题型四：刹车位移——停车时间+位移卡

### 如何识别

刹车/减速到停的问题里问"多远停住""某段时间内滑行多远"——《速度公式》单元停车时间卡的位移版。

### 为什么用这个方法

两步走：先算 $t_{\text{停}} = \frac{v_0}{|a|}$，再算位移——问的时间没超 $t_{\text{停}}$ 就正常代公式，超了就只算到停为止。刹车位移有一条速算路：平均速度法 $x = \frac{v_0}{2} \cdot t_{\text{停}}$，或"没有 t 的公式" $v^2 = v_0^2 - 2|a|x$（首推反求 $v_0$，如示范 2）。

适用条件：模型边界与 K005 相同——停后不动。上抛过顶不是刹车，上抛的位移要用完整公式让 x 自己变负，不套"截断"。

### 完整示范

:::problem
示范 1（2019 海南卷 T3 位移版）：20 m/s、$a = 8$ m/s²。$t_{\text{停}} = 2.5$ s，$x = \frac{20}{2} \times 2.5 = 25$ m。问"3 s 内滑行多远"答案仍是 25 m——多出来的 0.5 s 车没动。
:::

:::problem
示范 2（2017 海南卷 T3 原题，主讲篇第 5 题）：刹车线 25 m、$a = 8$ m/s²，$v^2 = 2 \times 8 \times 25$ → $v_0 = 20$ m/s。刹车线（胎痕）就是考场上的位移尺。
:::

### 条件变化后怎么调整

- 变式 1：两段刹车。反应距离（匀速）+ 刹车距离（匀减速）。应对：切段相加，这是"安全距离"类题的标准结构。
- 变式 2：减速到目标速度再匀速。（2022 湖北卷 T6 型，主讲篇第 6 题）减速段单独用卡，匀速段 $x = vt$。应对：别把"减速到 30 m/s"当"减到停"。
- 变式 3：列车过限速区。（2022 全国甲卷 T15 型）长车身问题：位移要含车长。应对：画"车头位置"示意图，区界与车头车尾对齐再算。

### 常见错误与适用边界

- 错因（建模）：不查 $t_{\text{停}}$ 直接代"6 s 内位移"。负位移或超量位移都是模型越界。
- 错因（概念）：刹车位移用 $v_0 t - 0.5|a|t^2$ 代了超过 $t_{\text{停}}$ 的 t。截断在 $t_{\text{停}}$。
- 边界：只管"减速到停停住不动"；冰面倒滑、上抛越顶另立模型。

## 题型五：v–t 图像面积——面积分块卡

### 如何识别

给 v–t 图像求位移，或多段折线图求全程位移、路程。

### 为什么用这个方法

v–t 图线与时间轴围成的面积 = 位移。倾斜直线下面积是梯形/矩形+三角形——位移公式 $x = v_0 t + \frac{1}{2}at^2$ 的图像版（主讲篇推导用的就是它）。三条使用规则：

1. 分块：复杂折线按"每段一个几何图形"切块，各块面积相加。
2. 正负：t 轴下方的面积算负位移（速度为负在往回走）；路程则把绝对值全加。代数面积与路程的分野在图像题里最直观。
3. 方向：总位移正负即总位移方向；"回到出发点"对应正负面积互相抵消（x = 0）。

适用条件：面积法对任何 v–t 图成立（包括曲线，高中曲线面积用数格近似）；匀变速直线用几何公式精确算。

### 完整示范

:::problem
示范 1（2014 全国卷同型，主讲篇第 19 题）：3 s 从 0 匀加速到 12 m/s，随后匀减速 6 s 停。v–t 图是一个大三角形（底 9 s、高 12 m/s），面积 = $0.5 \times 9 \times 12 = 54$ m——全程位移一眼出，比两段分别算加起来快得多。对称结构下三角形面积是首选。
:::

:::problem
示范 2（正负面积版）：v–t 图 0–4 s 从 0 到 8 m/s（正三角 16 m），4–6 s 从 8 m/s 匀减到 −4 m/s（穿 t 轴，上方小三角 8 m 正、下方小三角 2 m 负）。总位移 = $16 + 8 - 2 = 22$ m；总路程 = $16 + 8 + 2 = 26$ m。穿轴切段是负面积题的标准动作。
:::

### 条件变化后怎么调整

- 变式 1：梯形直接算。匀加速段就是梯形 $\frac{v_0+v}{2} \times t$——平均速度法的图像解释，两卡联动。
- 变式 2：判追及。两车 v–t 同图：面积差 = 距离变化；交点（速度相等）常是距离极值点。本单元点到为止，追及专题在主题⑩。
- 变式 3：a–t 图迁移。a–t 图的面积是 $\Delta v$ 不是位移——另一张牌，别混。

### 常见错误与适用边界

- 错因（概念）：把 t 轴下方面积也加正。位移带符号、路程取绝对值。
- 错因（读图）：把 x–t 图当 v–t 图求面积。先看纵轴。
- 边界：面积法只配 v–t 图；x–t 图没有"面积=位移"的属性。

| 平均速度法 | 中间时刻钥匙 | $\bar{v} = \frac{v_0+v}{2}$，仅匀变速 | 变加速硬套 |
| 比例与逐差 | 1:3:5 | 先查初速是否为零 | 1:4:9 与 1:3:5 混 |
| 刹车位移 | 停车+截断 | 先 $t_{\text{停}}$ 再算位移 | 超时直代 |
| 图像面积 | 分块+正负 | 上正下负；路程取绝对值 | 下方面积加正 |

到此匀变速四大公式（v、x、$\bar{v}$、$v^2$ 关系）全部到手，加上比例关系与面积法，工具箱满了。下一单元《自由落体运动》把 a 换成 g 做一次完整的"模型落地"——两个条件、三行公式、一组对称，外加伽利略四百年前的那场漂亮仗。
