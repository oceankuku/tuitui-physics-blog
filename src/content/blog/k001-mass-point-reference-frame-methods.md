两条题型线共用一个底层动作：先问标准，再下结论。质点问的标准是"大小形状碍不碍事"，参考系问的标准是"拿谁当基准"。高考在这两个考点上年年出题，从不考计算，考的就是这个动作标不标准。

## 题型一：质点判断——先看问题，再看物

![质点判定题型示意](/blog-images/k001-mass-point-reference-frame/K001-质点参考系-05-质点判定-题目.png)

图 1｜质点判断题型示意：同一物体，问题不同，结论不同

### 如何识别

题目出现这些信号就是它："可视为质点的是""一定能（不能）看成质点的是""研究XX时，XX能否看成质点"。选项常配四个情境（跳水、转弯、穿缝、估算时间这种），让同一个物体在不同问题里反复出现。

### 先分析什么、建什么模型

先别看物体，先圈出研究的问题。同一个地球，研究公转能缩成点，研究自转不能：问题变了，答案就翻。圈完问题再问一句：这个问题的答案，跟物体的大小形状有没有关系？

### 为什么用这个方法：三步判断卡

质点是个理想化模型，判断它只有一个标准：形状和大小对所研究问题的影响，能不能忽略。把这一句拆成固定三步：

1. 定对象：研究的是哪个物体。
2. 定问题：题目在研究这件事的什么（动作？轨迹？时间？姿态？）。
3. 判影响：大小形状碍不碍这个问题。碍就不能，不碍或小到可忽略就能。

第三步一锤定音。前两步走反了（先盯物体大小）就会掉进三个经典坑："小的就能看成质点"（乒乓球小，研究旋转时不能）、"大的就不能"（地球大，研究公转时能）、"质点是真实存在的小点"（它是模型，不存在）。

有一条经验规律可以加速判断：物体平动（各部分步调一致的整体移动）通常能看成质点，带转动或"动作研究"的场合一般不能。它能解决大半题目，但拿不准时回到三步卡，经验只是快查表，标准才是裁判。

方法的适用条件也要心里有数：这个判断只回答"能不能简化"，不涉及后续怎么算。别把"能看成质点"理解成"这个物体很小"或"这个物体没有形状"。模型的意思是"这些因素对当前问题无影响"，含义到这一层就停，不多不少。

### 完整示范

:::problem
<span class="prob-grade">示范题 1【基础题·易错题·选择题】</span><span class="prob-source">（原题讲解见主讲篇例题一）</span>：四个选项都是 2014 年索契冬奥会赛场上的判断——冰壶的旋转、冰球打门、速滑过弯的倾斜、空中技巧的翻腾。按三步卡走：
:::

- 冰壶的旋转：问题是"怎么旋、走什么弧线"→ 靠壶体各处运动的差异 → 缩成点旋转就没了 → 不能。
- 冰球打门：问题是"整体飞向球门的快慢和路线"→ 冰球的大小形状不碍这件事 → 能。答案 B。
- 速滑过弯的倾斜：问题是"身体姿态"→ 人缩成点，倾斜无从谈起 → 不能。
- 空中技巧的翻腾：问题是"动作"→ 动作跟着点一起消失 → 不能。

四步四个结论，每一步都有依据，这就是"可复现"的意思：换个人按同样的卡走，结论一致。

:::problem
<span class="prob-grade">示范题 2.【提升题·常考题·选择题】</span> <span class="prob-source">（2021 年福建卷）</span>

一游客在武夷山九曲溪乘竹筏漂流，途经双乳峰附近的 M 点和玉女峰附近的 N 点，如图 2 所示。已知该游客从 M 点漂流到 N 点的路程为 5.4 km，用时 1 h，M、N 间的直线距离为 1.8 km，则从 M 点漂流到 N 点的过程中（　）

![2021 年福建卷题图：武夷山九曲溪漂流路线示意图，双乳峰附近的 M 点与玉女峰附近的 N 点](/blog-images/k001-mass-point-reference-frame-methods/orig-shifan2-wuyishan-map.png)

图 2｜示范题 2 题图：九曲溪漂流路线，M 到 N 的路程 5.4 km，直线距离 1.8 km


　　A. 该游客的位移大小为 5.4 km


　　B. 该游客的平均速率为 5.4 m/s


　　C. 该游客的平均速度大小为 0.5 m/s


　　D. 若以所乘竹筏为参考系，玉女峰的平均速度为 0
:::

:::answer
答案：C。

　　A 错。位移是起点指向终点的有向线段，大小就是 M、N 间的直线距离 1.8 km。5.4 km 是漂过的路程，别认错对象。

　　B 错。平均速率走路程：路程 5.4 km = 5400 m，时间 1 h = 3600 s，$\frac{5400}{3600} = 1.5$ m/s，平均速率 1.5 m/s，不是 5.4 m/s。5.4 是"千米每小时"下的数值，直接搬进"米每秒"就错了。

　　C 对。平均速度走位移：位移大小 1.8 km = 1800 m，$\frac{1800}{3600} = 0.5$ m/s，平均速度大小 0.5 m/s。

　　D 错。竹筏一直在向玉女峰靠近，以竹筏为参考系，玉女峰的位置一直在变——它在"迎面漂来"，平均速度大小同样是 0.5 m/s，不是 0。
:::

这道真题的四个选项横跨位移、平均速率、平均速度、参考系。平均速度、平均速率的严格定义要到速度那一讲才给出，这里先按"位移比时间、路程比时间"的直觉用起来。它告诉我们综合概念题的真实形态：一道题串起一串概念，每个都得清晰，所以判断卡必须练到不用想。

### 条件变化后怎么调整：三个变式方向

变式方向 1：同一个物体，问题互换。示范题 1 里的冰壶，研究"旋转"不能简化；同一个冰壶要是只比较它和另一只壶谁先到营垒中心，就能。应对不变：还是三步卡，重走一遍第三步。这类"同物不同问"是这一节最常见的变化，本质是同一道题换一种穿法。

变式方向 2：跟谁比的问题。同一辆大巴（主讲篇例题二），从北京开往上海时车长可以忽略，路过一棵树时车长就是全部。判断不看尺寸的绝对大小，看它跟研究范围比出来的比例。题干里出现"过标、过树、过桥、穿缝"这类词，就是尺寸登场的信号。

变式方向 3：绝对化表述的选项。"必须体积小""只有各部分运动情况都相同""轻小的都可以"（例题三、练习一）这类一刀切的说法，找一个反例就能放倒：地球大，公转照样能简化；乒乓球小，研究旋转照样不能。反过来，判断句子本身的对错，别按语气站队。

### 常见错误与适用边界

- 错因归类（概念）：把"体积小/质量大"当判断依据。三步卡第二步走丢了。
- 错因归类（建模）：以为"看成质点"是真实操作，纠结"地球怎么可能是个点"。模型是简化工具，不是实体变形。
- 边界：质点判断不涉及任何计算；如果一道"质点题"需要算数才能判断，多半是想多了。带转动的物体在"研究转动"时不能简化，但同一个转动物体在"研究整体位移"时可以（如研究地球公转）。转动不是一票否决，还是要看问题。

## 题型二：参考系判断——先问以谁为标准

![参考系选择题型示意](/blog-images/k001-mass-point-reference-frame/K001-质点参考系-07-参考系选择-题目.png)

图 3｜参考系选择题型示意：描述运动前先选标准

### 如何识别

题目信号："以XX为参考系""坐在XX里看""歌词/诗句里描述的运动"，或者给一段对接、编队、加油的场景问动静。还有一种反向考法：给出"甲看乙是静止的"这类描述，反推参考系是谁。

### 先分析什么、建什么模型

先找标准物（拿谁当基准），再比较研究对象相对标准物的位置变没变。位置变=运动，位置不变=静止。整个判断就这一句。

### 为什么用这个方法：两步判断卡

1. 定标准：这段描述拿谁当参考系？没有明说时，默认以地面为参考系（全世界约定俗成）。
2. 比位置：研究对象相对标准物的位置，随时间变不变？

两条底层规则支撑这张卡：选择任意：原则上任何物体都能当参考系，唯独不能选研究对象自己（自己跟自己比永远静止，等于没比）；描述相对：同一个运动换标准结论可以翻，谁都不比谁更"正确"。

适用条件：两步卡处理的是"动没动、朝哪动"的定性判断。涉及"相对速度多大、位移怎么合成"的定量计算要等运动的合成（K001 只到定性层，主讲篇例题六的起重机题和下面的示范题 4 是延伸预告，不是必会要求）。

### 完整示范

:::problem
<span class="prob-grade">示范题 3【基础题·经典题·选择题】</span><span class="prob-source">（原题讲解见主讲篇例题四）</span>：飞行员在高空随手抓住了一颗"身边游动"的子弹，四个选项各给一句解释。先立事实：子弹在飞行员身边"游动"，说明它跟飞机的相对位置几乎不变。按两步卡走：
:::

- A 错。"子弹静止在空中"没说对谁。对地面，子弹正高速飞行，这句不成立。
- B 错。把"相对速度小"错当成了"子弹本身速度小"。对地面它一点不慢。
- C 错。方向反了：飞机若比子弹快很多，两者距离会迅速拉开，根本抓不到。
- D 对。同方向、速度大小接近，相对位置不变，互看都静止——这正是子弹能被随手抓住的条件。

:::problem
<span class="prob-grade">示范题 4.【提升题·经典题·选择题】</span> <span class="prob-source">（学而思高一暑期讲义·第 1 讲《运动的描述》，删去配图）</span>

一艘炮艇由西向东行驶，要击中岸上一个固定目标。若不计重力，射击方向应当（　）


　　A. 直接对准目标


　　B. 偏离目标东边一些


　　C. 偏离目标西边一些


　　D. 不能确定
:::

:::answer
答案：C。

炮弹离开炮口的那一刻，身上还带着炮艇的向东速度，往后飞的路上这份速度一直跟着它。直接瞄准目标，炮弹会在飞行途中继续向东漂，落到目标东侧。

想命中，就得预先把这段"漂移"让出来：瞄准点往西挪一些，让炮弹边飞边向东漂回来，正好落在目标上。

　　A 错。忘了炮弹身上还挂着艇的速度，落点必然偏东。

　　B 错。往东偏，漂移加偏移，错得更多。

　　C 对。先把漂移抵消掉，再谈瞄准。

　　D 错。方向关系是确定的，能定。
:::

这题跟主讲篇例题六是同一思路的两副面孔：例题六把"先随桥架走、再自己走"合成位移，这道题把"炮弹带着艇速"合成速度。"先抵消自己（或自己的载体）"这句话，位移、速度都适用。

反向考法示范（学而思讲义"思考辨析"栏同款）：敦煌曲子词里有一句"满眼风光多闪烁，看山恰似走来迎，仔细看山山不动，是船行"。"看山恰似走来迎"拿什么当参考系？答：船（船上的人）。山对地面纹丝不动，只有在船看来才"迎面走来"；后半句"是船行"又换回了地面参考系。反向题的解法：把描述里的"运动/静止"倒推回"相对位置变没变"，再找位置不变的那个基准。

### 条件变化后怎么调整：三个变式方向

变式方向 1：标准物轮换。同一场景，把参考系从 A 换到 B 换到地面，逐个问动静。主讲篇例题五（人坐火车里）就是这个变式：大地、人、火车挨个当标准，每换一个标准，重新比一次相对位置，不沿用上一个标准的结论。

变式方向 2：相对静止的场景包装。识别标志是"同速""并排""保持相对静止""抓子弹"这类词：飞行员抓子弹（例题四）、并行扶梯上互看静止的人（主讲篇练习六），包装千变万化，内核都是"速度大小方向都相同 → 互看静止"。看到标志词，直接套相对静止。

变式方向 3：方向与大小的相对运动（延伸层）。主讲篇例题六的起重机题是完整示范：小车先随桥架走 8 m，再沿桥架走 6 m，两个位移互相垂直，勾股合成，写成算式是：

:::formula
s = \sqrt{8^2 + 6^2}\ \text{m} = 10\ \text{m}
:::

示范题 4 的炮艇题是它的"只问方向"版：炮弹带着艇速飞行，瞄准点要往西让。这个变式涉及合成，属于延伸层：第一次学看懂"分层再合成"的思路即可，不必强求会算；学完运动的合成回头看，它们都是最简单的相对运动题。

### 常见错误与适用边界

- 错因归类（概念）：认为"静止是绝对的"。地球同步卫星"静止"只是对地面；换月亮看它以约 3.1 km/s 绕圈。动与静永远先问标准。
- 错因归类（读题）：把默认参考系（地面）漏掉。题目没提参考系时，"汽车在飞驰"这句话已经默认了地面。
- 错因归类（建模）：C、D 互为镜像的选项里摇摆。抓手一句：相对位置不变→互看都静止；C 对 D 必错，不存在"都对"。
- 边界：两步卡只管定性判断。题目问"以XX为参考系，速度多大/朝哪个方向"就进入了延伸层（相对运动定量计算），高一第一章只要求看懂思路，正式工具在后续章节。

## 条件与边界整理

![质点与参考系易错对照](/blog-images/k001-mass-point-reference-frame/K001-质点参考系-04-易错对照-大小与运动状态.png)

图 4｜易错对照：大小不是判定依据，影响才是

两张卡收进一张表，考前扫一眼：

| 判断 | 卡 | 标准句 | 高频坑 |
| --- | --- | --- | --- |
| 质点 | 定对象→定问题→判影响 | 大小形状对问题的影响能否忽略 | 盯物体大小不看问题；"过标过桥"漏看尺寸；"一定""只有……才"式绝对化选项 |
| 参考系 | 定标准→比位置 | 相对位置变不变 | 默认地面参考系漏读；镜像选项摇摆；把"相对静止"当"绝对静止" |

这一节依旧没有公式要背。示范题 2 那种一道题串起位移、平均速度、平均速率、参考系的混考，说明考试不满足于单独考概念，而是查"概念网络"：每个概念都要清晰，串起来才不丢分。

练习已经在路上：本单元练习篇《质点 参考系③》安排了 30 道题，从基础判断到综合辨析分层排布，只给题目不给答案：全部答案与解析放在下一个单元（时间 位移）练习篇的文末，做完对那次。为什么把答案放远处？做题时手边没有答案，才不会做一道看一道；订正时的"挣扎"本身就是记忆的一部分。
