# 单元内容与排版规范（2026-10-24 第二章实验试点定稿）

> 本规范从"第二章实验"三篇重构中提炼，供后续单元（K008 起）复用；与《AI_WRITING_GUIDE》冲突时以后者为准，本文件是其单元级细化。

## 总编辑要求（所有文章执行）

全文围绕明确的物理问题展开，按学生理解所需的顺序组织内容。概念先于使用，条件伴随公式，推导解释依据，例题形成递进，练习对应目标。主讲篇、方法篇和练习篇相互承接，必要内容适度重述，详细内容精准链接。保留亲切自然的教师口吻，但定义、规律、实验和解析采用严谨表述。所有题目独立复算，所有重要结论检查适用条件与反例。不得以口诀替代解释，不得以篇幅或题量代替完整性。

## 输出铁律（2026-10-24 增补，违反任何一条即不合格；站点等效实现见括号）

1. **公式**：一律 LaTeX，行内 `$...$`；独立公式在站点用 `:::formula` 容器（等效 `$$...$$`，且能进公众号复制管线）。物理量斜体（$F$、$v$、$m$），单位与算子正体——站点统一把单位写在 `$` 外（如 $v = 0.39$ m/s），或公式块内用 `\text{ s}`，两者等效。$\Delta$、$\sin$ 用 LaTeX 命令天然正体。不省略上下标；矢量写 $\vec{F}$，或在直线运动中先注明"以……为正方向"后代入带正负号的代数量。首次出现的符号在公式后紧跟"其中 $x$ 表示……"，不堆符号墙。
2. **配图**：凡受力分析、运动过程、$v$-$t$ 图、$x$-$t$ 图、电路、光路，先写【配图说明】＝类型 + 关键元素 + 标注要求，作为绘图任务单交 SVG 管线（`workspace/figs-questions.html`）执行成图；站点文章一律用真实成图，不贴绘图代码。
3. **表格**：对比类、分类类、易混概念类内容强制用表格，列数不超过 5 列、每格简短、适配手机端；表题用"表 N｜标题"格式并在正文中引用表号。
4. **文字**：第一人称"我"、对学生称"你"，允许口语化吐槽；禁模糊词（差不多、大概、显然）。每段连续文字不超过 4 行，用短段落、小标题、列表打断；禁"综上所述""由此可见"式套话，用一句具体结论收束。
5. **例题五件套**（适用于主讲篇例题与方法篇示范等讲解型例题；练习篇答案区按"答案—依据—检查"精简版执行）：
   - ① 题型识别标志：看到什么条件，想到什么模型；
   - ② 解题步骤模板：编号列出，可复用；
   - ③ 完整规范解答：含公式、代入、结果、单位；
   - ④ 易错点：具体到"第几步容易错成什么"；
   - ⑤ 变式一句话：改一个条件，考法怎么变。

## 一、物理主线与三篇职责

- **主线先行**：每单元先写下贯穿全篇的物理问题链（运动学实验为：如何记录运动 → 如何从记录中求速度 → 如何判断速度怎样变化 → 如何求加速度 → 如何判断结果是否可靠），在开篇亮出，每节开头交代本节解决链条的哪一环。文章是主线的展开，不是知识卡片合集。
- **主讲篇（建立物理理解）**：讲清原理、推导和适用条件，用少量例题帮助理解；全单元的推导只落在主讲篇；结尾明确"这些原理会形成哪些典型问题"。
- **方法篇（建立分析能力）**：沿实验过程组织正文——装置与操作 → 测量与读数 → 数据处理 → 结果评价；在各阶段标注常见题型（排序、计算、图像、误差分析等）作为检索标记；实验装置（纸带、光电门）作为贯穿情境。每类题回到同一条主线：我们要测什么、实际测到了什么、通过什么关系求出目标量。
- **练习篇（检验与反馈）**：按学习目标分层（概念辨析 / 基础应用 / 条件变化 / 综合评估），题量由覆盖需求决定；每题标注检测目标与对应讲解位置；答案区按题号"答案 — 依据 — 检查"，并指回需要重学的位置。
- **三篇衔接**：每篇开头用一小段承接前文，结尾说明下一篇解决什么问题。方法篇对必要公式和条件做简要重述，再精准链接主讲篇的推导——学生不必来回翻页，也不重复完整推导。同一套示例数据尽量跨篇复用（如"主线纸带"），形成连续讲解。

## 二、概念、公式与推导

- **重要结论五项信息**：研究情境、成立条件、推导、物理意义、使用边界（不机械列标题，但信息齐全）。分层结论不得混用：如 $\frac{d}{\Delta t}$ 的三层（挡光期平均速度 → 匀变速下中间时刻瞬时速度 → 遮光片足够短时对应门位置的近似）在所有文章中保持同一表述。
- **推导**：完整不等于堆代数。思路转折必须展开——为什么选这个研究对象、为什么取相等时间间隔、为什么这样分组、哪一步用了匀变速条件、实际数据不满足关系时怎么处理。

## 三、题卡与配色

- 题卡首行格式：`编号 + 分级 + 来源 + 题干`；分级【难度·功能·形式】（基础题/提升题 · 常考/易错/经典 · 选择/计算/实验/简答）；来源只在核实后标注，查不到的写（经典题）。
- 标签双色：分级用 `<span class="prob-grade">`，来源用 `<span class="prob-source">`；样式由主题变量提供，公众号复制由管线内联计算后的具体色值。
- 题目卡（灰底）与答案卡（绿底）为题、答两色；备注卡琥珀，只在有深度延伸时使用。
- 答案卡首行 `**答案：X。**`；选择题逐选项给错因，错因必须能复现出该选项的数值。

## 四、公式与图

- 公式规范见"输出铁律"第 1 条。
- 图四要素：编号、图注、正文显式引用、与正文符号一致。图要承担推理任务：装置图、过程图、数据图、误差示意图。
- 示意图由数据或函数生成（SVG + playwright 管线，源在 `workspace/figs-questions.html`）；新增图先写【配图说明】再交管线；装饰性插画不得替代物理示意图；同一装置沿用同一张基础图、逐步增加标注；alt 描述内容、不得泄露答案。

## 五、语言

- 禁承诺词与绝对化表达（必拿满分、秒杀、万能、闭眼套用、分数拿满、两板斧、铁律、直接舍弃等）；指令性内容改用"基本处理流程""应注意以下操作要求""先检查……再判断是否有依据剔除"一类表述。
- 口诀只能在原理讲清之后作为记忆辅助；"碎碎念"的个人风格留在引入、提醒和过渡，定义、推导、实验规范与解析使用稳定严谨的表述。
- 段落之间写明逻辑联系；表格用于比较与对应关系，不堆卡片和清单。

## 六、发布前检查清单（三遍审核，逐项执行，未通过不得标完成）

1. **物理审核**：重新推导、重新计算所有题目；检查每个结论的适用条件与反例；选择题逐项解释并验证答案唯一——实验操作存在多种可行顺序时，不得强行规定唯一答案设单选。
2. **教学审核**：前置知识、概念引入顺序、例题递进、三篇衔接、公式重述与链接是否到位；主线是否贯穿。
3. **编辑审核**：标题与正文数量一致；符号、单位、图号、表号、链接、排版统一；段落不超过 4 行；无禁用词；长公式、宽表格在手机端的显示。
4. 真题来源逐条登记 `docs/problem-source-register.md`；核实不到的不标来源。
5. `npm run build`、`npm run verify`、`npm run test:smoke` 全部通过；桌面与移动端实际显示检查；公众号复制预览检查（真实微信编辑器由作者最终确认）。
