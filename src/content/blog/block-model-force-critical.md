## 一、碎碎念开场

搬家时你在纸箱底下垫了块木板，箱子摞在木板上，一拖，箱子稳稳跟着走。可有时候一拉快了，箱子"哧溜"一下溜出去了。板块模型说的就是这件事：上面一块、下面一块，到底一起动，还是各动各的？你是不是也这样——公式都背了，一画受力就乱。今天把它拆成一条流水线。

## 二、知识锚点

先把手里的家伙认全（表 1）。

表 1｜板块模型的四个必备判据

| 判据 | 表达式 | 什么时候用它 |
| --- | --- | --- |
| 滑动摩擦力 | $f = \mu F_N$ | 已经发生相对滑动时，算摩擦大小 |
| 最大静摩擦 | $f_{\max} \approx \mu F_N$ | 判断"刚刚要滑还没滑"的临界 |
| 牛顿第二定律 | $F_{\text{合}} = ma$ | 对每个物体隔离列式，或对整体列 |
| 速度相等 | $v_1 = v_2$ | 找"共速"时刻——大多数临界发生在这里 |

其中 $F_N$ 表示接触面之间的正压力（水平板上等于上层物块的重力 $m_1 g$，$m_1$ 表示上层物块质量），$\mu$ 为动摩擦因数。

## 三、核心方法：五步流水线

1. **设正方向、分别画受力。**判断依据：滑动摩擦力与**相对滑动**方向相反，静摩擦与**相对运动趋势**方向相反——注意是"相对"，不是"运动"。
2. **假设一起动，先用整体法。**把两块当一个整体列 $F = (m_1 + m_2)a$。判断依据：整体法成立的前提是两者加速度相同，即暂无相对滑动。
3. **隔离验证这个假设。**对上层物块算"维持一起动需要多大摩擦"：$f_{\text{需}} = m_1 a$。判断依据：$f_{\text{需}} \le f_{\max}$ 则假设成立；超过，说明已经滑动。
4. **滑动了就分家。**各自用 $f = \mu F_N$ 代入，分别列 $ma$ 求各自的加速度。判断依据：滑动后两加速度不再相等，整体法作废。
5. **追临界：共速时刻。**分别写两物的速度表达式，令 $v_1 = v_2$ 解时刻。判断依据：共速瞬间相对速度为零，摩擦的方向和性质可能突变——共速之后必须**重新判一次**。

## 四、典型例题

### 例题 1（基础规范款）

:::problem
<span class="prob-grade">1.【综合题·经典题·计算题】</span><span class="prob-source">（经典题）</span>长木板 B 质量 $m_B = 2$ kg，静止在光滑水平面上；物块 A 质量 $m_A = 1$ kg，静放在 B 的左端。A、B 间动摩擦因数 $\mu = 0.4$，最大静摩擦按滑动摩擦力计算。现对 B 施加水平向右的恒力 $F = 6$ N（以向右为正方向，$g$ 取 10 m/s²）。求两物的加速度，并判断是否发生相对滑动。
:::

:::answer
**答案：$a_A = a_B = 2$ m/s²，方向向右，无相对滑动。**

**① 题型识别。**上下两物 + 水平拉力 + 问"一起动还是滑动"——板块模型，第一步永远先假设一起动。

**② 步骤模板。**整体求假设加速度 → 隔离算需要的摩擦 → 对照最大静摩擦 → 定案。

**③ 规范解答。**假设一起加速，$a = \frac{F}{m_A + m_B} = \frac{6}{1 + 2}$ m/s² $= 2$ m/s²，方向向右。A 能不能跟上？A 只靠 B 给它的静摩擦加速，需要 $f_{\text{需}} = m_A a = 2$ N；上限 $f_{\max} = \mu m_A g = 4$ N。$f_{\text{需}} < f_{\max}$，假设成立。检验：对 B 单独列式 $\frac{6 - 2}{2} = 2$ m/s²，与整体法一致。

**④ 易错点。**第 ② 步容易拿 $F$ 直接除 $m_A$，得 6 m/s²——拉力作用在 B 上，A 靠摩擦"转交"；第 ③ 步容易把正压力写成 $m_B g$——摩擦发生在 A、B 接触面，正压力取 $m_A g$。

**⑤ 变式。**把 $F$ 加大到 15 N：$f_{\text{需}} = 5$ N $> 4$ N，滑动！此时 $a_A = \mu g = 4$ m/s²，$a_B = \frac{15 - 4}{2} = 5.5$ m/s²，各算各的。
:::

### 例题 2（变式易错款）

:::problem
<span class="prob-grade">2.【综合题·经典题·计算题】</span><span class="prob-source">（经典题）</span>与例题 1 同一套装置（$m_A = 1$ kg、$m_B = 2$ kg、$\mu = 0.4$、光滑地面）。不同之处：不再拉 B，而是让 A 以 $v_0 = 6$ m/s 的初速度滑上静止的 B 的左端。求两物共速所用的时间、各自的位移，以及木板至少多长 A 才不会滑出。
:::

:::answer
**答案：$t = 1$ s 共速（共同速度 2 m/s）；$x_A = 4$ m、$x_B = 1$ m；板长至少 3 m。**

**① 题型识别。**"初速差"替代了"拉力"——比的对象从力变成速度：A 相对 B 向前滑，A 受向后的滑动摩擦，B 受向前的反作用力。

**② 步骤模板。**分别定摩擦方向 → 各列 $ma$ 求加速度 → 令 $v_1 = v_2$ 解共速 → 算位移差 → 共速后再判一次。

**③ 规范解答。**其中 $v_0$ 表示 A 滑上木板时的初速度。$a_A = -\mu g = -4$ m/s²（减速），$a_B = \frac{\mu m_A g}{m_B} = 2$ m/s²（加速）。共速条件 $6 - 4t = 2t$，得 $t = 1$ s，共速 $v = 2$ m/s。位移：$x_A = 6 \times 1 - \frac{1}{2} \times 4 \times 1^2 = 4$ m，$x_B = \frac{1}{2} \times 2 \times 1^2 = 1$ m。相对滑行 $\Delta x = x_A - x_B = 3$ m，A 从左端向右端滑，板长至少 3 m。检验：地面光滑，共速后两物以 2 m/s 一起匀速，摩擦消失——共速后重判，这道题的隐蔽分就在这里。

**④ 易错点。**第 ① 步把 A 的摩擦方向写成"与运动方向相反"（那样摩擦向左）——应该与**相对运动**方向相反：A 比 B 慢，相对 B 向后滑，摩擦向前；第 ② 步共速后忘记重判；板长条件写成 $x_A$ 而不是位移差。

**⑤ 变式。**地面不光滑呢？B 多受一份地面摩擦，共速后两物一起减速，又要重新判一次"还能不能一起减"——高三综合题就从这里长出来。

**方法归纳。**例题 1 比力（$f_{\text{需}}$ 对 $f_{\max}$），本题比速度（$v_1$ 追 $v_2$）：板块题的临界只有这两类入口，先问自己"现在在比哪个"。
:::

## 六、易错清单

1. 把拉力 $F$ 直接当上层物块受的力 → 上层只受摩擦，隔离分析 → 力是靠摩擦"转交"给它的。
2. 最大静摩擦用下层质量算 → 用接触面间的正压力 $\mu m_A g$ → 摩擦发生在哪个面，正压力就取哪个面的。
3. 相对滑动后仍用整体法 → 滑动即分家，各自列 $ma$ → 整体法的前提是加速度相同。
4. 共速后继续按滑动摩擦算 → 共速瞬间重新判一次 → 相对速度归零，摩擦的方向和性质可能突变。
5. 板长条件写成 $x_A$ 或 $x_B$ → 用相对位移 $|x_A - x_B|$ → 会不会滑出，看的是相对滑多远。

## 七、结尾一句

这个专题你如果只记一件事，记：**先假设一起动，再拿"需要的摩擦"对照"摩擦的上限"**——板块题的一切乱象，都是这一步没做。
