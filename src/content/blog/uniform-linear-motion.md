孩子刚上高一，第一次月考物理卷上丢分最狠的，十有八九是同一类题：一辆车先加速后刹车，问几秒后相距多远。公式背得滚瓜烂熟，一动笔就错，错完还不知道错在哪。

匀变速直线运动是整个高中运动学的地基。后面的平抛、带电粒子在电场里的偏转，到头来都是拿这三个公式在算。今天这一篇把它的概念、公式、推论、图像、陷阱和典型题型一次讲全，孩子对着文章能从头捋一遍，家长也能看懂孩子到底卡在哪。

## 先把"匀变速"三个字说清楚

匀速直线运动，速度不变。匀变速直线运动，加速度不变：速度均匀地变，每一秒变化得一样多。

抓两个条件。一是"匀"，加速度 a 恒定，大小方向都不变；二是"直线"，a 和 v 都在同一条直线上。落到公式上，直线运动可以用正负号代替方向，这也是运动学好算的原因。

加速度恒定包含两个特殊情形。a = 0 时是匀速，v 一直不变；v = 0 且 a 恒定时是从静止开始的匀加速。别看到"变速"就以为速度一定变，匀速是匀变速在 a = 0 时的特例，这个包含关系在判断题里考过。

![等时间间隔内速度变化量相同的情境引入图](/blog-images/uniform-acceleration/equal-time-velocity-change.png)

怎么判断一段运动是不是匀变速？看相同时间里速度变化量是否相同，或者看纸带上相邻相等时间间隔的位移差是否恒定（这条的完整推导在纸带那篇）。纸带点距均匀拉开，就是匀加速的铁证。

![小车拖着纸带做加速运动，点间距逐渐增大](/blog-images/uniform-acceleration/cart-tape-acceleration.png)

## 四个公式，各自管一段

设初速度 v₀、末速度 v、加速度 a、时间 t、位移 x。匀变速的全部公式就四个：

第一个，速度公式。加速度是速度的变化率，a 恒定，v 随 t 均匀增长：

:::formula
v = v₀ + at
:::

第二个，位移公式。匀速部分走 v₀t，再叠加"从零加速"补上的那一段，面积就是位移：

:::formula
x = v₀t + {1/2}at²
:::

第三个，速度位移公式。前两个消掉 t 得来：

:::formula
v² − v₀² = 2ax
:::

第四个，平均速度公式。匀变速里速度均匀变化，平均速度就等于初末的算术平均：

:::formula
v̄ = {(v₀ + v) / 2}
:::

四条并列摆出来，但出身不一样：前两条是根，后两条是推出来的枝。用熟之后要练的判断只有一个：题目给了什么、求什么、缺什么。

选公式的口诀是"缺谁用不含谁的"。不知道时间，用第三条；不涉及加速度，用第四条或第三条；求位移时间，前两条连立。五个量各管一摊，任何三个已知就能解出剩下两个，但一道题通常只用一次连立，别把四个公式全写上去碰运气。

再强调一遍符号约定：先规定正方向（通常取 v₀ 方向），同向为正、反向为负。刹车题里 a 取负号，竖直上抛里 a = −g，负号进了公式，答案的方向信息自动就出来了。符号错了，后面的计算再漂亮也是零分。

## 两个重要推论，考试更常用

推论一：中间时刻的瞬时速度，等于这段的平均速度：

:::formula
v(t/2) = v̄ = {(v₀ + v) / 2}
:::

匀变速里速度均匀变化，中间时刻的速度正好是首尾的平均。纸带求速度用的就是它（纸带那篇有完整推导），选择题里也常拿它秒杀：知道 v₀ 和 v，一段位移中间时刻的速度张口就来。

推论二：中间位置的瞬时速度，初末平方平均再开根：

:::formula
v(x/2) = √({v₀² + v² / 2})
:::

中间时刻和中间位置是两个不同的点。加速时先到中间时刻，后到中间位置，所以 v(x/2) > v(t/2)，这个大小关系选择题直接考。两点的速度谁大谁小，想不清就在 v-t 图上瞄一眼，两条水平线一画就明白。

还有一条前面出现过的位移差规律：相邻相等时间间隔内的位移差恒定：

:::formula
Δx = aT²
:::

它把"运动学公式"和"纸带、光电门实验"连在一起，实验题里的逐差法就是它的批量版。

## v-t 图像：一图抵四公式

v-t 图像是匀变速最直观的呈现，四个要点：

| 看图上的什么 | 它是什么 | 怎么用 |
| --- | --- | --- |
| 斜率 | 加速度 a | 直线斜率不变，对应 a 恒定；斜率向上加速，向下减速 |
| 面积 | 位移 x | 图线与时间轴围成的面积就是位移，梯形面积一算正是 x = v₀t + at²/2 |
| 交点 | 速度相等的时刻 | 追及问题里距离最大的临界点藏在这里，别把交点当成相遇 |
| 折点 | 分段交界 | 两段匀变速拼接，交界点的速度是两段的公共量 |

公式和图像是同一件事的两种说法。看图算不出数的题，回到公式；代公式代糊涂的题，回到图像。

![v-t 图像的斜率与交点标注：斜率是加速度，交点是速度相等的时刻](/blog-images/uniform-acceleration/vt-graph-slope-intersection.png)

## 两类特殊运动：自由落体和竖直上抛

自由落体：只受重力、从静止下落。取向下为正，v₀ = 0、a = g，四个公式全部代入特化：

:::formula
v = gt
:::

:::formula
h = {1/2}gt²
:::

:::formula
v² = 2gh
:::

它管两个条件：初速度为零，只受重力。空气阻力不能忽略时就不是自由落体。真空中硬币和羽毛下落一样快，伽利略的推断后来被牛顿管实验证实：抽掉空气，重的轻的同时落地。

![牛顿管演示羽毛与金属片在真空中同时落地](/blog-images/uniform-acceleration/newton-tube-freefall.png)

竖直上抛：取向上为正，a = −g，上升段匀减速。三个高频结论：

上升时间与下落时间相等，都是：

:::formula
t(升) = t(降) = {v₀ / g}
:::

最大上升高度：

:::formula
h(max) = {v₀² / 2g}
:::

对称性：同一点上升速度与下落速度大小相等、方向相反。整个运动对最高点对称，算下落段可以直接当成自由落体。

最高点是个经典考点：v = 0，a 仍然等于 g。速度为零和加速度为零是两回事，这句话在判断题里反复出现。

## 最容易丢分的刹车陷阱

刹车题几乎是必考的坑：给一个刹车加速度，问 5 秒后的位移。直接代公式，算出一个漂亮的大数，全错。

车停下之后就停着，不会倒着开。先算停车时间，问的时间超过它，末速度就按零算：

:::formula
t(停) = {v₀ / a}
:::

t(停) 之内，正常用公式；超过 t(停)，位移就等于停下来那一刻的位移，用 v² = 2ax 反推。判断题里还可以反过来用：某车刹车 5 秒滑行 30 米，若不判断直接代位移公式，可能解出一个倒车解，检验 v 是否已反向就能发现。

![汽车刹车到停止的问题模型示意](/blog-images/uniform-acceleration/braking-stop-model.png)

## 例题一：选公式，比硬算快

**题**：汽车以 10 m/s 行驶，刹车后以 2 m/s² 的加速度匀减速，求刹车后 6 秒内的位移。

**先算停车时间**：

:::formula
t(停) = {v₀ / a} = {10 / 2} s = 5 s
:::

6 秒大于 5 秒，车在 5 秒末就停了，后 1 秒静止。所以 6 秒内的位移等于 5 秒内的位移：

:::formula
x = {v₀² / 2a} = {10² / 2×2} m = 25 m
:::

**错误对照**：直接代 x = v₀t − at²/2，t = 6，算出 x = 60 − 36 = 24 m。数字很接近，过程全错，多算的那 1 秒被当成了倒车。阅卷时这两种解法一分一判，陷阱就在这。凡是减速到零的题，先问自己：它停了没有？

![刹车题分段分析：停车时间之前用公式，之后按静止处理](/blog-images/uniform-acceleration/braking-segment-analysis.png)

## 例题二：平均速度的巧劲

**题**：物体做匀加速直线运动，连续相等的两段时间各 2 秒，位移分别为 8 m 和 16 m，求加速度和初速度。

这种题硬设 v₀ 和 a 联立方程也能解，但用推论更快。第一段的平均速度等于中间时刻 t = 1 s 的瞬时速度：

:::formula
v₁ = v̄₁ = {8 / 2} m/s = 4 m/s
:::

第二段同理，t = 3 s 时刻的速度：

:::formula
v₂ = v̄₂ = {16 / 2} m/s = 8 m/s
:::

两个中间时刻相隔 2 秒，速度从 4 涨到 8：

:::formula
a = {Δv / Δt} = {(8 − 4) / 2} m/s² = 2 m/s²
:::

回推 t = 0 时的初速度，v₁ = v₀ + a×1，得：

:::formula
v₀ = 4 − 2×1 = 2 m/s
:::

三步走完。中间时刻速度法是等时分段题的万能钥匙，看到"连续相等时间"几个字就想起它。

## 例题三：追及相遇，抓速度相等

**题**：甲车以 10 m/s 匀速行驶，经过乙车身边时，乙车立即从静止以 2 m/s² 加速追赶。求乙车追上甲车前两者间的最大距离，以及追上所用的时间。

追及问题的第一反应写下来：**速度相等的时刻，距离最大**。乙比甲慢，距离一直在拉大；乙比甲快，距离开始缩小。转折点就在两者速度相同那一瞬。

设乙加速 t 秒后与甲等速：

:::formula
v(乙) = at = 2t = 10 → t = 5 s
:::

5 秒内甲走了 10×5 = 50 m，乙走了：

:::formula
x(乙) = {1/2}×2×5² m = 25 m
:::

最大距离：

:::formula
d(max) = 50 − 25 = 25 m
:::

追上时两车位移相等：

:::formula
10t = {1/2}×2×t² → t² − 10t = 0 → t = 10 s
:::

乙用 10 秒追上。验算一下：10 秒时乙的速度 20 m/s，前 5 秒平均比甲慢，后 5 秒平均比甲快，对称拉平，10 秒整追上，合理。

这类题的通法就三步：列两者的位移关于时间的表达式，找速度相等的时刻定临界，令位移相等解追上时间。相遇两次的变式（比如后车先减速再加速）也是这三步，注意判断解的个数和取舍。这类题在 v-t 图上一画就更清楚：两条图线围出的面积就是两车的距离差，三角形面积最大的地方，正是两线相交、速度相等的那一刻。

## 收个尾：解题的固定动作

匀变速的题千变万化，动作其实固定：画运动草图，标 v₀、a、t、x；定正方向，把负号提前处理好；按"缺谁用不含谁的"选公式；减速到零的先算停车时间；追及相遇先找速度相等。这套动作练熟，月考的运动学大题就是流程活。
