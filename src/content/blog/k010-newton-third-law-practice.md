定律在①、路径在②，这篇检验三件事：那对力找得准不准，两类力分得清不清，换了情境还会不会用。12 道题按学习目标分三层，做完再翻文末答案区，每题按"答案—依据—检查"给全，答案区在本单元内自闭环。

- 对应教材：人教版必修第一册 第三章 3 节 牛顿第三定律。
- 本篇类型：本单元练习篇。
- 前置知识：主讲篇《牛顿第三定律①》的定律内容与四个特点，方法篇《牛顿第三定律②》的五类题型路径。
- 学习目标：按层检验——概念是否清楚（A）、定律能否落到真实说法与场景（B）、转换研究对象和读实验曲线是否过关（C）。
- 使用规则：先独立完成再对答案；每题给自己标 ✓、△、✗，△ 和 ✗ 回到对应讲解位置重做一遍。

## 用法与分层说明

:::usage

- 第 1–5 题　概念辨析（必做）：识别反作用力、两类力的判据。
- 第 6–9 题　基础应用（必做）：把"等大、反向、异体"落到真实说法和场景里。
- 第 10–12 题　提升与综合（第 10、11 题推荐完成，第 12 题选做）：受力图与转换研究对象、传感器曲线分析。
- 题型分布：单选题 9 道（第 1–7、9、10 题），多选题 1 道（第 8 题），计算与简答 2 道（第 11、12 题）。
- 知识边界：全程不用 $F = ma$ 做计算；第 11 题的摩擦力大小 $f$ 已在题干给出，不需要求出它。

:::

## 本单元答案区（按题号逐题）

1. C。

依据：人走路蹬地时受到三个力——重力（地球施加）、地面的支持力、地面的摩擦力，每个力都有对应的反作用力：人对地球的引力、人对地面的压力、人对地面的摩擦力，共三对。

检查：按"人受到的每一个力，都各自有一个反作用力"逐个点名，就不会多数或漏数。

2. C。

依据：竹蜻蜓对空气的作用力与空气对竹蜻蜓的作用力是一对作用力和反作用力，大小总相等，方向相反。

　　A 错。等大，不会大于。

　　B 错。等大，不会小于。

　　D 错。方向相反，不会相同。

检查：凡是问一对相互作用力"谁大谁小、方向同不同"的选项，答案只会在"等大、反向"里，验证表述没有夹带其他错误即可。

3. D。

依据：拍打球的力与球撞击拍的力施受互换、同为弹力，是一对作用力和反作用力，同时产生、同时消失。

　　A 错。等大。

　　B 错。等大。

　　C 错。同时产生，没有先后。

检查：把"击打"想成"互相挤压"，先后感和大小差就都消失了；相互作用与谁主动、谁被动无关。

4. A。

依据：木箱匀速上升，箱子受重力（地球施加）与支持力（升降机地板施加），两力都作用在箱子上，箱子平衡，是一对平衡力。

　　A 对。同体、等大、反向、共线。

　　B 错。这两个力作用在同一物体上，不满足"异体"。

　　C 错。支持力作用在箱子上、压力作用在升降机上，施受互换，是相互作用力，不是平衡力。

　　D 错。重力是地球对箱子的力，压力是箱子对升降机的力，两者既不同体也不互为施受，什么都不是。

检查：先数受力物体再下判断，A 与 B 之争立刻见分晓。

5. D。

依据：$G_2$ 是重力的分力，仍作用在物体 A 上；A 对斜面的压力作用在斜面上。A 在垂直斜面方向平衡，斜面对 A 的支持力与 $G_2$ 大小相等；再由牛顿第三定律，A 对斜面的压力与该支持力等大，所以 $G_2$ 与压力大小相等。

　　A 错。$G_2$ 作用在 A 上，压力作用在斜面上，分力不是压力。

　　B 错。两个力作用在不同物体上，谈不上平衡。

　　C 错。压力的反作用力是斜面对 A 的支持力，不是重力的分力。

　　D 对。经支持力中转，两条关系都给出大小相等。

检查：带字母 G 的力都由地球（经由重力）施加，分力换不掉受力物体；"效果上压紧斜面"不等于"就是压力"。

6. C。

依据：相互作用力的大小与质量、运动状态都无关。

　　A 错。地对脚的力与脚蹬地的力等大；人前进是地面对人的摩擦力改变运动状态的结果，定量解释在第四章。

　　B 错。压力与支持力是相互作用力，静止、运动都等大反向。

　　C 对。A 压 B 与 B 支 A 等大，100 倍的质量差改变不了。

　　D 错。石头与鸡蛋之间的力等大，蛋破是因为蛋壳能承受的力小。

检查：四个选项都在"谁大"上做文章，答案指向"一样大"；再核对 C 的表述是否干净，没有夹带"只有静止才等大"之类的附加条件。

7. B。

依据：人对沼泽地面的压力与地面对人的支持力是一对作用力和反作用力，下陷时同样等大。

　　A 错、C 错。大小永远相等，不会偏向任何一方。

　　D 错。关系明确，可以确定。

检查：下陷的原因是松软地面能承受的力小、形变明显，与两力是否相等无关；"结果不对称"最容易诱导出"力不对称"的错觉。

8. CD（多选）。

依据：马拉车与车拉马是一对作用力和反作用力，永远等大反向，与车马是加速还是匀速无关。

　　A 错。加速时也等大。

　　B 错。等大与运动状态无关，不是匀速的专利。

　　C 对。如上。

　　D 对。这对力分别作用在车和马上，谁也抵消不了谁；车的运动状态由车受到的合力（拉力、阻力等）决定，马的运动状态同样由马受到的合力决定，定量关系在第四章展开。

检查：先锁定"哪一对力永远等大"（对应 C），再确认"运动状态归各个物体受到的合力管"（对应 D），两句话分工清楚。

9. B。

依据：把 P 受的力按方向分组——竖直方向是重力（地球施加）和支持力（桌面施加）；水平方向是绳的拉力（绳施加）和桌面的滑动摩擦力（桌面施加）。题目只问水平方向。

　　A 错。拉力的施力物体是绳，不是地球。

　　B 对。拉力和摩擦力，施力物体分别是绳和桌面。

　　C 错。重力是竖直方向的力，不在水平方向之列。

　　D 错。重力不在水平方向，且拉力的施力物体是绳。

检查：先按方向分组、再逐力找施力物体，两步做完，选项自动落定。

10. B。

依据：物体静止，竖直方向受重力与墙壁的静摩擦力，二力平衡。

　　A 错。F 作用在物体上，物体对墙壁的压力作用在墙上，不同物体之间谈不上平衡。

　　B 对。重力与静摩擦力同体、等大、反向。

　　C 错。静摩擦力大小始终等于重力，由平衡决定，不随 F 增大（第三章第二节的结论）。

　　D 错。F 与墙对物体的弹力都作用在物体上，水平方向二力平衡，不是相互作用力。

检查：把四个力按水平、竖直分成两组，每组内部配平，谁跟谁是平衡、谁跟谁是相互作用就一目了然。

11. 答案：压力大小为 Mg + f，方向竖直向下。

依据：分三步走。

　　先分析环：环沿杆加速下滑，受重力 mg（竖直向下）与杆给的滑动摩擦力 f（竖直向上），摩擦力大小题目已给出，不需要也不允许再用第四章的方法去求它。

　　再转换：杆对环的摩擦力与环对杆的摩擦力是一对作用力和反作用力，由牛顿第三定律，环对杆（也就是对箱子）的摩擦力大小为 f，方向竖直向下。

　　最后看箱子：箱子静止，受重力 Mg（竖直向下）、地面的支持力 N（竖直向上）、环对它的摩擦力 f（竖直向下），竖直方向二力平衡关系为：

:::formula
N = Mg + f
:::

由牛顿第三定律，箱子对地面的压力与地面对箱子的支持力等大反向，所以压力大小：

:::formula
F_{\text{压}} = N = Mg + f
:::

方向竖直向下。

检查：最容易漏的是"环对箱子的摩擦力"，或者把它的方向写到杆的受力图外面去；另外 f 是已知量，全程没有用 $F = ma$，符合本单元边界。

12. 答案：

　　(1) 任意时刻两只传感器之间的力大小相等、方向相反，是一对作用力和反作用力。

　　(2) 一样大。

　　(3) 错在把"力随时间变化"偷换成了"两个力不相等"，见下方解析。

依据：

　　(1) 两条曲线到时间轴的距离相等，说明大小相等；一正一负，正负表示各自的正方向，说明方向相反。这正是牛顿第三定律的实验图景。

　　(2) 拉动过程中两条曲线始终对称，增大的过程也不例外，任何时刻 $F_1$ 与 $F_2$ 大小都相等：

:::formula
\left|F_1\right| = \left|F_2\right|
:::

　　(3) "手拉得越快读数越大"这半句说的是力的大小随时间变化，本身没错；但从"两个读数都变大"推出"作用力大于反作用力"就错了——变大是两条曲线一起变大，任何时刻两者仍然等大。作用力和反作用力的等大关系与拉动快慢无关，不同时刻的读数也不能拿来互相比较。

检查：读实验图的顺序是先看"同一时刻"两条曲线的对称关系，再看"不同时刻"曲线怎么变；把这两个维度混在一起，就会得出 (3) 那样的错误结论。
