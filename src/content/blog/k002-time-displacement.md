## 知识点一：时刻 vs 时间间隔

时间轴是一条带箭头的直线。轴上每一个点，是一个"时刻"——某一瞬间，没有长度。比如 8:00 上课铃响，那是时刻 t₁；8:45 下课铃，是时刻 t₂。两点之间那段，才是"时间间隔"——一段过程，有长短，单位是秒、分、时。

![时间轴上的时刻（点）与时间间隔（线段）](/blog-images/k002-time-displacement/time-interval-intro.png)

最容易翻车的地方，就藏在这几个词的字眼里：

- "第 3 秒"：指的是第 3 个 1 秒，从 t = 2s 到 t = 3s，长度是 1 秒。它是**时间间隔**。
- "前 3 秒"：从 t = 0 到 t = 3s，长度 3 秒。**时间间隔**。
- "第 3 秒末" / "第 3 秒初"：一个瞬间，没有长度。是**时刻**。

一句话记：带"内""前""间隔"的是线段（过程）；带"初""末""时"的是点（瞬间）。高考年年考这个辨析，白送的分。

### 例题一

:::problem
下列关于时刻和时间间隔的说法，正确的是：
A. "第 3 秒内"表示时刻
B. "前 3 秒"表示时刻
C. "第 3 秒末"表示时间间隔
D. "第 3 秒内"表示时间间隔，长度为 1 秒
:::
:::answer
**答案：D。**

- **A 错。** "第 3 秒内"是 t = 2s 到 t = 3s 这段过程，是时间间隔，不是时刻。
- **B 错。** "前 3 秒"是 0 到 3s 的过程，时间间隔。
- **C 错。** "第 3 秒末"是一个瞬间，时刻。
- **D 对。** 第 3 秒内是长度为 1 秒的时间间隔。
:::

### 例题二

:::problem
一条纸带每隔 0.02 秒打一个点。某段纸带上有 5 个连续点 A、B、C、D、E。从 A 到 E 经历的时间间隔是多少？"第 3 个点 C"对应的是时刻还是间隔？
:::
:::answer
**答案：从 A 到 E 经历 4 个间隔，共 0.08 秒；"第 3 个点 C"是一个时刻。**

讲解：A 到 E 中间有 AB、BC、CD、DE 共 4 段，每段 0.02s，合计 0.08s，这是时间间隔。C 这个点是纸带上的某一个位置对应的瞬间，是时刻。
:::

### 例题三

:::problem
百米赛跑中，运动员听到枪声起跑。若发令枪响为 t = 0 时刻，运动员冲过终点为 t = 12.5s 时刻，则他跑完全程对应的物理量是时刻还是时间间隔？数值是多少？
:::
:::answer
**答案：时间间隔，12.5 秒。**

讲解：从起跑（t = 0）到冲线（t = 12.5s）是一段过程，是时间间隔，数值 12.5s。两个端点 t = 0、t = 12.5s 各自是时刻。
:::

### 练习一

:::problem
判断："第 2 秒初"与"第 1 秒末"是不是同一时刻？
:::
:::answer
**答案：是同一时刻。** 第 2 秒初就是 t = 1s 那个瞬间；第 1 秒末也是 t = 1s。两个说法指同一个点。
:::

### 练习二

:::problem
"前 2 秒内"与"第 2 秒内"的时间长度之比是多少？
:::
:::answer
**答案：2 : 1。** 前 2 秒内 = 0 到 2s，长 2s；第 2 秒内 = 1 到 2s，长 1s。
:::

### 练习三

:::problem
一节课 45 分钟，对应的是时刻还是时间间隔？
:::
:::answer
**答案：时间间隔，45 分钟。** 一节课是一段过程。
:::

## 知识点二：位移 vs 路程

这两个词孩子最容易混，但区别一句话就能说清：

- **路程**：你实际走了多长，是路径的总长度。标量，只讲大小，永远非负。
- **位移**：从"起点"到"终点"的一根有向线段。矢量，大小是首尾直线距离，方向从初位置指向末位置。

![位置与位移：用坐标确定位置，用有向线段表示位移](/blog-images/k002-time-displacement/position-displacement.png)

关键结论：只有物体做**单向直线**运动时，位移大小才等于路程。一旦拐弯、掉头、走曲线，位移大小就小于路程。位移只管首尾，不管中间怎么折腾。

![路程（虚线折线）与位移（红色箭头）对比](/blog-images/k002-time-displacement/path-vs-displacement.png)

高考常设的坑：让你算"位移"，你却把路程填上去；或者反过来。

### 例题一

:::problem
小明从家出发向东走了 300 m 到书店，又向西走了 100 m 到奶茶店。求小明全程的路程和位移（大小、方向）。
:::
:::answer
**答案：路程 400 m；位移大小 200 m，方向向东。**

讲解：路程 = 300 + 100 = 400 m（实际走的总长）。位移看首尾：家为原点，向东 300 再到西 100，末位置在家东边 200 m 处，所以位移大小 200 m，方向向东。
:::

### 例题二

:::problem
一个物体沿半径为 R 的圆周运动一周回到出发点。它的位移和路程各是多少？
:::
:::answer
**答案：位移为 0；路程为 2πR。**

讲解：回到出发点，初末位置重合，位移大小 0（方向无意义）。路程是一圈周长 2πR。这是"位移可以为 0 但路程不为 0"的经典反例。
:::

### 例题三

:::problem
下列关于位移和路程的说法，正确的是：
A. 位移大小一定小于路程
B. 位移为 0 时，路程一定为 0
C. 单向直线运动中，位移大小等于路程
D. 路程是矢量，位移是标量
:::
:::answer
**答案：C。**

- **A 错。** 单向直线时二者相等，不是"一定小于"。
- **B 错。** 圆周一周位移为 0，路程 2πR ≠ 0。
- **C 对。** 单向直线，路径即直线，首尾距离 = 路径长。
- **D 错。** 反了：位移是矢量，路程是标量。
:::

### 练习一

:::problem
某人向东走 4 m，再向北走 3 m。求位移大小和路程。
:::
:::answer
**答案：位移大小 5 m，方向东偏北；路程 7 m。**
:::

:::formula
位移大小 = √(4² + 3²) = 5 m
:::

讲解：位移是直角斜边 5 m；路程 4 + 3 = 7 m。

### 练习二

:::problem
物体从 A 出发沿直线到 B 再返回 A，总路程 20 m。求位移。
:::
:::answer
**答案：位移 0。** 回到起点，初末重合。
:::

### 练习三

:::problem
什么情况下位移大小等于路程？
:::
:::answer
**答案：物体做单向直线运动（不回头、不拐弯）时。**
:::

## 知识点三：坐标系与位移（矢量初步）

要算出位移，得先有坐标系。一维就够用：在直线上规定原点 O 和正方向，每个位置对应一个数 x（坐标）。

位移就用末坐标减初坐标：

:::formula
Δx = x(末) − x(初)
:::

Δx 的正负表示方向：为正，位移沿正方向；为负，沿负方向；为 0，回到原点。这一步是矢量思维的起点——物理量开始带"方向"了。后面所有运动学公式里的 v、a 都是带正负的，根子就在这。注意：位移大小是 |Δx|，别把负号当大小。

![一维坐标系中从 A 到 B 的位移 Δx](/blog-images/k002-time-displacement/coord-displacement.png)

### 例题一

:::problem
一维数轴上，质点从 x = 2 m 运动到 x = −3 m。求位移 Δx 和位移大小。
:::
:::answer
**答案：Δx = −5 m；位移大小 5 m。**

讲解：Δx = (−3) − 2 = −5 m，负号表示沿负方向；大小取绝对值 |−5| = 5 m。
:::

### 例题二

:::problem
质点先向右移动 6 m，再向左移动 10 m，以向右为正、起点为原点。求末位置坐标和总位移。
:::
:::answer
**答案：末位置 x = −4 m；总位移 Δx = −4 m。**

讲解：先 +6 到 x = 6，再 −10 到 x = −4。总位移从原点算 Δx = −4 − 0 = −4 m，方向向左。路程 = 6 + 10 = 16 m（这里考你别把位移和路程混）。
:::

### 例题三

:::problem
关于 Δx = x₂ − x₁，下列说法正确的是：
A. Δx 一定为正
B. Δx 为负表示位移方向为负方向
C. 位移大小等于 x₂ − x₁
D. 正方向向右时，x 大的位置一定在 x 小的位置的右边
:::
:::answer
**答案：B、D。**

- **A 错。** Δx 可正可负可为 0。
- **B 对。** 负号即沿负方向。
- **C 错。** 位移大小是 |x₂ − x₁|。
- **D 对。** 正方向向右时，数值大者在右。
:::

### 练习一

:::problem
质点从 x = −5 m 到 x = −1 m，Δx 是几？方向？
:::
:::answer
**答案：Δx = 4 m，沿正方向。** 讲解：(−1) − (−5) = 4。
:::

### 练习二

:::problem
位移大小为 8 m，初位置 x₁ = 3 m，末位置可能是多少？
:::
:::answer
**答案：x₂ = 11 m 或 x₂ = −5 m。** 讲解：|x₂ − 3| = 8 → x₂ − 3 = ±8。
:::

### 练习三

:::problem
"位移是矢量"这句话在坐标系里怎么体现？
:::
:::answer
**答案：体现在 Δx 有正负，正负代表方向。** 这是标量（如路程）没有的。
:::

## 经典题型：位移大小 vs 路程的陷阱

多段运动题，孩子一上手就容易把两段路程加起来当位移。固定破题动作就两句：

1. 先看清它问的是"走了多远"（路程）还是"从哪到哪"（位移）。
2. 运动是不是单向直线？不是的话，位移只算首尾直线距离，路程把每一段加起来。

![回到出发点：位移为 0，但路程不为 0](/blog-images/k002-time-displacement/return-origin-misconception.png)

### 示范题

:::problem
一质点沿直线运动，先以 2 m/s 匀速走 4 s，接着掉头以同样速率走 3 s。求全程路程与位移大小。
:::
:::answer
**答案：路程 14 m；位移大小 2 m。**

方法演示：第一段 2 × 4 = 8 m 向东，第二段 2 × 3 = 6 m 向西。路程 = 8 + 6 = 14 m。位移看首尾：净向东 8 − 6 = 2 m，大小 2 m。若问"位移"填 2 m 向东，问"路程"填 14 m——看清问的是哪个，这是这类题唯一的丢分点。
:::
