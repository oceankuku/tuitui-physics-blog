## 一、碎碎念开场

搬家时你在纸箱底下垫了块木板，箱子摞在木板上，一拖，箱子稳稳跟着走。可有时候一拉快了，箱子"哧溜"一下溜出去了。板块模型说的就是这件事：上面一块、下面一块，到底一起动，还是各动各的？你是不是也这样——公式都背了，一画受力就乱。今天把它拆成一条流水线。

## 二、知识锚点

先把手里的家伙认全（表 1）。

表 1｜板块模型的四个必备判据

| 判据 | 表达式 | 什么时候用它 |
| --- | --- | --- |
| 滑动摩擦力 | $f = \mu F_N$ | 已经发生相对滑动时，算摩擦大小 |
| 最大静摩擦 | $f_{\max} \approx \mu F_N$ | 判断"刚刚要滑还没滑"的临界 |
| 牛顿第二定律 | $F_{\text{合}} = ma$ | 对每个物体隔离列式，或对整体列 |
| 速度相等 | $v_1 = v_2$ | 找"共速"时刻——大多数临界发生在这里 |

其中 $F_N$ 表示接触面之间的正压力（水平板上等于上层物块的重力 $m_1 g$，$m_1$ 表示上层物块质量），$\mu$ 为动摩擦因数。

## 三、核心方法：五步流水线

1. **设正方向、分别画受力。**判断依据：滑动摩擦力与**相对滑动**方向相反，静摩擦与**相对运动趋势**方向相反——注意是"相对"，不是"运动"。
2. **假设一起动，先用整体法。**把两块当一个整体列 $F = (m_1 + m_2)a$。判断依据：整体法成立的前提是两者加速度相同，即暂无相对滑动。
3. **隔离验证这个假设。**对上层物块算"维持一起动需要多大摩擦"：$f_{\text{需}} = m_1 a$。判断依据：$f_{\text{需}} \le f_{\max}$ 则假设成立；超过，说明已经滑动。
4. **滑动了就分家。**各自用 $f = \mu F_N$ 代入，分别列 $ma$ 求各自的加速度。判断依据：滑动后两加速度不再相等，整体法作废。
5. **追临界：共速时刻。**分别写两物的速度表达式，令 $v_1 = v_2$ 解时刻。判断依据：共速瞬间相对速度为零，摩擦的方向和性质可能突变——共速之后必须**重新判一次**。

## 四、典型例题

### 例题 1（基础规范款）

:::problem
<span class="prob-grade">例题 1【基础题·常考题·计算题】</span><span class="prob-source">（2013 年高考江苏卷 第 14 题）</span>将小砝码置于桌面上的薄纸板上，用水平向右的拉力将纸板迅速抽出，砝码的移动很小，几乎观察不到，这就是大家熟悉的惯性演示实验。砝码和纸板的质量分别为 $m_1$ 和 $m_2$，各接触面间的动摩擦因数均为 $\mu$，重力加速度为 $g$。求：（1）纸板相对砝码运动时，纸板所受摩擦力的大小；（2）要使纸板相对砝码运动，所需拉力的大小；（3）本实验中，$m_1 = 0.5$ kg，$m_2 = 0.1$ kg，$\mu = 0.2$，砝码与纸板左端的距离 $d = 0.1$ m，$g$ 取 10 m/s²；砝码移动的距离超过 $l = 0.002$ m 时人眼就能感知。为确保实验成功，纸板所需的拉力至少多大？
:::

:::answer
**答案：（1）$f = \mu(2m_1 + m_2)g$；（2）$F > 2\mu(m_1 + m_2)g$；（3）至少 22.4 N。**

**① 题型识别。**上下两物 + 拉下面那块 + 问"恰好发生相对滑动"——板块模型的"滑动判据"入口。拉力作用在纸板上，砝码只能靠摩擦被带着走；纸板想独自加速，就得比砝码能跟上的极限更快。

**② 步骤模板。**数清两物各自受的摩擦 → 假设一起动，整体法求 $a$ → 隔离算需要的摩擦，对照上限 → 解出临界拉力 → 需要定量时，用运动学算相对位移。

**③ 规范解答。**（1）纸板上下各受一个滑动摩擦力：砝码给它的 $f_1 = \mu m_1 g$；桌面给它的正压力是两物总重，$f_2 = \mu(m_1 + m_2)g$。两个都阻碍纸板向右滑，纸板受到的摩擦力是两者之和：$f = \mu(2m_1 + m_2)g$。

（2）假设两者一起加速，对整体列 $F - f_2 = (m_1 + m_2)a$；砝码跟上这个加速度需要的摩擦 $f_{\text{需}} = m_1 a$，上限 $f_{\max} = \mu m_1 g$。令 $f_{\text{需}} = f_{\max}$，解得临界拉力 $F_0 = 2\mu(m_1 + m_2)g$（代入第（3）问数据是 2.4 N）。$F$ 一旦超过 $F_0$，需要的摩擦就超出上限，相对滑动发生。

（3）砝码离纸板左端 $d$：纸板比砝码多向右滑过 $d$，才算从砝码底下抽出。砝码分两段走：在纸板上以 $a_1 = \mu g = 2$ m/s² 匀加速 $t_1$，位移 $x_1 = \frac{1}{2}a_1 t_1^2$，离开时速度 $v_1 = a_1 t_1$；落到桌面后减速的加速度仍是 $\mu g$，又滑行 $x_2 = \frac{v_1^2}{2\mu g} = \frac{1}{2}a_1 t_1^2 = x_1$。总位移 $2x_1$ 不能超过 $l$，临界取 $x_1 = \frac{l}{2} = 0.001$ m。纸板在同一个 $t_1$ 内从静止匀加速，位移 $d + x_1 = \frac{1}{2}a_2 t_1^2$；两式都含 $\frac{1}{2}t_1^2$，相除消去时间，得 $a_2 = a_1\frac{d + x_1}{x_1} = 2 \times \frac{0.101}{0.001} = 202$ m/s²。对纸板再列一次牛顿第二定律，$F = m_2 a_2 + f_1 + f_2 = 20.2 + 1 + 1.2 = 22.4$ N，拉力至少 22.4 N。

**④ 易错点。**第 1 步容易漏掉桌面给纸板的摩擦，纸板上下各受一个；第 3 步容易把滑动条件写成"拉力大于总摩擦力"，拉力赢过摩擦不等于纸板加速得比砝码快；第 5 步容易只算砝码在纸板上那段位移，落到桌面后它还会滑出等长的一段。

**⑤ 变式。**把桌面换成光滑的：$f_2$ 消失，临界拉力降为 $\mu(m_1 + m_2)g$；桌面摩擦只记在纸板自己的账上，砝码能跟上的极限 $\mu g$ 不变。
:::

### 例题 2（变式易错款）

:::problem
<span class="prob-grade">例题 2【提升题·经典题·计算题】</span><span class="prob-source">（2009 年高考天津卷 第 10 题）</span>质量 $m_1 = 0.3$ kg 的小车静止在光滑水平面上，车长 $L = 1.5$ m。质量 $m_2 = 0.2$ kg 的物块（可视为质点）以水平向右的速度 $v_0 = 2$ m/s 从左端滑上小车，最后在车面上某处与小车保持相对静止。物块与车面间的动摩擦因数 $\mu = 0.5$，最大静摩擦按滑动摩擦力计算，$g$ 取 10 m/s²。求：（1）物块在车面上滑行的时间 $t$；（2）要使物块不从小车右端滑出，物块滑上小车左端的速度 $v_0'$ 不超过多少？
:::

:::answer
**答案：（1）$t = 0.24$ s，共同速度 0.8 m/s；（2）$v_0'$ 不超过 5 m/s。**

**① 题型识别。**"初速差"替代了"拉力"：物块相对小车向前滑，物块受向后的滑动摩擦，小车受向前的反作用力。问"初速不超过多少才不滑出"，临界画面是：物块恰好滑到右端时，两物刚好共速。

**② 步骤模板。**分别定摩擦方向 → 各列 $ma$ 求加速度 → 令 $v_1 = v_2$ 解共速 → 用位移差对板长 → 共速后再判一次。

**③ 规范解答。**其中 $a_{\text{块}}$、$a_{\text{车}}$ 表示物块、小车的加速度。滑动摩擦力 $f = \mu m_2 g = 1$ N，物块减速、小车加速：$a_{\text{块}} = \frac{f}{m_2} = \mu g = 5$ m/s²，$a_{\text{车}} = \frac{f}{m_1} = \frac{10}{3}$ m/s²。

（1）以向右为正方向，共速时 $v_0 - a_{\text{块}}t = a_{\text{车}}t$，得 $t = \frac{v_0}{a_{\text{块}} + a_{\text{车}}} = \frac{2}{5 + \frac{10}{3}} = 0.24$ s，共同速度 $v = a_{\text{车}}t = 0.8$ m/s。顺带检验：这段时间里物块滑行 $\frac{v_0^2 - v^2}{2a_{\text{块}}} = 0.336$ m，小车前进 $\frac{v^2}{2a_{\text{车}}} = 0.096$ m，相对滑过 0.24 m，物块停在离小车左端 0.24 m 处，确实没滑出。

（2）临界情况：物块到达右端时恰好共速，相对滑过的距离正好等于车长。共速时间 $t' = \frac{v_0'}{a_{\text{块}} + a_{\text{车}}} = \frac{3v_0'}{25}$，相对位移 $\Delta x = v_0't' - \frac{1}{2}(a_{\text{块}} + a_{\text{车}})t'^2 = \frac{v_0'^2}{2(a_{\text{块}} + a_{\text{车}})} = \frac{3v_0'^2}{50}$。令 $\Delta x = L = 1.5$ m，得 $v_0' = 5$ m/s（负根不符合初速向右的设定，舍去）。共速之后重判一次：地面光滑、水平方向没有外力，两物没有相对滑动趋势，摩擦消失，以共同速度一起匀速，题设的"保持相对静止"就停在这一步。

**④ 易错点。**第 1 步容易把小车受的摩擦画成向后——摩擦与**相对运动**方向相反：物块相对小车向前滑，反过来给小车的摩擦向前，小车是被"带着走"的；也容易把小车加速度写成 $\mu g$——车受到的摩擦是 $\mu m_2 g$，要除以的是 $m_1$；第 4 步容易把板长条件写成物块自己的位移——会不会滑出看的是位移差；第 5 步忘记重判，把"摩擦消失"写成"摩擦继续"。

**⑤ 变式。**地面不光滑呢？小车多受一份地面摩擦，共速后两物要靠一股静摩擦一起减速，还得重新判一次"这个静摩擦够不够"，高三综合题就从这里长出来。

**方法归纳。**例题 1 比加速度：下面的板要甩开上面的砝码，条件是板的加速度超过砝码能跟上的极限；本题比速度：物块的速度追上小车，滑动就结束。板块题的临界只有这两类入口，先问自己"现在在比哪个"。
:::

## 五、图像/表格总结

板块题最适合配 v–t 过程图，这张图值得自己动手画一次：以向右为正方向，物块从 2 m/s 出发往右下画直线（斜率大小 $a_{\text{块}} = 5$ m/s²），小车从 0 出发往右上画直线（斜率大小 $a_{\text{车}} = \frac{10}{3}$ m/s²）。两条线在 $t = 0.24$ s 处相交，交点纵坐标 0.8 m/s 就是共同速度；交点之后两线并成一条水平线，因为共速后重判的结果是摩擦消失、一起匀速。

表 2｜例题 2 的两段过程

| 阶段 | 摩擦力 | 加速度 | 运动 |
| --- | --- | --- | --- |
| 滑行（0 ~ 0.24 s） | 滑动摩擦 1 N，物块受向后、小车受向前 | 物块 5 m/s²，小车 $\frac{10}{3}$ m/s² | 匀减速对匀加速，相对滑过 0.24 m |
| 共速后 | 0 | 0 | 以 0.8 m/s 一起匀速 |

读图三步：交点的横坐标是共速时刻；交点之后图线怎么转折，由共速后重新判断的结果决定；两条线与时间轴之间的面积差就是相对位移，例题 2 第（2）问的临界，在图上就是交点左侧那块三角形，面积 $\frac{1}{2} v_0' t'$ 恰好等于车长 1.5 m。

## 六、易错清单

1. 把拉力 $F$ 直接当上层物块受的力 → 上层只受摩擦，隔离分析 → 力是靠摩擦"转交"给它的。
2. 摩擦的正压力随手拿下层重力充数 → 用该接触面实际受到的压力算 → 例题 1 里桌面给纸板的是 $(m_1 + m_2)g$，纸板给砝码的才是 $m_1 g$。
3. 相对滑动后仍用整体法 → 滑动即分家，各自列 $ma$ → 整体法的前提是加速度相同。
4. 共速后继续按滑动摩擦算 → 共速瞬间重新判一次 → 相对速度归零，摩擦的方向和性质可能突变。
5. 板长条件写成单个物体的位移 → 用位移差 $|x_{\text{块}} - x_{\text{车}}|$ → 会不会滑出，看的是相对滑多远。

## 七、结尾一句

这个专题你如果只记一件事，记：**先假设一起动，再拿"需要的摩擦"对照"摩擦的上限"**——板块题的一切乱象，都是这一步没做。
