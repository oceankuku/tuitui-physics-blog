# 图片与品牌素材

## 现有素材

`public/site-assets/` 保存12 套老师动作，包括桌前、思考、课本讲解、板书、实验、鼓励和纠错等。角色特征为长乱黑发、环形呆毛、半睁灰眼、轻微黑眼圈、灰度手绘风格；配色使用灰绿、纸面色与黑板色。

`public/brand/logo-source.png` 是头像原件。执行 `npm run brand:build` 自动派生：

- 导航与分享卡片使用的 `logo.png`。
- `favicon-16.png`、`favicon-32.png`。
- 根目录 `favicon.ico`，包含 16/32/48/64/128/256 六个尺寸。
- `apple-touch-icon.png`，180×180。
- `og-default.png`，1200×630，使用站点名称、身份和域名。

站名特别长时，需要打开生成的封面检查文字是否超出。不要手工编辑图标缓存。

## 正文图

原图放到 `public/blog-images/<文章名>/`，Markdown 用标准图片语法与真实路径：

```markdown
![准确描述图里发生了什么](/blog-images/my-note/illustration.png)
```

构建自动派生 640、960、1600 宽度以内的 WebP，根据原图大小去重并避免放大；添加 srcset、sizes 和真实尺寸。原图和 Markdown 不会被覆盖。SVG、动画及远程图片保留原形式；远程图片由作者确认可访问和可使用。

## 文章插图

需要生成插图时，使用当前可用的图像工具，并保留原图与来源记录。

1. 先写出插图用途、内容、比例和位置，确认确实帮助理解。
2. 优先复用已有老师动作；确需新图时，将现有角色作为参考，保留外观，只改变动作或教具。
3. 将输出原件保存到文章图片目录。提示词、来源、工具与实际生成日期写入 `workspace/image-notes/<文章名>.md`。
4. 文件存在后再加入 Markdown，不使用占位 URL 或推测路径。
5. `image` frontmatter 用于分享封面。若要正文展示，还需额外插入 Markdown 图片。
6. 检查桌面、手机和公众号复制结果。生成图不能作为公式、实验结果或教学事实的证据。

## 阅读分享卡片

选段卡片在浏览器 Canvas 中生成，不需要 AI 图像服务。它会携带当前站点 Logo、文章标题、作者与原文二维码，支持 PNG 下载、图片剪贴板及系统分享。二维码地址来自正式域名配置，因此发布前必须更改示例域名。
