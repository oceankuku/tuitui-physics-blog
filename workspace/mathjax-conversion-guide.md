# MathJax 公式改造规范（子代理执行手册）

目标：把旧公式语法改为 MathJax/LaTeX，分数一律竖式。**物理含义与数值绝对不许变。**

## 改造对象

每个 `.md` 文章文件，做三类修改：

### 0. frontmatter 加开关

在 `tags:` 行后加一行：

```yaml
mathjax: true
```

（若已有则跳过。注意 yaml 缩进对齐，tags 行是顶格的。）

### 1. `:::formula` 块内转 LaTeX

块内内容直接写 LaTeX（不需要 `$` 包裹，管线自动加 `$$`）。对照表：

| 旧语法 | LaTeX |
|---|---|
| `v̄ = {Δx/Δt}` | `\bar{v} = \frac{\Delta x}{\Delta t}` |
| `{a/b}` 分数 | `\frac{a}{b}` |
| `√(x)` | `\sqrt{x}` |
| `√({v₀² + v²/2})` | `\sqrt{v_0^2 + \frac{v^2}{2}}` |
| `lim{Δt→0}` | `\lim_{\Delta t \to 0}` |
| `×` | `\times` |
| `·` | `\cdot` |
| `≈` | `\approx` |
| `−`（数学减号） | `-` |
| `x₁`、`v₀`、`t₁` 下标 | `x_1`、`v_0`、`t_1` |
| `v²`、`m/s²` 上标 | `v^2`（单位上标见下） |
| 中文进公式 | `\text{中文}` |
| θ、α、ω 等希腊字母 | `\theta`、`\alpha`、`\omega` |
| `(g·sin²θ)` | `(g \sin^2\theta)` |
| `sin`/`cos`/`tan` | `\sin`/`\cos`/`\tan` |
| 三角函数上标 `(sin²θ)` | `\sin^2\theta` |
| v̄（组合变音符号） | `\bar{v}` |
| v⃗（矢量箭头） | `\vec{v}` |
| Δx 位移 | `\Delta x` |
| T′（撇号） | `T'` |

**注意**：
- 块内独立成行的公式直接写，一行一个公式
- 块内如有多行说明文字（非公式），把公式行转 LaTeX，说明文字用 `\text{...}` 或移出块外放正文
- `:::formula` 围栏本身保留不动

### 2. 行内符号转 `$...$` 行内公式

正文中出现的数学符号、算式：

- **所有分数一律竖式**：正文写 `1200 / 5400`、`路程/时间`、`x/10` 等算式分数 → `$\frac{1200}{5400}$`、`$\frac{\text{路程}}{\text{时间}}$`、`$\frac{x}{10}$`。嵌套分数分子分母也竖式：`9 / (1/12)` → `$\frac{9}{\frac{1}{12}}$`
- **带下标物理量**：`v₀` → `$v_0$`、`t₁` → `$t_1$`、`v(R)` → `$v_R$`、`x₂` → `$x_2$`
- **含分数的算式**：`a = (10 − 30) / 2 = −10` → `$a = \frac{10 - 30}{2} = -10$`
- **极限/趋近**：`Δt→0` → `$\Delta t \to 0$`
- **希腊字母参与运算**：`θ = 30°` 这类独立角度值**不转**，保持文本；但 `sinθ` 参与计算时转 `$\sin\theta$`
- **上下标组合**：`v₀²` → `$v_0^2$`

**保持不动的**：
- 单位：m/s、km/h、m/s²、cm/s、g/cm³ 等一律保持原文本（它们不是分数）
- 日期、题号、比例 `1:3:5`
- 已在 `$...$` 内的内容
- 纯文字叙述中不含分数的简单算式如 `30 km`、`0.5 h`
- 表格里的数字
- 20 m/s 这种「数值+单位」整体
- 不含分数的简单等式如 `x = 4 m`、`斜率为 0`（若该句已有其他公式改造则顺带转，否则保持）
- Unicode 上标²、下标₀在**非分数场景**（如 m/s²）保持原样

### 3. 特殊卡片区（:::problem / :::answer / :::note 内）

规则与正文相同：含 `$` 的文本会原样交给 MathJax。答案卡里 `**答案：X。**` 格式不许动。

## 校验清单（改完每篇自查）

1. `grep -n '{[a-zA-Z0-9]' 文件` —— 公式块外不应再有 `{a/b}` 旧分数（yaml 除外）
2. `grep -n '√(' 文件` —— 不应再有旧根号语法（除非在代码块）
3. `grep -n 'Δ\|≈\|v̄\|×' 文件` —— 数学符号若在算式中应已转 LaTeX；单位/纯文字中的可保留
4. 每个公式块的 `\frac{`、`}` 数量配平（大括号成对）
5. `$` 符号成对出现
6. frontmatter 有 `mathjax: true`
7. **逐处核对物理数值与含义不变**

## 最终检查命令

改完所有篇目后运行：

```bash
node scripts/lint-content.mjs   # 必须通过
```
