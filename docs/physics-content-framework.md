# 高中物理内容体系与建设路线（2026-10-21 建立）

> 本文件回答三个问题：整个系列覆盖什么、按什么顺序建、完成度怎么衡量。执行规则见 `AI_WRITING_GUIDE.md`，逐单元进度见 `workspace/course-progress.md`，题型覆盖见 `docs/physics-coverage-map.md`。

## 一、体系定位

- **对象**：首次学习高中物理的高一学生为主；兼顾基础差异（讲授从情境与前置知识起步）。
- **主线**：人教版 2019 版教材（必修第一册起），节次与课程编号 K00X 对应 `workspace/高中物理六册-非实验课程与题型配图规划.xlsx`。
- **兼容性**：通过知识主题、前置知识说明和教材对应关系，尽量兼容其他版本教材学生。
- **终点**：面向高考建立完整知识体系——明确范围内的核心知识、主要模型、方法和重要边界**有覆盖、有记录、有核验**。不承诺"穷尽所有题目变化"。

## 三、完成度的衡量（防"目录写完=内容完整"）

一个单元算**完成**，必须同时满足：

1. 三类教学任务（概念建立、题型方法、分层练习）均已完成或台账说明合并原因。
2. 题型与方法覆盖表已建立并逐项标记覆盖/审核状态（`docs/physics-coverage-map.md`）。
3. 所有题目来源已登记核验（`docs/problem-source-register.md`），例题已独立求解。
4. 关键图示齐备且与正文一致。
5. 学科审核与工程校验分别通过（台账状态到"已发布"）。

**"教材目录写完""题量足够""格式校验通过"都不等于内容完整**——完整性以覆盖表和核验记录为准。

## 四、跨单元一致性

- 知识边界：新单元只用已学知识；确需前置后置说明的（"先记住，第X单元解释"），登记台账待补区，到对应单元兑现。
- 符号约定：全系列保持一致（v(B) 括号下标、正方向约定等）；同一符号不在同一分析中混用。
- 模型与方法：同一模型在不同单元复现时，引用首次讲解位置但仍须给出该处需要的最低限度说明（不得只写"见前文"）。
- 教材位置：每篇开头标明对应教材章节，作为跨版本兼容锚点。
