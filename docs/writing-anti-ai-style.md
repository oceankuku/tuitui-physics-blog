# 博客自然写作规范

博客正文要保留作者自己的判断和说话方式，避免读起来像套用固定模板。写完后逐条检查下面的规则。

## 避免对称反转句式

不要使用“不是 X，而是 Y”及其变体，包括：

- “这不是 X，而是 Y”
- “不是 X，也不是 Y，而是 Z”
- “不是 X，是 Y”
- “与其说 X，不如说 Y”

直接写结论，或者拆成两句。引用中的原话可以保留。

## 不替读者评价引文

引用之后直接继续论述。不要添加“这句话精准地揭示了”“这话一针见血”“这句话直指核心”等拔高评价。

## 删除教科书式引导

直接进入内容，避免下面这类开场：

- “先看一个思想实验”
- “让我们深入分析”
- “值得注意的是”
- “这里的关键在于”

## 少用冒号式标题

减少“大主题：小主题”的标题。优先使用一句自然、完整的话来表达本节内容。

## 控制破折号

一篇文章最多保留一到两处破折号。普通补充说明改用逗号、句号或括号。

## 删除模式化过渡词

避免“换句话说”“换言之”“简而言之”“综上所述”“值得注意的是”“从某种意义上说”。需要换段时直接换段。

## 使用自然口吻

把书面腔改成日常表达。优先写具体经历、动作、判断和结果，少写抽象拔高。

## 避免金句式结尾

结尾不要使用对称排比，也不要为了制造金句再次总结全文。写清这次实践留下了什么、作者现在怎么判断即可。

## 克制使用加粗

全文只在确有必要时加粗一两处。连续段落和列表不依赖加粗制造重点。

## 完稿检查

发布前全文搜索以下表达并逐句判断：

```text
不是 / 而是 / 与其说 / 不如说
换句话说 / 换言之 / 简而言之 / 综上所述
值得注意的是 / 这里的关键 / 真正 / 本质
```

命中不代表一定错误，但作者必须确认它来自真实表达需要，而非自动生成的句式惯性。
