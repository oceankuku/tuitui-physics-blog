## 器材一：打点计时器——先搞清它打的每个点是什么

电磁打点计时器是实验室标配：接 50 Hz 交流电，振针每秒打 50 个点。打点周期（相邻两个点的时间间隔）：

:::formula
T = \frac{1}{f} = \frac{1}{50} \text{ s} = 0.02 \text{ s}
:::

使用步骤记三步：先通电、再放纸带（先放纸带会打出一片密集无用的点）；纸带穿过限位孔压在复写纸下面；小车拖动纸带运动，点就打上去了。

![观察打点纸带](/blog-images/k007-experiments/K007E-实验-02-器材-观察打点纸带.png)

### 计数点：0.02 秒太密，要"抽点"看

0.02 s 的间隔太短，点挨得太近，刻度尺量不准。习惯上每 5 个间隔取一个计数点，相邻计数点的时间间隔：

:::formula
T' = 5T = 5 \times 0.02 \text{ s} = 0.1 \text{ s}
:::

这里埋着实验题第一文字坑："每 5 个间隔取一个计数点"，T′ = 0.1 s；"每 5 个点取一个计数点"——5 个点之间只有 4 个间隔，T′ = 4T = 0.08 s。一字之差，答案差出一倍，先看题再动笔。

### 例题一

:::problem
1.【基础题·易错题·选择题】（打点周期概念，高频送分题）电磁打点计时器接 50 Hz 交流电。下列说法正确的是：
A. 它每 0.02 s 打一个点，与小车运动快慢无关
B. 小车运动越快，相邻点的时间间隔越大
C. 每 5 个点取一个计数点，相邻计数点时间间隔为 0.1 s
D. 打点计时器使用直流电源也能正常打点
:::
:::answer
**答案：A。**

- **A 对。**打点周期由交流电频率决定，$T = \frac{1}{f} = 0.02$ s，与纸带拉多快无关——这正是它能当"计时仪器"的原因。
- **B 错。**车快，点间距变大，时间间隔仍是 0.02 s。
- **C 错。**5 个点之间只有 4 个间隔，$T' = 4 \times 0.02 = 0.08$ s——"间隔"与"点"的区别。
- **D 错。**电磁打点计时器靠电流方向周期性变化使振针振动，必须用交流电；直流电振针会被吸在一边不打了。
:::

## 器材二：纸带数据处理——速度靠邻居，加速度靠逐差

### 求某点速度：中间时刻定理

纸带上某计数点的瞬时速度怎么求？用它的左右两段。原理是匀变速的核心推论（K005 讲过）：某段时间内的平均速度，等于中间时刻的瞬时速度。设 B 点两侧相邻计数点 A、C，两段位移 $x_1$、$x_2$，时间间隔都是 $T'$：

:::formula
v_B = \bar{v}_{AC} = \frac{x_1 + x_2}{2T'}
:::

严格说这是匀变速下的严格等式（不是近似），推导在 K005 题型篇。记住操作：量出左右两段，加起来除以两倍时间间隔。

### 例题二

:::problem
2.【基础题·常考题·实验题】（2021·福建卷 T13 同型题，改编）打点计时器频率 50 Hz，每 5 个间隔取一个计数点，得 A、B、C 三个计数点。量得 AB = 3.60 cm，BC = 4.20 cm。打 B 点时小车的速度大小为：
A. 0.39 m/s
B. 0.78 m/s
C. 39 m/s
D. 条件不足，无法确定
:::
:::answer
**答案：A。**

- 先定时间：每 5 个间隔取计数点，$T' = 0.1$ s。
- B 是 AC 段的中间时刻，用中间时刻定理：$v_B = \frac{x_{AB} + x_{BC}}{2T'} = \frac{0.036 + 0.042}{0.2} = 0.39$ m/s。
- C 的陷阱是没换单位：毫米、厘米混算会差百倍。纸带题动笔前先统一成米。
:::

### 求加速度：逐差法，六个数据全员上岗

匀变速还有一条性质（K006 推过）：相邻相等时间间隔内的位移差恒定：

:::formula
x_{n+1} - x_n = aT'^2
:::

最笨的办法是 $a = \frac{\Delta v}{\Delta t}$ 一段一段算再平均——但中间数据两两抵消，最后只剩首尾干活，偶然误差全压在两头。

正解是逐差法。连续 6 段位移 $x_1$ 到 $x_6$，前后各取 3 段错位相减：每组的差都是 $3aT'^2$：

:::formula
x_4 - x_1 = 3aT'^2

x_5 - x_2 = 3aT'^2

x_6 - x_3 = 3aT'^2
:::

三式相加，解出：

:::formula
a = \frac{(x_4 + x_5 + x_6) - (x_1 + x_2 + x_3)}{9T'^2}
:::

分母 9 的来历一目了然：3 段一差、3 差相加。六个数据全部参与，误差被摊薄——这就是逐差法存在的意义。

### 例题三

:::problem
3.【基础题·常考题·实验题】（2021·福建卷 T13 同型变式）纸带计数点间隔 $T' = 0.1$ s，连续四段位移为 $x_1 = 6.05$ cm、$x_2 = 6.80$ cm、$x_3 = 7.55$ cm、$x_4 = 8.30$ cm。小车的加速度大小为：
A. 0.75 m/s²
B. 0.19 m/s²
C. 7.5 m/s²
D. 0.30 m/s²
:::
:::answer
**答案：A。**

- 只剩 4 段时用 4 段版逐差（每 2 段一差）：$a = \frac{(x_3 + x_4) - (x_1 + x_2)}{4T'^2}$。
- 代入：$a = \frac{(7.55 + 8.30) - (6.05 + 6.80)}{4 \times 0.01}$ cm/s² = $\frac{15.85 - 12.85}{0.04} = 75$ cm/s² = $0.75$ m/s²。
- B 是没换米（75 当成 0.75 少除一次）；C 是 T′ 代成 0.02（没抽计数点）；D 是分子算错。单位与 T′，两大坑各埋一次。
- 顺手验证数据质量：$\Delta x = 0.75$ cm 恒定，匀加速无疑。
:::

## 器材三：光电门——更快的"表"，同样的物理

![光电门测量小车瞬时速度](/blog-images/k007-experiments/K007E-实验-04-光电门-光电门测量瞬时速度.png)

光电门是一个 U 形架：一侧发红外光，一侧接收。小车上装一片宽度 $d$（已测）的挡光片，经过门时把光挡住——计时器记下挡光时间 $\Delta t$。挡光片经过门的平均速度：

:::formula
v = \frac{d}{\Delta t}
:::

为什么平均速度可以当瞬时速度用？挡光片足够窄（d 只有厘米级）、挡光时间足够短（毫秒级），这段时间里速度来不及变化，平均速度就非常接近经过门那一瞬的瞬时速度——这就是 K003 讲的极限思想。高考真考过反向理解：挡光片换宽，测出来的仍是平均速度，但偏离瞬时速度更远，误差变大。

实验操作两个考点（"该步骤的目的"标准答案）：① 轨道先调平——轻推小车，两门读数几乎相等才算平，抵消重力分量；② 挡光片与运动方向平行——斜着过门，有效挡光宽度变大，测得速度偏大。

### 双门测加速度

一个门给一个速度；前后架两个门 A、B，各测一次，得到 $v_A$、$v_B$。小车在两门之间做匀加速（a 恒定），由速度位移关系（K007）：

:::formula
a = \frac{v_B^2 - v_A^2}{2L}
:::

其中 L 是两门间距。光电门的精度是毫秒级，人掐表反应约 0.2 s——差两百倍，所以出题人爱用它的数据设坑。

![双光电门测匀加速运动](/blog-images/k007-experiments/K007E-实验-05-光电门-双光电门测匀加速.png)

### 例题四

:::problem
4.【基础题·常考题·实验题】（光电门综合，数据计算型）气垫导轨上装两个光电门 A、B，间距 L = 50 cm。滑块上挡光片宽 d = 1.0 cm。滑块依次经过 A、B，挡光时间分别为 $\Delta t_A = 0.025$ s、$\Delta t_B = 0.010$ s。滑块在两门间的加速度大小为：
A. 0.84 m/s²
B. 6.0 m/s²
C. 12 m/s²
D. 0.60 m/s²
:::
:::answer
**答案：A。**

- 两门各自的速度：$v_A = \frac{d}{\Delta t_A} = \frac{0.010}{0.025} = 0.40$ m/s；$v_B = \frac{0.010}{0.010} = 1.0$ m/s。
- 匀加速、已知两点速度和间距，用速度位移关系：$a = \frac{v_B^2 - v_A^2}{2L} = \frac{1.0^2 - 0.4^2}{2 \times 0.5} = \frac{0.84}{1.0} = 0.84$ m/s²。
- B 的坑：用 $\frac{v_B - v_A}{L}$，量纲都错了；D 的坑：两速度差除以"挡光时间差"——时间基准完全不同，不能这么减。
- 注意 d 换成米再除——厘米/秒与米/秒又是一个换算坑。
:::

## 综合应用：一条纸带测 g

自由落体实验是纸带处理方法的落地：重物挂着纸带，穿过打点计时器限位孔，释放后打点。此时不用抽计数点（下落太快，0.02 s 间隔恰好合适），逐差法直接用打点周期 T。

### 例题五

:::problem
5.【提升题·常考题·实验题】（2021·全国甲卷实验题同型，改编）重物拖纸带自由下落，打点计时器 50 Hz。取连续 6 段位移：$x_1 = 19.6$ mm、$x_2 = 23.5$ mm、$x_3 = 27.4$ mm、$x_4 = 31.3$ mm、$x_5 = 35.2$ mm、$x_6 = 39.1$ mm。由这些数据测得的重力加速度大小为：
A. 9.75 m/s²
B. 9.8 m/s²
C. 9.86 m/s²
D. 39.1 m/s²
:::
:::answer
**答案：A。**

- 6 段逐差，T = 0.02 s：$g = \frac{(x_4 + x_5 + x_6) - (x_1 + x_2 + x_3)}{9T^2} = \frac{(31.3 + 35.2 + 39.1) - (19.6 + 23.5 + 27.4)}{9 \times 0.0004}$ mm/s²。
- 分子 $= 105.6 - 70.5 = 35.1$ mm；分母 $= 0.0036$ s²；$g = \frac{0.0351}{0.0036} = 9.75$ m/s²。
- 为什么不是 9.8（B）：那是标准值。实验测得 9.75，偏小——纸带与限位孔有摩擦、重物受空气阻力，加速度比自由落体理论值小。实验题答"误差"要说方向：本题是偏小。
- 这条纸带数据健康：相邻差 $\Delta x = 3.9$ mm 恒定，逐差法适用。
:::

## 误差分析：方向比大小重要

实验题最讨厌背"误差有哪些"，其实只需要抓住原理式、看哪个量被带歪：

- 纸带测 g 偏小：摩擦与空气阻力使 $a < g$，原理没毛病，阻力是系统误差主因。改进：换更重的重物（阻力占比变小）、用气垫导轨。
- 光电门测速偏大：挡光片不与运动方向平行，有效宽度 $d$ 变大，$v = \frac{d}{\Delta t}$ 分子虚高。
- 计数点时间用错：T′ 代错（0.02 当 0.1），a 会放大 25 倍——这是错误，不是误差。错误可以避免，误差只能减小。
- 图像法兜底：把各点速度描进 v–t 图，斜率即加速度；离谱的数据点一眼看出、直接舍弃。逐差法与图像法是数据处理的左右手。

判断纸带是否匀加速的快速体检：算相邻段位移差 $\Delta x$，基本恒定就是匀加速；越来越小，说明在减速（或读数有系统问题）。
