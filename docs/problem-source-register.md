- *知识/模型/方法标签*：与覆盖表（coverage-map）多对多关联；一题可多标签。
- *图示源文件*：题图 SVG 在 `workspace/figs-questions.html` 的 `#fig-xxx` 锚点；网图记录来源与权限。
- *近似题与重复情况*：同一情境换数字、同型不同问法的题互相引用登记号，避免无意识重复出题。
