# 知识、模型、方法与实验覆盖表（2026-10-21 建立）

> 本文件是全系列的覆盖清单：每个课程单元的题型与方法覆盖表登记在这里。主规范第四节要求"写作前先建覆盖表，再选题、配图和写解析"。
>
> 状态含义：`规划中` → `核验中` → `已覆盖`（讲清识别/方法/条件/变式/边界）→ `已审核`（学科审核通过）。**lint 通过不等于已审核。**

## 使用方式

1. 动笔一个单元前，先在对应单元小节填覆盖表（字段见下）。
2. 写作中逐项落实，状态推进。
3. 学科审核时逐项复核，通过才标"已审核"。
4. 复习或改版时以此核对覆盖缺口，缺口记入 `workspace/course-progress.md` 待补区。

## 覆盖表字段（每行一条题型）

| 字段 | 说明 |
| --- | --- |
| 编号与名称 | 如 T4-1「v–t 图像读运动信息」 |
| 所属知识目标 | 对应主讲篇哪条学习目标 |
| 物理情境与模型 | 情境、对象、过程模型 |
| 常见设问 | 高频问法 |
| 已知信息的表达方式 | 文字 / 图像 / 图形 / 表格 |
| 主要解题方法 | 方法名与关键步骤 |
| 方法适用条件 | 公式/方法成立的条件 |
| 关键变式与边界 | 过程分支、临界状态、易错边界 |
| 前置知识 | 需要哪些已学内容 |
| 典型例题与来源 | 题号，核验记录见 problem-source-register |
| 配图需求 | 需要什么图，是否已画 |
| 对应练习 | 练习篇的题号 |
| 覆盖与审核状态 | 规划中 / 核验中 / 已覆盖 / 已审核 |

**分类依据**：物理本质、关键条件和分析方法。不得仅按题目外观、考试题型或简单换数字重复分类。
