月考卷发下来，孩子盯着错题最常说的那句话是：这题我本来会，就是没想起来要这么做。前两章的丢分，一大半丢在"想不起来"上。

前两章是整个高中物理概念最密的地界。第一章五个名词挨个登场，质点、参考系、位移、速度、加速度；第二章又叠上四个公式、三串比例、两种图像、两套实验。单个知识点都不难，难在散。散的知识点光靠翻笔记理不齐，得有一张网。

这篇就是那张网。把《运动的描述》和《匀变速直线运动的研究》两章收拢成一份自查清单：每个考点一句话讲清，标注高频考法，哪一条卡住就点进对应文章回炉。合上书从头过一遍，比盲刷十道新题划算。

## 第一章过堂，五组名词各有一个坑

**质点。** 研究问题时忽略大小和形状、有质量的点，理想化模型。能不能看成质点，看大小形状对所研究的问题有没有影响。地球庞大，研究公转时是一个点；原子再小，研究电子绕核时就不能是一个点。火车过桥，车长不能丢；火车过上千米的长江大桥，车长可以丢。选择题最爱拿这两组对照出判断。

**参考系。** 说一个物体动没动，先问以谁为标准。坐在高铁里看邻线列车缓缓后退，到底是谁在动，换个参考系答案就反过来。考法两种：判断某个描述用的是哪个参考系，判断换参考系之后结论怎么变。地面是最常用的参考系，题目一旦明确换了，所有速度都得换算过来再说。

**位移和路程。** 位移是从初位置指向末位置的有向线段，只管两头，不管中间怎么绕；路程是实际轨迹的长度。绕四百米跑道跑一圈，路程四百米，位移是零。只有单向直线运动，两者大小才相等。这一节更要紧的任务是记牢矢量与标量的分家：位移是矢量，运算带方向；后面学的力、速度、加速度全是矢量，方向感从第一章开始攒。

**速度。** 三种身份要分清。平均速度等于位移除以时间，矢量；平均速率等于路程除以时间，标量；瞬时速度是某一时刻的速度，挡光片足够窄时用位移比时间逼近，[光电门那篇](/blog/photogate-experiment/)讲过这个极限思想。

![小车顶部装着挡光片正要穿过光电门，测瞬时速度的装置](/blog-images/photogate-experiment/cart-passing-photogate.png)

挖坑的地方有两个。一是平均速度的定义式是位移比时间，一般情况下它不等于初末速度的平均，匀变速里才有这条平均关系，两句话的适用范围差得远。二是"速度"这个词在题目里不注明就是指瞬时速度，注明"平均"才按平均处理。

**加速度。** 定义式与方向一并记：

:::formula
a = {Δv/Δt}
:::

它描述速度变化的快慢，方向与速度变化量相同。三句话判断题年年考：速度大，加速度不一定大，巡航的飞机几百公里每小时，加速度是零；速度为零，加速度不一定为零，竖直上抛到最高点，速度没了，加速度还是 g；加速还是减速，看 a 与 v 同向还是反向，跟 a 的正负没有必然关系。

![等时间间隔内速度变化量相同，加速度恒定的情境图](/blog-images/uniform-acceleration/equal-time-velocity-change.png)

第一章的自查办法：把这五组名词各用一句话讲给家长听。讲得顺，这章就算过关；卡壳的那句，就是月考要咬你的那句。

## 第二章过堂，四个公式一张网

第二章全部内容挂在一条 v-t 图上，公式、比例、实验都是这条图的展开。先把公式收齐。

四个基本公式，前两条是根，后两条是推出来的枝：

:::formula
v = v₀ + at

x = v₀t + {1/2}at²

v² − v₀² = 2ax

v̄ = {(v₀ + v) / 2}
:::

选公式的口诀是"缺谁用不含谁的"。不知道时间，用第三条；不涉及加速度，用第四条；五个量知三求二，一道题通常只用一次连立。完整的概念梳理和选法示范在[匀变速那篇](/blog/uniform-linear-motion/)。

两个推论，考试出场率不比公式低。中间时刻的瞬时速度等于这段的平均速度：

:::formula
v(t/2) = v̄ = {(v₀ + v) / 2}
:::

相邻相等时间间隔内的位移差恒定：

:::formula
Δx = aT²
:::

第一条是纸带求点速的原理，第二条是判断匀加速的体检法和逐差法的根。实验题的得分点全在这两条上，后面实验一节再收。

比例关系三串，只对初速度为零的匀加速成立，这是最常被忽略的前提。从静止开始，连续相等时间内的位移之比：

:::formula
1 : 3 : 5 : 7
:::

前 n 秒总位移之比：

:::formula
1 : 4 : 9
:::

速度之比：

:::formula
1 : 2 : 3
:::

通过相等位移的时间之比是 1 : √2 : √3，逆向思维题（匀减速到零）配这串数字正好。

![v-t 图像标注斜率与交点：斜率是加速度，交点是速度相等的时刻](/blog-images/uniform-acceleration/vt-graph-slope-intersection.png)

v-t 图像四要点，一图抵四公式：斜率是加速度；面积是位移；交点是速度相等的时刻；折点是分段的公共点。公式代糊涂的题，回到图像往往一眼看穿，这是匀变速那篇反复强调的话，考前再钉一遍。

## 两种特殊运动，两类必考陷阱

自由落体：初速度为零、只受重力，两个条件缺一不可。它是匀变速的特例，v₀ = 0、a = g，四个公式代进去剩三条：

:::formula
v = gt

h = {1/2}gt²

v² = 2gh
:::

牛顿管和月球上锤子羽毛同时落地的画面，考的就是"两个条件"那四个字。比例关系、纸带测 g、竖直上抛的对称性，[自由落体那篇](/blog/free-fall-motion/)一次讲全了。

![牛顿管抽成真空后硬币与羽毛同时落下](/blog-images/free-fall-motion/newton-tube-vacuum.png)

竖直上抛：取向上为正，a = −g。记两条。一是最高点速度为零，加速度仍是 g，"速度为零"和"停下来不受力"是两回事，2023 年广东卷的铯原子钟题考的就是这一句。二是对称与倒放：上升段倒着放就是自由落体，相等位移时间比 1 : √2 : √3 直接套，2019 年全国Ⅰ卷的扣篮题是标准示范。

刹车陷阱：车停下就停着，不会倒着开。减速的题先算停车时间，问的时刻超过它，位移按停下那一刻算，直接代公式会算出倒车解。

![汽车刹车到停止的问题模型示意](/blog-images/uniform-acceleration/braking-stop-model.png)

追及相遇：一个方程通吃。同向追上写位移相等，反向相遇写位移之和等于初始距离，最大距离和判撞都藏在速度相等的时刻。四类题型和五步流程，[追及相遇那篇](/blog/chase-meet/)刚讲过，考前把那张题型表再扫一眼。

![同向追及问题模型：速度相等时距离最大，位移相等时追上](/blog-images/uniform-acceleration/chase-equal-velocity.png)

## 实验题的固定得分点

前两章的实验大题，两套设备共用一套数学，得分点固定。

打点计时器：市电 50 Hz，打点周期 0.02 秒。习惯上每 5 个间隔取一个计数点，T′ = 0.1 秒。求某点速度用中间时刻法，等于相邻两段位移之和除以 2T′；求加速度用逐差法，六段位移错位相减：

:::formula
a = {(x₄ + x₅ + x₆) − (x₁ + x₂ + x₃) / 9T′²}
:::

判断匀加速看相邻段位移差是不是恒定。纸带的读点、推导和坑，[纸带那篇](/blog/paper-tape-analysis/)全部带推导讲过。

![电磁打点计时器与纸带装置，板书打点周期](/blog-images/paper-tape-analysis/timer-setup.png)

光电门：挡光片宽度 d 除以挡光时间得平均速度，片够窄就是瞬时速度；两个门前后架，加速度等于速度差比时间。步骤题爱考轨道调平和挡光片与运动方向平行，目的各写一句就得分。

两套设备核对下来就三样东西：中间时刻速度、Δx = aT²、逐差法。实验题换什么仪器，都是这三样的排列组合。

## 三张卡片，考前最后过一遍

合上书，按下面的顺序自查。卡壳的条目，回到上文找对应的段落。

公式卡，八条，要能默写。定义两条、基本四条、推论两条，上文全都给过公式块，这里不重复占地方，合上书挨条默，默不出哪条点哪段。

结论卡，六条，选择题的弹药库：

- 初速为零的比例三串（1 : 3 : 5 : 7、1 : 4 : 9、1 : 2 : 3），前提是从静止开始；
- 相等位移时间比 1 : √2 : √3，匀减速到零的题倒着用；
- 追及两条：速度相等定最大距离，位移相等定追上；
- 判撞临界：速度相等加位移差等于初始距离，联立；
- 刹车先算停车时间，超时的位移按停下那一刻算；
- 最高点速度为零、加速度不变（自由落体系里仍是 g）。

坑卡，七条，全是阅卷现场的高频失分点：

1. "每 5 个间隔"和"每 5 个点"，T′ 差着一倍，先数清楚再动笔；
2. 纸带读数是毫米，求加速度前没换算成米；
3. 平均速度随手取初末平均，忘了定义式是位移比时间；
4. 刹车题直接代公式，算出倒车解还蒙在鼓里；
5. v-t 图的交点当成相遇，交点只是速度相等；
6. 比例关系套在非静止起点上，前提没看；
7. 有往返的运动里位移当路程用，两者大小不相等。
