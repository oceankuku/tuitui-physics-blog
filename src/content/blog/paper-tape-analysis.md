上次讲光电门的时候留了个尾巴：有一条老前辈级别的纸带要讲。后台还真有家长留言问"纸带是什么"，先补一句：打点计时器固定在桌上，纸带一端绑在小车（或重物）上，通电后振针每 0.02 秒在纸上打一个点。物体一动，纸带跟着走，一串点就留下来了。纸带就是物体运动的自动签到表，每个点都带着时间和位置信息。

这玩意儿看着土，却是高考实验题的元老级考点，而且它的数据处理方法，光电门那篇说过，两套设备共用一套数学。今天把它一次讲透，公式全部带推导，孩子拿着文章能直接对一遍。

## 先认识这条纸：点里藏着时间轴

![电磁打点计时器与纸带，板书 T = 1/f](/blog-images/paper-tape-analysis/timer-setup.png)

看一条纸带，先找两样东西。

一是打点周期 T。市电频率 f = 50 Hz，振针每秒打 50 个点，打点周期是频率的倒数：

:::formula
T = {1/f} = {1/50} s = 0.02 s
:::

两个相邻点之间永远是 0.02 秒，不管小车跑多快。这是整条纸带唯一免费给你的信息。

二是计数点。0.02 秒太密，点挨得太近，刻度尺量不准。习惯上每 5 个间隔取一个计数点，相邻计数点之间的时间间隔：

:::formula
T′ = 5T = 5 × 0.02 s = 0.1 s
:::

注意题目怎么问的。说"每 5 个间隔取一个计数点"，T′ 就是 0.1 s；说"每 5 个点取一个计数点"，5 个点之间只有 4 个间隔，T′ = 4T = 0.08 s。这个文字坑几乎每年都有人掉进去。

![放大看纸带上的点：先数间隔，再定计数点](/blog-images/paper-tape-analysis/tape-dots-closeup.png)

## 第一步：求某点的瞬时速度

纸带上某一点的速度怎么求？用它的邻居。规则一句话：某段时间内的平均速度，等于中间时刻的瞬时速度。

设 B 点两侧相邻计数点为 A、C，AB 段位移为 x₁，BC 段位移为 x₂，时间间隔都是 T′。B 点速度推导如下，匀变速运动中，一段位移的平均速度等于初末速度的平均，也等于中间时刻的速度：

:::formula
v<sub>B</sub> = v̄<sub>AC</sub> = {x₁ + x₂ / 2T′}
:::

先看为什么 v̄<sub>AC</sub> 等于中间时刻速度。设 A 点速度 v<sub>A</sub>，加速度 a，则 C 点速度 v<sub>C</sub> = v<sub>A</sub> + 2aT′，AC 段平均速度：

:::formula
v̄<sub>AC</sub> = {v<sub>A</sub> + v<sub>C</sub> / 2} = {2v<sub>A</sub> + 2aT′ / 2} = v<sub>A</sub> + aT′
:::

而 B 点是 AC 的中间时刻，v<sub>B</sub> = v<sub>A</sub> + aT′，两个结果完全一样。这就是"平均速度=中间时刻速度"的完整出身，匀变速里它是严格等式，高考这么算不叫近似，叫定理。

## 第二步：求加速度，逐差法

速度有了，加速度就是 a = Δv/Δt，逐个算再取平均行不行？行，但亏。中间速度在式子里两两抵消，最后只剩首尾数据干活，偶然误差全压在两头。

正解是逐差法。设纸带连续 6 段位移为 x₁ 到 x₆，每段对应 T′。匀变速的基本性质先摆出来：相邻相等时间间隔内的位移差恒定，

:::formula
x₂ − x₁ = x₃ − x₂ = ⋯ = aT′² = Δx
:::

这条怎么来的？第 n 段位移可以写成 xₙ = v₀T′ + ½a(nT′)² 减去 v₀T′ + ½a((n−1)T′)²，展开整理：

:::formula
xₙ = v₀T′ + ½a(2n − 1)T′²
:::

于是 xₙ₊₁ − xₙ = ½a(2n+1)T′² − ½a(2n−1)T′² = aT′²，与 n 无关，等差成立。

把 6 段分成两组，错位相减，每组的三个差各自等于 3aT′²：

:::formula
x₄ − x₁ = 3aT′²　　x₅ − x₂ = 3aT′²　　x₆ − x₃ = 3aT′²
:::

三式相加，左边是两组位移和的差，右边是 9aT′²，解出：

:::formula
a = {(x₄ + x₅ + x₆) − (x₁ + x₂ + x₃) / 9T′²}
:::

分母 9 从哪来一目了然：3 段一差，3 差相加。六个数据全部上岗，误差被摊薄，这就是逐差法的价值。上篇光电门留的尾巴，Δx = aT² 的户口，就落在刚才那两行推导里。

![纸带上点的间距从上到下均匀增大，说明是匀加速](/blog-images/paper-tape-analysis/freefall-analysis.png)

## 经典应用：测重力加速度

纸带最高频的考题是测 g。重物挂着纸带自由下落，按逐差法算出的加速度就是 g（严格说略小于 9.8，纸带和限位孔有摩擦，还有空气阻力）。

![数据处理落地：描 v-t 图像，斜率即加速度](/blog-images/paper-tape-analysis/vt-graph.png)

数据也可以描成 v-t 图像：按第一步算出各点速度，描点连线，斜率即加速度。图像法的好处是离谱的点一眼可见，直接舍弃。逐差法和图像法是纸带处理的左右手，高考都考过。

判断纸带是否匀加速也有快速体检法：算相邻段位移差，差值基本相等就是匀加速；差值越来越大，加速度在变，数据就得小心。

## 考场提醒，三句话

第一，先看题问的是"每 5 个间隔"还是"每 5 个点"，定准 T′ 再动笔。第二，单位：纸带读数常给毫米，求 a 前换算成米，9T′² 里 T′ 用秒。第三，逐差法要凑偶数段，6 段最常见；只剩 5 段就舍弃最短的头一段（打点最密、相对误差最大），凑成 4 段用 4T′² 版本，公式同理换成 a = [(x₃ + x₄) − (x₁ + x₂)] / 4T′²。

给孩子检查这道题，就问一句：你中间那几个速度算出来干嘛用的？答"求加速度用的"，说明逐差法还没通；答"不干嘛，逐差法直接用位移"，那就真懂了。
