## 本单元答案区（按题号逐题）

1. D。

依据：惯性是一切物体的固有属性，与运动状态、是否受力无关，只由质量决定。

　　A 错。静止和运动的物体都有惯性，运动状态不是条件。


　　B 错。不受力时惯性照样存在。


　　C 错。速度大小不改变质量，也就不改变惯性。

检查：凡是给惯性附加条件（静止、受力、速度快慢、月球地球）的选项一律错，答案指向"任何情况下都有"。

2. B。

依据：题目选"不正确"的说法。惯性是固有属性，飞船内的物体仍然有惯性。

　　A 对。这正是定律后半句的含义。


　　B 不对。失重环境改变不了质量，也就消灭不了惯性。


　　C 对。状态改变必有外力，是定律的逆应用。


　　D 对。丢副油箱减小质量，从而减小惯性，便于改变运动状态。

检查：先看清"不正确"三个字；再核对 B 的说法与"惯性是固有属性"直接冲突，选定即可。

3. B。

依据：变速运动就是运动状态发生变化，而力是改变运动状态的原因。

　　A 错。匀速直线运动的物体不需要力来维持。


　　C 错。没有摩擦等阻力时，撤去力后物体保持匀速直线运动，不会停。


　　D 错。力也改变速度的方向，匀速转弯就是例子。

检查：四个选项都在考"力与运动谁因谁果"，逐项对照"力是改变运动状态的原因"这一句即可，注意 C 隐含了阻力。

4. C。

依据：质量是惯性大小的唯一量度，改变质量才能改变惯性。

　　A 错。发动机功率再大，赛车质量没变，惯性没变，功率与惯性无关。


　　B 错。子弹的质量不变，惯性不变；穿不透棉衣与它速度大、要改变的状态深有关。


　　C 对。摘下或加挂车厢直接改变列车的总质量，惯性随之改变。


　　D 错。转弯靠摩擦力改变速度方向，车手倾斜是为了配合受力，不是在调惯性。

检查：每个错误选项都在偷换"惯性的量度"，正确选项必须落在"质量"上才可靠。

5. B。

依据：牛顿第一定律描述"不受力"的理想情形，无法用实验直接验证，是在可靠事实基础上经理想实验和合理推理建立的。

　　A、C、D 都不选。胡克定律由实验直接归纳，牛顿第二定律由实验归纳定量关系，牛顿第三定律可由力传感器等实验直接验证。

检查：把"理想实验、无法直接验证"这一特征与四条定律一一对照，只有牛一符合。

6. C。

依据：车厢密封且无气流，烟离开卫生香时就具有和车相同的速度，之后随车一起匀速运动，相对车厢没有前后移动的趋势。

　　A 错、B 错。烟不需要力维持水平方向的运动，也不会凭空落后或超前。


　　D 不选。条件充足，可以确定。

检查：关键在"烟已具有车速"这个隐含条件；想通这一点，三个干扰项自动排除。

7. C。

依据：人竖直跳起，水平方向不受力，保持起跳瞬间的水平速度；落点在跳起点前方还是后方，取决于车速比人快还是慢。

　　A 错。匀速前进时人水平速度与车相同，同样落回原点。


　　B 错。匀速时落回跳起点，不在后方。


　　C 对。车加速，车速越来越大，人保持起跳时的较小速度，落点在后方。


　　D 错。减速时车速变小，人反而落在跳起点前方。

检查：把"人的水平速度锁定在起跳瞬间"与"车的速度在变"对比，三个错误选项各对应一种速度关系，别把"静止"当成落回原点的唯一条件。

8. C。

依据：列车进站要减速，水由于惯性保持原来较大的速度，相对车向前涌，液面变成前高后低。图中箭头向左，前方在左。

　　A 错。液面水平对应匀速或静止。


　　B 错。前低后高对应加速。


　　D 错。起伏波动是晃动，不是减速的特征。

检查：先定"前方"在哪头，再把水的惯性与车的减速对比，最后到图里找"前高后低"的那一幅。

9. B。

依据：水的质量远大于气泡，惯性的主角是水。车突然停止，水由于惯性继续向前，相对瓶子向前涌，把气泡挤向后方。

　　A 错。那是把人的前倾经验直接搬到气泡上，主角找错了。


　　C 错、D 不选。水与气泡惯性差异悬殊，相对运动方向明确。

检查：按方法篇示范 1 的三步走一遍：车变了、水没变、气泡被挤——结论自然是"向后"。

10. D。

依据：只有 ② 是实验室里真实做得到的经验事实；"如果没有摩擦"开头的 ③ 是推论；由 ③ 推出倾角减小仍达原高的 ①，再推到倾角为零的 ④。顺序为事实 ② → 推论 ③ → 推论 ① → 推论 ④。

　　A、B、C 均错。要么把 ① 当成了事实，要么颠倒了 ① 与 ④、③ 与 ① 的顺序。

检查：核对两点——事实只有一条；倾角逐次减小决定 ③、①、④ 的先后。都对了再选。

11. D。

依据：运动状态就是速度，速度是矢量，大小或方向任何一个变了，状态就变了。

　　A 错。匀速直线运动的状态不变。


　　B 错。多个力平衡时合力为零，状态同样不变。


　　C 错。大小不变方向变（匀速转弯），状态照样改变。

检查：把"状态 = 速度矢量"这层意思放到每个选项里过一遍，D 是它的原话。

12. A。

依据：桌面光滑，球在水平方向不受力，相对地面保持匀速直线运动；球的相对轨迹反映的是车的运动变化。

　　A 对。以球为参考系：球相对车向前（向左）运动，说明车速变小了；球相对车还向北（上）偏，说明车速向南偏了——车减速且向南转弯。


　　B 错。向北转弯时球相对车应向南偏，与图中从 A 到 B 向北矛盾。


　　C、D 错。加速时球相对车向后运动，与图中球向前运动矛盾。

检查：方向分两步核对——前后看快慢（球向前说明车减速），南北看转向（球向北偏说明车向南转）；两步都对上才选。

13. B。

依据：劈与小球各接触面都光滑，小球在水平方向不受任何力，水平方向的运动状态不变——原来水平方向静止，就保持水平方向静止；竖直方向上劈向下滑，支持力小于重力，小球竖直下落。

　　A、C 错。斜向下的轨迹要求球有水平方向的运动，但没有力提供水平方向的运动状态改变。


　　D 错。水平方向匀速运动同样需要初始速度，球原来是静止的。

检查：隐含条件是"各面光滑"，它保证水平方向无力；抓住"水平方向状态不变"，四个选项只剩一个。

14. BD（多选）。

依据：无摩擦环境中，人施加的力是巨轮受到的合外力。

　　A 错。有力作用就有加速度，"完全无法启动"与定律矛盾，惯性大只说明状态难改变，不是不能改变。


　　B 对。加速度与力同时产生、同时变化、同时消失，力一施加，加速度立即存在。


　　C 错。加速度的大小由力和质量即刻决定，数值虽小但不是"很久之后才产生"；"很久"的只可能是速度。


　　D 对。巨轮质量巨大，加速度很小，速度要长时间缓慢积累才看得出明显变化。

检查：区分"加速度"与"速度"这两个词是本题题眼——加速度随力即时产生，速度才需要时间积累。

15. D。

依据：木板对小车的作用力与小车对木板的作用力是一对作用力和反作用力，由牛顿第三定律，大小总相等。

　　A 错。小车向左加速，运动状态在改变，水平方向必有力的作用（木板给的摩擦力），不可能只受重力和支持力。


　　B 错。木板对小车的作用力包含竖直向上的支持力和水平方向的摩擦力，两者合成后的方向不在水平方向上。


　　C 错。相互作用力永远等大，不存在谁大谁小。

检查：先按方向把力分组，判断 A、B；再用牛三封死 C、D——这类"加速 + 相互作用"的题，牛三那句"一定相等"是定盘星。

16. AC（多选）。

依据：伽利略用理想斜面实验和逻辑推理研究力与运动、用实验加推理研究落体运动。

　　A 对。理想斜面实验的结论：维持物体的运动不需要力。


　　B 错。物体之间普遍存在相互吸引力是牛顿的万有引力定律，不是伽利略的发现。


　　C 对。轻重物体下落快慢相同由伽利略的斜面实验结合推理得出（K007 讲过这段历史）。


　　D 错。相互作用力等大反向是牛顿第三定律的内容。

检查：题干限制"伽利略发现的规律"，B、D 都是牛顿的成果，按人物排除即可。

17. 答案：慢慢加拉力时，悬挂端（书上方）的一段细绳断；迅速拉时，手握端（书下方）的一段细绳断。

依据：

　　慢拉：书处于静止，受力平衡。上段绳承受的拉力等于书的重力与下段绳拉力之和，下段绳只承受手的拉力：

:::formula
F_{\text{上}} = G_{\text{书}} + F_{\text{下}}
:::

所以上段绳中的张力始终更大，拉力逐渐加大时上段先断。

　　快拉：书的质量大、惯性大，运动状态难以改变。迅速一拽的瞬间，书几乎还保持不动，手的拉力骤增的部分几乎全部由下段绳承担，下段绳的瞬时张力远大于上段绳（上段只需承担书的重力），所以下段先断。

检查：两次结果不同的根源是书这个"大惯性物体"来不及改变运动状态——解释时按"研究对象原来的状态 → 谁的运动状态变了 → 谁由于惯性没变"三步说全，才是完整答案。
