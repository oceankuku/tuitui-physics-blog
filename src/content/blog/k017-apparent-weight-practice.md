## 本单元答案区（按题号逐题）

1. BC（多选）。

依据：超重失重只看加速度方向。加速上升与减速下降都是加速度向上，视重大于重力，超重；减速上升与加速下降都是加速度向下，视重小于重力，失重。

　　A 错。加速上升，加速度向上，超重而不是失重。

　　B 对。减速下降，速度向下减小，加速度向上，超重。

　　C 对。减速上升，速度向上减小，加速度向下，失重。

　　D 错。加速下降，加速度向下，失重而不是超重。

检查：把“向上加速、向上减速、向下加速、向下减速”四种组合对照主讲篇图 5 逐一过一遍，判断依据只有一个——加速度方向。

2. D。

依据：取竖直向上为正方向，人受重力 $mg$ 与支持力 $N$，由牛顿第二定律：

:::formula
N - mg = m \cdot \frac{g}{3}
:::

:::formula
N = m\left(g + \frac{g}{3}\right) = \frac{4}{3}mg
:::

人对电梯底部的压力与支持力是一对作用力和反作用力，大小为 $\frac{4}{3}mg$。

　　A 错。$\frac{1}{3}mg$ 是合力 $ma$ 的大小，不是支持力。

　　B 错。$2mg$ 对应加速度为 $g$ 的情形，本题只有 $\frac{g}{3}$。

　　C 错。$mg$ 是静止或匀速时的视重，加速上升时视重变大。

检查：$N = m(g + a)$ 里 $a$ 取 $\frac{g}{3}$，得 $\frac{4}{3}mg$；凡是“加速上升求压力”的题，答案一定大于 $mg$，可以先排除 A、C 再定量。

3. A。

依据：扶梯加速度斜向右上方，把它分解到竖直方向后分量向上，$N = m(g + a_y) > mg$，人处于超重状态。

　　A 对。竖直方向有向上的加速度分量，超重。

　　B 错。人有水平向右的加速度分量，这个分量由扶梯对人的静摩擦力提供，方向水平向右。

　　C 错。匀速阶段合力为零，人只受重力和支持力两个力，没有摩擦力。

　　D 错。匀速阶段 $N = mg$，支持力等于重力。

检查：这类“斜向加速度”题的固定动作是把 $a$ 分解到水平、竖直两个方向，竖直分量定超失重、水平分量定摩擦力方向（方法篇第二节的推广）。

4. BD（多选）。

依据：静止时弹簧弹力 $F_1$、重力 $mg$、箱顶压力 $F_2$ 三力平衡，$F_1 = mg + F_2$，所以 $F_1 > mg$。物块对箱顶刚好无压力时，$F_2 = 0$，但弹簧形变来不及改变，$F_1$ 仍是原值，物块受到的合力为 $F_1 - mg = F_2 > 0$，方向竖直向上，加速度向上。

　　A 错。加速下降加速度向下，物块会离得更紧，与加速度向上矛盾。

　　B 对。加速度向上，木箱可以加速上升。

　　C 错。减速上升加速度向下，同样矛盾。

　　D 对。加速度向上，木箱也可以减速下降。

检查：这一问的钥匙是“弹力不能突变、压力可以”——压力恰好为零的瞬间，剩下的两力不再平衡，合力方向由原来被抵消的 $F_2$ 决定，竖直向上（方法篇第三节的对照情形）。

5. D。

依据：$s$-$t$ 图像的斜率表示速度。0 到 $t_1$：斜率增大，$v$ 增大，乘客向下加速，加速度向下，$F_N < mg$；$t_1$ 到 $t_2$：斜率不变，匀速下降，$F_N = mg$；$t_2$ 到 $t_3$：斜率减小，$v$ 减小，向下减速，加速度向上，$F_N > mg$。

　　A 错。$v$ 增大没错，但加速向下时 $F_N < mg$。

　　B 错。$t_1$ 到 $t_2$ 内 $v$ 不变（匀速），$F_N = mg$。

　　C 错。$t_2$ 到 $t_3$ 内 $v$ 减小而不是增大。

　　D 对。向下减速，加速度向上，支持力大于重力。

检查：$s$-$t$ 图没有负斜率也在正常下楼——位移一直增大，只是快慢在变；判断超失重看的是斜率的变化趋势，不是位移是否增加。

6. B。

依据：竖直方向 $N = m(g + a)$，$a$ 以向上为正。前 2 s 内 $a > 0$，超重；2 s 到 4 s 内 $a > 0$ 但逐渐减小，所以 $N$ 逐渐变小；$t = 6$ s 时 $a = 0$，$N = mg$；$t = 8.5$ s 时 $a = -3\ \text{m/s}^2$ 达到负向最大，$N = m(g - 3)\ \text{N}$ 为最小。

　　A 错。前 2 s 加速度向上，超重不是失重。

　　B 对。向上的加速度在减小，人对地板的压力随之变小。

　　C 错。$a = 0$ 时压力为 $mg$，不是 0。

　　D 错。$t = 8.5$ s 时加速度向下最大，人处于“最失重”状态，压力最小。

检查：$a$-$t$ 图是唯一不用求导的图像——纵坐标直接就是加速度，正负即方向，对照 $N = m(g + a)$ 逐点读数即可。

7. A。

依据：返回舱竖直向下减速，加速度向上。设向上为正方向，受重力 $mg$（向下）和阻力 $f$（向上），由牛顿第二定律 $f - mg = ma$，即 $a = \frac{f}{m} - g$。速度减小，阻力 $f$ 随之减小，$a$ 一直减小。

　　A 对。$f$ 一直减小，$a$ 一直减小。

　　B 错。$a$ 增大需要 $f$ 增大，与“阻力随速度减小而减小”矛盾。

　　C 错、D 错。$a$ 随 $f$ 单调变化，没有先增后减或先减后增的转折。

检查：减速下降属于超重状态（加速度向上），本题进一步问“超重程度怎么变”——抓住“阻力是唯一随速度变的力”，其余顺势推出。

8. BD（多选）。

依据：匀速下滑时物块三力平衡，沿斜面方向有 $\mu mg\cos\theta = mg\sin\theta$，得 $\mu = \tan\theta$。升降机以加速度 $a$ 加速上升时，物块在竖直方向获得加速度 $a$，斜面对物块的正压力变为：

:::formula
F_N = m(g + a)\cos\theta
:::

正压力增大，B 对。摩擦力是滑动摩擦力，随之变为：

:::formula
f = \mu F_N = \tan\theta \cdot m(g + a)\cos\theta = m(g + a)\sin\theta
:::

把摩擦力与重力沿斜面的新分量 $m(g + a)\sin\theta$ 相比恰好相等——沿斜面方向仍然平衡，物块相对斜面仍匀速下滑，D 对、C 错；摩擦力增大，A 错。

　　A 错。正压力增大，滑动摩擦力按 $\mu F_N$ 同步增大。

　　B 对。见上式，正压力从 $mg\cos\theta$ 变为 $m(g + a)\cos\theta$。

　　C 错。沿斜面方向两个力同比例放大，仍然抵消。

　　D 对。相对运动状态不变，仍是匀速下滑。

检查：竖直方向超重相当于把“有效重力”从 $mg$ 放大为 $m(g + a)$，斜面上所有与重力成比例的量一起放大——正压力、摩擦力、沿斜面分量都乘同一个因子，平衡关系不变。

9. C。

依据：物体原本沿斜面下滑，说明 $\tan\theta > \mu$（重力沿斜面分量大于最大静摩擦力）。

　　A 可能。箱子水平匀加速时，物体可以只靠重力和支持力的合力获得水平加速度，摩擦力可以为零，恰好相对静止。

　　B 可能。箱子自由落体时处于完全失重，物体与斜面之间无相互作用力，物体也以 $g$ 下落，相对斜面静止。

　　C 不可能。箱子竖直向上匀加速时，物体相对斜面静止需要沿斜面向上的足够摩擦力；但竖直超重使正压力放大为 $m(g + a)\cos\theta$ 的同时，重力沿斜面的“破坏分量”也放大为 $m(g + a)\sin\theta$，两者同比例放大，$\tan\theta > \mu$ 的关系不变，物体仍要下滑，假设不成立。

　　D 可能。匀速圆周运动需要指向圆心的水平合力，重力和支持力（配合摩擦）可以提供，存在相对静止的可行配置。

检查：“不可能”的判定落在 C——竖直方向的加速不改变“$\tan\theta$ 与 $\mu$ 谁大”的格局，只等比例放大两边的力；这一点与第 8 题的 D 选项是同一个道理。

10. D。

依据：自由下落、竖直上抛、平抛、斜抛（忽略空气阻力）的容器加速度都是竖直向下的 $g$，容器和水处于完全失重，水与容器壁之间没有相互挤压，水不会从小孔漏出。

　　A 错。自由下落时完全失重，不漏水。

　　B 错。竖直上抛的全过程（上升段和下降段）加速度都是 $g$ 向下，全程不漏水。

　　C 错。平抛只受重力，加速度为 $g$，不漏水。

　　D 对。斜向上抛同样只受重力，全程完全失重，小孔不漏水。

检查：判断漏水不看容器往哪个方向“走”，只看加速度是不是竖直向下的 $g$；四种抛体只受重力，答案天然一致（主讲篇第四节的“内部相互作用消失”）。

11. BD（多选）。

依据：人受重力 $mg$、竖直向上的支持力 $F_N = 1.25mg$ 和水平方向的静摩擦力 $f$。加速度沿索道方向，与水平方向成 37°，把它分解为水平分量 $a\cos 37^{\circ}$ 和竖直分量 $a\sin 37^{\circ}$。竖直方向由牛顿第二定律：

:::formula
F_N - mg = ma\sin 37^{\circ}
:::

:::formula
1.25mg - mg = 0.6ma
:::

:::formula
a = \frac{0.25g}{0.6} = \frac{5g}{12}
:::

水平方向：

:::formula
f = ma\cos 37^{\circ} = m \times \frac{5g}{12} \times 0.8 = \frac{1}{3}mg
:::

　　A 错。加速度沿索道向上，车厢既可以向上加速，也可以向下减速，运动方向不能确定。

　　B 对。由竖直方向方程解得 $a = \frac{5g}{12}$。

　　C 错。人对厢底的摩擦力与厢底对人的摩擦力方向相反；厢底对人的摩擦力水平向右（提供水平加速度），所以人对厢底的摩擦力水平向左。

　　D 对。车厢对人的摩擦力大小为 $\frac{1}{3}mg$。

检查：压力 1.25 倍只在竖直方向方程里用，别把它乘到整体上去；加速度方向沿索道、支持力竖直、摩擦力水平，三个方向各管一角，方程自然分家。

12. D。

依据：上抛阶段实验舱只受重力（微重力 10 µg 近似为 0），匀减速 2 s 后速度减为零，所以释放即上抛的初速度为：

:::formula
v = gt = 10 \times 2\ \text{m/s} = 20\ \text{m/s}
:::

　　A 错。电磁弹射阶段加速度 $a = 5g = 50$ m/s²，把实验舱从静止加速到 20 m/s 用时 $t = \frac{v}{a} = \frac{20}{50}\ \text{s} = 0.4$ s。

　　B 错。弹射阶段上升距离 $x = \frac{v^2}{2a} = \frac{20^2}{2 \times 50}\ \text{m} = 4$ m。

　　C 错。上抛阶段的运行长度 $h = \frac{v^2}{2g} = \frac{20^2}{2 \times 10}\ \text{m} = 20$ m。

　　D 对。由上抛时间 2 s 得初速度 20 m/s。

检查：先分清三段——弹射（匀加速 5g）、上抛（完全失重）、下落（完全失重）；“微重力时间 4 s”正是上抛加下落的 2 s 加 2 s，装置的巧思就在这里。

13. A。

依据：绳断后，乒乓球因浮力大于重力而加速上升，加速度向上，处于超重状态；与此同时，球原来占据的位置由同体积的水加速下降填补，这部分水的加速度向下，处于失重状态。球轻、同体积的水重，水中“下坠的一侧”质量占优，容器内整体的重心加速度向下，整体处于失重状态，体重计示数比静止时小。

　　A 对。下降的“水的空位”比上升的球重，整体失重，示数减小。

　　B 错。只看球超重、不看水失重，才会选它。

　　C 错。系统内部有相对加速运动，示数不会保持不变。

　　D 错。受力关系明确，可以判断。

检查：这是称重情境的变化版——体重计称的是整个系统，示数由系统重心加速度决定；内部的“一升一降”要按质量加权后一起算，不能只盯着显眼的乒乓球。
