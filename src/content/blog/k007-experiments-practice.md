注①（第 1–5 题）：
1. B——打点周期 $T = \frac{1}{f} = \frac{1}{50} = 0.02$ s；A 错（电磁打点计时器用 4–6 V 低压交流，220 V 是电火花计时器）、C 错（车快间距大、间隔不变）、D 错（必须交流）。
2. A——$v = \frac{0.012 + 0.016}{0.2} = \frac{0.028}{0.2} = 0.14$ m/s。
3. A——点疏＝同时间内位移大＝速度大；向右拉、右边快，即向右加速。
4. A——$v = \frac{d}{\Delta t} = \frac{0.0080}{0.020} = 0.40$ m/s。
5. B——摩擦与阻力使实际加速度小于 g；换重物可减小阻力占比。

注②（第 6–10 题）：
6. B——先通电待振针稳定，开头不废点。
7. B——3 段一差、3 差相加：$3 \times 3 = 9$。
8. A——中间时刻定理（匀变速严格等式）。
9. B——均匀分布画直线，斜率即 a；强行穿点是过拟合，折线连线无意义。
10. B——$\Delta x$ 恒定是匀加速判据；A 只说明轨迹直（变速直线也直）。

注③（第 11–13、23 题）：
11. $\Delta x = 0.6$ cm 恒定，$a = \frac{\Delta x}{T'^2} = \frac{0.006}{0.01} = 0.60$ m/s²（逐差验证 $\frac{(3.2+3.8)-(2.0+2.6)}{0.04}$ cm/s² $= \frac{2.4}{0.04} = 60$ cm/s² ✓）。
12. $a = \frac{v_B^2 - v_A^2}{2L} = \frac{0.64 - 0.16}{1.0} = 0.48$ m/s²（L 换 0.50 m）。
13. 偏大——不平行使有效挡光宽度大于真实 d，$v = \frac{d}{\Delta t}$ 分子虚高。
23. 保留 $x_2$ 到 $x_6$ 五段，弃异常的 $x_1$，用四段逐差（弃最短段的原则一致：点密、相对误差大、本例还异常）；异常数据不能硬套公式。

注④（第 14、24 题）：
14. 相邻速度差恒 0.30 m/s，$a = \frac{0.30}{0.1} = 3.0$ m/s²（逐差验证 $\frac{(1.10+1.40)-(0.20+0.50)}{0.03}$ m/s² $= \frac{1.8}{0.03} = 60$？——注意分母：4 段版是 $4T'^2 = 0.04$，速度差版对应 $\frac{(1.10+1.40)-(0.20+0.50)}{4T'} = \frac{1.8}{0.4} = 4.5$？——最稳的算法：相邻速度差恒定 $= aT'$，$a = \frac{0.30}{0.1} = 3.0$ m/s²）。
24. 月面 g 小，相等时间位移更小、点迹更密；逐差法只依赖"匀加速 + 相等时间"，与 g 数值无关，公式照样适用，算出的 a 就是月面 g。

注⑤（第 15、25 题）：
15. 25.0 mm = 0.0250 m，误当 0.25 m 用则 a 放大 10 倍——数值差十倍优先查单位换算链。
25. C——代错数据是计算错误，可避免；A、B、D 是不可避免的系统/偶然误差。

注⑥（第 16 题）：
16. 能初步判断"速度大小不变"，但严格讲还需确认是直线运动且方向不变（间距均匀 + 点迹在同一直线上），两者齐备才能下"匀速直线"结论。

注⑦（第 17、27 题）：
17. 匀速：速度不随位置变，$\frac{d}{\Delta t}$ 分子分母同比例变化，测得速度不变；加速：挡光时间变长，平均速度"偏低"更多，测得速度偏小（更偏离中点瞬时值）。
27. (a) 段位移 4.00、4.60、5.20、5.80、6.40、7.00 cm，$\Delta x = 0.60$ cm 恒定 → 匀加速。

    (b) $v_2 = \frac{x_2 + x_3}{2T'} = \frac{0.046 + 0.052}{0.2} = 0.49$ m/s；$v_5 = \frac{0.058 + 0.064}{0.2} = 0.61$ m/s。

    (c) $a = \frac{(5.80+6.40+7.00)-(4.00+4.60+5.20)}{0.09}$ cm/s² $= \frac{19.20-13.80}{0.09} = 60$ cm/s² $= 0.60$ m/s²。

    (d) $v_0 = v_2 - 2aT' = 0.49 - 0.12 = 0.37$ m/s。

注⑧（第 18、28 题）：
18. 5 个点 4 个间隔，$T' = 0.08$ s；误按 0.1 s 算，$a = \frac{\Delta x}{T'^2}$ 分母偏大 → 结果偏小（真值的 0.64 倍）。
28. (a) $v_A = \frac{0.010}{0.020} = 0.50$ m/s；$v_B = \frac{0.010}{0.0080} = 1.25$ m/s。

    (b) $a = \frac{1.25^2 - 0.50^2}{2 \times 0.80} = \frac{1.3125}{1.6} \approx 0.82$ m/s²；验证 $\frac{v_B - v_A}{t} = \frac{0.75}{1.6} \approx 0.47$ m/s²。

    (c) 两结果不等：$v_A$、$v_B$ 是两门位置的速度，而 $t$ 是"两挡光事件之间"的时间，两者不对应同一段过程（挡光发生在门位置附近，计时起点终点错位），且平均加速度≠瞬时加速度在变加速下不成立——以 $v^2$ 关系为准。

注⑨（第 19、29 题）：
19. $x_n = v_1(n-1)T' + \frac{1}{2}aT'^2 \cdot (2n-1)$ 推导太绕，直接用第 n 段初速 $v_{n-1}$：$x_n = v_{n-1}T' + \frac{1}{2}aT'^2$，$x_{n+1} = v_nT' + \frac{1}{2}aT'^2 = (v_{n-1} + aT')T' + \frac{1}{2}aT'^2$，相减 $x_{n+1} - x_n = aT'^2$ ✓。
29. 翘起 → 挡光片扫过的有效宽度 > 真实 d → 分子虚高 → 测得速度偏大 → 两门都偏大，但门 B 处速度大、同一角度下 B 门的有效宽度增量绝对值占比更小（比例误差 $\frac{\delta d}{d}$ 相同），两速度近似同比例偏大 → $a = \frac{v_B^2 - v_A^2}{2L}$ 偏大的幅度近似为速度偏差的两倍比例——偏差方向：a 偏大；主修正：重新安装平行。

注⑩（第 20、26、30 题）：
20. 优点：异常点一眼可见可舍弃；直线拟合利用全部数据摊薄偶然误差。
26. 减偶然误差：多次测量取平均；修正系统误差方向：检查挡光片是否平行（消除 d 虚高）。
30. 开放题，要点对照：甲方案误差来自摩擦+阻力（系统、偏小）、操作简单但要处理纸带；乙方案无接触、精度高（毫秒级），误差主要是光电门安装与挡光计时，操作对调平/对准敏感。任选一套、三条理由自洽即可。

（第 28 题为开放编题作业的对照组：本单元第 30 题即开放设计题，答案以"三方面比较齐全、结论自洽"为合格标准。）
