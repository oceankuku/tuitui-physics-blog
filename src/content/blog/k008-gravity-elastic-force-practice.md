1. A。

依据：

　　A 对。弹簧秤的原理是胡克定律，测的是拉力（弹力）的大小，不依赖重力。

　　B 错。天平靠两盘重力对横梁的力矩平衡工作，重力消失时两盘质量无论多少都"平衡"，无法称量。

检查：分清"测力的仪器"与"靠重力工作的装置"，一条就能排掉全部干扰项。

2. BD。

依据：

　　A 错。自由下落正是重力作用的结果，下落中重力照常存在。

　　B 对。竖直向下就是与当地水平面垂直向下的方向，两种说法一致。

　　C 错。对绳的拉力是弹力，施力物体是物体；重力的施力物体是地球，两力大小相等、性质不同。

　　D 对。天平比较质量，与地点无关；弹簧测力计测重力，北极的 $g$ 略大，由 $G = mg$ 示数略增。

检查：A、C 都是"把一种力和另一种力画等号"的老坑，性质和施力物体是判断标准。

3. D。

依据：

　　A 错。重心是重力的等效作用点，与"哪一点最重"无关。

　　B 错。缺了"质量分布均匀"这个前提，形状规则但一边嵌了铅块的物体重心会偏。

　　C 错。圆环的重心在圆心，可以不在物体上。

　　D 对。静止时重力和绳的拉力二力平衡，两力必须沿同一条直线，重力作用线即悬线所在直线，重心在这条线上。

检查：D 的依据就是悬挂法找重心的原理，把"为什么"说全才算真懂（对照第 5 题）。

4. D。

依据：

　　A 错。桌面形变要恢复原状，给书的是向上的支持力，方向说反。

　　B 错。桌面形变产生的弹力作用在书身上，不能作用在桌面自己身上。

　　C 错。书形变产生的弹力作用在桌面上，不是给书。

　　D 对。书底面被压凹，恢复原状时向下弹，给桌面向下的压力。

检查：口诀式的"谁形变，力给对方"在这里两面验证——施力物体形变、受力物体是对方。

5. 二力平衡。

依据：物体被悬挂静止时，只受重力和细线的拉力，二力平衡要求两力等值、反向、共线；拉力沿细线，所以重力作用线也必沿细线所在直线，重心在这条线上。换一个位置再悬一次，两条直线的交点即重心。

检查：只答"平衡"得一半，答出"两力共线、重力作用线过悬点"才完整（对照第 3 题 D 项）。

10. C。

依据：形变量 $x = l - l_0$，由胡克定律 $F = kx$ 得

:::formula
k = \frac{F}{x} = \frac{F}{l - l_0}
:::

检查：A、B 的分母分别用了原长和现长——$k$ 的定义里只有形变量，分子分母要对"同一件事"（力除以它造成的伸长）。

11. B。

依据：两只轻弹簧秤挂钩串联，平衡时弹力沿整条链处处相等，都等于外拉的 100 N，所以两秤示数都是 100 N。乙秤的示数不是"甲推它的力的一半"，也不需要把两秤的读数相加。

检查：把乙秤想成一段轻绳最直观——绳上各处张力相等，弹簧秤只是把张力读出来。

12. B。

依据：钩码静止，弹簧弹力与钩码重力平衡，$F = G = 2.0$ N。由胡克定律

:::formula
x = \frac{F}{k} = \frac{2.0\ \text{N}}{10.0\ \text{N/cm}} = 0.2\ \text{cm}
:::

即伸长量为 0.2 cm。选项把"长度"与"伸长量"对调，A、C 都偷换了概念；弹簧原长未知，长度本就求不出。

检查：看到 N/cm 不要慌着换成 N/m，分子分母单位一致即可；要盯的是"问的是长度还是伸长量"。

13. A。

依据：

　　读图丙。两线都过原点，横轴是新弹簧整体的伸长量，斜率即新弹簧的劲度系数：$a$ 线过 $(0.1\ \text{m},\ 2\ \text{N})$，$k_a = 20$ N/m；$b$ 线过 $(0.4\ \text{m},\ 2\ \text{N})$，$k_b = 5$ N/m。

:::formula
k_a = \frac{2\ \text{N}}{0.1\ \text{m}} = 20\ \text{N/m}
:::

　　定身份。并联组合比单根硬、串联组合比单根软，所以 $a$ 是甲图（并联）、$b$ 是乙图（串联），D 错。设每根弹簧劲度系数为 $k_0$：并联 $k_a = 2k_0 = 20$ N/m，得 $k_0 = 10$ N/m；再用 $b$ 线验证：串联 $k_b = \frac{k_0}{2} = 5$ N/m，与读图一致——两条线自洽，说明读图没读错。

　　判选项。

　　A 对。甲图并联，$F = 2$ N 时整体伸长 $\frac{2\ \text{N}}{20\ \text{N/m}} = 0.1\ \text{m}$；并联的两根弹簧伸长量相同，每根都伸长 0.1 m。

　　B 错。乙图串联，每根弹簧受的都是全部拉力 2 N，每根伸长 $\frac{2\ \text{N}}{10\ \text{N/m}} = 0.2\ \text{m}$，不是 0.1 m。

　　C 错。每根弹簧 $k_0 = 10$ N/m；20 N/m 是并联组合的值，不是单根的。

检查：这类题最值钱的一步是"两线互验"——先由陡线定 $k_0$，再回头核对缓线；对不上说明读错了线。并联分力、串联传力，选项里的"0.1 m 还是 0.2 m"全由这一句决定。

14. 并联 $F = 2k\Delta x$；串联 $F = k\Delta x$。

依据：

　　并联：两根弹簧并排，形变量同为 $\Delta x$，每根弹力都是 $k\Delta x$，外力由两根共同承担：

:::formula
F = k\Delta x + k\Delta x = 2k\Delta x
:::

　　串联：两根弹簧首尾相连，轻弹簧各段弹力相等，每根都受全部外力，每根形变 $\Delta x$：

:::formula
F = k\Delta x
:::

检查：并联"分力"、串联"传力"——同样的形变量，一个除以二、一个不除，这正是第 13 题两条图线一陡一缓的原因。

15. (1) $1.8x$；

　　(2) $\frac{x_1 + x_2}{4}$。

依据：

　　(1) 均匀弹簧截去 $\frac{1}{10}$，长度变为原来的 $\frac{9}{10}$，劲度系数变为原来的 $\frac{10}{9}$（越短的弹簧越硬）：

:::formula
k' = \frac{G}{\frac{9}{10}x} = \frac{10G}{9x}
:::

挂 $2G$ 时伸长量

:::formula
x' = \frac{2G}{k'} = \frac{2G \times 9x}{10G} = 1.8x
:::

　　(2) 滑轮两侧轻绳拉力相等，两根弹簧各受 $\frac{G}{2}$：$a$ 伸长 $\frac{x_1}{2}$，$b$ 伸长 $\frac{x_2}{2}$。滑轮下降时，绳两端分别下移这两段伸长量，动滑轮居中，下降距离为两端下移量的平均：

:::formula
d = \frac{1}{2}\left( \frac{x_1}{2} + \frac{x_2}{2} \right) = \frac{x_1 + x_2}{4}
:::

检查：(1) 的关键在"截短后的 $k$ 变大"，若把新弹簧仍按原 $k$ 算就会得 $2x$；(2) 的 $\frac{1}{2}$ 来自滑轮两侧平均，漏掉它答案会大一份。

16. D。

依据：轻弹簧的质量为零，无论左端是墙、等值拉力还是运动中的物块，弹簧平衡（或视为轻质）时内部弹力处处等于右端拉力 $F$，与左端状态无关。四根完全相同的弹簧受力相同，由 $F = kx$ 伸长量相同：$l_1 = l_2 = l_3 = l_4$。四个选项中只有 $l_2 = l_4$ 成立，故选 D。

检查：A、B、C 都在"谁比谁大"上做文章，而四个量其实全相等——先证相等，再挑唯一不含"大于"的选项。

17. (1) 8；25。

　　(2) 1.00；1.75。

依据：

　　(1) $F = 0$ 时弹簧处于原长，图线与横轴交点 $x_0 = 8$ cm。在直线上取相距较远的两点 $(8, 0)$ 与 $(40, 8)$，斜率即劲度系数：

:::formula

:::

　　(2) 毫米刻度尺估读到最小分度的下一位，指针示数 1.00 cm。此时弹簧被压缩，形变量

:::formula
\Delta L = 8.00\ \text{cm} - 1.00\ \text{cm} = 7.00\ \text{cm} = 0.0700\ \text{m}
:::

钩码重等于弹簧弹力：

:::formula
F = k\Delta L = 25\ \text{N/m} \times 0.0700\ \text{m} = 1.75\ \text{N}
:::

检查：本实验横轴是弹簧长度，截距是原长、不是"第一个数据点"；算压缩量用 8.00 减 1.00，别拿 1.00 直接当代形变量。

18. D。

依据：

　　初始状态。$a$ 压在弹簧 $P$ 上，$P$ 的弹力等于 $a$ 的重量，压缩量 $\frac{G}{k}$；$b$ 下面的弹簧 $Q$ 承托 $a$、$b$ 两者，压缩量 $\frac{2G}{k}$。

　　末状态。$Q$ 刚脱离地面时弹力恰好为零、恢复原长；$b$ 由 $P$ 拉住，$P$ 的弹力等于 $b$ 的重量，伸长量 $\frac{G}{k}$。

　　求上升高度。$P$ 由压缩 $\frac{G}{k}$ 变到伸长 $\frac{G}{k}$，长度变化

:::formula
\Delta L_P = \frac{G}{k} + \frac{G}{k} = \frac{2G}{k}
:::

$Q$ 由压缩 $\frac{2G}{k}$ 变到原长，$b$ 上升

:::formula
h_b = \frac{2G}{k}
:::

$a$ 的高度变化等于 $b$ 的上升量加上 $P$ 自身的长度变化：

:::formula
h_a = h_b + \Delta L_P = \frac{2G}{k} + \frac{2G}{k} = \frac{4G}{k}
:::

故选 D。

检查：最容易在"P 的长度变化"上丢一截——从压缩 $\frac{G}{k}$ 到伸长 $\frac{G}{k}$ 跨了两个 $\frac{G}{k}$，只算一半就选了 B。画一条"初始—末态"的位置示意图，两个弹簧行行对齐，答案不容易漏。

:::

　　(2) $\Delta L_i = L_{i+3} - L_i$ 是相差 3 个钢球的两组读数之差，所以平均值对应管中增加 3 个钢球的压缩量。

　　(3) 球在斜管中静止，弹簧弹力沿管轴方向与 $n$ 个球重力沿管的分力平衡。3 个球的分力为 $3mg\sin 30°$，由胡克定律

:::formula
k = \frac{3mg\sin 30°}{\overline{\Delta L}} = \frac{3 \times 0.200\ \text{kg} \times 9.80\ \text{m/s}^2 \times 0.5}{0.0605\ \text{m}} \approx 48.6\ \text{N/m}
:::

检查：分子是"3 个球"的分力、分母是"3 个球"的压缩量，两个 3 对齐才不出错；$\sin 30°$ 别代成 $\cos 30°$。

20. (4) 15.35。

　　(5) 约 127（125～130 均可，题源参考答案 128）。

依据：

　　(4) 刻度尺最小分度 1 mm，估读到下一位，读数 $l = 15.35$ cm。

　　(5) 表中相邻两次的长度差依次为 1.51、1.52、1.51、1.51 cm，即每加 5 枚硬币橡皮筋伸长约 1.51 cm。图线上取相距较远的两组数据算斜率，每枚硬币对应

:::formula
\frac{16.56\ \text{cm} - 10.51\ \text{cm}}{25 - 5} = 0.3025\ \text{cm/枚}
:::

外推到 $n = 0$ 得橡皮筋原长

:::formula
l_0 = 10.51\ \text{cm} - 5 \times 0.3025\ \text{cm} \approx 9.00\ \text{cm}
:::

放入玩具后橡皮筋的伸长量对应"等效硬币数"

n' = \frac{15.35\ \text{cm} - 9.00\ \text{cm}}{0.3025\ \text{cm/枚}} \approx 21.0
:::

玩具质量
