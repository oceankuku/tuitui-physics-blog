孩子放学回家，转述的物理第一课很可能是这样的：我们老师说了，地球是一个点。家长第一反应是孩子听岔了，第二反应是老师是不是口误。过两天孩子又补了一句：乒乓球反而不能当成一个点。得，更糊涂了。

孩子没听岔，这就是高中物理第一课《质点 参考系》的内容。它不讲公式、不算数，只干一件事，教你把真实世界简化成物理能处理的样子。听着玄，其实是全书最讲道理的一节，判断标准就一条。这一条没吃透，后面的题目会换着花样回来收利息，高考也年年在这里放送分题，就看你接不接得住。

从这篇起，按人教版教材一节一篇往下写，课堂讲到哪，文章写到哪。这是系列第一课，欢迎上车。

## 这篇的路线图，先看一眼再往下走

先说清楚：这一节远不止"质点""参考系"两个名词。完整的一节还包括 6 道例题、6 道练习、两张"判断卡"，这才是高考真把它当考点考的样子。整篇骨架：

- 知识点一：质点——什么时候能把物体缩成一个点（地球能、乒乓球不能的那个判断标准），配 3 道例题 + 3 道练习；
- 知识点二：参考系——说"动"之前为什么要先选标准（高铁看邻线的那个困惑），同样 3 道例题 + 3 道练习；
- 经典题型：把前面所有判断动作收成两张"判断卡"，考场拿到题照着走；
- 物理学史：亚里士多德的"重快轻慢"为什么统治两千年，伽利略的大船怎么逼出"先选标准，再谈动"。

每道题的来源都标在题干首行，高考真题和经典讲义题分得清清楚楚，题目用卡片框出来，答案解析单独一张卡片，练完当场对。中途看到琥珀色小卡片是"备注"，放深度理解，赶时间的家长可以跳过，不碍主线。

好，从质点开始。开始之前，先讲一段历史：这一节要立的两个规矩，都是两千年里吵出来的。

## 物理学史：亚里士多德、伽利略与那艘大船

公元前四世纪，亚里士多德在《物理学》里给运动下过两条断语：物体越重，下落越快；要让东西一直动，就得一直推。这两句话跟日常经验严丝合缝，马车不推就停，铁球确实比羽毛落得快，所以统治了西方将近两千年。它的问题不在观察，在于没把空气阻力和摩擦从现象里剥出去，把"被干扰的样子"当成了规律本身。

十七世纪的伽利略换了打法：先想清楚该测什么。他用斜面"冲淡"重力，让运动慢到可测，再用水钟（据说赶时间就用脉搏）计时，发现小球滚过的距离跟时间的平方成正比；把斜面越抬越陡，规律不变，于是外推：没有阻力的自由下落，也该是这样"均匀变快"的运动。这套"实验加推理"的组合拳，到自由落体那一讲我们再完整拆一遍。

参考系的思想，藏在伽利略《关于两大世界体系的对话》里那艘大船：船匀速行驶时，舱里的水滴竖直落下、蝴蝶照常飞，你在船舱里做任何实验，都判断不出船是停着还是在匀速前进。也就是说，"动没动"从来不是物体一个人的事，必须先说清拿谁当标准。这条后来被称作"伽利略相对性原理"的思想，由牛顿写进了力学的地基，也正是这一节"先选参考系"的源头。

顺带记一个方法论：亚里士多德不是输在不聪明，是输在没有"模型"这层意识，把真实世界里删不掉的阻力、摩擦，先在脑子里删掉，才看得清主干规律。下面要讲的质点，就是我们删出来的第一个模型。

## 知识点一：质点——地球什么时候能缩成一个点

质点的定义一句话：用来代替物体的、有质量的点。它是理想化模型，现实中不存在，物理书也从来不会真把地球捏成一个点。造这个概念，是为了让问题算得动。

![老师板书讲解质点与参考系：质点是用有质量的点代替物体，条件是形状和大小对所研究问题的影响可以忽略](/blog-images/k001-mass-point-reference-frame/point-reference-frame-concepts.png)

图 1｜质点与参考系板书：形状和大小对所研究问题的影响能否忽略

板书上的判定条件就是全节唯一的裁判：形状和大小对所研究问题的影响，能不能忽略。下面用数字把这个标准演一遍。

看一个数字对比就明白。研究地球绕太阳公转，地球直径约 1.3 万公里，公转轨道半径约 1.5 亿公里，差一万多倍。悬殊到这个地步，地球多大、什么形状，对轨道计算毫无影响，把它缩成一个带质量的点，规律一下子清爽了。

所以能不能看成质点，跟物体本身大不大没关系，只看一件事：它的大小和形状，对眼下研究的这个问题有没有影响。有影响就不能，没影响或者小到可以忽略就能。

同一个地球，问题一换，答案立刻反转。研究公转，能缩成点；研究自转，比如各地为什么有昼夜交替，研究的就是它身上每个点怎么转，缩成点就什么都没了，不能。

火车也一样。算它过桥要多久，从车头上桥到车尾离桥，桥长之外还得把车长搭进去，车长丢不得，不能看成质点；算它从北京到广州要几个小时，几百米的车身对一千多公里的路程，可以忽略，能。

有三个误区顺手清掉。第一，"小的就能看成质点"？乒乓球够小，研究它的旋转时偏偏不能，旋转研究的是球面各点的运动，缩成一个点，连"转"都谈不上了。第二，"大的就不能"？地球够大，公转照样能。第三，"质点是个真实存在的小点"？它压根不存在，是模型。判断的裁判始终只有一位：大小形状对这个问题的影响，能不能忽略。

![老师板书易错对照：物体大小不是判定质点的依据，关键看形状和大小对所研究问题的影响能否忽略](/blog-images/k001-mass-point-reference-frame/size-vs-motion-misconception.png)

图 2｜易错对照：物体大小不是判定质点的依据

还有条经验规律：物体平动（各部分步调一致地整体移动）时通常能看成质点，带转动的场合一般不能。它能解释大半判断题，但最终还是要回到上面那条标准。

### 例题一

:::problem
<span class="prob-grade">1.【基础题·易错题·选择题】</span> <span class="prob-source">（学而思高一暑期讲义·第 1 讲《运动的描述》）</span>

2014 年索契冬奥会的赛场上：冰壶运动员需要运用多种旋转技术把冰壶推出去，冰球运动员需要用力将冰球打入对方大门，短道速滑运动员在弯道处要控制好身体的倾斜程度，自由式滑雪运动员在高空中要做出各种高难度翻转。在这些项目中，研究对象可以看成质点的是（　）


　　A. 冰壶比赛中运动的冰壶


　　B. 冰球比赛中运动的冰球


　　C. 短道速滑中的运动员


　　D. 高空翻腾技巧运动中的运动员
:::

:::answer
答案：B。

逐项看一遍，每一项错在哪：

　　A 错。冰壶的看点恰恰在旋转：出手时怎么旋、擦冰之后走什么弧线，靠的是壶体各处运动的差异。缩成一个点，旋转的信息全没了。

　　B 对。判断冰球能不能进门，只关心它整体飞向球门的快慢和路线。冰球多大、什么形状，不碍这件事。大小形状可以忽略，能看成质点。

　　C 错。"倾斜程度"说的就是身体姿态，人一缩成点，倾斜无从谈起。

　　D 错。空中技巧的评分对象就是翻转动作本身，动作跟着点一起消失。
:::

:::note
备注：这题四个选项全在冬奥赛场，区别不在运动员还是器械，在"研究的问题"。冰壶和冰球都是"球"，一个研究转、一个研究飞，结论就分了岔。看到"质点"两个字，先圈出研究的问题，这个动作从第一道例题就开始练。
:::

### 例题二

:::problem
<span class="prob-grade">2.【基础题·易错题·选择题】</span> <span class="prob-source">（学而思高一暑期讲义·第 1 讲《运动的描述》）</span>

关于物体的运动，下列说法正确的是（　）


　　A. 研究大巴从北京开往上海的时间，不能将大巴视为质点


　　B. 研究大巴路过一棵树的时间，可以将大巴视为质点


　　C. 研究子弹射中目标的轨迹，可以将子弹视为质点


　　D. 研究子弹在枪管中的运动姿态，可以将子弹视为质点
:::

:::answer
答案：C。

逐项看：

　　A 错。北京到上海一千多公里，十几米的大巴丢掉不影响"要多久"这个数，能看成质点。"不能"两个字说反了。

　　B 错。"路过一棵树"的时间，从车头对齐树干数到车尾离开，走的就是车长。车长是主角，丢不得，不能看成质点。

　　C 对。轨迹只记录子弹整体飞到过哪里，它自转与否不影响这条线。大小形状对这个问题没有影响，能。

　　D 错。枪管里的来复线让子弹旋着前进，"姿态"研究的就是它怎么旋、朝向怎么摆，缩成点就什么都没了。
:::

:::note
备注：这题里同一辆大巴出场两次：跑长途时是"点"，路过一棵树就成了"尺子"。能不能简化，不看东西本身的尺寸，看它跟研究的问题比起来大不大。题干里出现"过标、过树、过桥、穿缝"这类词，就是尺寸登场的信号。
:::

### 例题三

:::problem
<span class="prob-grade">3.【基础题·易错题·选择题】</span> <span class="prob-source">（学而思高一暑期讲义·第 1 讲《运动的描述》）</span>

下面关于质点的说法正确的是（　）


　　A. 能够看成质点的物体必须体积足够小


　　B. 能够看成质点的物体必须质量足够小


　　C. 只有物体各部分运动情况都相同，才能将它看成质点


　　D. 我们只关注物体整体的运动时，就可以把它看成质点
:::

:::answer
答案：D。

　　A 错。地球体积够大，研究公转照样能简化。体积不是门槛。

　　B 错。判断标准里根本没有"质量小"这一条，质量大小跟简化无关。

　　C 错。"只有……才"把话说得太满。地球公转时各部分运动并不完全相同（它还在自转），公转问题照样能把地球缩成点。各部分运动情况相同（平动）时通常能简化，但它不是必要条件。

　　D 对。只关注整体的运动，正是"大小形状碍不着这件事"的场合，可以简化。
:::

:::note
备注：这题的陷阱藏在句式里。A、B、C 都把话说满了："必须""只有……才"。判断题里见到一刀切的词，最快的检验办法是找一个反例——地球够大照样能简化，A、B 就塌了；带着自转的公转照样能简化，C 就塌了。D 说的就是那条唯一的裁判，所以对。
:::

### 练习一

:::problem
<span class="prob-grade">4.【基础题·易错题·选择题】</span> <span class="prob-source">（学而思高一暑期讲义·第 1 讲《运动的描述》）</span>

关于质点，下列说法中正确的是（　）


　　A. 质点是一个理想化模型，实际上并不存在，因此没有物理意义


　　B. 只有体积很小的物体才能看作质点


　　C. 物体的形状和大小对所研究的问题可以忽略时，可把物体看作质点


　　D. 轻小的物体，都可以看作质点
:::

:::answer
答案：C。

　　A 错。前半句对，后半句错。质点确实不存在，但它是把真实世界简化成能算的问题的关键工具，意义就在这里。

　　B 错。"只有……才能"又是绝对化表述。地球体积大，研究公转时照样能看作质点。

　　C 对。这就是那条唯一的判断标准，一个字都不用改。

　　D 错。轻小的物体研究旋转时照样不能简化，"轻"不在判断标准里。

真正的依据只有一个：大小形状对所研究问题的影响能否忽略。
:::

### 练习二

:::problem
<span class="prob-grade">5.【基础题·经典题·计算题】</span> <span class="prob-source">（2002 年上海卷）</span>

研究物理问题时，常常需要忽略某些次要因素，建立理想化的物理模型。例如"质点"模型忽略了物体的体积、形状，只计其质量。请再写出两个你所学过的物理模型的名称。
:::

:::answer
答案：写出任意两个即可，如光线、磁感线（初中学过）；点电荷、轻弹簧、理想气体（后面会学到）。

模型的共同套路是"抓住主要因素，忽略次要因素"。光线忽略了光的宽度，只留下传播路径；磁感线是为了描述磁场画出来的假想曲线，磁场里并没有真实的线。当年参考答案给的两个是点电荷（把带电体缩成一个带电的点）和理想气体（忽略分子自身体积和分子间的作用力），这两个模型你到高一后面和高二会正式见到。现在只需要记住：物理模型不是"骗人"，是让问题算得动。
:::

### 练习三

:::problem
<span class="prob-grade">6.【基础题·经典题·计算题】</span> <span class="prob-source">（改编自学而思高一暑期讲义·第 1 讲"格尔木—拉萨列车"情境，数据为改编补充）</span>

一列长 400 m 的列车沿铁路从格尔木开往拉萨，全程约 1100 km，平均每小时行 88 km，途中还要以 20 m/s 的速度匀速通过一座长 1600 m 的大桥。


　　(1) 估算全程运行时间；算这个时间时，能把列车看成质点吗？


　　(2) 从车头上桥到车尾离桥需要多长时间？算这个时间时，还能把列车看成质点吗？
:::

:::answer
答案：

　　(1) 约 12.5 小时，能；

　　(2) 100 s，不能。


　　(1) 全程时间按"路程除以速度"算：$t = \frac{1100}{88}$ h $= 12.5$ h。这道题里，车长 400 m 摆在 1100 km（一百多万米）的全程面前，只占万分之几，连零头都算不上。大小形状对"全程要多久"没有影响，能把列车看成质点。


　　(2) 从车头上桥到车尾离桥，列车要走的路程是桥长加车长：

$s = 1600\ \text{m} + 400\ \text{m} = 2000\ \text{m}$，

用时 $t = \frac{s}{v} = \frac{2000}{20}$ s $= 100$ s。

这时要是把列车缩成一个点，路程就只剩桥长 1600 m，算出 80 s，比真实时间少了 20 s，误差两成。车长足有桥长的四分之一，丢不得，不能看成质点。

同一列车，问"全程多久"时是点，问"过桥多久"时就得是整列车。能不能简化，永远由问题说了算。
:::

## 知识点二：参考系——不先选标准，连"动"都说不清

先看个场景。你坐在高铁里，邻线一列车缓缓向后退，你以为自己的车开了，低头看站台，才发现动的是邻线。同一个画面，两套结论，分歧出在哪？出在拿谁当标准。

![老师手持列车模型与站台模型讲解参考系：乘客相对车厢静止、相对站台运动，描述运动前先选参考系](/blog-images/k001-mass-point-reference-frame/train-platform-reference-frame.png)

图 3｜参考系板书：同一乘客，相对车厢静止、相对站台运动

图里这块板书就是全节题眼：同一节车厢里的乘客，拿车厢当标准，他一动没动；拿站台当标准，他一路向东。描述运动之前，先得说清拿谁当标准。

物理学把这件事说得很干脆：用来作参考、判断物体动没动的物体，叫参考系。不选参考系，"运动"两个字根本无从谈起。

参考系有两条脾气。一是选择任意，原则上任何物体都能当参考系，唯独不能选研究对象自己（自己跟自己比，永远静止，等于没比）。二是描述相对，同一个运动，换参考系结论可以完全不同，高铁上那一幕就是证据。地面上研究运动，不作特别说明时默认以地面为参考系，这是全世界的约定俗成。

这一节还有个高频结论叫相对静止：两个物体速度大小、方向都相同，互为参考系时彼此就是静止的。飞行员能伸手抓住身边飞过的子弹、并行扶梯上的人互看静止，全是这句话的应用，后面例题和练习里挨个见。

高考在这里的考法常见两种：给一段描述，判断说的是谁看谁；换一个参考系，看结论怎么翻。例题四、例题五一种配一题，例题六再往前多走一步。

### 例题四

:::problem
<span class="prob-grade">7.【基础题·经典题·选择题】</span> <span class="prob-source">（学而思高一暑期讲义·第 1 讲《运动的描述》，删去配图）</span>

相传，第一次世界大战期间，一名法国飞行员在高空驾机飞行时，感觉身边好像有一只小昆虫在游动，他顺手抓过来一看，竟然是一颗子弹。如果这个故事是真实的，那么故事中的情景可以说明（　）


　　A. 子弹是静止在空中的


　　B. 子弹的飞行像小昆虫在游动一样，速度很小


　　C. 飞机飞行的速度比子弹运动的速度大很多


　　D. 子弹与飞机同方向运动，且它们的速度大小很接近
:::

:::answer
答案：D。

先立一个事实：子弹在飞行员眼里"像小昆虫在游动"，意味着它跟飞机之间的距离几乎不变——以飞机为参考系，子弹几乎静止。

　　A 错。静止是相对的。以地面为参考系，子弹正以几百米每秒飞行，没有"静止在空中"这回事。

　　B 错。觉得慢是因为相对速度小，不是子弹本身慢。对地面它照样是一颗高速子弹。

　　C 错。要是飞机比子弹快很多，两者的距离会迅速拉开，飞行员只能看着它远去，抓不着。

　　D 对。同方向、速度大小接近，相对位置才几乎不变，子弹才能像悬停在身边一样被随手抓走。这就是相对静止。
:::

:::note
备注：抓子弹的物理内核就一句：相对位置不变，互看都静止。飞行员靠的不是手快，是选对了参考系——他和子弹根本没在相对运动。判断的抓手永远是：看它们俩的相对位置变没变。
:::

### 例题五

:::problem
<span class="prob-grade">8.【基础题·常考题·选择题】</span> <span class="prob-source">（学而思高一暑期讲义·第 1 讲《运动的描述》）</span>

火车在铁路上运动，人坐在火车里。下列说法中正确的是（　）


　　A. 以大地为参考系，人是静止的，而火车是运动的


　　B. 以人为参考系，大地是运动的，火车也是运动的


　　C. 以火车为参考系，人是静止的，而大地是运动的


　　D. 以人为参考系，火车是静止的，大地也是静止的
:::

:::answer
答案：C。

判断动作就两步：先定标准，再比位置。四个选项换了三个标准，逐个来：

　　A 错。以大地为标准，人随火车一起跑，位置一直在变，人也是运动的。

　　B 错。以人为标准，火车跟人一起走，位置不变，火车是静止的。"也是运动的"错了一半。

　　C 对。以火车为标准，人坐着没挪窝，静止；大地不断向后退，运动。

　　D 错。半对半错最迷惑：火车对人确实静止，但大地对人的位置一直在变，是运动的。
:::

:::note
备注：同一节车厢、同一个人，换一个标准，动静就翻一次。A、B、D 都在"半对"里埋了雷——参考系题要按选项逐句核对，每换一个标准就重新比一次位置，别被前半句带跑。
:::

### 例题六

:::problem
<span class="prob-grade">9.【提升题·经典题·选择题】</span> <span class="prob-source">（2022 年辽宁卷）</span>

如图 4 所示，桥式起重机主要由可移动"桥架""小车"和固定"轨道"三部分组成。在某次作业中桥架沿轨道单向移动了 8 m，小车在桥架上单向移动了 6 m。该次作业中小车相对地面的位移大小为（　）

![2022 年辽宁卷题图：桥式起重机实景与装置示意，桥架沿轨道行驶，小车在桥架上行驶](/blog-images/k001-mass-point-reference-frame/orig-9-crane-device.png)

图 4｜题 9 装置图：桥架沿轨道单向移动，小车在桥架上沿垂直于轨道的方向单向移动


　　A. 6 m


　　B. 8 m


　　C. 10 m


　　D. 14 m
:::

:::answer
答案：C。

小车的运动分两层：它先随桥架沿轨道走了 8 m，又自己沿垂直于轨道的方向在桥架上走了 6 m。两个位移互相垂直，合位移从起点直指终点，用勾股定理合成，得 10 m（算式见答案卡下方的公式块）。

　　A 错。只算了小车在桥架上自己走的那段，把随桥架走的 8 m 丢了。

　　B 错。只算了桥架载着它走的 8 m，把小车在桥架上的 6 m 丢了。

　　C 对。两个互相垂直的位移勾股合成，10 m。

　　D 错。把两段直接相加得 14 m，那是路程的算法。位移要从起点直指终点，两段互相垂直时走勾股，不走加法。
:::

合成这步的算式：

:::formula
s = \sqrt{8^2 + 6^2}\ \text{m} = \sqrt{100}\ \text{m} = 10\ \text{m}
:::

:::note
备注：这道题里参考系分了两层：小车相对桥架走 6 m，桥架又载着它相对地面走 8 m。先把"跟着载体走"的算一遍，再算"自己走"的，最后合成——这是参考系思想的第一次实战。合成用的是初中学过的勾股定理；完整的矢量合成到后面的章节才正式学，这里看懂"分层再合成"这个思路就够了。
:::

### 练习四

:::problem
<span class="prob-grade">10.【提升题·易错题·选择题】</span> <span class="prob-source">（学而思高一暑期讲义·第 1 讲《运动的描述》）</span>

两列火车平行地停在同一站台上。过了一会儿，甲车内的乘客发现窗外树木在向西移动，而乙车内的乘客发现甲车仍然没有动。以地面为参考系，上述事实说明（　）


　　A. 甲车向东运动，乙车静止


　　B. 乙车向东运动，甲车静止


　　C. 甲车向西运动，乙车向东运动


　　D. 甲、乙两车以相同的速度向东运动
:::

:::answer
答案：D。

两条观察倒着推，一步一步来。

第一句：树木长在地上，对地面本来静止。甲车乘客看树向西退，说明甲车相对地面向东走——窗外景物向后跑，正是你自己在向前的证据。

第二句：乙车乘客看甲车不动，说明甲、乙相对位置不变，两车同速同向。甲对地面向东，乙也跟着对地面向东。

　　A 错。乙若静止，甲车乘客看乙车应当向西退，跟"甲车没动"的观察矛盾。

　　B 错。甲车明明在动，树木西退就是证据。

　　C 错。方向推反了：树向西退，对应的恰恰是甲车向东。

　　D 对。两条观察拼出来的唯一结论。
:::

### 练习五

:::problem
<span class="prob-grade">11.【基础题·易错题·选择题】</span> <span class="prob-source">（学而思高一暑期讲义·第 1 讲《运动的描述》）</span>

地面上的人看雨滴竖直下落。坐在匀速行驶的列车车厢里的乘客，看到的雨滴是（　）


　　A. 向前运动


　　B. 向后运动


　　C. 倾斜落向前下方


　　D. 倾斜落向后下方
:::

:::answer
答案：D。

以乘客为参考系，雨滴身上叠着两个运动：竖直方向，它照旧下落；水平方向，列车向前走，雨滴相对列车就在向后退。两个运动合起来，雨滴斜着往后下方落。

　　A、B 错。只看到水平或竖直中的一个，丢了另一个。

　　C 错。前后方向搞反了：是车在向前走，不是雨滴在向前冲。

　　D 对。向后，加上向下，就是后下方。
:::

### 练习六

:::problem
<span class="prob-grade">12.【提升题·常考题·选择题·多选】</span> <span class="prob-source">（学而思高一暑期讲义·第 1 讲《运动的描述》，方向说明已写入题干）</span>

商场里，甲、乙、丙三人各乘一部自动扶梯。三部扶梯互相平行、倾角相同、运行速率相同，水平方向都朝同一侧移动：甲乘下行扶梯从二楼到一楼，乙乘下行扶梯从三楼到二楼，丙乘上行扶梯从一楼到二楼。下列说法正确的是（　）


　　A. 乙相对丙静止，相对甲运动


　　B. 乙相对甲静止，相对丙运动


　　C. 甲与丙在竖直方向上是相对静止的


　　D. 甲与丙在水平方向上是相对静止的
:::

:::answer
答案：BD。

三部扶梯同侧、同倾角、同速率，每个人的速度都可以拆成相同的水平分量和大小相等的竖直分量；甲、乙的竖直分量向下，丙的向上。

　　A 错。乙对丙，一个向下一个向上，竖直方向的间隔一直在变，是相对运动——前半句就错了。

　　B 对。乙和甲同为下行、速率相同，每个方向的间隔都不变，相对静止；乙和丙竖直方向一个向下一个向上，相对运动。

　　C 错。甲向下、丙向上，竖直方向间隔越拉越远，是相对运动。

　　D 对。三人水平方向的分速度完全相同，甲和丙的水平间隔始终不变，水平方向相对静止。
:::

## 题型精讲：两张判断卡，拿到题按步骤走

质点和参考系的题目不考计算，考的是判断动作标不标准。两张判断卡收好，考场上照着走就行。

### 题型一：质点判断，先看问题再看物

三步：研究对象是谁，研究的问题是什么，大小形状碍不碍这件事。第三步一锤定音。

示范：下面两个判断对不对？

一，研究花样滑冰运动员整套动作的编排，把她看成质点。错，研究的正是肢体怎么动，人缩成点，编排就没法看了。

二，研究地铁从起点站到终点站的用时，把列车看成质点。对，全程十几公里，百米级的车长可以忽略。

同一位运动员、同一列车，问题一换，结论就换。再给一张场景速查表，判断题的常见配置全在里面：

| 场景 | 能否看成质点 | 一句话原因 |
| --- | --- | --- |
| 地球绕太阳公转 | 能 | 直径远小于轨道半径 |
| 地球自转 | 不能 | 研究的就是身上各点的转动 |
| 火车过桥、过隧道 | 不能 | 车长要计入路程 |
| 火车跨城运行时间 | 能 | 车长远小于全程 |
| 乒乓球、羽毛球的旋转 | 不能 | 旋转靠形状和各点差异 |
| 跳水、体操等动作研究 | 不能 | 动作本身就是研究对象 |

### 题型二：参考系判断，先问以谁为标准

两步：这段描述拿谁当标准；换个标准，结论往哪边翻。

示范：空中加油机给歼击机空中加油时，两机必须同速同向飞行。以加油机为参考系，歼击机是什么状态？油管为什么能稳稳连着？

答：静止。两机速度相同，相对位置不变，油管两端相当于插在同一个物体上。速度但凡有一丝差别，相对位置就漂移，油管立刻出事。编队飞行、飞船对接、传送带上随动的包裹，全是同一句话的不同穿法。

这一节没有公式要背，就这两张卡。考点看着简单，高考却年年安排，因为它考的是思维习惯：下判断之前，先问对象、问题和标准。这个习惯攒住了，后面加速度那一课会顺手得多。
