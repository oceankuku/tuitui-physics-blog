## 一、先立主线：一座双向桥

先看一个你肯定遇过的场面：冰壶出手后沿冰面滑行，慢慢停下来。问它滑多远，你得先知道它减速多快；问它减速多快，你得先算冰面给它的摩擦力。力和运动就这样咬在一起：力决定加速度，加速度决定速度怎么变，速度又反过来决定你需要多大的力。

把这件事拆开，就是本章的主线问题链：

- 拿到一个动力学问题，先分清"已知"在力这边还是运动这边；
- 力这边的已知量，要经过"合力 → 加速度"这座桥走到运动那边；
- 运动这边的已知量，要经过"加速度 → 合力"这座桥走回力这边；
- 桥不止一段（多阶段）或不止一辆车（多物体）时，桥怎么搭。

### 物理学史一瞥

"力，形之所以奋也。"公元前四世纪，《墨经》已经用八个字点出力是改变物体运动的原因。两千多年后，伽利略用斜面实验清除了"运动需要力来维持"的错觉，牛顿在 1687 年的《自然哲学的数学原理》里把这三条运动定律写成了完整的体系。再往后，18 世纪的欧拉用数学方法把第二定律整理成处理任意受力的普遍工具，工程师靠它算桥、算炮、算机器——定律从"陈述"变成了"方法"。这一单元学的，正是把定律当成方法来用的第一步。

## 二、两类基本问题：框架图

用 $F = ma$ 解决动力学问题，起点和终点只有两种搭配，也就是课本说的两类基本问题（图 1）。

![老师与黑板：动力学两类问题——已知受力求加速度再求运动，已知运动求加速度再求受力，中间都要过加速度这一环](/blog-images/k016-newton-laws-applications/K016-牛顿运动定律的应用-02-概念讲解-动力学两类问题.png)

图 1｜两类基本问题：加速度 $a$ 是双向桥的桥心

- 第一类，已知受力情况求运动情况：先分析物体受哪些力、合力多大，用牛顿第二定律求出加速度，再用运动学公式求速度、位移或时间。路线是"力 → $a$ → 运动"。
- 第二类，已知运动情况求受力情况：先从运动学关系里求出加速度，再回到牛顿第二定律解出某个未知的力。路线是"运动 → $a$ → 力"。

两类问题的正反方向不同，但都绕不开同一个中间量：加速度 $a$。它左连合力、右连运动变化，是整座桥的桥心。所以拿到题，第一反应应该是问自己：我能不能先把 $a$ 找出来？

动手之前还有三件准备工作，每次都要做：

- 定对象：明确研究哪一个物体，把它从情境里"隔离"出来；
- 画受力图：只画这个物体受到的力，每个力说得出施力物体（K010 讲过的规矩）；
- 定正方向：直线运动先声明正方向，各量按正负号代入（K002 的约定）。

## 三、第一类问题：已知力求运动

这类问题的完整流程是四步：受力分析 → 正交分解 → 列 $F = ma$ 求加速度 → 接运动学公式。其中正交分解是关键动作：把每个力沿两个互相垂直的方向分解（通常一个方向沿运动方向），在每个方向上分别列方程。

水平面上的情形最基础。物体在水平面上受重力 $mg$、支持力 $N$、拉力 $F$、摩擦力 $f$ 四个力，竖直方向没有运动，两个力平衡：

:::formula
N = mg
:::

于是水平方向的合力就是 $F - f$，牛顿第二定律写成：

:::formula
F - f = ma
:::

其中 $f$ 是滑动摩擦力时，$f = \mu N = \mu mg$（K009 的结论）；$a$ 一旦求出，运动学三件套（$v = v_0 + at$、$x = v_0 t + \frac{1}{2}at^2$、$v^2 - v_0^2 = 2ax$）随便调用。看一道完整的题，它还多了一层：力在中途变了，运动要分段处理。

### 例题一

:::problem
<span class="prob-grade">1.【基础题·常考题·计算题】</span><span class="prob-source">（自编，与本章课程板书一致）</span>质量 $m = 2$ kg 的物块静止在水平面上，物块与水平面间的动摩擦因数 $\mu = 0.20$。现对物块施加水平向右的恒力 $F = 10$ N，作用 2 s 后撤去。物块在拉力作用阶段始终向右滑动，重力加速度 $g$ 取 10 m/s²。求：

　　(1) 撤去拉力那一瞬间，物块的速度大小；

　　(2) 撤去拉力后，物块继续滑行到停止所需的时间和位移。
:::

![课程板书题面：水平面上的物块先受 10 N 拉力作用 2 s，之后撤去拉力，求撤力时速度与撤力后的时间和位移](/blog-images/k016-newton-laws-applications/K016-牛顿运动定律的应用-05-单物体多阶段-题目.png)

图 2｜例题一题面（课程板书）

:::answer
答案：(1) 6 m/s。(2) 3 s；9 m。

　　① 题型识别。已知力和求运动，且力在中途改变——两个阶段、两套受力，必须分段，每段各求各的加速度。

　　② 步骤模板。每段三步：查这段物体受哪些力 → 沿运动方向列 $F_{\text{合}} = ma$ → 用运动学公式求目标量；两段之间靠"撤力瞬间的速度"衔接。

　　③ 规范解答。摩擦力全程是滑动摩擦力，$f = \mu mg = 0.20 \times 2\ \text{kg} \times 10\ \text{m/s}^2 = 4\ \text{N}$。

阶段一（0～2 s，有拉力），取向右为正方向，由 $F - f = ma_1$ 得：

$a_1 = \dfrac{10\ \text{N} - 4\ \text{N}}{2\ \text{kg}} = 3\ \text{m/s}^2$，撤力瞬间的速度 $v = a_1 t_1 = 3\ \text{m/s}^2 \times 2\ \text{s} = 6\ \text{m/s}$。

阶段二（撤力后），水平方向只剩摩擦力，仍取向右为正，由 $-f = ma_2$ 得：

$a_2 = -\dfrac{4\ \text{N}}{2\ \text{kg}} = -2\ \text{m/s}^2$。停止时间 $t_2 = \dfrac{0 - v}{a_2} = \dfrac{-6\ \text{m/s}}{-2\ \text{m/s}^2} = 3\ \text{s}$，撤力后滑行的位移 $x_2 = \dfrac{0 - v^2}{2a_2} = \dfrac{-36\ \text{m}^2/\text{s}^2}{-4\ \text{m/s}^2} = 9\ \text{m}$。

　　④ 易错点。第 ③ 步撤力后最容易出现两个错：一是以为"力撤了物体立刻停"，忘记速度不能突变；二是摩擦力的正负号——它始终与运动方向相反，取向右为正时必须带负号代入。两个阶段的加速度不同，绝不能拿 $a_1$ 算第二段。

　　⑤ 变式。把"作用 2 s 后撤去"改成"物块前进 6 m 后撤去"，求总位移——运动学条件换了媒介，路径不变：第一段先用 $v^2 = 2a_1 x_1$ 求撤力时速度，其余照旧。
:::

![课程板书解析：两段各自的加速度、撤力时的速度、停止时间与位移，衔接点是速度连续](/blog-images/k016-newton-laws-applications/K016-牛顿运动定律的应用-06-单物体多阶段-解析.png)

图 3｜例题一板书解析：分段求加速度，速度连续衔接

## 四、第二类问题：已知运动求力

把桥反过来走。题目告诉你物体怎么动（匀速、加速、减速、几秒内速度从多少变到多少），你先从运动学关系里把 $a$ 算出来，然后回到受力那边：合力多大、方向朝哪，再逐个解出未知的力。匀速直线运动是这类问题里的特例——$a = 0$，合力为零，直接用平衡条件。

### 例题二

:::problem
<span class="prob-grade">2.【基础题·常考题·选择题】</span><span class="prob-source">（2022 年重庆卷，据真题汇编标注）</span>如图所示，吸附在竖直玻璃上质量为 $m$ 的擦窗工具，在竖直平面内受重力、拉力和摩擦力（图中未画出摩擦力）的共同作用做匀速直线运动。若拉力大小与重力大小相等，方向水平向右，重力加速度为 $g$，则擦窗工具所受摩擦力（　）

![擦窗工具吸附在竖直玻璃上，受水平向右的拉力和竖直向下的重力](/blog-images/k016-newton-laws-applications/fig-l2-window.png)

图 5｜擦窗工具的三力平衡：摩擦力与重力、拉力的合力等大反向

　　A. 大小等于 $mg$

　　B. 大小等于 $\sqrt{2}mg$

　　C. 方向竖直向上

　　D. 方向水平向左
:::

:::answer
答案：B。

　　① 题型识别。已知运动情况（匀速直线运动），求未知的力——第二类问题的特例，加速度为零，直接用三力平衡。

　　② 步骤模板。一画受力图，把已知力按大小方向标出来；二求已知力的合力；三令摩擦力与这个合力等大反向，读出大小和方向。

　　③ 规范解答。重力竖直向下，大小 $mg$；拉力水平向右，大小 $mg$。两个互相垂直的力，合力大小为 $F_{\text{合}} = \sqrt{(mg)^2 + (mg)^2} = \sqrt{2}mg$，方向指向右下方、与水平方向成 45°。匀速运动要求三力平衡，所以摩擦力与这个合力等大反向：大小 $\sqrt{2}mg$，方向斜向左上方、与水平方向成 45°。

　　④ 易错点。第 ③ 步容易凭直觉选 C（"摩擦力托住工具，应该竖直向上"）——竖直向上的力只能平衡重力，平衡不了水平方向的拉力。还有一点值得说清：玻璃给工具的接触力实际包含垂直玻璃的吸附弹力和沿玻璃的摩擦，题目按命题约定把它们统称"摩擦力"，考试按三力平衡处理即可。

　　⑤ 变式。若撤去拉力，工具只在重力和玻璃作用下匀速下滑，摩擦力多大？答：$mg$，竖直向上——运动方向变了，"合力为零"的判据不变。
:::

## 五、斜面动力学专题

斜面是第一、第二两类问题的合练场，也是高考本章的常客。斜面上的麻烦只有一个：重力的方向和运动方向不重合，需要分解。取沿斜面向下为 $x'$ 轴、垂直斜面向上为 $y'$ 轴（图 6），重力沿两个轴分开：

![斜面物块的正交分解：重力分解为沿斜面的 mg sinθ 与垂直斜面的 mg cosθ，另有支持力 N 与沿斜面向上的摩擦力 f](/blog-images/k016-newton-laws-applications/fig-c-incline-forces.png)

图 6｜斜面受力分解：重力拆成沿斜面和垂直斜面两个分量

:::formula
mg\sin\theta \quad（沿斜面向下）,\qquad mg\cos\theta \quad（垂直斜面压向斜面）
:::

垂直斜面方向没有运动，力是平衡的：

:::formula
N = mg\cos\theta
:::

沿斜面方向用牛顿第二定律。物块沿斜面下滑时，滑动摩擦力 $f = \mu N = \mu mg\cos\theta$ 沿斜面向上：

:::formula
mg\sin\theta - \mu mg\cos\theta = ma
:::

其中 $\theta$ 是斜面倾角，$\mu$ 是动摩擦因数。这条方程藏着两个常考的判断：

- 能不能下滑：物块能从静止开始下滑，要求 $mg\sin\theta > \mu mg\cos\theta$，也就是 $\tan\theta > \mu$。反之，$\tan\theta \le \mu$ 时物块可以静止在斜面上。
- 上滑是减速：以初速度沿斜面向上滑时，重力分量和摩擦力都指向下方，$mg\sin\theta + \mu mg\cos\theta = ma$，物块做匀减速运动，直到速度为零——停住之后能不能再滑下来，还要回头用第一条判断。

### 例题三

:::problem
<span class="prob-grade">3.【基础题·常考题·选择题】</span><span class="prob-source">（2022 年北京卷，据真题汇编标注）</span>如图所示，质量为 $m$ 的物块在倾角为 $\theta$ 的斜面上加速下滑，物块与斜面间的动摩擦因数为 $\mu$。下列说法正确的是（　）

![倾角为 θ 的斜面上，一个物块正在加速下滑](/blog-images/k016-newton-laws-applications/orig-2022bj-incline.png)

图 7｜正在斜面上加速下滑的物块

　　A. 斜面对物块的支持力大小为 $mg\sin\theta$

　　B. 斜面对物块的摩擦力大小为 $\mu mg\cos\theta$

　　C. 斜面对物块作用力的合力大小为 $mg$

　　D. 物块所受的合力大小为 $mg\sin\theta$
:::

:::answer
答案：B。

　　① 题型识别。斜面 + 加速下滑，四个说法考的全是"斜面上每个力到底多大"——用图 6 的正交分解逐项核对。

　　② 步骤模板。先写垂直斜面方向的平衡式定支持力，再写滑动摩擦力，最后沿斜面方向写牛顿第二定律，逐项比对。

　　③ 规范解答。垂直斜面方向平衡：$N = mg\cos\theta$，A 错。物块在滑动，摩擦力是滑动摩擦力：$f = \mu N = \mu mg\cos\theta$，B 对。沿斜面方向，合力为 $F_{\text{合}} = mg\sin\theta - \mu mg\cos\theta$，它不等于 $mg\sin\theta$（除非没有摩擦），D 错。斜面对物块的作用力是支持力与摩擦力的合力，大小为 $mg\cos\theta\sqrt{1 + \mu^2}$；物块加速下滑说明 $mg\sin\theta > \mu mg\cos\theta$，即 $\tan\theta > \mu$，由此可以推出这个合力小于 $mg$，C 错。

　　④ 易错点。第 ③ 步 D 的迷惑性最强：光滑斜面上合力确实是 $mg\sin\theta$，多考一个摩擦力它就变了——"结论要有条件"在这一步体现得最典型。C 的判断涉及平方和比较，考场上若推不动，可以取特殊值检验：令 $\theta = 30°$、$\mu = 0.5$，代入发现斜面作用力约为 $0.99mg$，已经小于 $mg$。

　　⑤ 变式。把"加速下滑"改成"匀速下滑"，哪些说法变了？支持力、摩擦力表达式不变，但合力变为零，且由 $\tan\theta = \mu$ 反过来能求动摩擦因数——"测动摩擦因数"的斜面实验就是这条式子的应用。
:::

## 六、连接体基础：整体法与隔离法

前面都是单个物体。两个（或更多）物体用绳、弹簧或直接叠放连在一起运动时，叫连接体。连接体的问题多出一个新任务：除了整体的加速度，还常常要问"绳的张力多大""A 给 B 的力多大"这类物体之间的内力。

处理思路是两条规矩（图 8）：

![课程板书：整体法求系统加速度可消去内力，隔离法求物体间的拉力、压力或摩擦力，整体式成立需各物体加速度相同](/blog-images/k016-newton-laws-applications/K016-牛顿运动定律的应用-03-原理关系-整体与隔离.png)

图 8｜整体法与隔离法的分工

- 整体法：把几个物体打包成一个整体，物体之间的力是内力，成对出现互相抵消（牛顿第三定律，K010），方程里只剩下外力。用它求共同的加速度最快。
- 隔离法：把其中一个物体单独拎出来分析，它受的每个力——包括同伴给它的力——都要画在图上。用它求内力。

最常见的组合打法是"先整体、后隔离"：先用整体法求出共同的加速度，再隔离受力最少的那一个物体解出内力。要注意整体法的适用前提：各物体的加速度必须相同。

答案：(1) 2 m/s²，方向向右。(2) 4 N。

　　① 题型识别。两个物体一起加速，既问加速度又问绳的张力——标准的"先整体、后隔离"。

　　② 步骤模板。第一步把 A、B 看成整体列 $F = m_{\text{总}}a$ 求加速度；第二步隔离受力少的物体（这里是只受绳拉力的 A）列方程求张力。

　　③ 规范解答。整体在水平方向只受拉力 $F$（光滑，无摩擦；绳的张力是内力，不出现），由 $F = (m_A + m_B)a$ 得：

$a = \dfrac{10\ \text{N}}{2\ \text{kg} + 3\ \text{kg}} = 2\ \text{m/s}^2$，方向向右。

隔离 A，水平方向只受绳的拉力 $T$，由 $T = m_A a$ 得：

$T = 2\ \text{kg} \times 2\ \text{m/s}^2 = 4\ \text{N}$。

　　④ 易错点。第 ③ 步常见错法是列整体方程时把张力 $T$ 也塞进去——内力在整体法里必须消掉，写了它说明对象没定清楚。隔离 B 也能求出 $T$（$F - T = m_B a$，得 $T = 4$ N），两条路结果一致，可以互查。

　　⑤ 变式。地面不再光滑，A、B 与地面间的动摩擦因数都是 $\mu$，张力还等于 $m_A a$ 吗？等于。整体方程变成 $F - \mu(m_A + m_B)g = (m_A + m_B)a$，隔离 A 仍是 $T - \mu m_A g = m_A a$，两式相除可验证 $T = F m_A / (m_A + m_B)$，与地面是否光滑无关——这是连接体里非常经典的结论。
:::

## 七、常见错误与边界

![课程板书：应用定律前的三个关键判断——速度为零不代表加速度为零，临界状态找即将变化的约束，力改变后重新求合力和加速度](/blog-images/k016-newton-laws-applications/K016-牛顿运动定律的应用-04-易错对照-三个关键判断.png)

图 11｜应用定律前的三个关键判断

错误一：把"速度为零"当成"合力为零"。例题一里物块停止的瞬间，速度是零，但摩擦力还在，只要撤力后不再施加其他水平力，物块就保持静止，合力才为零；而竖直上抛的物体在最高点速度为零、合力却是 $mg$。速度描述运动状态，合力决定状态怎么变，两码事。

错误二：力一变，加速度不跟着变。撤去拉力、摩擦力从静摩擦突变为滑动摩擦、斜面倾角改变——这些时刻都必须重新画受力图、重新求合力和加速度。例题一的两个阶段正是为此分段。

错误三：整体法用在不该用的地方。各物体加速度不同（比如一个已经相对另一个滑动）时，$F_{\text{外}} = m_{\text{总}}a$ 里的 $a$ 就没有统一的值，整体法失效，只能逐个隔离。

边界说明：本单元的板块模型和传送带问题只处理"共速后一起运动"的基础形式；涉及摩擦生热、相对滑动全程的能量分析，要等学完功和能之后回补；超重和失重现象（电梯里的体重秤问题）归下一单元《超重和失重》。

## 八、本节知识整理

表 1｜牛顿运动定律的应用要点

| 要点 | 内容 |
| --- | --- |
| 两类基本问题 | 已知力求运动：力 → $a$ → 运动；已知运动求力：运动 → $a$ → 力 |
| 中间量 | 加速度 $a$ 是两边的桥，拿到题先问"$a$ 能不能求" |
| 标准流程 | 定对象 → 画受力图 → 定正方向 → 正交分解 → 列 $F = ma$ → 接运动学 |
| 斜面两式 | $N = mg\cos\theta$；沿斜面 $mg\sin\theta \mp \mu mg\cos\theta = ma$（上滑加、下滑减） |
| 下滑条件 | 从静止下滑需 $\tan\theta > \mu$ |
| 连接体 | 整体法求共同加速度（内力消去），隔离法求内力；整体法要求各物体加速度相同 |
