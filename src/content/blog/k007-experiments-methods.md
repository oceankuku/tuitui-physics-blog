## 题型一：步骤排序与目的——操作逻辑卡

### 如何识别

"下列操作顺序合理的是""实验中'先通电再放纸带'的目的是""某同学的操作错误在于"。

### 为什么这样排

所有操作步骤都服务于一条主线：**让有效数据尽量多、让系统状态先稳定**。记三条铁律，排序题不用背：

- **打点计时器：先通电、再放纸带。** 通电后振针要几十毫秒才稳定；先放纸带，开头一段全是密集废点。
- **先调平、再测量。** 光电门实验轻推小车看两门读数是否几乎相等，先抵消重力分量，测出来的 a 才是"目标力"贡献的。
- **先试跑、再正式。** 确认计时器归零、挡光片完整过门，浪费的只是试跑一次，救回的是整组数据。

### 完整示范

:::problem
**示范 1（步骤排序）**用光电门测滑块加速度的合理操作顺序是：
①给气垫导轨供气，轻推滑块，观察两光电门读数是否几乎相等
②用游标卡尺测量挡光片宽度 d
③安装挡光片，使其与滑块运动方向平行
④释放滑块，记录两门挡光时间
⑤重复测量多次，取平均值
A. ②③①④⑤　　B. ③②①④⑤　　C. ①②③④⑤　　D. ②①③⑤④
:::
:::answer
**答案：A。**

- 主线：先测器材常数（②d 是计算输入）→ 装好并校正姿态（③平行，否则 d 虚高）→ 调平系统（①，轻推看读数）→ 正式测量（④）→ 重复取平均减偶然误差（⑤）。
- **C 的陷阱**：先调平（①）再测 d 也不算致命错，但③必须在④前、⑤必须在④后——B、D 都破坏了这条底线。D 还把"重复测量"塞到正式测量前面，逻辑不通。
- 记忆锚点：**常数 → 姿态 → 调平 → 测量 → 重复**。
:::

### 常见错误与边界

- **错因**：把"目的"答成"现象"。问"轻推滑块看读数相等的目的"，答"为了看它匀速"不得分；答"**检验导轨是否水平，以抵消重力沿轨道方向的分量**"才完整。
- **边界**：不同装置的"目的"不互套。打点计时器"先通电"是为了振针稳定；光电门"先供气"是为了形成气膜减小摩擦——别写串。

## 题型二：读数与单位换算——换算链卡

### 如何识别

数据带 mm、cm，问 m/s²；或者选项之间恰好差 10 倍、100 倍。

### 为什么用这个方法

纸带、刻度尺的原始读数几乎都是毫米；而公式里长度一律用米。**换算错误不是误差，是错误**——丢分最冤。立一条铁律：**动笔前，把所有长度统一换成米、时间统一换成秒，写在草稿最上面一行**。

### 完整示范

:::problem
**示范 2（2021·福建卷 T13 同型）**纸带计数点间隔 $T' = 0.1$ s，测得相邻相等时间间隔内的位移差恒为 $\Delta x = 4.0$ mm。加速度大小为：
A. 0.40 m/s²　　B. 4.0 m/s²　　C. 40 m/s²　　D. 0.040 m/s²
:::
:::answer
**答案：A。**

- 换算链先行：$\Delta x = 4.0 \text{ mm} = 4.0 \times 10^{-3}$ m；$T'^2 = 0.01$ s²。
- 代入 $\Delta x = aT'^2$：$a = \frac{\Delta x}{T'^2} = \frac{0.0040}{0.01} = 0.40$ m/s²。
- 四个选项就是换算链的四个断点：B 少除一次 10，C 少除两次，D 多除一次。**选项差十倍 = 出题人在量你的单位功**。
:::

### 常见错误与边界

- **错因**：口算跳步。4.0 mm 直接当 0.04 m 用（差 10 倍）。
- **边界**：最终答案保留几位看题目要求；中间过程别四舍五入太早，逐差法分子是两个大数相减，提前舍入会放大误差。

## 题型三：纸带完整数据处理——四步流水线卡

### 如何识别

给一条纸带七八个计数点坐标，问"判断运动性质 / 求某点速度 / 求加速度"，大题 8–10 分。

### 为什么用这个方法

纸带大题就是一条流水线，四步走完分数拿满：

1. **算段位移**：相邻计数点坐标相减，得到 $x_1$ 到 $x_6$；
2. **体检**：算 $\Delta x = x_{n+1} - x_n$，基本恒定 → 匀加速（这是第一问的答案，也是后续方法的适用前提）；
3. **求点速度**：中间时刻定理 $v_n = \frac{x_n + x_{n+1}}{2T'}$（左右两段夹住的那点）；
4. **求加速度**：逐差法 $a = \frac{(x_4+x_5+x_6)-(x_1+x_2+x_3)}{9T'^2}$，与第 2 步的 $\frac{\Delta x}{T'^2}$ 互为验证。

### 完整示范

:::problem
**示范 3（纸带大题标准流程）**打点计时器 50 Hz，每 5 个间隔取一个计数点。计数点 0–6 的坐标为 0、1.20、2.80、4.80、7.20、10.00、13.20 cm。(a) 判断小车的运动性质；(b) 求计数点 3 的瞬时速度；(c) 求加速度；(d) 求打计数点 0 时的速度。
:::
:::answer
**答案：(a) 匀加速直线运动；(b) 0.22 m/s；(c) 0.40 m/s²；(d) 0.10 m/s。**

- **第 1 步 算段位移**：$x_1$ 到 $x_6$ = 1.20、1.60、2.00、2.40、2.80、3.20 cm。
- **第 2 步 体检**：$\Delta x = 0.40$ cm 恒定 → 匀加速（$T' = 0.1$ s）。
- **第 3 步 求点速**：$v_3 = \frac{x_3 + x_4}{2T'} = \frac{0.020 + 0.024}{0.2} = 0.22$ m/s（用计数点 2、4 夹住 3）。
- **第 4 步 逐差**：$a = \frac{(x_4+x_5+x_6)-(x_1+x_2+x_3)}{9T'^2} = \frac{(2.4+2.8+3.2)-(1.2+1.6+2.0)}{9 \times 0.01}$ cm/s² = $\frac{8.4-4.8}{0.09} = 40$ cm/s² = $0.40$ m/s²。与体检值 $\frac{\Delta x}{T'^2} = \frac{0.004}{0.01} = 0.40$ m/s² 一致，数据可信。
- **求 $v_0$**：从计数点 0 到 3 经历 $3T'$，$v_0 = v_3 - 3aT' = 0.22 - 3 \times 0.40 \times 0.1 = 0.10$ m/s。
:::

### 常见错误与边界

- **错因一**：求 $v_3$ 用了 $x_3$ 单段——那是平均速度不是瞬时速度。
- **错因二**：逐差分组交叉错（$x_4 - x_2$ 之类）——记住"前 3 后 3 各自求和再相减"。
- **边界**：逐差法要偶数段；5 段时弃最短的头一段（打点最密、相对误差最大）用 4 段版。

## 题型四：光电门综合——两门两速度卡

### 如何识别

给挡光片宽度 d、两个门的挡光时间，问速度、加速度；或者问"挡光片变宽会怎样"。

### 为什么用这个方法

光电门的全部计算就两板斧：

- 单门：$v = \frac{d}{\Delta t}$（极限思想把它当瞬时速度）；
- 双门：两点速度 $v_A$、$v_B$ + 间距 $L$ → 匀加速用 $a = \frac{v_B^2 - v_A^2}{2L}$（缺时间，用 $v^2$ 关系）。

### 完整示范

:::problem
**示范 4（双门大题）**气垫导轨上 A、B 两光电门间距 L = 60 cm，滑块挡光片宽 d = 0.50 cm。经过 A、B 的挡光时间分别为 $\Delta t_A = 12.5$ ms、$\Delta t_B = 5.0$ ms。(a) 求滑块经过两门的速度；(b) 求加速度；(c) $v_A$ 对应的是挡光片"刚接触光"那一刻的速度吗？
:::
:::answer
**答案：(a) $v_A = 0.40$ m/s，$v_B = 1.0$ m/s；(b) 0.70 m/s²；(c) 不是，它更接近挡光期间的中间时刻。**

- (a) 先换算：$d = 0.0050$ m。$v_A = \frac{0.0050}{0.0125} = 0.40$ m/s；$v_B = \frac{0.0050}{0.0050} = 1.0$ m/s。
- (b) $a = \frac{v_B^2 - v_A^2}{2L} = \frac{1.0^2 - 0.40^2}{2 \times 0.60} = \frac{0.84}{1.2} = 0.70$ m/s²。
- (c) $v_A$ 是**挡光这段时间的平均速度**。滑块在加速，挡光期间速度越来越大，平均速度等于**中间时刻**的瞬时速度——比"刚接触光"那一刻大，比"离开光"那一刻小。这正是"窄挡光片更接近瞬时速度"的物理内核。
:::

### 常见错误与边界

- **错因**：ms 没换 s（12.5 ms 当 12.5 s，速度小一千倍）；或用 $\frac{v_B - v_A}{L}$（量纲都不对）。
- **边界**：$v^2$ 关系要求匀加速。若滑块匀速，$v_A = v_B$，谈不上 a；若题目只说"求两门间平均加速度"，公式照样可用（平均意义）。

## 题型五：误差方向判断——原理式追凶卡

### 如何识别

"测得的 g 偏小，原因可能是""测得速度偏大，由于""下列属于错误而非误差的是"。

### 为什么用这个方法

不背误差清单，**盯着原理式看哪个量被带歪**：

$$g = \frac{\Delta x_{\text{测}}}{T'^2}, \quad v = \frac{d}{\Delta t}$$

每个实验量与真值的偏差往式子里一代，方向自动出来。三条高频结论都这么推：

- **纸带测 g 偏小**：摩擦+空气阻力使实际加速度 $< g$，测的是"实际加速度"，自然偏小。改进：加重物（阻力占比小）、气垫导轨。
- **挡光片不平行 → v 偏大**：有效挡光宽度比真实 d 大，分子虚高。
- **重物选太轻 → g 偏小更多**：阻力不变、重力变小，阻力占比升高。

**误差与错误的分界**：误差是不可避免、只能减小的偏差（有方向可分析）；错误是操作违规造成的（T′ 代错、先放纸带后通电），必须避免，谈不上"偏大偏小"。

### 完整示范

:::problem
**示范 5（误差分类四连）**下列说法正确的是：
①纸带测 g 结果 9.72，比 9.8 小——摩擦与空气阻力所致，属系统误差
②挡光片没装平，测得速度偏大——仪器操作问题，属错误
③把 T′ = 0.1 s 代成 0.02 s——数据单位没换——属读数误差
④多次测量取平均——为了减小偶然误差
A. ①③④　　B. ①④　　C. ②③　　D. ①②④
:::
:::answer
**答案：B。**

- ① 对：阻力是实验系统固有的，方向明确（偏小），系统误差。
- ② 错：装歪挡光片是操作不规范，属于**错误**——但很多解析把它归为"操作误差"，注意本课件的口径：违规操作=错误，可避免。
- ③ 错：T′ 代错不是"读数误差"，是**计算错误**，量级差 25 倍，与"误差"无关。
- ④ 对：偶然误差忽大忽小，取平均正是它的克星。
:::

### 常见错误与边界

- **错因**：只答"有摩擦"不答方向。标准答案要写全：**"纸带与限位孔摩擦、空气阻力使加速度偏小"**。
- **边界**：不同装置的误差结论不互套——光电门的误差分析（挡光片平行度）与纸带（限位孔摩擦）是两套，别混写。

## 题型六：图像法处理——描点连线卡

### 如何识别

"在坐标纸中作出 v–t 图像""由图线斜率求加速度""图像法有什么优点"。

### 为什么用这个方法

逐差法算 a 只给一个数；图像法把整条 v–t 关系摊开看：**描点 → 目测画一条过尽量多点、两侧点均匀分布的直线 → 斜率即 a**。离谱的数据点一眼可见，直接舍弃——这是它比逐差法强的地方。两法是左右手：大题第一问常要"一条纸带两种处理"。

### 完整示范

:::problem
**示范 6（图像斜率）**小车拖纸带做匀加速，按中间时刻定理算得计数点 1–6 的速度为 0.31、0.49、0.69、0.89、1.09、1.29 m/s，对应时刻 0.1–0.6 s。用图像法求加速度，并说明图像法的一个优点。
:::
:::answer
**答案：$a \approx 2.0$ m/s²；优点：能直观发现异常数据点。**

- 描点后直线斜率 $a = \frac{\Delta v}{\Delta t} = \frac{1.29 - 0.31}{0.6 - 0.1} = \frac{0.98}{0.5} \approx 2.0$ m/s²。
- 各点相邻差 0.18–0.20 m/s，微小波动是读数偶然误差，画直线时让它均匀分布在两侧即可，不必强行穿过每个点。
- **优点**（答一条即可）：异常点一眼识别可舍弃；或：直线拟合利用了全部数据、减小偶然误差；或：能直观展示速度随时间线性变化。
- 对照逐差法：本题数据逐差 $a = \frac{(v_4+v_5+v_6)-(v_1+v_2+v_3)}{9T'} = \frac{(0.89+1.09+1.29)-(0.31+0.49+0.69)}{0.9} = \frac{3.27-1.49}{0.9} \approx 2.0$ m/s²——两法互验，数据可信。
:::

### 常见错误与边界

- **错因**：把相邻速度差 $\Delta v = 0.2$ m/s 直接当 a——还差一个除以 $T'$。
- **边界**：图像法要求点足够多（≥5 组）才谈得上拟合；只有两三组数据时老实用逐差/定义式。
