速度看不见，加速度更抽象，实验要干的事只有一件：把它们变成一串能算的数。这一章的四个实验——练习使用打点计时器、探究小车速度随时间的变化、用光电门测速度、自由落体测 g——共用同一条数据链：**计时，量位移，处理数据，检验结果**。把这条链走通一遍，实验题的每个问法都能在链上找到位置。

- 前置知识：匀变速的速度公式与"平均速度等于中间时刻速度"（K005）、位移差恒定 $\Delta x = aT'^2$（K006，本篇会完整重推一遍）。
- 学习目标：说清每个器材在数据链里的角色；独立完成"量位移 → 判性质 → 求点速 → 求加速度"的完整处理；能对任何一个结果回答"偏大还是偏小、为什么"。
- 配套文章：题型与方法见《第二章实验②》，分层练习见《第二章实验③》。

## 一、计时：把时间"刻"在纸带上

![老师与讲台上的打点计时器](/blog-images/k007-experiments/K007E-实验-01-器材-电磁打点计时器.png)

图 1｜打点计时器与低压电源

电磁打点计时器接 4–6 V 低压交流电（实验室另配学生电源），振针每秒打 50 个点。它计时的依据是一条：**打点周期由交流电频率决定**，与纸带拉多快无关——这正是它能当计时仪器的原因。打点周期（相邻两点的时间间隔）：

:::formula
T = \frac{1}{f} = \frac{1}{50} \text{ s} = 0.02 \text{ s}
:::

实验室还有一种电火花计时器，用 220 V 交流电，靠火花放电在纸带上打点，不用复写纸。两种计时器电压不同、打点方式不同，打点周期同样是 0.02 s——考试爱在这个电压区别上设选项。

操作顺序只有一条主线：**先通电，待打点稳定后再放纸带**。原因有两层：振针刚通电时有几十毫秒的起动过程，这段时间打的点规律性差；纸带长度有限，先放纸带会让开头一段全是密集废点，白白浪费纸带。其余操作都服务于数据质量：纸带穿过限位孔、压在复写纸下面；小车释放前靠紧打点计时器，让有限长度的纸带尽量多记录有效运动。

0.02 s 的间隔太短，相邻点挨得太近，刻度尺量不准。习惯上每 5 个间隔取一个计数点，相邻计数点的时间间隔：

:::formula
T' = 5T = 5 \times 0.02 \text{ s} = 0.1 \text{ s}
:::

这里埋着实验题的第一文字坑："每 5 个**间隔**取一个计数点"，$T' = 0.1$ s；"每 5 个**点**取一个计数点"，5 个点之间只有 4 个间隔，$T' = 4T = 0.08$ s。一字之差结果差 25%（见本篇例题后的条件变化），动笔前先把这句读清楚。

### 例题一

:::problem
<span class="prob-grade">1.【基础题·易错题·选择题】</span><span class="prob-source">（经典题）</span>电磁打点计时器接 50 Hz 交流电。下列说法正确的是：
A. 它每 0.02 s 打一个点，与小车运动快慢无关
B. 小车运动越快，相邻点的时间间隔越大
C. 每 5 个点取一个计数点，相邻计数点时间间隔为 0.1 s
D. 打点计时器使用直流电源也能正常打点
:::

:::answer
**答案：A。**

- **A 对。**打点周期由交流电频率决定，$T = \frac{1}{f} = 0.02$ s；纸带拉得快只改变点间距，不改变时间间隔。
- **B 错。**车快，点间距变大，时间间隔仍是 0.02 s。
- **C 错。**5 个点之间只有 4 个间隔，$T' = 4 \times 0.02 = 0.08$ s。
- **D 错。**电磁打点计时器靠电流方向周期性变化带动振针振动，必须用交流电；接直流电振针会被吸在一边。
:::

条件变化：若电网频率不稳定、实际是 49 Hz，打点周期变成 $\frac{1}{49} \approx 0.0204$ s。仍按 0.02 s 计算，时间被代小了，由此带来的偏差方向在《第二章实验②》任务四里推导。

## 二、测位移：哪些量是直接测的

纸带实验里，真正用刻度尺量出来的只有**各段位移**；时间不用量，由打点周期"白送"；至于速度、加速度、重力加速度，全部是用公式从这两类数据**间接算出来**的。

这个区分不是概念游戏，它决定后面误差怎么分析：直接测量量的偏差来自刻度尺估读（偶然误差，靠多次测量摊薄）；间接量的偏差来自公式里每个输入量的传递——哪个量被带歪了，方向可以顺着公式推出来。本篇第七节全靠这条。

读数还有一个固定动作：刻度尺读数要估读到最小分度的下一位，毫米尺读到 0.1 mm；计算前把所有长度统一换成米。纸带题最冤的丢分从来不是不会，是 25.0 mm 被当成 25.0 cm 代进公式。

## 三、从位移到速度：中间时刻定理

纸带上某计数点的瞬时速度怎么求？用它的左右两段。设 A、B、C 是相邻三个计数点，AB 段位移 $x_1$、BC 段位移 $x_2$，时间间隔都是 $T'$（图 2）。

![中间时刻速度：AC 段的平均速度等于 B 点的瞬时速度](/blog-images/k007-experiments/fig-tape-midpoint.png)

图 2｜中间时刻速度：左右两段夹住中间点

匀变速里，一段时间的平均速度等于首末速度的平均（K005 的推论），也等于中间时刻的瞬时速度。两件事拼起来就是定理。推导只需要两步：设 A 点速度为 $v_A$、加速度为 $a$，则 $v_C = v_A + 2aT'$；

:::formula
\bar{v}_{AC} = \frac{v_A + v_C}{2} = \frac{v_A + (v_A + 2aT')}{2} = v_A + aT'
:::

而 B 恰好是 AC 段的中间时刻，$v_B = v_A + aT'$，与平均速度完全相等：

:::formula
v_B = \bar{v}_{AC} = \frac{x_1 + x_2}{2T'}
:::

注意它的适用前提：**匀变速**。匀变速里这是严格等式，不是近似；运动性质未知时，它只是近似——实验里恰好先用它求速度、再反过来检验是否匀变速，两步互为支撑。

### 例题二

:::problem
<span class="prob-grade">2.【基础题·常考题·实验题】</span><span class="prob-source">（经典题）</span>打点计时器频率 50 Hz，每 5 个间隔取一个计数点，纸带上依次量得 AB = 3.60 cm、BC = 4.20 cm。打 B 点时小车的速度大小为：
A. 0.39 m/s
B. 0.78 m/s
C. 39 m/s
D. 条件不足，无法确定
:::

:::answer
**答案：A。**

- 先定时间：每 5 个间隔取计数点，$T' = 0.1$ s；再换单位：3.60 cm $= 0.036$ m，4.20 cm $= 0.042$ m。
- B 是 AC 段的中间时刻：$v_B = \frac{x_{AB} + x_{BC}}{2T'} = \frac{0.036 + 0.042}{0.2} = 0.39$ m/s。
- 检查：量级与常见小车速度一致；C（39 m/s）是厘米没换米的结果。
:::

## 四、从位移到加速度：逐差法

有了速度，加速度可以直接用定义 $a = \frac{\Delta v}{\Delta t}$ 算。但纸带给了六段位移，怎么用最充分？

最直接的想法：每段位移算一个加速度，再取平均。设第 $n$ 段末的速度是 $v_n$，则 $a_n = \frac{v_n - v_{n-1}}{T'}$。把六段加起来时会发现一个麻烦：求 $a_2$ 用到的 $v_1$，正好是求 $a_1$ 的结果，中间速度在上一个式子里是末速度、在下一个式子里是初速度，相加时两两抵消——

:::formula
\bar{a} = \frac{(v_1 - v_0) + (v_2 - v_1) + \cdots + (v_6 - v_5)}{6T'} = \frac{v_6 - v_0}{6T'}
:::

中间四个速度全消掉了，平均值只由首尾两个速度决定。首尾恰恰是误差最大的地方：开头的点最密、刻度尺估读的相对误差最大。也就是说，量了六个数据，其实只用了两个。

逐差法绕开这个问题。它的出发点是匀变速的另一条性质：相邻相等时间间隔内的位移差恒定，

:::formula
x_{n+1} - x_n = aT'^2
:::

这条式子的依据在 K006 推过：第 $n$ 段位移 $x_n = v_{n-1}T' + \frac{1}{2}aT'^2$，代入 $v_n = v_{n-1} + aT'$，相邻两段相减，$v_{n-1}T'$ 项消去，剩下 $aT'^2$。

六段位移分成前后两组，隔 3 段两两相减（图 3）。隔 3 段，位移里相差的是 3 个 $aT'^2$：

![六段纸带的逐差分组](/blog-images/k007-experiments/fig-tape-six-segments.png)

图 3｜六段位移分两组，隔 3 段相减

:::formula
x_4 - x_1 = 3aT'^2, \quad x_5 - x_2 = 3aT'^2, \quad x_6 - x_3 = 3aT'^2
:::

三式相加，左边是两组位移和的差，右边是 $9aT'^2$，解出

:::formula
a = \frac{(x_4 + x_5 + x_6) - (x_1 + x_2 + x_3)}{9T'^2}
:::

分母的 9 就是这么来的：隔 3 段一差，乘 3；三差相加，再乘 3。六个数据全部进入算式，没有任何一个被抵消，偶然误差被摊到每个数据头上——这就是逐差法相对"逐段平均"的全部优势。

用逐差法有两个前提，动笔前各检查一遍：一是 $T'$ 必须是所选各段的共同时间间隔（计数点规则先核对）；二是段数必须是偶数。只剩 5 段时，弃掉最短的开头段（点最密、相对误差最大），用剩下的 4 段做同样分组：

:::formula
a = \frac{(x_3 + x_4) - (x_1 + x_2)}{4T'^2}
:::

### 例题三

:::problem
<span class="prob-grade">3.【基础题·常考题·实验题】</span><span class="prob-source">（经典题）</span>纸带计数点间隔 $T' = 0.1$ s，连续四段位移为 $x_1 = 6.05$ cm、$x_2 = 6.80$ cm、$x_3 = 7.55$ cm、$x_4 = 8.30$ cm。小车的加速度大小为：
A. 0.75 m/s²
B. 0.19 m/s²
C. 7.5 m/s²
D. 18.75 m/s²
:::

:::answer
**答案：A。**

- 核对前提：$\Delta x = 0.75$ cm 恒定，匀加速成立，4 段版逐差可用。
- 求解（单位先统一成米）：$a = \frac{(x_3 + x_4) - (x_1 + x_2)}{4T'^2}$，
  分子 $(0.0755 + 0.0830) - (0.0605 + 0.0680) = 0.1585 - 0.1285 = 0.030$ m，
  $a = \frac{0.030}{4 \times 0.01} = 0.75$ m/s²。
- 检查：用体检式 $\frac{\Delta x}{T'^2} = \frac{0.0075}{0.01} = 0.75$ m/s² 互验，一致。
- **B 错。**把 $T'$ 当成 0.2 s 代入，$\frac{0.030}{0.16} \approx 0.19$ m/s²，是间隔数错了。
- **C 错。**75 cm/s² 换算成 m/s² 时错了一位（应除以 100）。
- **D 错。**把 $T'$ 当成打点周期 0.02 s（没抽计数点），$\frac{0.030}{0.0016} = 18.75$ m/s²。
:::

与逐差法互补的另一条路是图像法：用中间时刻定理算出各点速度，在 v–t 图上描点，画一条让数据点均匀分布在两侧的直线，斜率即加速度。它算得不如逐差快，但离谱的数据点在图上一眼可见——两法怎么选、怎么互验，《第二章实验②》任务二里展开。

## 五、光电门：更快的"表"

光电门是一个 U 形架：一侧发红外光，一侧接收。小车上装一片宽度 $d$（用游标卡尺测出）的挡光片，经过门时把光挡住，计时器记下挡光时间 $\Delta t$。挡光片经过门的平均速度：

:::formula
v = \frac{d}{\Delta t}
:::

问题是：平均速度凭什么当瞬时速度用？匀变速里，一段位移上的平均速度等于**这段位移中点**的瞬时速度（速度随位置线性变化，中间位置前半程亏的正好补后半程赚的）。所以 $\frac{d}{\Delta t}$ 严格等于"挡光片中心经过门"那一刻的速度。挡光片越窄，这个中点越贴近门位置，测的就是"经过光电门"的速度；挡光片变宽，测得的仍是平均速度，只是对应了更靠前的中点位置，与"过门那一刻"的偏差变大——高考考过这个反向理解。

两个操作考点（"该步骤的目的"要答全）：① 轨道先调平：轻推小车，两门读数几乎相等，说明重力沿轨道方向的分量已被抵消；② 挡光片与运动方向平行：若斜着过门，遮光期间小车实际前进的距离是 $d\cos\theta$（$\theta$ 为倾斜角），比 $d$ 小，而计算仍用 $d$ 除，测得速度偏大。

一个门给一个位置的速度；前后架两个门 A、B，得到 $v_A$、$v_B$。由上面说的中点论证，$v_A$、$v_B$ 就是小车经过两门位置时的速度。小车在两门间做匀加速时，用速度位移关系（K006）：

![双光电门测匀加速运动](/blog-images/k007-experiments/fig-photogate-double.png)

图 4｜双光电门测加速度：两个门给两个位置的速度

:::formula
a = \frac{v_B^2 - v_A^2}{2L}
:::

其中 $L$ 是两门间距。注意它的成立条件：匀加速，且 $v_A$、$v_B$ 确实是两门位置的速度——这两条由"遮光中点"论证保证。若运动不是匀加速，这个式子算出的只是一个定义出来的数字，不再有加速度的含义。光电门的计时精度是毫秒级，人掐表的反应约 0.2 s，差两百倍，所以出题人爱拿它的数据设单位与时间的坑。

### 例题四

:::problem
<span class="prob-grade">4.【基础题·常考题·实验题】</span><span class="prob-source">（经典题）</span>气垫导轨上装两个光电门 A、B，间距 $L = 50$ cm。滑块上挡光片宽 $d = 1.0$ cm。滑块依次经过 A、B，挡光时间分别为 $\Delta t_A = 0.025$ s、$\Delta t_B = 0.010$ s。滑块在两门间的加速度大小为：
A. 0.84 m/s²
B. 1.2 m/s²
C. 0.60 m/s²
D. 0.36 m/s²
:::

:::answer
**答案：A。**

- 先换算：$d = 0.010$ m，$L = 0.50$ m。两门速度：$v_A = \frac{0.010}{0.025} = 0.40$ m/s，$v_B = \frac{0.010}{0.010} = 1.0$ m/s。
- 求解：$a = \frac{v_B^2 - v_A^2}{2L} = \frac{1.0^2 - 0.4^2}{2 \times 0.5} = \frac{0.84}{1.0} = 0.84$ m/s²。
- 检查：$v_B > v_A$，加速，$a > 0$，量级合理（0.5 m 内速度翻倍出头）。
- **B 错。**$\frac{v_B - v_A}{L} = 1.2$，速度差除以了长度，量纲就不对——想用 $a = \frac{\Delta v}{\Delta t}$ 却拿 $L$ 当了时间。
- **C 错。**$\frac{v_B - v_A}{2L} = 0.60$，忘了平方。
- **D 错。**$\frac{(v_B - v_A)^2}{2L} = 0.36$，把"各自平方再相减"做成了"先相减再平方"。
:::

## 六、综合：一条纸带测 g

自由落体测 g 是这条数据链的完整落地，按实验自己的逻辑走一遍：

**测什么**：重力加速度 g——间接量，来自"重物下落是匀加速、加速度就是 g"这个模型。

**如何测**：重物挂纸带，穿过打点计时器限位孔，先通电再释放（图 5）。直接测量量是各段位移；时间是打点周期白送的。开头一段点距只有两毫米上下，估读误差占比太大，不参与测量；从点距可测的位置起，取连续 6 段。

![自由落体测 g 装置](/blog-images/k007-experiments/fig-freefall-setup.png)

图 5｜自由落体测 g：重物拖纸带穿过限位孔

**怎样处理**：先体检（$\Delta x$ 恒定确认匀加速），再逐差。此时不必再抽计数点：可测段的点距已有厘米级，直接用打点周期 $T = 0.02$ s，六段逐差。

**是否可信**：见例题五的最后一步与第七节。

### 例题五

:::problem
<span class="prob-grade">5.【提升题·常考题·实验题】</span><span class="prob-source">（经典题）</span>重物拖纸带自由下落，打点计时器 50 Hz。取连续 6 段位移：$x_1 = 19.6$ mm、$x_2 = 23.5$ mm、$x_3 = 27.4$ mm、$x_4 = 31.3$ mm、$x_5 = 35.2$ mm、$x_6 = 39.1$ mm。由这些数据测得的重力加速度大小为：
A. 9.75 m/s²
B. 9.8 m/s²
C. 9.86 m/s²
D. 39.1 m/s²
:::

:::answer
**答案：A。**

分析：自由落体是匀加速直线运动，纸带给出了 6 段位移，目标是加速度——正是逐差法的标准场景。先核对两个前提：$T = \frac{1}{50} = 0.02$ s；相邻差 $\Delta x = 3.9$ mm 恒定，数据自洽，匀加速成立。

求解（单位先统一：19.6 mm $= 0.0196$ m，六段同）：

:::formula
g = \frac{(x_4 + x_5 + x_6) - (x_1 + x_2 + x_3)}{9T^2}
  = \frac{(0.0313 + 0.0352 + 0.0391) - (0.0196 + 0.0235 + 0.0274)}{9 \times 0.02^2}
:::

:::formula
g = \frac{0.1056 - 0.0705}{0.0036} = \frac{0.0351}{0.0036} = 9.75 \text{ m/s}^2
:::

检查：分子 0.0351 m 与单段位移同量级，分母 0.0036 s²，商落在 9–10 之间，合理。

- B（9.8）是标准值。实验测得 9.75，偏小——纸带与限位孔的摩擦、重物受的空气阻力都向下拉加速度。设阻力合计 $f$，则 $g_{\text{测}} = g - \frac{f}{m}$，方向必然偏小，这是系统误差。回答"误差"必须带方向。
- C、D 的数值无法由这组数据用任何正确算法得出；若算出了这两个数，回头检查分母里 $T$ 有没有平方、单位有没有换。
:::

条件变化：如果电源频率不稳定，实际每秒打 49 个点，打点周期比 0.02 s 略长。我们仍按 0.02 s 代入，分母偏小，测得的 g 会偏大——方向由原理式直接看出，不需要背结论。

## 七、结果可信吗：误差与错误

实验结果和真值总有偏差，偏差分三种，处理方式完全不同：

**系统误差**：方向固定、原因明确。纸带测 g 偏小就是典型：设纸带与限位孔的摩擦、空气阻力合计为 $f$，重物质量 $m$，实际加速度 $a = g - \frac{f}{m} < g$，测的是这个"打了折的加速度"，所以必然偏小。改进措施必须对着原因去：换更重的重物（$f$ 不变、$m$ 变大，$\frac{f}{m}$ 占比下降；有条件时用真空管消除空气阻力）。挡光片不平行使测得速度偏大，同理由 $d\cos\theta < d$ 推出，而不是背出来的。

**偶然误差**：忽大忽小、没有固定方向，来自刻度尺估读这一类。对策是多次测量取平均，或者用逐差法、图像法把全部数据都用上。

**错误**：操作或计算违规造成的，可避免，谈不上"偏大偏小"。把 $T' = 0.1$ s 代成 0.02 s，$\frac{1}{T'^2}$ 放大 $\left(\frac{0.1}{0.02}\right)^2 = 25$ 倍——这是错误，不是误差。判断纸带是否匀加速的体检（$\Delta x$ 是否恒定）也属于"检验"这一环：发现数据不符合预期，先怀疑操作和数据，别急着改结论。

下篇预告：原理通了，题还是可能不会做——因为题目问的是"任务"：求速度、求加速度、判断性质、评估可信度。《第二章实验②》把实验题按这四类任务各给一条分析路径，还会揭晓本篇埋的问题：有同学测出 g = 11 m/s²，为什么老师说这不是误差、是错误？
