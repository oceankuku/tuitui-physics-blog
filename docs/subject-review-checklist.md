# 学科审核清单（2026-10-21 建立）

> 主规范第十二节要求：学科审核与工程校验分别执行、分别记录，**lint 通过不能代替学科审核**。本清单是学科审核的执行依据；审核结果记入台账状态列（待学科审核 → 待工程校验）。
>
> 审核人须逐项给出"通过 / 不通过（注明问题与位置）"，不得笼统签"已审核"。证据不足、解析未完成、来源未核实或关键图缺失时，标记待处理，不得记录为审核通过。

## 一、概念与规律（对应框架第三级目标）

- [ ] 概念定义准确，物理意义讲清（不是背定义文字）。
- [ ] 规律、公式的**成立条件**已注明；定义式/实验规律/理想化模型/数学推论的性质已说明。
- [ ] 没有编造推导或循环论证；该说"实验规律"的地方没硬推。
- [ ] 变量首次出现有说明；同一符号在同一分析中不混用。
- [ ] 矢量与大小、分量与代数量、平均量与瞬时量区分清楚。
- [ ] 没有把"通常如此"说成"必然如此"；近似的结论注明近似条件。

## 二、知识边界（超前内容分流）

- [ ] 正文和必做题只使用已学知识；前置知识开头已交代。
- [ ] 需要超前知识才能解释的结论，已明确"先记住，第X单元解释"并登记待补。
- [ ] 摩擦力等未学动力学前的单元，题目求解范围已限制，未混用后续方法。
- [ ] 超前的综合形式（动态平衡、多过程动力学等）已分层或分流，未塞进首次学习。
- [ ] "待后续知识补全"标记的内容已记录（覆盖表 + 台账）。

## 三、题型覆盖（对照覆盖表）

- [ ] 覆盖表先于写作建立；分类以物理本质、关键条件和分析方法为依据。
- [ ] 框架第四节五个维度查过遗漏：物理任务 / 情境结构 / 信息表达 / 条件变化 / 方法。
- [ ] 主要题型都有代表例题；实质不同的变式有对应处理，未用"一道代表题"冒充覆盖整类。
- [ ] 题型与方法是多对多关联，未强行一一对应；方法比较只在有实际价值处展开。
- [ ] 没有无教学价值的多解堆砌，没有为展示技巧引入超前工具。

## 四、推导与解析完整性（主规范第五节）

- [ ] 解析达到学生能独立复现的程度；关键步骤未跳。
- [ ] 没有"显然""易得""整理可得""同理"替代关键分析（无害的简单算术合并除外）。
- [ ] 九个不得跳过的步骤逐项核对（按题目涉及项）：方程从何而来 / 正负号如何定 / 隐含条件转化 / 图像斜率面积截距意义 / 分段分情况原因 / 临界条件建立依据 / 不等式变形与范围 / 多根取舍依据 / 数学解不符合物理条件的原因。
- [ ] 推论和口诀没有替代条件与论证；结论表配有完整推导。
- [ ] 单位、方向、范围和物理意义检查已做；有效数字合理。

## 五、题目与答案（对照 problem-source-register）

- [ ] 每道题都有登记号；类型明确（原题/节选/改编/自编）。
- [ ] 来源经核验：年份、卷别、题号与题干、选项、图示、答案一致；未凭记忆填写。
- [ ] 改编题已复查条件充分性、答案唯一性、数值合理性，改动已记录。
- [ ] 自编题未虚构学校、年份、考试来源；无"经典题 No.X"包装编号。
- [ ] **所有题目独立求解过**（答案不是抄来的）。
- [ ] 选择题逐选项给判断依据；多选题明确标注。
- [ ] 答案与解析无计算错误；同一题在例题篇与练习篇的数值一致。

## 六、分类讨论与临界

- [ ] 分段、分情况的原因讲清，不是罗列结论。
- [ ] 临界条件的建立依据完整（谁先谁后、恰好、最大最小）。
- [ ] "速度相等"没有普遍等同于"相遇"或"距离最小"，结合相对位置和具体过程判断。
- [ ] 多解情形完整（时间多解、双解、舍根），物理筛选有依据。
- [ ] 刹车停止、弹簧超限度等"不能倒推/不能过头"类陷阱已覆盖或有边界提示。

## 七、图文一致

- [ ] 每张图核对八项：对象与数量 / 方向角度连接接触关系 / 字母单位数值 / 关键状态 / 箭头含义 / 坐标轴与比例 / 与正文方程一致 / 手机端可读。
- [ ] 受力图没有把速度、位移等画成力；辅助量同图时明确区分。
- [ ] 原题含图处提供准确对应图；情境图与分析图功能不混淆。
- [ ] 网图物理准确、来源权限清楚；无装饰图冒充解题图。
- [ ] 正文引用并解释图中信息，不是只插不讲。
- [ ] 实验图对应实际装置；误差方向由具体模型推导，未凭经验套用。

## 八、方法适用范围

- [ ] 每种方法讲清：为什么适用、如何执行、什么时候不能用。
- [ ] 公式混用时检查各公式适用条件一致（如匀变速公式用于单方向匀变速段）。
- [ ] 图像面积法区分代数面积与路程。
- [ ] 图像交点不自动当相遇；比例关系注明初始条件。

## 九、练习对应关系（练习篇专项）

- [ ] 练习与主讲篇、题型篇逐项对应，不是题库随机拼接。
- [ ] 分层清楚（基础理解/典型应用/变化迁移/综合提升），必做与选做明确。
- [ ] 核心目标均有检测（对照框架第三级目标逐条核对）；无大量同质换数字题。
- [ ] 解析足以独立订正；典型错误归类（概念/建模/规律选择/读图/数学处理/表达）并回链讲解位置。
- [ ] 学生首次需要的方法处未只写"见前文"。
- [ ] 题目区与解析区分开，公众号阅读不依赖网页折叠。

## 十、表达与导航

- [ ] 表达风格过 `docs/writing-anti-ai-style.md` 自查（内容性禁令逐条）。
- [ ] 五要素齐全（教材位置/篇目类型/前置知识/学习目标/配套导航）。
- [ ] 长表格改短表或列表，不依赖横向滚动；段落适合手机。
- [ ] 没有承诺词（必考/押中/秒杀/一篇拿满分）。
- [ ] 涉及旧文修订时：updatedAt 已填、相关内链已同步。

```

审核人/日期：
一~十各项：通过 / 不通过（问题 + 位置）

```
