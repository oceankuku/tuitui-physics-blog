# 博客自然写作规范（2026-10-21 修订）

> 2026-10-21 按《高中物理公众号写作、审核与发布规范》第十一节修订：去除 AI 痕迹不等于机械禁用正常句式。句式本身不是问题，**句式成为无意识模板才是问题**。发布前逐条自查下面的内容性要求；对句式的检查标准是"确有解释价值"，不是"一律禁止"。

## 内容性禁令（硬性）

- **空泛铺垫和反复总结**：直接进入内容；不为"完整感"补引言、总结、FAQ。
- **人为制造反转**：不要为了吸引眼球把平实知识包装成颠覆性发现。
- **没有依据的结论与评价**：不虚构统计、教学结果、案例；不给引文加"一针见血""直指核心"式拔高评价，引用之后直接继续论述。
- **用口诀代替条件和论证**：口诀可以辅助记忆，但适用条件、推理过程必须写清。
- **把"通常如此"说成"必然如此"**：近似、经验性、特定条件下成立的结论，注明条件与例外。
- **为口语化牺牲术语准确性**：梗和口语停留在引入与过渡，术语、推导、结论保持准确严谨。
- **为去除 AI 痕迹机械禁用正常句式**：见下一节。

## 句式自查（标准是"确有解释价值"）

以下表达**可以用**，但用之前确认它承担了真实的解释任务，而不是自动生成的惯性：

- "不是 X，而是 Y"及其变体——仅在确有对比解释价值时用（如"位移不是路程，而是初位置指向末位置的有向线段"就是有效的物理澄清）；不得为制造修辞效果堆叠。
- "换句话说""换言之"——仅在换一种表述确实更清楚时用。
- "值得注意的是""这里的关键在于"——仅在真正需要提醒重点时用。
- 破折号——补充说明优先用逗号、句号或括号；全文破折号以一两处为宜，不为凑风格清零，也不连续滥用。
- 加粗——用于关键条件、结论和易错点，不整段加粗，不靠加粗制造全部重点。

## 自然口吻

把书面腔改成日常表达。优先写具体经历、动作、判断和结果，少写抽象拔高。允许教师式解释与必要提醒。

每段应承担明确任务：定义、解释、论证、示范、比较或纠错。空转的过渡段直接删。

## 结尾

不使用对称排比制造金句，不为总结而总结。写清这次讲清了什么、边界在哪、下一篇衔接什么即可（固定收尾段为可选项，见主规范第十节）。

## 完稿自查清单

发布前全文搜索以下表达，逐个判断"是否承担了解释价值"：

```text
不是 / 而是 / 与其说 / 不如说
换句话说 / 换言之 / 简而言之 / 综上所述
值得注意的是 / 这里的关键 / 真正 / 本质
显然 / 易得 / 整理可得 / 同理
```

命中不代表错误，但必须能说清它为什么在。其中"显然 / 易得 / 整理可得 / 同理"出现在**解析的关键推导步骤**时一律改写（主规范第五节），仅允许在真正无害的简单算术处出现。
