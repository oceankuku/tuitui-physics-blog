# 高中物理内容体系与建设框架（2026-10-21 建立）

> 本文件规定"建设什么、如何分类、如何判断覆盖充分"。具体写作、题目核验、配图、审核与发布，遵守 `AI_WRITING_GUIDE.md`。当前建设重点是高一新学课程，以人教版必修第一册起步，后续按实际教学顺序逐步扩展。

## 一、建设目标

建立一套适合初学者、与高中课程及高考能力要求衔接的学习资源。学生通过配套文章能够：

1. 理解概念。
2. 掌握规律及适用条件。
3. 识别物理情境与模型。
4. 选择分析方法。
5. 完整表达推理与计算。
6. 处理图像、数据和实验信息。
7. 在条件变化后迁移方法。
8. 通过练习发现并修正问题。

**高考衔接通过持续建设实现，不把高一初学文章改造成超前综合题集。**

### 第二级：课程单元

单元原则上对应教材小节或相对独立的知识主题（K 编号，来源 xlsx 规划）。每个单元记录：单元编号与主题名称、对应教材版本和位置、学习阶段、前置知识、核心学习目标、知识与公式、模型题型与方法、图像和数学工具、实验内容、易错点与适用边界、配套文章、待后续补全内容、核验依据与更新时间。

**单元地图与覆盖状态在 `docs/physics-coverage-map.md` 维护。**

### 第三级：教学目标与训练任务

每个目标建立"讲解—示范—练习—核验"对应关系。不能只记录"讲过加速度"，要记录：是否理解物理意义、是否区分速度/速度变化量/加速度、是否会判断方向、是否会基本计算、是否理解相应图像信息、是否知道结论适用条件、是否有对应检测。

## 三、每个单元的三类内容

每单元三类文章（主讲 `-concepts` / 题型与方法 `-methods` / 练习 `-practice`），骨架模板见 `BLOG_TEMPLATE.md`，写作要求见主规范第三、四、六节。完成标准：

- **A 主讲篇**：初学者能够理解本节，并具备进入典型题型学习的基础。
- **B 题型与方法篇**：主要题型有依据地覆盖，解析可复现，关键变式有处理，方法不脱离适用条件。
- **C 练习篇**：核心目标均有检测，题目与前两篇对应，难度和知识边界清楚。

## 四、题型分类的多维检查

题型目录必须结合具体知识建立，不能用一套空泛标签套所有章节。用以下维度**检查遗漏**，不机械生成所有组合；只纳入本节实际涉及的结构，不人为增加无关题型：

1. **按物理任务**：概念辨析 / 关系判断 / 定性解释 / 定量计算 / 规律或关系推导 / 条件反求 / 范围和极值 / 临界状态 / 实验设计与评价 / 数据处理和结论判断。
2. **按情境结构**：单对象与多对象 / 单阶段与多阶段 / 单过程与关联过程 / 固定约束与变化约束 / 理想模型与实际因素修正 / 对称、特殊和一般情形。
3. **按信息表达**：文字 / 情境示意图 / 物理图像 / 表格数据 / 实验记录 / 公式关系 / 混合信息。
4. **按条件变化**：已知量与未知量互换 / 方向或正负改变 / 起始状态改变 / 过程先后变化 / 阶段数量变化 / 约束条件改变 / 临界值与特殊值 / 参数范围变化 / 信息不足或条件冗余。
5. **按方法**：记录每种方法为什么适用、如何执行、什么时候不能用。**题型与方法多对多关联**：一个题型可能有多种方法，一种方法也可能服务多个题型，不得强行一一对应。

## 五、方法体系（随课程逐步引入，形成专题索引）

方法在对应知识单元中讲清，再形成专题索引。**涉及后续知识的方法先登记，不提前塞入当前单元；数学工具必须满足学生前置基础，超出时先补充说明或安排后续学习。**

1. **对象与过程分析**：研究对象选择 / 整体与隔离 / 状态与过程区分 / 分阶段分析 / 关联条件分析。
2. **表征与建模**：情境图与分析图 / 坐标系建立 / 矢量表示与分解 / 图像分析 / 等效与理想化 / 几何关系与约束关系。
3. **规律选择**：按运动特点选运动学关系 / 按受力和运动关系选动力学分析 / 按过程特点选功和能方法 / 按系统及外界作用判断守恒条件 / 多规律联立与过程衔接。
4. **数学处理**：比例关系 / 方程与方程组 / 函数关系 / 图像斜率截距与面积 / 几何与三角关系 / 不等式与范围 / 分段表达 / 数据拟合与线性化。
5. **检验与推理**：量纲和单位检查 / 极限情况检查 / 特殊情形检查 / 对称性分析 / 反例检验 / 结果数量级与物理合理性检查。

这些方法既用于学生训练，也用于内部审核（见 `docs/subject-review-checklist.md`）。

## 六、必修第一册启动建设目录

20 个主题的详细地图（现有文章映射、覆盖状态、缺口）在 `docs/physics-coverage-map.md`。**实际教材小节名称与顺序在动笔前核对，再确认最终课程编号。**

- 第一组 运动的描述：① 质点参考系与坐标描述 ② 时间与位移 ③ 速度 ④ 加速度
- 第二组 匀变速直线运动：⑤ 速度随时间变化的实验研究 ⑥ 速度与时间关系 ⑦ 位移与时间关系 ⑧ 运动学关系综合与推论 ⑨ 自由落体运动 ⑩ 运动学综合专题（追及相遇、临界等）
- 第三组 相互作用与平衡：⑪ 重力弹力与相互作用基础 ⑫ 摩擦力 ⑬ 牛顿第三定律 ⑭ 力的合成与分解 ⑮ 共点力平衡及应用
- 第四组 牛顿运动定律：⑯ 牛顿第一定律与惯性 ⑰ 加速度与力质量关系的实验 ⑱ 牛顿第二定律 ⑲ 力学单位制 ⑳ 牛顿运动定律的应用

关键口径（写作与审核共同遵守）：

- 速度图像交点**不自动表示相遇**；不得把"速度相等"普遍等同于"发生相遇"或"距离最小"，必须结合相对位置变化和具体过程判断。
- 图像代数面积与路程计算的区别必须讲清。
- 常用推论不得只给结论表，必须说明条件与推导。
- 摩擦力在未学动力学前限制求解范围，不提前混用后续方法。
- 动态平衡、复杂临界题按学生基础分层，不把全部高考综合形式集中在首次学习阶段。
- 板块、传送带等模型先建基础形式，涉及后续能量分析的部分登记到后续补全。
- 竖直上抛是否作为当前拓展，根据教材、教学进度和前置知识确定。

## 七、实验内容独立建表

每个实验至少记录：研究问题 / 原理 / 变量与控制方法 / 器材及作用 / 装置与连接 / 操作步骤 / 测量量 / 数据记录 / 数据处理 / 结论依据 / 误差来源 / 改进方案 / 安全与操作限制 / 实验变式。

- **实验图必须对应实际装置。** 误差方向根据具体模型推导，不能凭经验套用。
- 结合实际使用的纸带、传感器或其他装置分别核验，**不混写不同设备的操作细节**；不同装置的误差结论不互相套用。
- 现有存量：纸带问题、光电门两篇旧专题（挂板块 17），对应单元实验内容在建单元时嵌入。

## 八、题型与素材库

**题库**（登记处：`docs/problem-source-register.md`）每题记录：题目编号、来源及核验状态、原题/节选/改编/自编、知识标签、模型标签、方法标签、前置知识、难度与预计教学用途、完整答案与解析、图示源文件、易错点、已使用文章、近似题与重复情况。

**图素材索引**：站点素材库（`scripts/static-assets.mjs` labels，标题+描述+适用场景）承担现有索引职能；题图 SVG 源文件在 `workspace/figs-questions.html`。相同外观的图**不能随意复用**：方向、状态、连接和符号变化时必须重新核对；记录适用条件、可修改内容和来源权限。

## 九、覆盖状态与单元完成检查

覆盖状态七档（同一内容可同时具有多个状态，如"已讲解、已示范，但尚无练习"，不得笼统标为完成）：

**未规划 → 已规划 → 已讲解 → 已示范 → 已练习 → 已核验**，另有 **待后续知识补全**（跨单元分流的超前内容专用）。

> 与台账的关系：本七档记录**教学内容完成度**（coverage-map 维护）；台账八档（规划中→…→已发布）记录**文章生命周期**（course-progress 维护）。内容到"已核验"才算覆盖闭环，文章到"已发布"才算上线。

每个单元完成前检查：核心知识是否遗漏 / 主要题型是否有代表例题 / 实质不同的变式是否覆盖 / 方法条件是否说清 / 关键推导是否完整 / 必要图示是否齐全 / 练习是否逐项对应 / 超前内容是否明确分流 / 来源是否核实 / 已发现问题是否处理。

## 十、查漏与修订机制

每个单元用以下材料交叉检查：已确认版本的教材、适用课程与考试要求、经核验的相关试题、不同体系的教辅分类、学生反馈与实际错误。

不同材料出现分歧时，区分：表述不同但物理等价 / 成立条件不同 / 模型近似不同 / 教学深度不同 / 内容本身存在错误。**不得按出现次数多数决定物理正确性。**

发现遗漏后：① 登记问题（台账待补区或覆盖表）→ ② 判断影响范围 → ③ 修订正文、例题、图示或练习 → ④ 重新核验相关内容 → ⑤ 更新版本与配套链接（`updatedAt`）→ ⑥ 必要时安排补充专题。**已经发布不代表永久完成。**

## 十一、实施顺序（六阶段）

1. **第一阶段**：核对教材与现有项目，清点已发布、已写和缺失内容。✅（2026-10-21 完成，见台账"现有文章盘点"区）
2. **第二阶段**：建立全系列板块目录及必修第一册详细单元地图。✅（本文件第二节 + coverage-map 课程地图）
3. **第三阶段**：优先完善当前正在写的课程单元（K008），形成一组符合新标准的主讲、题型与方法、练习文章。
4. **第四阶段**：用这组文章检验模板、配图、公式和审核流程，修正后推广到后续单元。
5. **第五阶段**：逐步补齐旧文章中的知识边界、题型覆盖、推导、图示与练习对应问题。
6. **第六阶段**：随课程推进，补全模型专题、方法专题、实验专题和跨章节综合专题。

**不要一次生成整套课程后直接批量发布。先把体系规划完整，再逐单元深入建设和审核。**
