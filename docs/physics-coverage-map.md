# 知识、模型、方法与实验覆盖表（2026-10-21 按内容框架升级）

> 本文件是必修第一册课程地图 + 各单元题型覆盖表。板块级目录见 `docs/physics-content-framework.md`；文章生命周期状态见 `workspace/course-progress.md`。
>
> **覆盖状态七档**：未规划 → 已规划 → 已讲解 → 已示范 → 已练习 → 已核验，另有"待后续知识补全"（超前内容分流专用）。同一内容可同时具有多个状态（如"已讲解、已示范，尚无练习"），不得笼统标完成。
>
> 题型多维检查维度（物理任务/情境结构/信息表达/条件变化/方法）见框架第四节；lint 通过不等于已核验。

## 使用方式

1. 动笔一个单元前，先在该单元小节填覆盖表（字段见下）。
2. 写作中逐项推进状态；学科审核（`docs/subject-review-checklist.md`）通过才标"已核验"。
3. 用多维维度检查遗漏，缺口记入本文件该单元"缺口"行，并在台账待补区登记。

## 覆盖表字段（每行一条题型）

| 字段 | 说明 |
| --- | --- |
| 编号与名称 | 如 T8-1「v–t 图像读运动信息」 |
| 所属知识目标 | 对应主讲篇哪条学习目标 |
| 物理情境与模型 | 情境、对象、过程模型 |
| 常见设问 | 高频问法 |
| 已知信息的表达方式 | 文字/图像/图形/表格 |
| 主要解题方法 | 方法名与关键步骤（多对多关联） |
| 方法适用条件 | 公式/方法成立的条件 |
| 关键变式与边界 | 过程分支、临界状态、易错边界 |
| 前置知识 | 需要哪些已学内容 |
| 典型例题与来源 | 登记号（problem-source-register） |
| 配图需求 | 需要什么图，是否已画 |
| 对应练习 | 练习篇的题号 |
| 关联真题 | gaokao-validation-register 登记号（GV-xxx） |
| 尚未覆盖内容 | 明确记录缺口，不得留空了事 |
| 覆盖与审核状态 | 七档 |

**分类依据**：物理本质、关键条件和分析方法；不得仅按题目外观或换数字重复分类。
