# 文章框架总结（一页速查）

> 提炼自 `AI_WRITING_GUIDE.md`（执行规则）、`BLOG_TEMPLATE.md`（骨架模板）、`docs/physics-content-framework.md`（内容体系）。写文章时对照本页即可，细节争议回主规范查。

## 一、整体结构：一个单元三篇

每个课程单元（教材一节，K 编号）固定产出三类文章，共享单元编号、学习目标、知识边界和覆盖清单：

| 篇目 | 后缀 | 职责 | 完成标准 |
| --- | --- | --- | --- |
| 主讲篇 | `-concepts` | 建立概念、理解规律、明确适用条件 | 初学者能懂本节，具备进入题型的基本功 |
| 题型与方法篇 | `-methods` | 题型分类 + 固定破题动作 | 主要题型有依据地覆盖，解析可复现，变式有处理 |
| 练习篇 | `-practice` | 分层检测 + 独立订正 | 核心目标均有检测，与前两篇逐项对应 |

- 内容多可拆篇（如 ①上/①下），slug 加 `-2`、`-3`；内容少可合并，但须在台账说明原因，三类教学任务都得完成。
- **编号体例**：标题统一「主题①｜副题」（①主讲、②题型、③练习；拆篇加"上/下"）。不出现 K 编号和发布序号；禁"必考/秒杀/押中"承诺词。

## 二、每篇开头的五要素

开头（引言区，紧凑交代，不机械列表）：

1. **对应教材位置**（人教版第 X 章 第 X 节）
2. **本篇类型**（主讲 / 题型方法 / 练习）
3. **前置知识**（缺了先回哪篇）
4. **学习目标**（可检验）
5. **配套文章导航**（本单元另外两篇指向哪里）

## 三、主讲篇骨架

概念来源与困惑引入 → 学习目标与前置知识（含**知识边界**：本节不涉及什么）→ 概念与物理意义 → 规律公式与**成立条件**（公式性质必须说明：定义式/实验规律/理想化模型/数学推论，不得编造推导）→ 必要推导或实验依据 → 基础示例（1–2 道）→ 常见错误与边界 → 本节知识整理（短表，适配手机）→ 配套文章导航。

## 四、题型与方法篇骨架（重点建设）

**动笔前先建覆盖表**（`docs/physics-coverage-map.md`），再选题写解析。

题型总览短表（题型/识别特征/方法/对应练习）→ 每类题型固定八问：**如何识别 → 先分析什么 → 建什么模型 → 为什么用这个方法 → 规律适用条件 → 完整解题过程 → 条件变化后怎么调整（变式）→ 常见错误与边界**。

- 代表题用题卡（来源四类：原题/节选/改编/自编，全部登记 `docs/problem-source-register.md`）。
- 物理过程明显不同的**必须补变式**，不能一道代表题冒充覆盖整类。
- 方法比较只在有实际价值处写，不堆砌多解、不引入超前工具。

## 五、练习篇骨架

开头说明分层结构与对应关系 → 四层题目：**基础理解 → 典型应用 → 变化迁移 → 综合提升**，标注必做/选做 → 自测对照表（题号/检测目标/讲解位置/错因类型）。

- 题目区与答案解析**分开**，公众号阅读不依赖网页折叠。
- 每题解析足以独立订正：选择题逐选项说明，多选题明确标注，典型错误归类（概念/建模/规律选择/读图/数学处理/表达）并回链讲解位置。
- 学生首次需要的方法不得只写"见前文"。
- 现行约定（存量单元）：练习只放题目 30 道，答案放下一个单元练习篇文末；**K008 起每单元答案自己闭环**。

## 六、解析完整度（三篇通用）

解析达到**学生能独立复现**的程度。禁用"显然/易得/整理可得/同理"替代关键推导。九个不得跳过的步骤（按题目涉及项核对）：方程从何而来 / 正负号如何定 / 隐含条件转化 / 图像斜率面积截距意义 / 分段分情况原因 / 临界条件建立依据 / 不等式变形与范围 / 多根取舍依据 / 数学解不合物理条件的原因。不机械套成十三个标题，按题目自然组织。

## 七、通用技术约定

- **公式**：独立公式用 `:::formula` 块；分数 `{a/b}` 竖式，禁 Unicode（½）；根号 `√(2)` 带括号；叙述里的分数算式移进公式块。
- **题卡**：`:::problem`（题干）/ `:::answer`（答案，首行 `**答案：X。**` 独立成段，选择题逐选项列表）/ `:::note`（备注，可选）。四种围栏**严禁嵌套**；选项 A. B. C. D. 各占一行。
- **配图**：按教学功能配（无最低数量），图示能减少歧义处必须配；原题含图必须补画；正文须讲图，不能只插不讲。
- **表达**：准确自然直接，允许教师式解释；禁空泛铺垫、人为反转、口诀代论证、把"通常"说成"必然"；每段承担明确任务。固定结尾三段与彩蛋为可选。
- **审校**：学科审核（`docs/subject-review-checklist.md` 十项）+ 工程校验（lint/build/verify/smoke）分别执行；未过审稿件不走发布通道。

## 八、一篇的验收清单（发文前自查）

- [ ] 五要素齐全，标题体例「主题①｜副题」
- [ ] 覆盖表已建（题型篇）、题目来源已登记、例题独立求解过
- [ ] 解析无跳步、无"显然易得"；选择题逐选项
- [ ] 关键图示齐且与正文一致
- [ ] 练习与前两篇逐项对应
- [ ] lint / build / verify / smoke 全过，台账状态已更新
