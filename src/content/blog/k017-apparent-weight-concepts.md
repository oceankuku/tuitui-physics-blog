你拎着一台体重秤进电梯，从 1 楼站上去按了 18 楼。电梯启动的一瞬间，秤上的数字猛地涨了一截；快到楼层时，它又缩了回去，比你的真实体重还小。你原地没动，质量也没变，秤却前后给你报了三个不同的数。这台秤到底在量什么？答案是：它量的从来就不是重力，而是你对它的压力。这个数有个专门的名字，叫视重。视重、超重、失重和完全失重，就是本篇要讲清的四件事。

## 一、秤在量什么：视重与实重

![黑板情境页：电梯向上加速、向下加速、匀速三种情形下体重计读数分别变大、变小、不变，重力并未改变](/blog-images/k017-apparent-weight-concepts/K017-超重和失重-01-情境引入-电梯中的体重计.png)

图 1｜电梯里的体重计：读数在变，人没变

先分清两个词。实重就是重力本身，$G = mg$，由你所在位置的重力加速度和质量决定；你站在 1 楼还是 18 楼，只要还在同一地点，$g$ 就没变，实重就没变。视重则是“支撑你的那个力的大小”——你站在秤上，它等于秤对你的支持力；你挂在弹簧测力计下，它等于测力计对你的拉力。秤的示数显示的正是这个视重。

![黑板讲解页：视重是支持力或悬挂拉力的大小，超重为视重大于重力，失重为视重小于重力，完全失重为视重为零](/blog-images/k017-apparent-weight-concepts/K017-超重和失重-02-概念讲解-超重与失重.png)

图 2｜视重的定义：支持力或悬挂拉力的大小

所以开头那台秤没有坏，也没量错：电梯启动时它对你的支持力变了，它如实报告了支持力的大小。物理学把“视重大于实重”叫超重，“视重小于实重”叫失重，“视重恰好为零”叫完全失重。三个词说的都是支撑力与重力的比较，没有一个说“重力本身变了”——图 1 黑板最下面那行字就是这条底线。

## 二、什么决定视重：加速度，而且是唯一的决定者

![电梯中站在体重计上的人的受力图：支持力 N 竖直向上长于重力 mg，旁边画竖直向上的加速度 a](/blog-images/k017-apparent-weight-concepts/fig-c-elevator-fbd.png)

图 3｜电梯里的人只受两个力：重力 mg 与支持力 N

推导只需要两步。研究对象取电梯里的人，他只受两个力：重力 $mg$（地球施加，竖直向下）和秤的支持力 $N$（秤施加，竖直向上）。取竖直向上为正方向，把牛顿第二定律 $F_{\text{合}} = ma$ 用在这两个力上：

:::formula
N - mg = ma
:::

其中 $N$ 表示秤对人的支持力，$m$ 表示人的质量，$a$ 表示加速度（向上为正）。移项就得到视重的表达式：

:::formula
N = m(g + a)
:::

这个式子就是全部结论。$a > 0$（加速度向上）时 $N > mg$，超重；$a = 0$ 时 $N = mg$，视重等于实重；$-g < a < 0$（加速度向下但小于 $g$）时 $N < mg$，失重；$a = -g$ 时 $N = 0$，完全失重。

![黑板对照页：以竖直向上为正方向，a 大于零超重、a 在负 g 与零之间失重、a 等于零视重等于实重、a 等于负 g 完全失重](/blog-images/k017-apparent-weight-concepts/K017-超重和失重-03-原理关系-加速度决定视重.png)

图 4｜一张表记住：加速度方向决定视重大小（黑板版）

### 向上运动不等于超重

最容易出的错在这里：把“往上走”当成超重，把“往下走”当成失重。判断依据是加速度方向，与速度方向无关——速度只告诉你往哪边走，加速度才告诉你合力朝哪边。向上运动时既可以超重也可以失重，向下运动同理（图 5）。

![黑板对照页：向上加速超重、向上减速失重、向下加速失重、向下减速超重，判断依据是加速度而不是速度方向](/blog-images/k017-apparent-weight-concepts/K017-超重和失重-04-易错对照-看加速度方向.png)

图 5｜四种组合：判断依据是加速度，不是速度方向

把四种情况对着 $N = m(g + a)$ 逐一核对：向上加速，$a$ 向上，超重；向上减速，速度向上但 $a$ 向下，失重；向下加速，$a$ 向下，失重；向下减速，$a$ 向上，超重。下行的电梯启动和刹车时你膝盖感受到的“一轻一重”，对应的就是后两种。

### 例题一：电梯启动时的示数

:::problem
<span class="prob-grade">1.【基础题·常考题·计算题】</span><span class="prob-source">（自编，配套本篇课程板书图）</span>质量 $m = 50$ kg 的人站在电梯内的体重计上，电梯以 $a = 2$ m/s² 的加速度竖直向上做匀加速运动。人与秤保持接触，取 $g = 10$ m/s²。求：(1) 秤对人的支持力大小；(2) 秤受到的压力；(3) 此时人处于超重状态还是失重状态。
:::

:::answer
答案：(1) 600 N；(2) 600 N；(3) 超重。


　　① 题型识别。已知加速度求秤的示数——视重计算的标配问法，对象取人，两个力一条方程。


　　② 步骤模板。一定对象（人）；二列两个力（重力 $mg$ 向下、支持力 $N$ 向上）；三取正方向（竖直向上）；四列 $N - mg = ma$ 代入求解；五用牛顿第三定律把支持力换成压力。


　　③ 规范解答。取竖直向上为正方向，对人有：

$$N - mg = ma$$


$$N = m(g + a) = 50 \times (10 + 2)\ \text{N} = 600\ \text{N}$$


秤对人的支持力为 600 N。人对秤的压力与秤对人的支持力是一对作用力和反作用力（牛顿第三定律），大小相等，所以秤受到的压力也是 600 N。静止时视重应为 $mg = 50 \times 10\ \text{N} = 500\ \text{N}$，现在 $600\ \text{N} > 500\ \text{N}$，视重大于实重，人处于超重状态。


　　④ 易错点。第 ③ 步容易把 $N$ 直接当成“秤受到的力”——$N$ 是秤给人的力，作用在人身上；作用在秤上的是它的反作用力。数值相等靠的是牛顿第三定律，不是“同一个力”。


　　⑤ 变式。若电梯改为以 $a = 2$ m/s² 竖直向下匀加速，$N = m(g - a) = 50 \times 8\ \text{N} = 400\ \text{N}$，示数变小，失重。加速度换个方向，公式里的 $a$ 变号，仅此而已。

图 6｜例题一的问题页（黑板版）

![课程板书解析页：对人列 N − mg = ma，代入得 600 N，压力与支持力等大，600 N 大于 500 N 为超重](/blog-images/k017-apparent-weight-concepts/K017-超重和失重-06-电梯视重-解析.png)

## 三、一趟电梯的全程：示数怎么变

![上行电梯的 F-t 曲线：静立时为 mg，加速上升高于 mg，匀速等于 mg，减速上升低于 mg，停靠后回到 mg](/blog-images/k017-apparent-weight-concepts/fig-c-elevator-ft.png)

图 8｜一趟上行电梯的示数曲线：三段平台对应三种状态

真实电梯的行程分几段：启动（匀加速）、中途（匀速）、进站（匀减速）、停稳。对应到 $N = m(g + a)$，示数依次是：高于 $mg$、等于 $mg$、低于 $mg$、回到 $mg$。图 8 的曲线平台一个比一个低，最后回到虚线 $mg$——整趟电梯里重力没变过，变的只是 $N$。这张图也是图像题的原型：给你 $v$-$t$ 图或 $a$-$t$ 图，问示数怎么变，方法篇第二节专门讲。

### 例题二：下降时也会超重

:::problem
<span class="prob-grade">2.【提升题·易错题·计算题】</span><span class="prob-source">（自编，配套本篇课程板书图）</span>电梯正在下降，速度由 6 m/s 均匀减小到 2 m/s，这一过程历时 2 s。质量 $m = 50$ kg 的人站在电梯内的体重计上，与秤保持接触，取 $g = 10$ m/s²。求：(1) 这一过程加速度的大小和方向；(2) 秤受到的压力；(3) 人处于超重状态还是失重状态。
:::

:::answer
答案：(1) 2 m/s²，方向竖直向上；(2) 600 N；(3) 超重。


　　① 题型识别。先由速度变化求加速度，再求示数——运动学加动力学的两段式。陷阱在“下降”两个字：很多人看速度朝下就填失重。


　　② 步骤模板。一取正方向（竖直向上）；二按符号法则写出初、末速度；三用 $a = \frac{v - v_0}{t}$ 求加速度；四代 $N = m(g + a)$；五按牛顿第三定律给压力。


　　③ 规范解答。取竖直向上为正方向，则 $v_0 = -6$ m/s，$v = -2$ m/s，代入加速度定义式：

$$a = \frac{v - v_0}{t} = \frac{-2 - (-6)}{2}\ \text{m/s}^2 = 2\ \text{m/s}^2$$


结果为正，说明加速度竖直向上——下降得越来越慢，合力必须朝上。再由牛顿第二定律：

$$N = m(g + a) = 50 \times (10 + 2)\ \text{N} = 600\ \text{N}$$


由牛顿第三定律，秤受到的压力为 600 N。视重大于实重 500 N，人处于超重状态。速度向下、加速度向上，两件事同时成立。


　　④ 易错点。第 ② 步的符号最容易乱：速度是负的（向下），“减小到”意味着末速度比初速度离零更近，$-2$ 比 $-6$ 大，所以 $a$ 算出来是正的。若不想用符号，可以按“向下为正”再算一次：$a = \frac{2 - 6}{2}\ \text{m/s}^2 = -2\ \text{m/s}^2$，负号表示加速度与正方向相反，即竖直向上——两种取法结果一致。


　　⑤ 变式。若电梯下降时速度由 2 m/s 均匀增大到 6 m/s，$a$ 变为竖直向下 2 m/s²，$N = 400\ \text{N}$，失重。同是下降，加速与减速的视重一个小于 $mg$、一个大于 $mg$。

![课程板书解析页：取向上为正，v0 为负 6、v 为负 2，算得 a 为 2 m/s² 向上，N 为 600 N，超重](/blog-images/k017-apparent-weight-concepts/K017-超重和失重-08-加速减速辨析-解析.png)

## 四、完全失重：视重为零，重力仍在

现在把失重推到头。当人随电梯以 $a = g$ 竖直向下加速（比如忽略阻力的自由下落），代入 $N = m(g + a)$，$a = -g$：

:::formula
N = m(g - g) = 0
:::

支持力为零，视重为零，这就是完全失重。它有两个要点，缺一不可。

![自由下落的电梯内：人悬浮、脚离开体重计，秤的读数为零，水滴悬在空中，旁边画竖直向下的 a 等于 g](/blog-images/k017-apparent-weight-concepts/fig-c-weightless.png)

图 11｜完全失重情境：人和电梯一起以 g 下落，彼此无挤压

第一，完全失重时重力并没有消失。人受的重力照旧是 $mg$，正是这个力让他获得了 $g$ 的加速度。消失的只是“相互挤压”：人和电梯以同样的加速度下落，谁也不推谁，秤读零、脚离地、身体飘起来。

第二，凡是内部以重力获得加速度的场合，内部的相互作用都会消失。把一杯水泼出去让它自由下落，水在空中不洒（各部分以 $g$ 下落，互不挤压）；竖直上抛、平抛、斜抛的物体在只受重力时加速度也是 $g$，同样处于完全失重——扔出去的水瓶在空中时，瓶与水之间没有压力。绕地球飞行的空间站里航天员处处飘浮，也是同一类现象；它的完整解释要用到轨道运动，到必修二万有引力部分再展开，这里先记住：空间站中不是“没有引力”，而是引力全部用来产生加速度，物体之间不再相互挤压。

### 例题三：自由下落的电梯里，人受几个力

:::problem
<span class="prob-grade">3.【提升题·经典题·简答题】</span><span class="prob-source">（自编，配套本篇课程板书图；理想情境）</span>电梯连同其中的人（质量 $m = 50$ kg）一起由静止开始自由下落，忽略空气阻力和一切其他约束，取 $g = 10$ m/s²。问：(1) 人受到的重力多大？(2) 秤对人的支持力多大？(3) 能否说“人不受重力”？
:::

:::answer
答案：(1) 500 N；(2) 0 N；(3) 不能。


　　① 题型识别。自由落体加视重——完全失重的判断与解释，考的恰恰是“视重为零”与“重力为零”是不是一回事。


　　② 步骤模板。一写重力（永远 $mg$）；二由运动定加速度（自由落体 $a = g$，方向竖直向下）；三代 $N - mg = ma$ 解支持力；四按“视重与重力分开”作答。


　　③ 规范解答。重力照常存在：

$$G = mg = 50 \times 10\ \text{N} = 500\ \text{N}$$


自由下落意味着加速度大小为 $g$、方向竖直向下。取竖直向上为正方向，$a = -g$，对人有：

$$N - mg = m(-g)$$


$$N = m(g - g) = 0\ \text{N}$$


秤对人的支持力为零，人对秤也没有压力，视重为零。(3) 不能说人不受重力——重力 500 N 一直都在，它正是人获得 $g$ 加速度的原因；消失的只是人与秤之间的弹力。


　　④ 易错点。第 (3) 问最常见的错误是“完全失重就是没有重力”。检验方法：若真没有重力，人将保持静止或匀速直线运动（牛顿第一定律），根本不会跟着电梯一起加速下落——现象本身否定了这个说法。


　　⑤ 变式。若电梯以 $a = g$ 竖直向上加速，$N = m(g + g) = 2mg = 1000\ \text{N}$，视重翻倍——对称地叫“完全超重”的极端。上下两个极端放在一起，$N = m(g + a)$ 这条式子就吃透了。

## 五、从黑板到实验室：称重与传感器情境

课本里的“视重”不只属于电梯。凡是能读出“支撑力或拉力大小”的装置，都是视重的测量仪，高中阶段常见三类。

第一类是弹簧测力计与台秤：挂在下面或放在上面，示数就是视重，重力计、磅秤都属此类。第二类是力传感器：把重物挂在传感器下，计算机直接记录拉力随时间的变化曲线，相当于把图 8 的曲线自动画出来。第三类是自制加速度计：课本和北京卷都考过一个装置——弹簧下挂钢球、旁边立一把直尺，加速度变，弹簧伸长变，指针指的刻度就变，标定之后“看刻度、读加速度”。这三类的解题动作完全一致：读数是弹力，弹力进 $N - mg = ma$，解出未知量。方法篇第四节用一道高考真题完整示范。

顺带交代一句历史。人类对“失去支撑”的体验相当晚近：1961 年 4 月 12 日，加加林乘东方一号绕地球飞行一圈，成为第一个在轨道上持续感受完全失重的人；2003 年杨利伟乘神舟五号进入太空，中国人第一次在自己的飞船里体验飘浮；2021 年 12 月 9 日，航天员王亚平在天宫课堂里把一个水球悬在空中讲光学——水球能保持球形不落不洒，正是“内部相互作用消失”的演示。从牛顿笔下的思想实验到课堂里的水球，凭的都是今天这两条式子：$N - mg = ma$ 和 $N = m(g + a)$。

## 六、常见错误与边界

错误一：用速度方向判断超失重。向上运动可以失重（减速上升），向下运动可以超重（减速下降）。唯一的判据是加速度方向，见第二节图 5 的四种组合。

错误二：认为超重、失重时重力变了。重力 $mg$ 由质量和当地重力加速度决定，与运动状态无关；电梯里的人从超重到失重，重力一个单位都没变，变的是支持力。

错误三：把完全失重当成不受重力，或把失重范围说成“ $N$ 可以小于零”。加速度向下超过 $g$ 时，人必须靠安全带之类向下的拉力按住（飞机急剧下坠就是这个情境），此时“对座椅的压力”已无从谈起；这些边界情况方法篇示范 1 会算给你看。

边界说明：本单元全部情境限于一维竖直方向（或加速度沿索道的斜直运动），不涉及轨道航天器的引力计算，也不引入能量分析；完全失重只做现象级解释。

## 七、本节知识整理

表 1｜超重与失重要点

| 要点 | 内容 |
| --- | --- |
| 实重 | $G = mg$，由质量与当地重力加速度决定，不随运动状态变化 |
| 视重 | 支撑力（支持力或悬挂拉力）的大小，即秤的示数 |
| 判断依据 | 取向上为正，$N = m(g + a)$；只看 $a$ 的方向，不看速度方向 |
| 超重 | $a$ 向上，$N > mg$（向上加速、向下减速） |
| 失重 | $a$ 向下且大小小于 $g$，$N < mg$（向上减速、向下加速） |
| 完全失重 | $a = g$ 竖直向下（自由落体、各类抛体），$N = 0$，内部相互作用消失，重力仍在 |
| 常见装置 | 体重计、磅秤、弹簧测力计、力传感器、竖直加速度测量仪 |

下篇预告：概念只有一条式子，题目却有四副面孔——示数计算、图像判断、完全失重现象、传感器与称重实验。《超重和失重②》给每类题一条固定路径。

> 家长翻译器：您跟孩子可以只问两句。“电梯往上走，人一定超重吗？”答“不一定，向上减速时是失重，得看加速度”就过关了。“跳楼机的下坠段人为什么感觉轻飘飘？”答“人和座椅都以接近 g 下落，彼此不挤压，视重接近零”就说明完全失重是真懂了。
