你多半见过这个场面：家里挪柜子，你憋红了脸推，它纹丝不动；再加个人手，柜子"哐"地滑动起来——动起来之后，维持它滑动反而不用那么大力气了。推不动的时候，是谁在跟你较劲？动起来之后，较劲的力为什么变小了？

两个问题的答案都是摩擦力，但它们不是同一种摩擦力。前者叫静摩擦力，后者叫滑动摩擦力。这一篇把这两类力讲透：怎么产生、方向怎么定、大小怎么算。

再补一个更邪门的真实场景：中央电视台《是真的吗》栏目做过一期实验，把两本书一页对一页交叉叠好、压实，然后用电动装置对拉，结果拉力加到很大，两本书依然分不开。学完这篇，你可以自己回家解释它。

## 一、物理学史：被琢磨了两千年的"熟悉的陌生人"

摩擦是那种人人天天在用、却迟迟没被研究明白的现象。古代人靠润滑、滚木这些经验对付它，真正动手做实验研究摩擦的第一人，是画蒙娜丽莎那位——达·芬奇。

![老师站在黑板前讲解推而未动与滑动两类情境](/blog-images/k009-friction/K009-摩擦力-01-情境引入-推箱子与相对运动.png)

图 1｜推而未动（有相对运动趋势）与滑动（有相对运动）是两种不同状态

15 世纪末，达·芬奇在笔记本里画了一个测量摩擦的装置：木块放在木板上，绳子绕过滑轮挂砝码，刚好能拉动物块时，砝码的重力就等于摩擦力。根据手稿记载，他得出两条非常超前的结论：摩擦力与正压力成正比；摩擦力与接触面积基本无关。这两条直到今天还写在教材里。可惜手稿没有发表，一压就是两百多年。

1699 年，法国科学院的阿蒙东（Guillaume Amontons）用类似的装置重新做了实验，向科学院报告了同样的规律：摩擦力与正压力成正比、与接触面积无关，还给出一个粗略比例——摩擦力约为正压力的三分之一。这几乎就是 $f = \mu F_N$ 的雏形，后人把这两条合称阿蒙东定律。

1781 年，法国科学院以"简单机械理论"为题悬赏，获奖的是库仑（Charles-Augustin de Coulomb，就是后来电学里那个库仑）。他把静摩擦和动摩擦明确区分开，指出最大静摩擦力略大于滑动摩擦力，滑动摩擦力在低速范围内几乎不随速度变化。高中摩擦力的知识框架，在库仑这里基本成型。

至于摩擦力的微观本质——接触面凹凸的相互啮合、表面分子之间的电磁相互作用——要到二十世纪才逐渐弄清。所以你觉得摩擦力"看着简单、细想别扭"，很正常，人类整体也是这么过来的。

## 二、定义与产生条件：差一个字，差一个世界

两个相互接触的物体，发生相对运动或具有相对运动趋势时，在接触面上会产生阻碍相对运动或相对运动趋势的力，这就是摩擦力。按接触面之间"动没动"，摩擦力分两类。

![黑板对比静摩擦力与滑动摩擦力的定义与条件](/blog-images/k009-friction/K009-摩擦力-02-概念讲解-静摩擦与滑动摩擦.png)

图 2｜静摩擦力与滑动摩擦力：接触面之间"没滑动"与"滑动了"

- 滑动摩擦力：接触面之间发生了相对滑动时产生的摩擦力。
- 静摩擦力：接触面之间保持相对静止、但有相对运动趋势时产生的摩擦力。

产生条件两条共用，三条，缺一不可：

1. 接触并挤压（接触面之间有弹力）；
2. 接触面粗糙；
3. 发生相对运动（滑动摩擦力），或有相对运动趋势（静摩擦力）。

表 1｜两类摩擦力速览

| 项目 | 静摩擦力 | 滑动摩擦力 |
| --- | --- | --- |
| 接触面间的状态 | 相对静止，有相对运动趋势 | 发生相对滑动 |
| 方向 | 与相对运动趋势方向相反 | 与相对运动方向相反 |
| 大小 | 由受力情况定，$0 \le f \le f_{max}$ | $f = \mu F_N$ |
| 有无公式 | 没有（用平衡求） | 有 |

先看一道辨析题，把"摩擦力离不开弹力"这件事钉牢。

### 例题一

:::problem
<span class="prob-grade">1.【基础题·易错题·选择题】</span><span class="prob-source">（学而思秋季讲义《摩擦力和受力分析》即学即练 1）</span>下列关于摩擦力与弹力关系的说法中，正确的是（　　）

　　A．有弹力一定有摩擦力

　　B．有摩擦力不一定有弹力

　　C．有摩擦力一定有弹力

　　D．有弹力不一定有摩擦力
:::

:::answer
答案：CD。

　　① 题型识别。问"摩擦力与弹力谁离不开谁"，考的是产生条件第二条的依赖关系：摩擦力的条件里包含弹力，反过来不成立。

　　② 步骤模板。把产生条件摆出来——接触并挤压（弹力）、粗糙、有相对运动或趋势——然后对每个选项问一句：条件齐了吗？

　　③ 规范解答。有摩擦力，三个条件必须齐全，其中就包括弹力，所以"有摩擦力一定有弹力"，C 对、B 错。有弹力只满足了第一条，如果接触面光滑、或者没有相对运动也没有相对运动趋势，就没有摩擦力，D 对、A 错。举两个现成的例子：竖直墙边挨着一面光滑的镜子，互相接触挤压但没有摩擦（面光滑）；放在水平地面上的箱子，与地面既有弹力又粗糙，但没推它时没有运动趋势，也没有摩擦（无趋势）。

　　④ 易错点。第 ③ 步容易把"接触"当成"挤压"——两个物体挨着但互相不压，连弹力都没有，摩擦力更谈不上。弹力是摩擦力的必要条件，不是充分条件。

　　⑤ 变式。把"有弹力一定有摩擦力"改成"有摩擦力一定有弹力"再判断一次？这正是 C 的内容，是对的——条件列表里写着呢。
:::

## 三、方向：跟"相对"这两个字过不去

摩擦力的方向：沿接触面，与相对运动方向相反（滑动摩擦力），或与相对运动趋势方向相反（静摩擦力）。

这句话里最难的是"相对"。它永远指互相接触的两个物体互为参照物，跟地面、跟旁观的我们都无关。所谓相对运动趋势，用一个假设来定义：假如接触面突然变光滑，物体将朝哪个方向相对滑动，它原本的趋势就朝哪个方向。

例题一里"有摩擦力一定有弹力"，这里再补一句方向上的配套关系：同一接触面上的弹力与摩擦力互相垂直——弹力垂直于接触面，摩擦力沿接触面。

摩擦力阻碍的是"相对运动"，不一定阻碍物体的运动。人走路就是最好的例子：后脚向后蹬地，脚相对地面有向后滑的趋势，地面给后脚向前的静摩擦力——正是这个力把你推向前进；前脚向前迈、落地瞬间相对地面有向前滑的趋势，地面给前脚向后的静摩擦力，防止你滑出去。一个向前、一个向后，全看"相对趋势"，不看"人在往哪走"。

### 例题二

:::problem
<span class="prob-grade">2.【基础题·经典题·选择题】</span><span class="prob-source">（学而思秋季讲义《摩擦力和受力分析》即学即练 4，题干缺损文字按原题语境复原）</span>在校田径运动会上，高一某班李好同学奋力拼搏，勇夺男子百米冠军，如图为该同学奔跑途中的两个瞬间，用 $f_1$、$f_2$ 分别表示该同学在图甲、图乙两瞬间所受到的摩擦力，则关于 $f_1$、$f_2$ 的方向，以下说法正确的是（　　）

　　A．$f_1$、$f_2$ 均向后

　　B．$f_1$、$f_2$ 均向前

　　C．$f_1$ 向前，$f_2$ 向后

　　D．$f_1$ 向后，$f_2$ 向前
:::

:::answer
答案：C。

　　① 题型识别。问摩擦力方向，先别看人在往哪跑，只问一件事：这只脚相对地面往哪边滑（或想往哪边滑）。

　　② 步骤模板。定接触面（脚与地面）→ 假设脚底绝对光滑、问脚会往哪边滑 → 摩擦力方向与它相反。

　　③ 规范解答。图甲是后脚蹬地：后脚用力向后蹬，若地面光滑这只脚会向后滑，所以它受到地面向前的静摩擦力，$f_1$ 向前——人正是靠这个力向前跑的。图乙是前脚前跨落地：前脚相对地面有向前滑的趋势，地面对它的静摩擦力向后，$f_2$ 向后。选 C。

　　④ 易错点。最容易凭直觉选 B（"人向前跑，摩擦力都向前"）——判断对象搞错了：摩擦力跟的是"脚相对地面的趋势"，前后脚的趋势相反，受力就相反。

　　⑤ 变式。原地站着的同学受摩擦力吗？不受——双脚与地面既无相对运动也无相对运动趋势，两个条件都不占。
:::

![黑板上画着传送带上的箱子受到向右的滑动摩擦力](/blog-images/k009-friction/K009-摩擦力-04-易错对照-摩擦力可以是动力.png)

图 4｜摩擦力可以是动力：传送带把箱子向前"带"，靠的是向右的滑动摩擦力

传送带上的箱子也一样：刚放上去时箱子比带慢，相对传送带向后滑，传送带给它向前的滑动摩擦力——这个摩擦力是箱子加速的动力。摩擦力是阻力还是动力，取决于它阻碍的相对运动恰好与物体的运动同向还是反向，别提前下结论。

## 四、静摩擦力的大小：一个"看外力脸色"的力

静摩擦力没有现成公式，它的大小由受力情况决定。物体静止时，沿运动趋势方向看：外力想推多少，静摩擦力就补多少，恰好抵消。

:::formula
f = F_{\text{外}}（物体静止、沿接触面方向二力平衡时）
:::

它的取值范围是 $0 \le f \le f_{max}$：最小可以是零（没有趋势就没有摩擦），最大到 $f_{max}$——超过这个数，物体就要滑起来了。

![黑板上列出推力依次为 0、3、5 N、最大静摩擦力 6 N 的问题](/blog-images/k009-friction/K009-摩擦力-05-静摩擦判断-问题模型.png)

图 5｜推力从 0 加到 5 N，箱子始终没动，各阶段静摩擦力多大

### 例题三

:::problem
<span class="prob-grade">3.【基础题·常考题·计算题】</span><span class="prob-source">（自编，与本文图 5、图 6 配套）</span>一只木箱放在水平地面上。某人用水平推力推它，推力大小依次取 0、3 N、5 N，木箱始终静止。已知木箱与地面间的最大静摩擦力为 6 N。求推力分别为 0、3 N、5 N 时，木箱受到的摩擦力的大小和方向。
:::

:::answer
答案：摩擦力依次为 0、3 N（方向与推力相反）、5 N（方向与推力相反）。

　　① 题型识别。"始终静止 + 问摩擦力"，走静摩擦路线：用平衡求，不用 $f = \mu F_N$。

　　② 步骤模板。一核对状态（静止？）→ 二看水平方向受几个力 → 三按二力平衡写出 $f = F$，方向与推力相反 → 四确认没超过 $f_{max}$。

　　③ 规范解答。三个阶段木箱都静止，水平方向只有推力和静摩擦力。推力为 0 时，木箱没有运动趋势，$f = 0$。推力为 3 N 时，$f = F = 3$ N，方向与推力相反——3 N 小于最大静摩擦力 6 N，木箱保持静止，判断成立。推力为 5 N 时同理，$f = F = 5$ N，方向与推力相反。

　　④ 易错点。第 ② 步最容易顺手写 $f = \mu F_N$——公式是滑动摩擦力的，静摩擦力不吃这一套。本题没给 $\mu$，就是在提醒你这条路不通。

　　⑤ 变式。推力加到 8 N 呢？超过了 $f_{max} = 6$ N，木箱滑动，摩擦力改由滑动摩擦力接管（本文第六节处理这个局面）。
:::

![黑板解析：F=0、3 N、5 N 时静摩擦力分别为 0、3 N、5 N，方向向左](/blog-images/k009-friction/K009-摩擦力-06-静摩擦判断-平衡条件解析.png)

图 6｜静摩擦力随推力"量身定做"，始终与推力平衡

静摩擦力是个被动力：外力要多少，它在额度内给多少，像一把"智能刹车"。记住它的两个特征——大小看外力、上限是 $f_{max}$——本单元一半的题就够用了。

## 五、最大静摩擦力：滑动前的门槛

$f_{max}$ 是静摩擦力的上限：两物体即将发生相对滑动、又还没滑动时的静摩擦力。它跟两件事有关：接触面之间的正压力越大，$f_{max}$ 越大；接触面越粗糙，$f_{max}$ 越大。

实验还发现，$f_{max}$ 略大于滑动摩擦力。所以拉一个重物有个常见体验：最费劲的是让它"动起来"的那一下，动起来之后反而省力——因为摩擦力从 $f_{max}$ 跳到了较小的滑动摩擦力。不过这个差别不大，做计算时，题目通常会声明"最大静摩擦力近似等于滑动摩擦力"，按声明处理。

## 六、滑动摩擦力：f = μF_N

滑动摩擦力的大小与正压力成正比：

:::formula
f = \mu F_N
:::

其中 $f$ 表示滑动摩擦力的大小；$F_N$ 表示正压力，即垂直于接触面的压力（K008 里支持力、压力那一套）；$\mu$（读作"谬"）叫动摩擦因数。

三个量各有讲究：

- $F_N$ 是正压力，不一定等于重力。物体放在水平面上、竖直方向只受重力和支持力时，才有 $F_N = mg$；要是有人向下压它、或斜着拉它，$F_N$ 就变了。把所有摩擦力都写成 $\mu mg$，是这个单元丢分最多的一步。
- $\mu$ 是两个力的比值，没有单位，由接触面的材料和粗糙程度决定，与接触面积大小无关、与滑动速度无关（低速范围）。玻璃对玻璃与橡胶对沥青，$\mu$ 完全不同，教科书列过常见值：钢对钢约 0.1 到 0.25（有润滑时更小），橡胶对沥青路面约 0.7。
- $f$ 的方向与相对运动方向相反，沿接触面。

### 例题四

:::problem
<span class="prob-grade">4.【基础题·常考题·计算题】</span><span class="prob-source">（自编，与本文图 10、图 11 配套）</span>质量 $m = 2$ kg 的木块在粗糙的水平面上向右滑动，木块与水平面间的动摩擦因数 $\mu = 0.20$，取 $g = 10$ m/s²。求木块受到的滑动摩擦力的大小和方向。
:::

:::answer
答案：4 N，方向水平向左。

　　① 题型识别。"滑动 + 给 μ"，走滑动摩擦公式 $f = \mu F_N$；关键是先求正压力 $F_N$。

　　② 步骤模板。一分析竖直方向求 $F_N$ → 二代入 $f = \mu F_N$ → 三按相对运动方向定方向。

　　③ 规范解答。木块在水平面上滑动，竖直方向只受重力 $mg$ 和支持力 $F_N$，二力平衡，$F_N = mg = 2 \times 10 \text{ N} = 20 \text{ N}$。代入滑动摩擦力公式，$f = \mu F_N = 0.20 \times 20 \text{ N} = 4 \text{ N}$。木块相对地面向右滑动，摩擦力方向与相对运动方向相反，水平向左。

　　④ 易错点。第 ② 步最容易把 $F_N$ 与 $mg$ 混为一谈就直接跳过去——本题恰好相等，但这是"竖直方向只受这两个力"的结果，不是定义。第 ③ 步方向容易丢：只答大小不答方向，计算题要扣分。

　　⑤ 变式。滑动中再加一个 8 N 的水平向右拉力，摩擦力变吗？不变——还是 4 N，滑动摩擦力只认 $\mu$ 和 $F_N$，不认别的力。改成用一个 30 N 的力竖直向下压木块呢？$F_N$ 变成 $20 \text{ N} + 30 \text{ N} = 50 \text{ N}$，摩擦力变成 $0.20 \times 50 \text{ N} = 10 \text{ N}$——正压力一变，公式立刻给出新答案。
:::

## 七、μ 是谁、怎么测：一个不需要匀速的好装置

$\mu$ 反映的是接触面本身的性质：同样的压力下，$\mu$ 越大，滑动摩擦力越大。想测两物体间的 $\mu$，思路直接：测出滑动摩擦力 $f$ 和正压力 $F_N$，按定义算比值 $\mu = \frac{f}{F_N}$——这正是阿蒙东和库仑当年做的事。

初学者最容易想到的办法是弹簧测力计拉着物块做匀速运动（拉力才等于摩擦力）。但"手控匀速"几乎做不到，测出来的示数忽大忽小。看下面这个装置怎么绕开这个麻烦。

### 例题五

:::problem
<span class="prob-grade">5.【基础题·经典题·选择题】</span><span class="prob-source">（学而思暑假讲义《摩擦力》即学即练 9）</span>如图所示为研究木板与木块之间摩擦力大小的实验装置，将一木块和木板叠放于水平桌面上，轻质弹簧测力计一端固定，另一端用细线与木块水平相连。现在用绳子与长木板连接，用手向右水平拉绳子，使长木板在桌面上滑动，下列说法中正确的是（　　）

　　A．木块与木板之间的摩擦力是静摩擦力

　　B．木板必须在桌面上做匀速直线运动

　　C．木板必须在桌面上做匀加速直线运动

　　D．木板运动过程中，弹簧测力计示数等于木块受到的摩擦力
:::

:::answer
答案：D。

　　① 题型识别。装置题：先问每个部分"动没动、相对谁动"，再问示数由谁决定。

　　② 步骤模板。一判摩擦力种类（木块与木板之间有相对滑动 → 滑动摩擦力）→ 二看滑动摩擦力由什么决定（$\mu$ 与 $F_N$，与木板跑多快无关）→ 三对木块用平衡读出示数。

　　③ 规范解答。木板被拉动后，木块相对木板向左滑动（木板向右走），两者之间是滑动摩擦力，A 错。滑动摩擦力大小 $f = \mu F_N$，$\mu$ 和 $F_N$ 都不变，木板匀速还是加速都一样，B、C 错。木块始终静止，水平方向受测力计拉力和滑动摩擦力，二力平衡，示数始终等于摩擦力，D 对。

　　④ 易错点。第 ② 步容易沿袭"必须匀速"的旧印象选 B——那是"拉物块做匀速运动"那个老装置的要求。这里动的是木板，木块根本没动，示数自然稳。

　　⑤ 变式。读出示数 $F$、再称出木块重力 $G$，怎么算 $\mu$？$F_N = G$（木块竖直方向平衡），$\mu = \frac{F}{G}$。第三章的实验篇会用纸带和光电门把这套测量再做一遍。
:::

## 八、常见错误与边界情况

表 2｜高频错误与正确处理

| 错误 | 反例或边界 | 正确处理 |
| --- | --- | --- |
| 有摩擦力就写 $f = \mu F_N$ | 静摩擦力没有公式 | 先判状态：静止用平衡，滑动用公式 |
| 正压力一律写 $mg$ | 竖直墙、夹板、外加压力的情境 | 对受力物体做竖直（垂直于接触面）方向分析求 $F_N$ |
| 摩擦力一定是阻力 | 人走路、传送带加速行李 | 摩擦力阻碍相对运动，可以与运动方向相同 |
| 运动的物体不受静摩擦力 | 随传送带匀速上行的物体 | 静摩擦力看"相对"，不看"动没动" |
| 静止的物体不受滑动摩擦力 | 擦黑板时静止的黑板 | 黑板相对板擦在滑，受滑动摩擦力 |
| 忽略"最大静摩擦力近似等于滑动摩擦力"的声明 | 计算题与图线题 | 没声明时只定性比较，声明了才代入计算 |

## 九、本节知识整理

表 3｜K009 核心结论

| 结论 | 内容 | 条件与边界 |
| --- | --- | --- |
| 产生条件 | 接触挤压（弹力）、粗糙、相对运动或趋势 | 三条同时满足，缺一不可 |
| 静摩擦方向 | 与相对运动趋势方向相反，沿接触面 | 趋势 = 假想接触面光滑时的滑动方向 |
| 静摩擦大小 | $0 \le f \le f_{max}$，静止时与外力平衡 | 与正压力无关；没有公式 |
| 最大静摩擦力 | 与正压力成正比，略大于滑动摩擦力 | 计算中按题目声明近似处理 |
| 滑动摩擦力 | $f = \mu F_N$ | $F_N$ 为正压力，不一定等于 $mg$ |
| 动摩擦因数 | $\mu = \frac{f}{F_N}$，无单位 | 由材料与粗糙程度决定，与面积、速度无关 |

## 十、这些知识会长成哪些题

原理就这六条，题目千变万化，落点无非六类：判断有没有摩擦力、判断方向、算静摩擦力、用公式算滑动摩擦力、抓"静变滑"的突变瞬间、读 f-F 图像。《摩擦力②》按这六类题各给一条"识别、思路、方法"的固定路径，示范题全部来自真题与经核验的教辅题；练手题在《摩擦力③》，答案自闭环。

> 家长翻译器：跟孩子就问三句。"推箱子没推动，摩擦力多大？"答"等于推力，推力多大它多大"就通了。"什么力决定动不动得了？"答"最大静摩擦力"。"滑动之后摩擦力还跟着推力变吗？"答"不变，只看压力和粗糙程度"——三问都对，这一节就过关了。
