开学第一周，有个学生问我：老师，我打游戏扔雷，明明往远处扔，怎么每次都砸脚边？我说这个问题问得好，高考每年都考，就是你扔出去那个雷的运动方式，学名叫平抛运动。

今天把这道题彻底讲明白。放心，不需要你先学会微积分，高中学的方法其实相当漂亮。

## 先看一个实验：两个球，谁先落地

桌边固定一个装置，能同时干两件事：把一颗钢球水平弹出去，另一颗同样的钢球被松开、竖直下落。一颗走曲线，一颗直线下坠。

凭直觉，水平飞出去的那颗走的路更远，应该更晚落地才对。

实验结果是两颗球每次都同时落地。不管弹射速度快一点还是慢一点，也不管桌子高一点还是矮一点，只要它们从同一高度同时出发，落地的声音永远只有一下。

![平抛与自由落体对比实验，两球同时落进沙槽](/blog-images/projectile-motion-lab/two-balls-land-together.png)

这个现象说明一件事：水平方向的运动，完全不影响竖直方向的下落。两个方向各忙各的，互不打扰。这就是平抛运动全部秘密的入口。

## 拆开看：一个曲线运动，其实是两个直线运动

平抛运动定义很简单：只受重力、有水平初速度的抛体运动。麻烦在于它的轨迹是曲线，速度的大小和方向每时每刻都在变，直接套匀速或匀加速的公式全都行不通。

高中物理处理曲线运动的标准思路是分解。把一个复杂的曲线运动，拆成两个互相垂直的直线运动，分别算清楚，再合起来。

拆法如下：

- **水平方向**：不受力（忽略空气阻力），所以是匀速直线运动，速度一直是抛出时的 v₀。
- **竖直方向**：初速度为零，只受重力，是标准的自由落体运动。

![平抛运动分解原理：水平匀速，竖直自由落体](/blog-images/projectile-motion-lab/decomposition-principle.png)

拆开之后，每个方向都是你最熟悉的运动，公式直接搬过来（下式中 vₓ、v_y 分别是水平、竖直分速度）：

水平方向保持初速度不变，位移随时间均匀增长：

:::formula
vₓ = v₀　　x = v₀t
:::

竖直方向从零开始越落越快，位移按平方增长：

:::formula
v_y = gt　　y = {1/2}gt²
:::

那两个球为什么同时落地？因为竖直方向它们做的是同一个运动：都从静止开始、以同样的加速度 g 下落。落地时间由高度单独决定，跟水平扔多快没有任何关系。

:::formula
t = √({2h/g})
:::

![两球同高同时释放的实验原理示意图](/blog-images/projectile-motion-lab/principle-diagram.png)

记住这个结论，它反过来也是平抛题目的第一问常客：给高度求时间。不管题目给了多花哨的情景，平抛运动在空中的时间只由下落高度决定。

## 轨迹为什么是抛物线

把两个方向的位移合在一起。从竖直式子里解出落地时间，代进水平式子，整理得到：

:::formula
y = {g·x² / 2v₀²}
:::

眼熟吗？这是数学课上的抛物线。"抛物线"这个名字，本来就是这么来的：东西抛出去，走的就是这条线。

实验室里验证这一步的办法很朴素：用小钢球重复多次平抛，每次在坐标纸上留下一个点，最后用平滑曲线把点连起来。描出来的形状和推导一致。

![描点法观察平抛运动轨迹](/blog-images/projectile-motion-lab/trajectory-observation.png)

## 考试的时候，题目会怎么挖坑

平抛是高考力学板块的常客，单独考或者跟斜面、传送带、圆周运动拼在一起考。分享三个最常踩的坑。

**第一个坑：落地时间由谁决定。** 很多学生看球飞得快，就默认它在空中待得更久。上面那个根式已经证明了，空中时间只看高度。想要飞得远，光快没用，还得抛得高。速度影响的是水平位移 x = v₀t，时间不变，速度越大飞得越远，这是两个独立的变量。

**第二个坑：把速度直接相加。** 求落地速度，常见错误是 v = v₀ + gt。速度是矢量，方向不同不能直接加减，要用勾股定理合成：

:::formula
v(落) = √(v₀² + (gt)²)

tanθ = {gt/v₀}
:::

第一个式子算落地速度大小，第二个式子算它与水平方向的夹角 θ。θ 是速度偏角，别跟位移偏角搞混，这两个角之间有个常考关系：速度偏角的正切值，正好是位移偏角正切值的两倍，即 tanθ = 2tanα。

**第三个坑：反过来用，从轨迹求初速度。** 题目给一条带网格的抛物线，问初速度。思路倒过来走：读出某点的坐标 (x, y)，竖直方向先用公式块里的式子算时间，水平方向再算：

:::formula
v₀ = {x/t}
:::

正着拆、反着合，平抛题翻来覆去考的就这两下。

## 这个方法的价值，超出这道题

分解运动这个思路，后面还要反复用到。斜面上的物体，沿斜面方向和垂直斜面方向分解；带电粒子在电场里偏转，跟平抛几乎一模一样，只是把重力换成了电场力，物理圈管它叫"类平抛"。

学会平抛，等于同时学完了类平抛。高考物理里，一个方法吃两章内容，这种买卖不常有。

给孩子辅导的时候，不用急着上公式。饭桌上问问：往水流的反方向走和顺着水流走，哪个先到对岸？划船渡河的问题跟平抛共用同一套分解逻辑。物理感觉是在这种闲聊里长出来的，比多刷十道题管用。

下一篇打算讲斜面上的分解，那是平抛的表亲，坑也一样多。
