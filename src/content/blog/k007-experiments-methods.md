实验原理看完《第二章实验①》，题还是可能不会做——差距不在物理，在翻译：题目给的是一段情境和几个数据，你要能把它翻译回一个测量任务，再选出对应的处理路径。这篇把运动学实验题按任务分成四类，每类走一遍"问题实质 → 已知与目标 → 路径选择 → 完整示范 → 条件变化 → 方法边界"。

- 对应教材：人教版必修第一册 第二章 实验节。
- 本篇类型：第二章实验单元题型与方法篇。
- 前置知识：主讲篇《第二章实验①》的全部推导（中间时刻定理、逐差法、光电门、误差方向）都在①里，本篇只引用不重复。
- 学习目标：拿到任何一道运动学实验题，先说出它属于哪类任务、缺什么条件、该走哪条路径，再说"为什么是这条路"。
- 配套文章：原理见《第二章实验①》；分层练习 24 道见《第二章实验③》，文末附本单元答案区。

## 任务总览

| 任务 | 问题实质 | 需要的条件 | 路径 | 常见问法 |
| --- | --- | --- | --- | --- |
| 一、求速度 | 已知两段位移求中间点，或已知遮光量求过门速度 | 纸带三相邻点；或 d 与 Δt | 中间时刻定理；$v = \frac{d}{\Delta t}$ | "打 B 点时速度""经过光电门的速度" |
| 二、求加速度 | 从多段位移或两点速度中提取 a | 偶数段位移 + T′；或双门速度 + L；或多组 (v, t) | 逐差法；$\frac{v_B^2 - v_A^2}{2L}$；v–t 图斜率 | "加速度大小""逐差法处理" |
| 三、判断性质与取舍数据 | 确认模型是否成立、数据能不能用 | 各段位移或 $\Delta x$ | $\Delta x$ 体检；异常点查原因 | "判断运动性质""如何处理这组数据" |
| 四、评估可信度 | 结果偏差的方向、原因与改进 | 原理式 + 每个量的偏差 | 偏差代回原理式推方向 | "偏大还是偏小""属于误差还是错误" |

## 任务一：求速度——先看"哪两段、哪个量"

问题实质：速度是间接量，题目必须提供"位移与时间"（纸带）或"遮光宽度与遮光时间"（光电门）。求速度前先问自己：时间从哪来？

- 纸带上求某计数点的速度：时间来自计数点间隔 $T'$，用中间时刻定理 $v_n = \frac{x_n + x_{n+1}}{2T'}$，左右两段夹住中间点。前提是匀变速（实验里先处理再检验，两步互证）。
- 光电门求过门速度：$v = \frac{d}{\Delta t}$，本质是遮光段的平均速度，匀变速下严格等于遮光片中点经过门位置的速度（主讲篇第五节的论证）。
- 双门都给了数据、又缺两门之间的时间：别硬凑 $\frac{\Delta v}{\Delta t}$，改用不含时间的 $a = \frac{v_B^2 - v_A^2}{2L}$——这是任务二的路，但它先要求出两个速度。

### 完整示范

:::problem
<span class="prob-grade">示范 1【基础题·常考题·实验题】</span><span class="prob-source">（经典题）</span>气垫导轨上 A、B 两光电门间距 $L = 60$ cm，滑块挡光片宽 $d = 0.50$ cm。经过 A、B 的挡光时间分别为 $\Delta t_A = 12.5$ ms、$\Delta t_B = 5.0$ ms。(a) 求滑块经过两门的速度；(b) 求加速度；(c) $v_A$ 对应的是挡光片"刚接触光"那一刻的速度吗？
:::

:::answer
**答案：(a) $v_A = 0.40$ m/s，$v_B = 1.0$ m/s；(b) $0.70$ m/s²；(c) 不是。**

- (a) 动笔前统一单位：$d = 0.0050$ m，$\Delta t$ 用秒。$v_A = \frac{0.0050}{0.0125} = 0.40$ m/s；$v_B = \frac{0.0050}{0.0050} = 1.0$ m/s。
- (b) 匀加速、有 $L$、没有两门间的时间，选不含时间的速度位移关系：$a = \frac{v_B^2 - v_A^2}{2L} = \frac{1.0^2 - 0.40^2}{1.2} = 0.70$ m/s²。
- (c) $v_A$ 是遮光这段时间的平均速度。滑块在加速，遮光期间速度越来越大，平均速度等于**遮光中点**的速度：比"刚接触光"那一刻大，比"离开光"那一刻小。挡光片越窄，这三者越接近——这就是"窄片更接近瞬时速度"的物理内核。
:::

### 条件变化

- **挡光片从 1.0 cm 换成 2.0 cm（仍平行）**：匀速滑块，$\frac{d}{\Delta t}$ 分子分母同比例变化，测得速度不变；加速滑块，宽片中点更靠前，测得的速度对应更靠后位置的速度，**略大**——变化的是"它代表哪个位置的速度"，不是对错。
- **挡光片倾斜 θ 角**：遮光期间实际前进 $d\cos\theta < d$，仍用 $d$ 计算，$v_{\text{测}} = \frac{v_{\text{真}}}{\cos\theta}$，偏大（误差链的完整推导见《第二章实验③》第 23 题）。

方法边界：$v = \frac{d}{\Delta t}$ 不要求匀加速，它永远是遮光段的平均速度；$\frac{v_B^2 - v_A^2}{2L}$ 则要求匀加速，非匀加速时它没有加速度的含义。

## 任务二：求加速度——三条路径，按条件选

问题实质：加速度不能直接测，必须从位移、速度、时间中"提"出来。三条路径对应三种手里有的数据：

| 手里的数据 | 路径 | 成立条件 |
| --- | --- | --- |
| 偶数段位移（纸带） | 逐差法 $a = \frac{(x_4+x_5+x_6)-(x_1+x_2+x_3)}{9T'^2}$ | 匀变速 + 各段同用 $T'$ |
| 两点速度 + 间距（双门） | $a = \frac{v_B^2 - v_A^2}{2L}$ | 匀加速 |
| 多组 (v, t) 数据 | v–t 图描点，斜率即 a | 点足够多（5 组以上） |

三条路径不是并列的偏好，是数据形态决定的：给位移用逐差，给两点速度用 $v^2$ 关系，给多组速度用图像。题目问"用逐差法处理"，就是在告诉你数据形态。

### 完整示范

:::problem
<span class="prob-grade">示范 2【基础题·常考题·实验题】</span><span class="prob-source">（经典题）</span>打点计时器 50 Hz，每 5 个间隔取一个计数点。计数点 0–6 的坐标为 0、1.20、2.80、4.80、7.20、10.00、13.20 cm。(a) 判断小车的运动性质；(b) 求计数点 3 的瞬时速度；(c) 求加速度；(d) 求打计数点 0 时的速度。
:::

:::answer
**答案：(a) 匀加速直线运动；(b) 0.22 m/s；(c) 0.40 m/s²；(d) 0.10 m/s。**

- 第 1 步，算段位移：相邻坐标相减，$x_1$ 到 $x_6$ = 1.20、1.60、2.00、2.40、2.80、3.20 cm，单位统一为米。
- 第 2 步，体检：$T' = 0.1$ s；$\Delta x = 0.40$ cm 恒定 → 匀加速，逐差法的适用前提成立。
- 第 3 步，求点速（任务一）：$v_3 = \frac{x_3 + x_4}{2T'} = \frac{0.020 + 0.024}{0.2} = 0.22$ m/s（计数点 2、4 夹住 3）。
- 第 4 步，逐差（本任务）：$a = \frac{(2.4 + 2.8 + 3.2) - (1.2 + 1.6 + 2.0)}{9 \times 0.01} \times 10^{-2}$ m/s² $= \frac{3.6}{0.09} \times 10^{-2} = 0.40$ m/s²，与体检式 $\frac{\Delta x}{T'^2} = 0.40$ m/s² 互验一致。
- (d) 从计数点 0 到 3 经历 $3T'$：$v_0 = v_3 - 3aT' = 0.22 - 3 \times 0.40 \times 0.1 = 0.10$ m/s。
:::

### 条件变化

- **只剩 5 段（奇数）**：弃最短的开头段（点最密、估读相对误差最大），用剩余 4 段做 $4T'^2$ 版逐差。弃数据必须能说明原因，"看着不顺眼就删"不行。
- **电源实际 49 Hz，仍按 50 Hz 算**：$T_{\text{真}} = \frac{1}{49} > T_{\text{代}} = 0.02$ s。位移是真实发生的，$a_{\text{测}} = \frac{\Delta x_{\text{真}}}{T_{\text{代}}^2} = a_{\text{真}}\left(\frac{T_{\text{真}}}{T_{\text{代}}}\right)^2 = a_{\text{真}} \times \left(\frac{50}{49}\right)^2 \approx 1.04\,a_{\text{真}}$，偏大约 4%。分母被代小，结果偏大——方向由原理式推出。

方法边界：逐差法给的是一个"平均"的 a，中间过程真有变速，它发现不了；图像法摊开全程，异常点一眼可见。大题常要求"两种方法互验"，两边一致说明数据质量好。

## 任务三：判断性质与取舍数据——模型成立的关口

问题实质：后面所有计算都建立在"匀变速"上，这个前提本身需要检验；检验不过的数据，要有规矩地处理。

- **判断匀加速**：算相邻段位移差 $\Delta x$，基本恒定即成立（在估读误差范围内）；越差越大是变速，别硬套匀变速公式。
- **取舍数据**：异常点只有能说明原因时才舍弃——开头段点密、估读相对误差大，是可说明的系统性理由；中间某段明显跳变且查得到操作原因（如纸带卡了一下），也可弃并注明。"无依据删除异常数据"是实验的大忌，等于让数据迁就答案。
- **动笔前的换算检查**：读数几乎都是毫米，公式里长度必须用米。例如 $\Delta x = 4.0$ mm、$T' = 0.1$ s，则 $a = \frac{0.0040}{0.01} = 0.40$ m/s²；选项里出现恰好差十倍的干扰项时，第一个检查单位链。

### 完整示范

:::problem
<span class="prob-grade">示范 3【基础题·常考题·实验题】</span><span class="prob-source">（经典题）</span>用光电门测滑块加速度的合理操作顺序是：
①给气垫导轨供气，轻推滑块，观察两光电门读数是否几乎相等
②用游标卡尺测量挡光片宽度 d
③安装挡光片，使其与滑块运动方向平行
④释放滑块，记录两门挡光时间
⑤重复测量多次，取平均值
A. ②③①④⑤
B. ③②①④⑤
C. ①②③④⑤
D. ②①③⑤④
:::

:::answer
**答案：A。**

排序不靠背，靠依赖关系，每一步都"因为下一步需要它"：

- ② 在最前：d 是后续一切计算的输入，且必须在安装前测——装上滑块后卡尺不便测量。
- ③ 紧随 ②：装上并调平行，否则 d 有效宽度变大（主讲篇第五节的 $d\cos\theta$）。
- ① 必须在 ③ 之后：调平靠"轻推滑块看两门读数是否相等"，挡光片不装上，门根本没有读数，调平无从谈起。
- ④ 在系统就绪后进行；⑤ 在 ④ 后，重复取平均减小偶然误差。

据此逐项排除：C 先调平——没有挡光片读不出数，不成立；B 先装后测 d，测装好了的片再返工，不合理；D 把重复测量放在正式测量前，无数据可平均。只有 A 满足全部依赖关系。
:::

方法边界：不同装置的"目的"不互套。打点计时器"先通电"为的是振针起动稳定、开头不废点；光电门"先供气"为的是形成气膜、抵消摩擦。答"目的"要答到"为了什么物理条件"，答成操作现象不给分。

## 任务四：评估可信度——把偏差代回原理式

问题实质：结果偏大还是偏小、为什么、怎么改进。不背误差清单，盯着原理式，看哪个量被带歪了：

:::formula
g = \frac{\Delta x_{\text{测}}}{T'^2}, \qquad v = \frac{d}{\Delta t}
:::

每个量的真实值与代入值的偏差往式子里一代，方向自动出来。三条高频结论都这样推：

- **纸带测 g 偏小**：摩擦与空气阻力使实际加速度 $a = g - \frac{f}{m} < g$，测的是"实际加速度"。改进：换更重的重物（$\frac{f}{m}$ 占比变小）、有条件时用真空管消除空气阻力。
- **挡光片不平行，测得速度偏大**：实际遮光期间前进 $d\cos\theta < d$，仍按 $d$ 除，$v_{\text{测}} = \frac{v_{\text{真}}}{\cos\theta}$。
- **重物太轻，g 偏小得更多**：阻力 $f$ 基本不变、$m$ 变小，$\frac{f}{m}$ 变大。

### 完整示范

:::problem
<span class="prob-grade">示范 4【提升题·易错题·选择题】</span><span class="prob-source">（经典题）</span>下列说法正确的是：
①纸带测 g 结果 9.72，比 9.8 小，摩擦与空气阻力所致，属系统误差
②挡光片没装平，测得速度偏大，是仪器操作问题，属错误
③把 $T' = 0.1$ s 代成 0.02 s，属读数误差
④多次测量取平均，为了减小偶然误差
A. ①③④
B. ①④
C. ②③
D. ①②④
:::

:::answer
**答案：B。**

- **① 对。**阻力方向固定（使结果偏小）、原因是装置固有的，属系统误差。
- **② 按本课口径判为错误。**装歪挡光片是安装不符合规范，可避免。说明一下考试口径：部分教辅把它归为"系统误差（装置因素）"；实验题的给分点在"测得速度偏大 + 原因（有效遮光距离变了）"，分类名称通常不单独扣分，把方向和原因答全最重要。
- **③ 错。**代错数据是计算错误，量级差 25 倍（$\frac{0.1^2}{0.02^2}$），与"误差"无关，必须避免。
- **④ 对。**偶然误差忽大忽小，取平均正是对策。
:::

揭晓主讲篇埋的问题：有同学测出 g = 11 m/s²，老师说不是误差、是错误。误差只能让结果在 9.8 附近小幅度摆动（且方向已知是偏小），11 超出了误差能解释的范围——最可能是把 $T'$ 代小了（比如该用 0.1 s 的计数点间隔，代成了 0.02 s 的打点周期，数值放大 25 倍），或者长度单位没换。方向明显反常的结果，先查操作和计算，再谈误差。

方法边界：装置之间的误差结论不互套——纸带的问题在限位孔摩擦，光电门的问题在挡光片姿态与遮光近似，两套原因各自成链。

## 条件与边界总表

| 任务 | 标准动作 | 高频坑 |
| --- | --- | --- |
| 求速度 | 先问时间从哪来；中点定理 / $\frac{d}{\Delta t}$ | 单段平均当瞬时；厘米不换米 |
| 求加速度 | 按数据形态选路：位移逐差 / 双门 $v^2$ / 图像斜率 | 逐差分组交叉；漏平方 |
| 判断与取舍 | $\Delta x$ 体检；弃数据必须带原因 | 无依据删异常；前提没检验就套公式 |
| 评估可信度 | 偏差代回原理式推方向 | 只答原因不说方向；错误当误差 |
