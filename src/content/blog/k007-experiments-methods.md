## 一、装置与操作：如何记录运动【常见题型：排序题、目的表述题】

先重述两条计时关系：电磁打点计时器接 4–6 V 低压交流电（电火花计时器用 220 V），打点周期由电源频率决定、与纸带运动无关，

:::formula
T = \frac{1}{f} = 0.02 \text{ s}
:::

每 5 个**间隔**取一个计数点则 $T' = 0.1$ s；每 5 个**点**取一个计数点则 $T' = 4T = 0.08$ s——动笔前先核对题目用的是哪种说法。推导与计数点的作用见主讲篇第一节。

操作顺序不靠背，靠依赖关系：每一步都是因为"下一步需要它"。

- **先通电，待打点稳定再放纸带。**振针起动有几十毫秒的不稳定期；纸带长度有限，先放纸带会让开头一段全是密集废点。
- **光电门实验先装挡光片、再供气调平。**调平靠"轻推滑块、看两门读数是否几乎相等"——挡光片不装上，门根本没有读数，调平无从谈起；供气为的是形成气膜、抵消摩擦，让调平判读的是几何水平而非摩擦差异。
- **先试跑，再正式记录。**确认计时器归零、挡光片完整过门，试跑浪费一次，救回整组数据。

### 完整示范

:::problem
<span class="prob-grade">示范 1【基础题·常考题·实验题】</span><span class="prob-source">（经典题）</span>用光电门测滑块加速度的合理操作顺序是：
①给气垫导轨供气，轻推滑块，观察两光电门读数是否几乎相等
②用游标卡尺测量挡光片宽度 d
③安装挡光片，使其与滑块运动方向平行
④释放滑块，记录两门挡光时间
⑤重复测量多次，取平均值
A. ②③①④⑤
B. ①④②③⑤
C. ②①④③⑤
D. ②③④①⑤
:::

:::answer
**答案：A。**

两条**物理上过不去**的硬依赖先立住：调平判读需要挡光片在滑块上，故 ③ 必须先于 ①；重复取平均需要正式数据，故 ⑤ 必须后于 ④。逐项对照：B 在供气、调平之前就释放滑块，气膜未形成、系统未校准，数据无效；C 在安装挡光片之前释放，两门不计时；D 把释放放在调平之前，记录的是未校准系统的读数。A（②③①④⑤）是唯一全部满足依赖关系的顺序。

两点说明：② 与 ③ 的先后互换（先装后测 d）操作上不妥但并非不可行，本题不以此设错；d 是后续一切计算的输入，先测完再安装是更稳的顺序，所以 A 也是实际操作里的最优解。检查："目的"要答到物理条件——问"轻推滑块看读数相等的目的"，答"检验导轨是否水平，抵消重力沿轨道方向的分量"才完整，答"看它匀速"是现象不是目的。
:::

方法边界：不同装置的"目的"不互套——打点计时器"先通电"为的是振针起动稳定，光电门"先供气"为的是气膜抵消摩擦。

## 二、测量与读数：实际测到了什么【常见题型：换算计算题】

实验里真正直接读出来的量只有两类：**长度**（刻度尺量纸带段位移，估读到最小分度下一位）和**时间**（打点周期"白送"，或光电门的挡光时间）。速度、加速度、g 全部由关系间接算出——间接量出偏差，才能顺着公式追方向（第四节）。

动笔前的固定动作是过一遍单位链：读数几乎都是毫米，公式里长度必须用米。例如 $\Delta x = 4.0$ mm、$T' = 0.1$ s，则 $a = \frac{\Delta x}{T'^2} = \frac{0.0040}{0.01} = 0.40$ m/s²；选项里出现恰好差十倍、百倍的干扰项时，第一个检查单位链。

光电门的读数 $v = \frac{d}{\Delta t}$ 要分三层理解（完整论证见主讲篇第五节）：它是遮光时间内的平均速度（无条件）；匀变速中等于该时段中间时刻的瞬时速度；把它当作"过门位置"的速度，是遮光片足够短时、中点贴近门位置的近似。挡光片变宽，改变的是第三层对应的位置，不是前两层。

## 三、数据处理：从记录到目标量【常见题型：计算题、图像题】

**求速度。**纸带上求计数点速度用中间时刻定理：

:::formula
v_n = \frac{x_n + x_{n+1}}{2T'}
:::

条件：匀变速（严格等式）；左右两段夹住目标点，推导见主讲篇第三节。光电门单门 $v = \frac{d}{\Delta t}$ 见上节。

**求加速度**，按手里数据的形态选路径：

| 手里的数据 | 路径 | 成立条件 |
| --- | --- | --- |
| 偶数段位移（纸带） | 逐差法 $a = \frac{(x_4+x_5+x_6)-(x_1+x_2+x_3)}{9T'^2}$ | 匀变速 + 各段同用 $T'$ |
| 两点速度 + 间距（双门） | $a = \frac{v_B^2 - v_A^2}{2L}$ | 匀加速 |
| 多组 (v, t) 数据 | v–t 图描点，斜率即 a | 点足够多（5 组以上） |

逐差法"为什么这样推"，一条线读完：匀变速保证相邻等时位移差恒定（$x_{n+1} - x_n = aT'^2$）→ 隔 3 段相减每位差 $3aT'^2$、且六段各用一次 → 三差相加得 $9aT'^2$。逐段平均不行，因为中间速度两两抵消、只剩首尾承担全部误差。完整推导见主讲篇第四节。双门公式同理要求匀加速——非匀加速时它只是一个没有加速度含义的数字。

### 完整示范

:::problem
<span class="prob-grade">示范 2【基础题·常考题·实验题】</span><span class="prob-source">（经典题）</span>打点计时器 50 Hz，每 5 个间隔取一个计数点。计数点 0–6 的坐标为 0、1.20、2.80、4.80、7.20、10.00、13.20 cm。(a) 判断小车的运动性质；(b) 求计数点 3 的瞬时速度；(c) 求加速度；(d) 求打计数点 0 时的速度。
:::

:::answer
**答案：(a) 匀加速直线运动；(b) 0.22 m/s；(c) 0.40 m/s²；(d) 0.10 m/s。**

这条纸带正是主讲篇例题二、三的主线纸带（坐标相减即得六段位移），两篇对照着看，方法和数据是同一套。

- 第 1 步，算段位移：相邻坐标相减，$x_1$ 到 $x_6$ = 1.20、1.60、2.00、2.40、2.80、3.20 cm，统一为米。
- 第 2 步，体检：$T' = 0.1$ s；$\Delta x = 0.40$ cm 恒定 → 匀加速，逐差法的适用前提成立。
- 第 3 步，求点速：$v_3 = \frac{x_3 + x_4}{2T'} = \frac{0.020 + 0.024}{0.2} = 0.22$ m/s（计数点 2、4 夹住 3）。
- 第 4 步，逐差：$a = \frac{(2.4 + 2.8 + 3.2) - (1.2 + 1.6 + 2.0)}{9 \times 0.01} \times 10^{-2}$ m/s² $= \frac{3.6}{0.09} \times 10^{-2} = 0.40$ m/s²，与体检式互验一致。
- (d) 计数点 0 到 3 经历 $3T'$：$v_0 = v_3 - 3aT' = 0.22 - 0.12 = 0.10$ m/s。
:::

### 条件变化

- **只剩 5 段（奇数）**：弃最短的开头段（点最密、估读相对误差最大），用剩余 4 段做 $4T'^2$ 版逐差——主讲篇例题三 (c) 用同一组数据演示过，结果不变。弃数据必须能说明原因。
- **电源实际 49 Hz，仍按 50 Hz 算**：$T_{\text{真}} = \frac{1}{49} > T_{\text{代}}$，$a_{\text{测}} = a_{\text{真}}\left(\frac{50}{49}\right)^2 \approx 1.04\,a_{\text{真}}$，偏大约 4%。方向由原理式推出：分母被代小，结果偏大。

**图像法**是数据处理的另一条路：用中间时刻定理算出各点速度，在 v–t 图上描点，画一条让数据点均匀分布在两侧的直线，斜率即加速度。仍用主线纸带：五个计数点的速度为 0.14、0.18、0.22、0.26、0.30 m/s，对应时刻 0.1–0.5 s（图 1）。

![主线纸带各点速度的 v–t 图：描点后画线取斜率](/blog-images/k007-experiments-methods/fig-vt-fit.png)

图 1｜主线纸带的 v–t 图：斜率即加速度

由图 1 的斜率三角形，$a = \frac{\Delta v}{\Delta t} = \frac{0.04}{0.1} = 0.40$ m/s²；用速度版逐差验证：$(v_4 + v_5) - (v_1 + v_2) = 6aT'$，$\frac{(0.26 + 0.30) - (0.14 + 0.18)}{6 \times 0.1} = 0.40$ m/s²，两法一致。同一组数据、两条路径、同一个答案——这就是"互验"的含义。

## 四、结果评价：这个结果可信吗【常见题型：误差分析题、辨析题】

偏差分三类，对策完全不同：**系统误差**方向固定、原因明确（摩擦与空气阻力使 g 偏小，$g_{\text{测}} = g - \frac{f}{m}$）；**偶然误差**忽大忽小（刻度尺估读），靠多次测量取平均、或用逐差与图像把数据用足来摊薄；**错误**是操作或计算违规（$T'$ 代错、先放纸带后通电），可避免，谈不上偏大偏小。

评价的方法是把每个量的偏差代回原理式推方向，两条高频结论的依据：纸带测 g 偏小，来自 $a = g - \frac{f}{m} < g$；挡光片倾斜使测得速度偏大，来自遮光期间实际前进 $d\cos\theta < d$（推导见主讲篇第五节与《第二章实验③》第 23 题）。

### 完整示范

:::problem
<span class="prob-grade">示范 3【提升题·易错题·选择题】</span><span class="prob-source">（经典题）</span>下列说法正确的是：
①纸带测 g 结果 9.72，比 9.8 小，摩擦与空气阻力所致，属系统误差
②挡光片没装平，测得速度偏大，是仪器操作问题，属错误
③把 $T' = 0.1$ s 代成 0.02 s，属读数误差
④多次测量取平均，为了减小偶然误差
A. ①③④
B. ①④
C. ②③
D. ①②④
:::

:::answer
**答案：B。**

- **① 对。**阻力方向固定（使结果偏小）、原因是装置固有的，属系统误差。
- **② 按本课口径判为错误。**装歪挡光片是安装不符合规范，可避免。考试口径说明：部分教辅把它归为"系统误差（装置因素）"；实验题的给分点在"测得速度偏大 + 原因"，分类名称通常不单独扣分，把方向和原因答全最重要。
- **③ 错。**代错数据是计算错误，量级差 25 倍（$\frac{0.1^2}{0.02^2}$），与"误差"无关。
- **④ 对。**偶然误差忽大忽小，取平均正是对策。
:::

揭晓主讲篇埋的问题：有同学测出 g = 11 m/s²，为什么老师说这不是误差、是错误？误差只能让结果在 9.8 附近小幅摆动，且方向已知偏小；11 超出了误差能解释的范围。最可能是把 $T'$ 代小了（计数点间隔 0.1 s 代成了打点周期 0.02 s，数值放大 25 倍），或长度单位没换。方向明显反常的结果，先查操作和计算，再谈误差。

取舍数据也有规矩：异常点必须能说明原因才可舍弃——开头段点密、估读相对误差大，是可说明的系统性理由；查不出原因的异常不能删，先查操作和读数。"无依据删除异常数据"等于让数据迁就答案。

方法边界：装置之间的误差结论不互套——纸带的问题在限位孔摩擦，光电门的问题在挡光片姿态与遮光近似，两套原因各自成链。
