速度看不见，加速度更抽象，实验要干的事只有一件：把它们变成一串能算的数。这一章的四个实验——练习使用打点计时器、探究小车速度随时间的变化、用光电门测速度、自由落体测 g——其实在回答同一条主线上的五个问题：如何记录运动 → 如何从记录中求速度 → 如何判断速度怎样变化 → 如何求加速度 → 如何判断结果是否可靠。打点计时器管第一步，纸带读数和中间时刻定理管第二步，$\Delta x$ 体检和逐差法管第三、四步，光电门是更快的记录与测速手段，误差分析收尾第五步。每读完一节回看一次链条走到哪一环，"为什么接下来学这个"就有了答案。

:::usage
- 前置知识：匀变速的速度公式与"平均速度等于中间时刻速度"（K005）、位移差恒定 $\Delta x = aT'^2$（K006，本篇会完整重推一遍）。
- 学习目标：说清每个器材在数据链里的角色；独立完成"量位移 → 判性质 → 求点速 → 求加速度"的完整处理；能对任何一个结果回答"偏大还是偏小、为什么"。

## 一、计时：把时间"刻"在纸带上

![老师与讲台上的打点计时器](/blog-images/k007-experiments/K007E-实验-01-器材-电磁打点计时器.png)

图 1｜打点计时器与低压电源

电磁打点计时器接 4–6 V 低压交流电（实验室另配学生电源），振针每秒打 50 个点。它计时的依据是一条：打点周期由交流电频率决定，与纸带拉多快无关——这正是它能当计时仪器的原因。打点周期（相邻两点的时间间隔）：

:::formula
T = \frac{1}{f} = \frac{1}{50} \text{ s} = 0.02 \text{ s}
:::

实验室还有一种电火花计时器，用 220 V 交流电，靠火花放电在纸带上打点，不用复写纸。两种计时器电压不同、打点方式不同，打点周期同样是 0.02 s——考试爱在这个电压区别上设选项。

操作顺序只有一条主线：先通电，待打点稳定后再放纸带。原因有两层：振针刚通电时有几十毫秒的起动过程，这段时间打的点规律性差；纸带长度有限，先放纸带会让开头一段全是密集废点，白白浪费纸带。其余操作都服务于数据质量：纸带穿过限位孔、压在复写纸下面；小车释放前靠紧打点计时器，让有限长度的纸带尽量多记录有效运动。

0.02 s 的间隔太短，相邻点挨得太近，刻度尺量不准。习惯上每 5 个间隔取一个计数点，相邻计数点的时间间隔：

:::formula
T' = 5T = 5 \times 0.02 \text{ s} = 0.1 \text{ s}
:::

这里藏着实验题里最常见的文字坑："每 5 个间隔取一个计数点"，$T' = 0.1$ s；"每 5 个点取一个计数点"，5 个点之间只有 4 个间隔，$T' = 4T = 0.08$ s。一字之差结果差 25%（方法篇示范 3 埋的就是这个坑），动笔前先把这句读清楚。

## 二、测位移：哪些量是直接测的

纸带实验里，真正用刻度尺量出来的只有各段位移；时间不用量，由打点周期"白送"；至于速度、加速度、重力加速度，全部是用公式从这两类数据间接算出来的。

这个区分不是概念游戏，它决定后面误差怎么分析：直接测量量的偏差来自刻度尺估读（偶然误差，靠多次测量摊薄）；间接量的偏差来自公式里每个输入量的传递——哪个量被带歪了，方向可以顺着公式推出来。本篇第七节全靠这条。

读数还有一个固定动作：刻度尺读数要估读到最小分度的下一位，毫米尺读到 0.1 mm；计算前把所有长度统一换成米。纸带题最冤的丢分从来不是不会，是 25.0 mm 被当成 25.0 cm 代进公式。

## 三、从位移到速度：中间时刻定理

纸带上某计数点的瞬时速度怎么求？用它的左右两段。设 A、B、C 是相邻三个计数点，AB 段位移 $x_1$、BC 段位移 $x_2$，时间间隔都是 $T'$（图 4）。

![中间时刻速度：AC 段的平均速度等于 B 点的瞬时速度](/blog-images/k007-experiments/fig-tape-midpoint.png)

图 4｜中间时刻速度：左右两段夹住中间点

匀变速里，一段时间的平均速度等于首末速度的平均（K005 的推论），也等于中间时刻的瞬时速度。两件事拼起来就是定理。推导只需要两步：设 A 点速度为 $v_A$、加速度为 $a$，则 $v_C = v_A + 2aT'$；

:::formula
\bar{v}_{AC} = \frac{v_A + v_C}{2} = \frac{v_A + (v_A + 2aT')}{2} = v_A + aT'
:::

而 B 恰好是 AC 段的中间时刻，$v_B = v_A + aT'$，与平均速度完全相等：

:::formula
v_B = \bar{v}_{AC} = \frac{x_1 + x_2}{2T'}
:::

注意它的适用前提：匀变速。匀变速里这是严格等式，不是近似；运动性质未知时，它只是近似——实验里恰好先用它求速度、再反过来检验是否匀变速，两步互为支撑。

　　（2）量得六段距离 $x_1$ 到 $x_6$ 依次为 3.59、4.41、5.19、5.97、6.78、7.64 cm，其中 $x_1$ 是 A、B 间的距离，其余依次类推。求小车的加速度（要求充分利用测量的数据），并求打出 B 点时小车的瞬时速度。（结果均保留两位有效数字）

答案：（1）AB；（2）加速度 0.80 m/s²，$v_B$ = 0.40 m/s。


　　① 题型识别。第（1）问考“哪些措施必需”；见到第（2）问的“计数点 + 左右两段位移”，想到中间时刻定理；“充分利用测量的数据”是逐差法的招牌要求（逐差法在下一节完整推导，这里先用）。


　　② 步骤模板。第（1）问逐项过堂。第（2）问一核 $T'$（间隔还是点），二换单位，三逐差求 a，四代 $v_n = \frac{x_n + x_{n+1}}{2T'}$，五查量级。


　　③ 规范解答。

　　（1）A 必要：细线不平行，拉力方向随小车位置变化，小车可能偏离直线。B 必要：先接通电源、待打点稳定后再释放，正是本节那条操作主线。C 不必要：本实验不测力，不需要“拉力近似等于钩码重力”的条件。D 不必要：摩擦力只要恒定就不影响“匀变速”的判断（与例题一 A 项同一判断）。

$$a = \frac{(x_4 + x_5 + x_6) - (x_1 + x_2 + x_3)}{9T'^2} = \frac{(0.0597 + 0.0678 + 0.0764)\ \text{cm} - (0.0359 + 0.0441 + 0.0519)\ \text{cm}}{9 \times 0.01\ \text{s}^2} = 0.80\ \text{m/s}^2$$

其中 $x_1$、$x_2$ 分别表示 A→B、B→C 两段位移，

$$v_B = \frac{x_1 + x_2}{2T'} = \frac{0.0359 + 0.0441}{2 \times 0.1}\ \text{m/s} = 0.40\ \text{m/s}$$


　　④ 易错点。第（1）问容易把 C、D 也判成“必需”——把牛顿第二定律实验的要求迁移过来。第（2）问最容易把“还有 4 个点未画出”当成 4 个间隔，算出 $T' = 0.08$ s；厘米忘换米会得出 40 m/s 的荒谬值——量级检查就是拦这个的；“充分利用数据”不用逐差而逐段相减取平均，中间速度两两抵消，误差全压在首尾两段。


　　⑤ 变式。改求 D 点的速度？换用 $x_3$、$x_4$ 两段：$v_D = \frac{0.0519 + 0.0597}{0.2} \text{ m/s} = 0.56 \text{ m/s}$——B 到 F 这一串点速，正是方法篇第三节图像法的描点数据；逐差法的完整推导与分组技巧，见下节例题三。

方法归纳。“左右两段夹中间点”与器材无关——光电门只是把两段位移缩成一片遮光，物理是同一个。

## 四、从位移到加速度：逐差法

有了速度，加速度可以直接用定义 $a = \frac{\Delta v}{\Delta t}$ 算。但纸带给了六段位移，怎么用最充分？

最直接的想法：每段位移算一个加速度，再取平均。设第 $n$ 段末的速度是 $v_n$，则 $a_n = \frac{v_n - v_{n-1}}{T'}$。把六段加起来时会发现一个麻烦：求 $a_2$ 用到的 $v_1$，正好是求 $a_1$ 的结果，中间速度在上一个式子里是末速度、在下一个式子里是初速度，相加时两两抵消——

:::formula
\bar{a} = \frac{(v_1 - v_0) + (v_2 - v_1) + \cdots + (v_6 - v_5)}{6T'} = \frac{v_6 - v_0}{6T'}
:::

中间四个速度全消掉了，平均值只由首尾两个速度决定。首尾恰恰是误差最大的地方：开头的点最密、刻度尺估读的相对误差最大。也就是说，量了六个数据，其实只用了两个。

逐差法绕开这个问题。它的出发点是匀变速的另一条性质：相邻相等时间间隔内的位移差恒定，

:::formula
x_{n+1} - x_n = aT'^2
:::

这条式子的依据在 K006 推过：第 $n$ 段位移 $x_n = v_{n-1}T' + \frac{1}{2}aT'^2$，代入 $v_n = v_{n-1} + aT'$，相邻两段相减，$v_{n-1}T'$ 项消去，剩下 $aT'^2$。

六段位移分成前后两组，隔 3 段两两相减（图 6）。隔 3 段，位移里相差的是 3 个 $aT'^2$：

![六段纸带的逐差分组](/blog-images/k007-experiments/fig-tape-six-segments.png)

图 6｜六段位移分两组，隔 3 段相减

:::formula
x_4 - x_1 = 3aT'^2, \quad x_5 - x_2 = 3aT'^2, \quad x_6 - x_3 = 3aT'^2
:::

三式相加，左边是两组位移和的差，右边是 $9aT'^2$，解出

:::formula
a = \frac{(x_4 + x_5 + x_6) - (x_1 + x_2 + x_3)}{9T'^2}
:::

分母的 9 就是这么来的：隔 3 段一差，乘 3；三差相加，再乘 3。六个数据全部进入算式，没有任何一个被抵消，偶然误差被摊到每个数据头上——这就是逐差法相对"逐段平均"的全部优势。

两个设计选择值得停下来想。为什么隔 3 段相减，而不是相邻两段一差？相邻差 $x_{n+1} - x_n$ 只用到两段数据，逐差再平均会回到中间项相消的老问题；隔 3 段，每个差用掉 4 段、三个差恰好把六段各用一次——这是"用足数据"与"不重复用数"之间的平衡，换成 8 段就是隔 4 段、分母 $16T'^2$。哪一步用了匀变速条件？出发点 $x_{n+1} - x_n = aT'^2$ 那一步——它由匀变速推出，所以体检不过关就不能往下走。实际数据不完全满足这条关系怎么办？体检时允许 $\Delta x$ 在估读误差范围内波动；波动明显超出，先查操作和读数，而不是硬套公式。

用逐差法有两个前提，动笔前各检查一遍：一是 $T'$ 必须是所选各段的共同时间间隔（计数点规则先核对）；二是段数必须是偶数。只剩 5 段时，弃掉最短的开头段（点最密、相对误差最大），用剩下的 4 段做同样分组：

:::formula
a = \frac{(x_3 + x_4) - (x_1 + x_2)}{4T'^2}
:::

### 例题三

:::problem
<span class="prob-grade">3.【提升题·常考题·实验题】</span><span class="prob-source">（2016 年天津卷·实验题第(2)问，改编）</span>仍用例题二的主线纸带。

　　(a) 通过位移差判断小车是否做匀加速直线运动；

　　(b) 用逐差法求加速度（保留两位有效数字）；

　　(c) 若纸带末段污损，$x_6$ 读不出来，只剩 $x_1$ 到 $x_5$ 五段，加速度还能不能算？给出方案与结果。
:::

:::answer
答案：

　　(a) 是；

　　(b) 0.80 m/s²；

　　(c) 能，约 0.79 m/s²。


　　① 题型识别。“先判性质、再求加速度”是纸带大题的标准开场：体检（$\Delta x$ 是否恒定）永远在逐差之前。


　　② 步骤模板。一体检（$\Delta x$ 围绕定值波动 → 匀变速成立）→ 二统一单位 → 三六段分两组隔 3 段相减 → 四与体检式 $\frac{\Delta x}{T'^2}$ 互验。


　　③ 规范解答。

　　(a) 逐段相减，$\Delta x$ 依次为 0.82、0.78、0.78、0.81、0.86 cm：围绕 0.8 cm 上下波动，没有逐段增大或减小的趋势，波动量与刻度尺两次估读的舍入误差同量级，可视为恒定——匀加速成立。

　　(b) 其中 $x_1$ 到 $x_6$ 依次表示相邻计数点间的六段位移（已换算为米）：
$a = \frac{(x_4 + x_5 + x_6) - (x_1 + x_2 + x_3)}{9T'^2} = \frac{(0.0597 + 0.0678 + 0.0764) - (0.0359 + 0.0441 + 0.0519)}{9 \times 0.01 \text{ s}^2} = \frac{0.0720}{0.09} \text{ m/s}^2 = 0.80 \text{ m/s}^2$；
体检式 $\frac{\Delta x}{T'^2} = \frac{0.0080}{0.01} \text{ m/s}^2 = 0.80 \text{ m/s}^2$，两条路一致。


　　④ 易错点。第 ③ 步最容易把分组做成交叉相减（$x_4 - x_2$ 之类），错位一次六个数据全废；单位忘记换算则整体差 100 倍。还有一处新坑：真实数据的 $\Delta x$ 不会像课本例数那样分毫不差，体检看的是“是否围绕定值波动”，不是“是否完全相等”。


　　⑤ 变式。

　　(c) 就是现成的条件变化——只剩 $x_1$ 到 $x_5$ 五段：弃掉最短的开头段 $x_1$（点最密、估读相对误差最大），用剩余四段
$a = \frac{(x_4 + x_5) - (x_2 + x_3)}{4T'^2} = \frac{0.1275 - 0.0960}{0.04} \text{ m/s}^2 \approx 0.79 \text{ m/s}^2$，
与六段结果 0.80 只差 0.01，在估读误差以内——弃段的代价是精度略降，结论不变。

方法归纳。条件变化改变的是分组方式，不变的是“等时位移差反映加速度”这条物理依据——四段、六段、八段的公式都是它的不同分组。
:::

与逐差法互补的另一条路是图像法：用中间时刻定理算出各点速度，在 v–t 图上描点，画一条让数据点均匀分布在两侧的直线，斜率即加速度。它算得不如逐差快，但离谱的数据点在图上一眼可见——两法怎么选、怎么互验，《第二章实验②》第三节里展开。

## 五、光电门：更快的"表"

纸带能记录全程，读数终究要靠刻度尺；想要更快、更准的速度，就要换一只更快的"表"。光电门是一个 U 形架：一侧发红外光，一侧接收。小车上装一片宽度 $d$（用游标卡尺测出）的挡光片，经过门时把光挡住，计时器记下挡光时间 $\Delta t$。挡光片经过门的平均速度：

:::formula
v = \frac{d}{\Delta t}
:::

这个式子凭什么能当瞬时速度用？要分三层说，三层的前提各不相同：

1. $\frac{d}{\Delta t}$ 首先是挡光这段时间的平均速度——这一层是定义，不需要任何条件；
2. 小车做匀变速直线运动时，它等于该时段中间时刻的瞬时速度（K005 的推论）；
3. 说它是"经过门位置"的瞬时速度，是第三层：匀变速中速度随位置线性变化，平均速度恰好等于遮光片中点经过门那一刻的速度。挡光片越窄，中点越贴近门，第三层的近似越好。

三层在题目里经常来回切换：挡光片变宽，前两层不变，第三层对应的位置偏离变远——"还能不能当瞬时速度"的判断题考的就是这一层，高考考过。

两个操作考点（"该步骤的目的"要答全）：① 轨道先调平：轻推小车，两门读数几乎相等，说明重力沿轨道方向的分量已被抵消；② 挡光片与运动方向平行：若斜着过门，遮光期间小车实际前进的距离是 $d\cos\theta$（$\theta$ 为倾斜角），比 $d$ 小，而计算仍用 $d$ 除，测得速度偏大。

一个门给一个位置的速度；前后架两个门 A、B，得到 $v_A$、$v_B$。由上面说的中点论证，$v_A$、$v_B$ 就是小车经过两门位置时的速度。小车在两门间做匀加速时，用速度位移关系（K006）：

![双光电门测匀加速运动](/blog-images/k007-experiments/fig-photogate-double.png)

图 7｜双光电门测加速度：两个门给两个位置的速度

:::formula
a = \frac{v_B^2 - v_A^2}{2L}
:::

其中 $L$ 是两门间距。注意它的成立条件：匀加速，且 $v_A$、$v_B$ 确实是两门位置的速度——这两条由"遮光中点"论证保证。若运动不是匀加速，这个式子算出的只是一个定义出来的数字，不再有加速度的含义。光电门的计时精度是毫秒级，人掐表的反应约 0.2 s，差两百倍，所以出题人爱拿它的数据设单位与时间的坑。

### 例题四

:::problem
<span class="prob-grade">4.【基础题·常考题·实验题】</span><span class="prob-source">（同步实验讲义《研究自由落体运动的规律》典例 2，整题搬运）</span>某同学用如图（a）所示的装置测量重力加速度。

![同步实验讲义原题配图：（a）铁架台上端固定光电门，带两条黑色挡光片的玻璃条竖直下落，下方放缓冲物；（b）刻度尺读数放大图，两挡光片间距离读得 15.40 cm](/blog-images/k007-experiments/orig-liti4-glass.png)

图 8｜例题四的装置与读数：（a）玻璃条自由下落依次遮光，（b）两挡光片间距的毫米尺读数

实验器材：有机玻璃条（白色是透光部分，黑色是宽度均为 $d = 1.00$ cm 的挡光片），铁架台，数字计时器（含光电门），刻度尺。主要实验过程如下：

　　（1）将光电门安装在铁架台上，下方放置承接玻璃条下落的缓冲物；

　　（2）用刻度尺测量两挡光片间的距离，刻度尺的示数如图（b）所示，读出两挡光片间的距离 $L =$____ cm；

　　（3）手提玻璃条上端使它静止在____方向上，让光电门的光束从玻璃条下端的透光部分通过；

　　（4）让玻璃条自由下落，测得两次挡光的时间分别为 $t_1 = 10.003$ ms 和 $t_2 = 5.000$ ms；

　　（5）根据以上测量的数据计算出重力加速度 $g =$____ m/s²（结果保留三位有效数字）。
:::

:::answer
答案：（2）$L = 15.40$ cm；（3）竖直；（5）9.74 m/s²。


　　① 题型识别。光电门给 $d$ 和两个挡光时间——每道门各能算一个速度；已知两处速度和一段间距、不给运动时间——选不含时间的速度位移关系 $\frac{v_2^2 - v_1^2}{2L}$。第（2）（3）问考的是测量与操作规范。


　　② 步骤模板。一换单位（厘米、毫秒都换成米、秒）→ 二用单门关系各算速度 $v = \frac{d}{\Delta t}$ → 三代入 $g = \frac{v_2^2 - v_1^2}{2L}$ → 四与 9.8 对照查量级。


　　③ 规范解答。

　　（2）下挡光片对齐零刻线，上挡光片对齐 15.40 cm 刻线（毫米尺估读到下一位），$L = 15.40$ cm。

　　（3）竖直。玻璃条歪斜会让挡光片斜着过门，遮光宽度不再是 $d$，速度测量就系统性偏大。

　　（5）其中 $d$ 表示挡光片宽度，$t_1$、$t_2$ 表示两次挡光时间，$L$ 表示两挡光片间距。$v_1 = \frac{d}{t_1} = \frac{0.0100}{0.010003} \text{ m/s} \approx 1.00 \text{ m/s}$，$v_2 = \frac{d}{t_2} = \frac{0.0100}{0.005000} \text{ m/s} = 2.00 \text{ m/s}$；$g = \frac{v_2^2 - v_1^2}{2L} = \frac{2.00^2 - 1.00^2}{2 \times 0.1540} \text{ m/s}^2 = \frac{3.00}{0.308} \text{ m/s}^2 \approx 9.74 \text{ m/s}^2$。检查：$t_2 < t_1$，后过门的挡光片用时更短，速度更大，玻璃条在加速；结果落在 9–10 之间，量级合理。


　　④ 易错点。第 ① 步两种典型错法——毫秒不当秒（差 1000 倍）、厘米不当米（差 100 倍）；第 ③ 步漏平方或先相减再平方，得数会明显偏离 9.8，量级对照能当场拦住；第（2）问漏掉估读位、把 15.40 cm 记成 15.4 cm，也丢测量规范的分。


　　⑤ 变式。若玻璃条歪着下落，挡光片斜着过门，有效遮光宽度小于 $d$，测得速度偏大（第五节 $d\cos\theta$ 的分析在这里原样成立）——这正是第（3）问要把“竖直”写进操作要求的原因。

方法归纳。缺时间选 $\frac{v^2 - v_0^2}{2L}$，给时间选 $\frac{\Delta v}{\Delta t}$——手里数据的形态决定选哪条关系；光电门的数据以毫秒计，单位链检查是这类题的第一道闸。
:::

## 六、综合：一条纸带测 g

自由落体测 g 是这条数据链的完整落地，按实验自己的逻辑走一遍：

测什么：重力加速度 g——间接量，来自"重物下落是匀加速、加速度就是 g"这个模型。

如何测：重物挂纸带，穿过打点计时器限位孔，先通电再释放（图 9）。直接测量量是各段位移；时间是打点周期白送的。开头一段点距只有两毫米上下，估读误差占比太大，不参与测量；从点距可测的位置起，取连续 6 段。

![自由落体测 g 装置](/blog-images/k007-experiments/fig-freefall-setup.png)

图 9｜自由落体测 g：重物拖纸带穿过限位孔

怎样处理：先体检（$\Delta x$ 恒定确认匀加速），再逐差。此时不必再抽计数点：可测段的点距已放大到 5 mm 上下，估读的相对误差可以接受，直接用打点周期 $T = 0.02$ s，六段逐差。

是否可信：见例题五的最后一步与第七节。

### 例题五

:::problem
<span class="prob-grade">5.【提升题·常考题·实验题】</span><span class="prob-source">（教辅《力学实验题集粹》第 8 题）</span>用自由落体测重力加速度：重物拖动纸带下落，打点计时器接 50 Hz 交流电。取纸带上连续、清晰的 7 个点，用米尺测得第 2、3、4、5、6、7 各点到第 1 点的距离依次为 6.0、12.5、19.3、26.5、34.1、42.1 cm。用这些数据求重力加速度的测量值。（要求写出数据处理过程）
:::

:::answer
答案：9.7 m/s²。


　　① 题型识别。“重物 + 纸带 + 测 g”：自由落体模型 + 逐差法，运动学实验的综合收官题。题干给的是各点到第 1 点的距离——累计长度，先化成段位移。


　　② 步骤模板。一化段位移 → 二体检（$\Delta x$ 围绕定值波动？）→ 三统一单位 → 四六段逐差 → 五与 9.8 对照说方向 → 六误差归因。


　　③ 规范解答。相邻两点的距离依次为 6.0、6.5、6.8、7.2、7.6、8.0 cm；相邻差依次为 0.5、0.3、0.4、0.4、0.4 cm，在 0.4 cm 上下波动、波动不超过 0.1 cm（与末位估读同量级），匀加速成立。点距已达毫米级，不必抽计数点，$T = \frac{1}{50} \text{ s} = 0.02 \text{ s}$。其中 $x_1$ 到 $x_6$ 表示连续六段位移（已换算为米）：分子 $(0.072 + 0.076 + 0.080) - (0.060 + 0.065 + 0.068) = 0.035$ m，分母 $9T^2 = 9 \times 0.02^2 \text{ s}^2 = 0.0036 \text{ s}^2$，$g = \frac{0.035}{0.0036} \text{ m/s}^2 \approx 9.7 \text{ m/s}^2$（完整算式见下方公式块；距离只记到 0.1 cm，结果保留两位有效数字）。检查：分子与单段位移同量级，商落在 9–10 之间，合理。


　　④ 易错点。第 ① 步最容易把题干里的累计距离直接当段位移代入逐差——12.5 cm 是前两段之和，不先相减，六个数据全错；其次，这里没有抽计数点，$T$ 就是打点周期 0.02 s，不要顺手代成 0.1 s。与标准值 9.8 对照必须说方向：测得 9.7 偏小约 1%——设摩擦与空气阻力合计为 $f$，则 $g_{\text{测}} = g - \frac{f}{m} < g$，这是系统误差。回答“误差”必须带方向。


　　⑤ 变式。电源实际 49 Hz 仍按 50 Hz 算？分母被代小，测得的 g 偏大约 4%——方法篇第四节有完整推导。

方法归纳。“测什么—如何测—怎样处理—是否可信”四问在本题各对应一步；数据链的最后一环是回答“可信吗”，不是算完就停。
:::

:::formula
g = \frac{(x_4 + x_5 + x_6) - (x_1 + x_2 + x_3)}{9T^2} = \frac{0.228 - 0.193}{9 \times 0.02^2 \text{ s}^2} = \frac{0.035 \text{ m}}{0.0036 \text{ s}^2} \approx 9.7 \text{ m/s}^2
:::

条件变化：如果电源频率不稳定，实际每秒打 49 个点，打点周期比 0.02 s 略长。我们仍按 0.02 s 代入，分母偏小，测得的 g 会偏大——方向由原理式直接看出，不需要背结论。

## 七、结果可信吗：误差与错误

实验结果和真值总有偏差，偏差分三种，处理方式完全不同：

系统误差：方向固定、原因明确。纸带测 g 偏小就是典型：设纸带与限位孔的摩擦、空气阻力合计为 $f$，重物质量 $m$，实际加速度 $a = g - \frac{f}{m} < g$，测的是这个"打了折的加速度"，所以必然偏小。改进措施必须对着原因去：换更重的重物（$f$ 不变、$m$ 变大，$\frac{f}{m}$ 占比下降；有条件时用真空管消除空气阻力）。挡光片不平行使测得速度偏大，同理由 $d\cos\theta < d$ 推出，而不是背出来的。

偶然误差：忽大忽小、没有固定方向，来自刻度尺估读这一类。对策是多次测量取平均，或者用逐差法、图像法把全部数据都用上。

错误：操作或计算违规造成的，可避免，谈不上"偏大偏小"。把 $T' = 0.1$ s 代成 0.02 s，$\frac{1}{T'^2}$ 放大 $\left(\frac{0.1}{0.02}\right)^2 = 25$ 倍——这是错误，不是误差。判断纸带是否匀加速的体检（$\Delta x$ 是否恒定）也属于"检验"这一环：发现数据不符合预期，先怀疑操作和数据，别急着改结论。

下篇预告：原理通了，题还是可能不会做——因为题目问的是"任务"：求速度、求加速度、判断性质、评估可信度。《第二章实验②》把实验题按这四类任务各给一条分析路径，还会揭晓本篇埋的问题：有同学测出 g = 11 m/s²，为什么老师说这不是误差、是错误？

> 家长翻译器：这一节你跟孩子就问两句："纸带求某点速度用哪两段？"答"左右相邻两段加起来除以两倍时间间隔"就通了；"逐差法分母为什么是 9？"答"隔 3 段一差、三差相加"说明推导是真懂的。
