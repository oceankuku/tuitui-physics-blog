# 近十年高考真题反向验证登记（2026-10-22 建立）

> 总规范第十四节：以近十个完整高考年度的约定范围试题，逐题检查课程覆盖情况与解题质量。**"满分"是严谨求解与评分核验的追求，不作为未经验证的宣传承诺。**

## 验证范围约定

- **起止年份**：按执行时最近一个已完成高考年度向前十年。首次执行（2026 年）范围：**2017–2026 年**。
- **试卷范围**：全国卷（甲/乙/Ⅰ/Ⅱ/Ⅲ）、各自主命题省市卷（北京、天津、山东、海南、浙江、河北、辽宁、江苏、广东、福建、湖北、湖南等）。全国同卷去重，保留地区信息。
- **模拟题与正式高考题分开**，模拟题不进入本登记（入 problem-source-register）。
- **区分建设样本与阶段验收试题**：已经详细讲过的原题不算独立迁移能力证明；验收优先选用未在文章中出现过的新题。

## 验收口径（防虚报）

- **无可靠评分细则时**：只能声明"完成物理解答核验"，**不得声称"确认满分"**。
- 报告必须明确分母：**计划多少、取得多少、核验多少、解答多少、尚缺多少**。
- 不得用"已覆盖运动学"等笼统表述代替逐题映射。
- 区分两种通过：物理解答正确 ≠ 评分得满分。
