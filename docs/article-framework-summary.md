# 文章框架总结（一页速查 · 2026-10-22 整合修订版）

> 提炼自《课程建设与文章写作总规范（整合修订版）》及 `AI_WRITING_GUIDE.md`、`BLOG_TEMPLATE.md`、`docs/physics-content-framework.md`。写文章对照本页；细节争议回主规范查。

## 一、整体结构：一个单元三类文章

每个课程单元（教材小节或独立知识主题，K 编号）共享单元编号、学习目标、知识边界和覆盖清单，产出三类文章：

| 篇目 | 后缀 | 职责 | 完成标准 |
| --- | --- | --- | --- |
| 主讲篇 | `-concepts` | 建立概念、解释物理意义、明确成立条件、完成必要推导或实验说明 | 初学者能懂本节，具备进入题型学习的基础 |
| 题型与方法篇 | `-methods` | 系统分类题型、建立模型、解释方法选择、完整求解、处理变式与边界 | 主要题型有依据地覆盖，关键推导可复现，重要变式有处理，必要图示齐全 |
| 练习篇 | `-practice` | 分层检测、巩固应用、迁移训练、独立订正 | 核心目标均有检测，与前两篇逐项对应，答案解析形成闭环 |

**拆篇与合并**：三类是教学任务，不是篇数上限。复杂单元可拆上下篇或多篇（slug 加分篇标识并检查唯一性）；简单单元确需合并须在台账说明原因，三类教学任务仍须完成。**不得为凑固定篇数删题型、压推导、减配图。**

**标题与编号**：`主题①｜副题`（①主讲、②题型、③练习；拆篇注上/下）。K 编号与发布序号仅用于管理，不进公开标题。禁"必考、秒杀、押中、全部拿满分"等承诺。历史 slug 不随意改；确需调整须处理重定向与关联链接。

## 二、每篇开头的五要素 + 知识边界

引言自然交代（不机械列五条）：①对应教材位置；②本篇类型；③前置知识及回看处；④**可检测**的学习目标；⑤配套文章导航。另须交代**本篇知识边界**，说明哪些问题留待后续。未发布文章不放失效链接，可标"待更新"。

## 三、主讲篇骨架

具体问题或困惑 → 学习目标与前置知识 → 概念及物理意义 → 规律与成立条件 → 必要推导或实验依据 → 基础示例 → 易错辨析与边界 → 知识整理 → 配套导航。

强制要求：解释概念**为什么需要引入**；区分定义/实验规律/理想模型/数学推论；公式说明各量含义及适用条件；关键推导完整，不编造推导不循环论证；必要时用反例说明误用；基础示例按目标配置（通常少量精选，**不机械限定 1–2 道**）；知识整理适配手机，不用过宽表格压正文。

## 四、题型与方法篇（重点建设）

**动笔前先建覆盖表**（`docs/physics-coverage-map.md`）。

**分类依据**：物理本质、关键条件、过程结构、分析任务。交叉检查维度：概念与条件辨析 / 对象与情境 / 单对象多对象 / 单过程多阶段 / 文字图像表格实验信息 / 判断解释计算推导反求范围临界 / 约束变化与特殊状态 / 方法选择及其边界。**查漏维度，不机械组合**；不得只按选择题/填空题/计算题分类，不得把换数字当新题型。

**覆盖表字段**（每题型一行）：编号名称 / 学习目标 / 识别特征 / 模型与条件 / 常见设问 / 主要方法 / 前置知识 / 代表例题 / 重要变式 / 配图 / 对应练习 / **关联真题** / 来源与审核状态 / **尚未覆盖内容**。

**每类题型固定回答八问**（自然组织，不机械八个标题）：①如何识别 ②先分析什么 ③建什么模型 ④为什么用这个方法 ⑤规律适用条件 ⑥完整过程怎样展开 ⑦条件变化后怎样调整 ⑧常见错误与适用边界。

**代表题与变式**：代表题展示典型结构，不自动覆盖整类。初始条件、方向正负、对象阶段数、约束、接触分离松弛绷紧、图像数据表达、参数范围、临界状态、多解与舍根——这些变化导致分析实质改变时**必须补变式**。相同结构可归并，条件不同必须区分。

**方法比较**：有实际价值才安排多解；说明条件、步骤、适用情形和局限，不以解法数量论质量。"固定破题动作"是**有条件的分析程序**，不写成万能套路。

## 五、解析完整度（三篇通用）

解析达到**学生能独立复现**。按题目需要含：信息整理 → 对象与过程 → 参考系坐标符号 → 模型条件约束 → 图示 → 规律选择 → 方程建立 → 代入消元求解 → 分类讨论 → 多解检验与舍根 → 单位方向范围合理性检查 → 方法归纳（**不机械堆十二个标题**）。

**不得跳过的关键步骤**：方程从何而来 / 正负号如何确定 / 隐含条件如何转化 / 图像斜率面积截距的意义 / 分段分类的原因 / 临界条件的建立依据 / 不等式变形与范围判断 / 多根取舍依据 / 数学解不符合物理条件的原因。禁用"显然、易得、整理可得、同理"替代这些步骤。

简单算术可合理合并；影响理解的代数、几何、函数处理必须展开。复杂题加篇幅或独立成篇，**不降低解析标准**。

## 六、练习篇与答案闭环

结构：分层与对应说明 → 题目区 → 答案与详细解析 → 自测对照与回看建议。

**分层**：基础理解 / 典型应用 / 变化迁移 / 综合提升。明确必做与选做；综合题同样遵守前置知识边界。

**题量**：**取消固定 30 题的质量要求**。题量由学习目标、题型差异、技能熟练需求和学生负担决定——不为凑数重复，不因达标数提前停止覆盖。

**答案**：题目区与答案区分开，不依赖网页折叠。每题解析足以独立订正：选择题逐选项说明、多选题明确标注、计算题展开关键过程、实验题说明操作数据误差依据。建立题号 ↔ 检测目标 ↔ 讲解位置 ↔ 错因类型对应。首次需要的方法不得只写"见前文"。

**历史遗留**：K008 起单元内答案闭环。K001–K007 答案放下一个单元的历史结构不必推翻，但**原文件须补准确答案导航**；条件允许补建独立答案页。不得让学生等下一期才能订正。

## 七、题目来源与核验

题目四类：原题 / 节选 / 改编 / 自编，登记 `docs/problem-source-register.md`。原题核对年份卷名题号条件选项图示；节选保留必要条件并标注；改编记录来源与改动并重新独立求解；自编不虚构考试身份。搜索摘要与转载标题不替代最终核验；不凭记忆补来源；同一题多个转载不算独立证据；条件不足、答案争议、图示缺失先处理再使用。优先教学匹配、边界合适、代表性充分，在此基础上优先真题。可交叉参考教辅，不照搬成段解析、独特编排、无授权图示。

## 八、配图、图像与表格

- **配图原则**：按教学功能配，无机械最低数量；能减少歧义或支撑推理必须配；原题有图必须配准确图，无图但需要分析也必须补画。情境图、受力图、阶段图、几何辅助图、结果图按需分别提供。正文逐步引用图中对象、方向、标记、状态，不能只插不讲。
- **准确性核对**：对象数量关系 / 方向角度约束 / 字母数值 / 关键状态 / 箭头含义 / 比例或示意性质 / 与正文方程一致。受力图不得把速度、位移或合力与分力重复计入。
- **图像**：坐标轴、量名、单位、关键点、线型、辅助线清楚；区分精确绘图与示意图；斜率面积截距的标示符合物理意义。
- **表格**：用于比较、映射、数据整理，不替代论证；控制列数避免横向滚动，过宽拆表或改列表；数值单位小数位对齐统一。
- **来源与制作**：网络图核验准确性来源权限；没有合适图自行绘制，不用近似图代替题目条件；精确物理图优先矢量方式，保留源文件与导出文件。

## 九、公式与题卡技术约定

独立公式 `:::formula`；分数 `{a/b}` 渲染竖式；不用 Unicode 分数字符；根号、上下标、矢量按渲染器统一语法；叙述中复杂分数算式移入公式块。`:::problem` / `:::answer` / `:::note` / `:::formula` **不得嵌套**；选项 A B C D 各一行；答案首行独立成段。题卡不能嵌公式块时，在合法位置拆分题卡与公式，不生成看似正确但无法解析的结构。变量下标兼容现有实现，显示须清楚、符合物理阅读习惯。**任何语法迁移先验证，不直接全站替换。**

## 十、统一视觉规范

细则见 `docs/visual-style-guide.md`。要点：正文 16–17px、行高 1.7–1.9 作移动端起始，最终以公众号预览为准；统一标题层级、正文图注、题干答案解析、留白间距、公式对齐、图片边距、表格样式、配色强调；克制配色，重要信息不只靠颜色；长公式按推理分行，不靠缩小字号；检查约 360–430px 宽度无横向溢出；**网页渲染与公众号实际效果分别验收**，网页截图不能替代公众号预览；无法实际预览时如实记录未验收。

## 十一、表达风格

准确、自然、直接，允许教师式解释。禁：空泛铺垫 / 人为反转 / 无依据夸大 / 口诀替代论证 / 把通常说成必然 / 用"很简单"评价学生可能卡住的步骤 / 以"去AI味"牺牲严谨性。不机械禁用正常句式；每段承担明确任务。固定结尾、彩蛋、碎碎念可选，置于核心教学内容之后。

## 十二、近十年真题反向验证

按执行时最近一个已完成高考年度向前十年，明确起止年份、地区、试卷范围；全国同卷去重保留地区信息；模拟题与正式高考题分开。登记处：`docs/gaokao-validation-register.md`。每题记录：来源题号 / 知识模型方法实验标签 / 对应文章 / 独立解答 / 答案核对 / 评分依据 / 发现的课程缺漏 / 修订状态。

区分**建设样本**与**阶段验收试题**——详细讲过的原题不算独立迁移能力证明。无可靠评分细则时只能声明完成物理解答核验，不声称确认满分。报告明确分母：计划多少、取得多少、核验多少、解答多少、尚缺多少；不用"已覆盖运动学"代替逐项映射。

## 十三、审核与发布

- **学科审核**（`docs/subject-review-checklist.md`）：知识正确、条件明确、题型覆盖、推导完整、题目独立求解、答案正确、分类讨论、图文一致、练习对应、前置知识边界。复核含重新求解、来源对照、反例或极限检查等**实际动作**，不只重复阅读后声明正确。
- **工程审核**：lint / build / verify / smoke，查题卡公式图片链接导航构建。**工程通过不代表学科通过**。
- 审核未通过不得进正式发布渠道；保留已授权的自动发布流程，但明确触发路径，避免待审核稿误上线。频率服从质量，不为"每日三篇"降标准。

## 十四、状态管理

目录、写作、核验、发布状态分别管理。**已写作、已讲解、已练习、已核验、已发布不得混称"完成"**。文件体系：主规范（AI_WRITING_GUIDE）→ 模板（BLOG_TEMPLATE）→ 风格（writing-anti-ai-style）→ 框架（physics-content-framework）→ 覆盖矩阵（physics-coverage-map）→ 题目登记（problem-source-register）→ 学科审核（subject-review-checklist）→ 视觉规范（visual-style-guide）→ 真题验证（gaokao-validation-register）→ 进度台账（workspace/course-progress）。
