## 题型一：位移公式计算——直代卡

![位移公式问题模型](/blog-images/k006-displacement-time-formula/K006-匀变速直线运动的位移与时间的关系-05-位移公式-问题模型.png)

图 1｜位移公式问题模型

### 如何识别

题目给（或可求）$v_0$、a、t 求位移 x；或给 x 反求其中一个量。情境：汽车制动、航母起飞、客机减速下落、传送带加速。

### 为什么用这个方法

公式一行：

:::formula
x = v_0 t + \frac{1}{2} a t^2
:::

读法照旧：前一半匀速打底，后一半加速加成。动作四步：定正方向 → 列已知带符号 → 代入 → 检查结果正负与物理意义。三条纪律从速度公式延续并加码：

1. 符号纪律：减速段 a 代负；x 为负表示终点在正方向反侧（如上抛落回原点以下）。
2. 时间只代一次：t 是"本段"的总时长，"加速 2 s 后又匀速 4 s"必须分段，各段各用各的时间。
3. 单位统一：先换 m/s 再动笔。

适用条件：匀变速直线运动专用。变加速、拐弯全失效。配套工具：知三求二，即 x、$v_0$、a、t 四量知三求一，与 $v = v_0 + at$ 联立可解更复杂的组合。

### 完整示范

:::problem
<span class="prob-grade">示范 1【基础题·常考题·计算题】</span><span class="prob-source">（2024 北京卷 T2，主讲篇第 1 题）</span>汽车以 10 m/s 匀速行驶，制动后匀减速，经 2 s 停止，求制动距离。$a = \frac{0 - 10}{2} = -5$ m/s²，$x = 10 \times 2 + \frac{1}{2} \times (-5) \times 2^2 = 20\ \text{m} - 10\ \text{m} = 10$ m。平均速度法验算：$x = \frac{10 + 0}{2} \times 2 = 10$ m。两条路同答案，考试时一正一验，稳。
:::

:::problem
<span class="prob-grade">示范 2【提升题·经典题·计算题】</span><span class="prob-source">（反求型，2013 广东卷 T13，主讲篇第 3 题）</span>航母跑道长 200 m，飞机滑行的最大加速度 6 m/s²，起飞最低速度 50 m/s，求弹射系统须提供的最小初速度。设滑行用时 t：由 $50 = v_0 + 6t$ 得 $v_0 = 50 - 6t$，代进位移公式 $200 = v_0 t + 3t^2$，得 $3t^2 - 50t + 200 = 0$，解出 $t = \frac{50 \pm 10}{6}$，即 10 s 或 $\frac{20}{3}$ s。舍根依据：$t = 10$ s 算出 $v_0 = -10$ m/s，初速度为负与弹射向前助跑矛盾，舍去；故 $v_0 = 50 - 6 \times \frac{20}{3} = 10$ m/s。跑道长就是位移，"情境翻译"先行；学完速度位移关系式 $v^2 = v_0^2 + 2ax$ 后，$v_0^2 = 50^2 - 2 \times 6 \times 200 = 100\ \text{m}^2/\text{s}^2$ 一行出答案。
:::

### 条件变化后怎么调整

- 变式 1：多段接力。加速—匀速—减速的行程问题。应对：切段，各段选各自的公式（匀速段 $x = vt$），段间末速接初速，位移相加。主讲篇练习二、五的传送带就是这条路的分段实战。
- 变式 2：过零反向。求出的 x 为负或某时刻速度反向。应对：以 v = 0 时刻为界切段，正负号交给公式，图景交给检查。
- 变式 3：比例条件反求。"第 1 s 内与第 3 s 内位移之比"，进题型三。

### 常见错误与适用边界

- 错因（数学）：$\frac{1}{2}at^2$ 项漏乘 0.5 或漏平方。推荐固定书写顺序：先写公式原形，再代数。
- 错因（概念）：把 x 当路程用。往返或减速过头时两者不同。
- 边界：单段匀变速内使用；跨段问题切段处理；本单元不用面积微元做非匀变速。

## 题型二：平均速度法——中间时刻钥匙卡

![平均速度法问题模型](/blog-images/k006-displacement-time-formula/K006-匀变速直线运动的位移与时间的关系-07-平均速度法-问题模型.png)

图 2｜平均速度法问题模型

### 如何识别

匀变速段里出现"中间时刻的速度""首末速度已知""位移与时间的搭配"类问题；或题目结构让你预感"直接代位移公式会算很久"。

### 为什么用这个方法

匀变速直线运动有一条漂亮的推论：中间时刻的瞬时速度等于这段的平均速度：

:::formula
v_{\frac{t}{2}}\,(\text{中点}) = \bar{v} = \frac{v_0 + v_{\text{末}}}{2}
:::

于是位移多了一条快路：

:::formula
x = \bar{v} t = \frac{v_0 + v_{\text{末}}}{2}\, t
:::

为什么成立：v–t 图是倾斜直线，梯形面积 = 中位线 × 高。中位线恰好立在时间中点上。"为什么选它当钥匙"：它把"带 $t^2$ 的计算"换成"首末速度平均后乘时间"，数字漂亮时口算都行；2023 山东卷 T6（公交 RST）那一整类难题，钥匙就是它。

适用条件：只在匀变速段成立（v–t 必须是直线）。变加速不能用；跨段（先减速后匀速）不能整段套，切开后各段各用。

### 完整示范

:::problem
<span class="prob-grade">示范 1【提升题·易错题·选择题】</span><span class="prob-source">（题库《高中物理题型全总结》专题 1.2 第 5 题，主讲篇第 8 题）</span>匀加速直线运动的物体第 3 s 内位移 5 m。"第 3 s 内"的平均速度是 5 m/s，它就是 2.5 s 时刻的瞬时速度（中间时刻钥匙）；而 2.5 s 恰好是前 5 s 的中间时刻，所以前 5 s 位移 $x = 5\ \text{m/s} \times 5\ \text{s} = 25$ m。整题没算加速度——钥匙插进锁眼，一拧就开。选项里"第 3 s 末速度一定是 6 m/s""加速度一定是 2 m/s²"全是坑：中间时刻的速度定了，初速度和加速度仍可以各取各的。
:::

:::problem
<span class="prob-grade">示范 2【提升题·经典题·选择题】</span><span class="prob-source">（题库《高中物理题型训练》1.1 第 2 题，主讲篇第 9 题）</span>斜面上匀加速下滑的小球依次经过 A、B、C，AB = 18 m、BC = 30 m，两段用时都是 2 s，求三个点的速度。B 是 AC 段的中间时刻：$v_B = \frac{18 + 30}{4} = 12$ m/s；再由 BC 段位移公式 $30 = 12 \times 2 + \frac{1}{2}a \times 4$ 解出 $a = 3$ m/s²，回代 AB 段得 $v_A = 6$ m/s，则 $v_C = 12\ \text{m/s} + 6\ \text{m/s} = 18$ m/s，选 D。学过知识点三的逐差后更快：$a = \frac{30 - 18}{2^2} = 3$ m/s²，两步并一步。
:::

### 条件变化后怎么调整

- 变式 1：首末速度不齐。已知 $v_0$ 和 a、t：先 $v_{\text{末}} = v_0 + at$，再平均。应对：两步合一步写。
- 变式 2：位移中点速度。位移中点的速度是另一条推论 $v_{\frac{x}{2}} = \sqrt{\frac{v_0^2 + v^2}{2}}$，与中间时刻不同（变速时 $v_{\frac{x}{2}} > v_{\frac{t}{2}}$ 恒成立）。本单元认识即可，不展开推导。
- 变式 3：非匀变速段。平均速度法只剩定义式 $\bar{v} = \frac{\Delta x}{\Delta t}$ 可用，推论失效。识别标志：v–t 图是否直线。

### 常见错误与适用边界

- 错因（条件）：在变加速段用 $\frac{v_0 + v}{2}$。先确认匀变速再上钥匙。
- 错因（混淆）：中间时刻与位移中点当成同一个点。变速时两者不重合。
- 边界：本卡解决匀变速段的 x、$\bar{v}$、$v_{\frac{t}{2}}$ 互求；不处理变加速与曲线。

## 题型三：比例关系与逐差——1:3:5 卡

![逐差关系问题模型](/blog-images/k006-displacement-time-formula/K006-匀变速直线运动的位移与时间的关系-09-逐差关系-问题模型.png)

图 3｜逐差关系问题模型

### 如何识别

题目出现"初速度为零""连续相等时间间隔""第 n 个 T 内位移""连续相等位移""纸带或雷达的连续等时间隔数据"。这是初速为零匀加速的专属赛道。

### 为什么用这个方法

初速为零的匀加速直线运动，从静止起按相等时间 T 切段，四条比例关系（主讲篇已逐条推导）：

1. 速度比：1 s 末、2 s 末、3 s 末……速度之比 = 1 : 2 : 3 : …
2. 位移比：前 1、前 2、前 3 个 T 内位移之比 = 1 : 4 : 9 : …（$x \propto t^2$）
3. 逐段比：第 1、第 2、第 3 个 T 内位移之比 = 1 : 3 : 5 : …（连续奇数比）
4. 逐差恒定：相邻相等时间间隔位移差 $\Delta x = aT^2$（对任意匀变速成立，不限初速为零）

适用条件：前三条必须初速为零（或能"逆向"化为初速为零，见变式 2）；第四条 $aT^2$ 是匀变速通吃。比例是有条件的结论，条件丢了就错。

### 完整示范

:::problem
<span class="prob-grade">示范 1【基础题·经典题·选择题】</span><span class="prob-source">（题库《高中物理题型全总结》专题 1.1 第 8 题，主讲篇第 16 题）</span>石块自由下落，把空中运动时间三等分，第一段位移 1.2 m。初速为零匀加速，三段位移之比 1:3:5，第三段占 5 份，$x_3 = 5 \times 1.2\ \text{m} = 6.0$ m，选 C。比例一摆，不用算 $t^2$；用 1:4:9 的"总位移比"去乘（$1.2 \times 9 = 10.8$ m）就掉进 D 选项的坑——"第几段"和"前几段"是两族比例。
:::

:::problem
<span class="prob-grade">示范 2【提升题·经典题·选择题】</span><span class="prob-source">（题库《高中物理题型训练》1.2 第 5 题，主讲篇第 13 题）</span>四个水球挡子弹，子弹恰好穿出第四个。倒过来读：穿出前是"初速为零的匀加速，连续通过四段相等位移"，时间之比 $1 : (\sqrt{2}-1) : (\sqrt{3}-\sqrt{2}) : (2-\sqrt{3})$；正向穿过水球的顺序恰好把它倒过来，A 选项 $(2-\sqrt{3}) : (\sqrt{3}-\sqrt{2}) : (\sqrt{2}-1) : 1$ 正确。B、C、D 各错在：位移相等但时间不等，平均速度不同；$\Delta v = a\Delta t$，各水球用时不同则速度变化量不同；等位移的"末速比"是 $1 : \sqrt{2} : \sqrt{3} : 2$，正向进入的初速之比是它的倒序 $2 : \sqrt{3} : \sqrt{2} : 1$。逆向思维是这张卡的标配。
:::

:::problem
<span class="prob-grade">示范 3【提升题·常考题·实验题】</span><span class="prob-source">（2022 全国乙卷·实验题，主讲篇第 15 题）</span>雷达每 1 s 测一次飞行器位置，六段位移依次 507、587、665、746、824、904 m。相邻位移差依次约 80、78、81、78、80 m，在误差范围内近似恒定，这就是 $\Delta x = aT^2$ 的匀加速判据；逐差分组 $a = \frac{(x_4 + x_5 + x_6) - (x_1 + x_2 + x_3)}{9T^2} = \frac{2474 - 1759}{9} \approx 79$ m/s²。求 $x = 507$ m 处的瞬时速度则用中间时刻钥匙：它前后各 1 s，$v = \frac{0 + 1094}{2} = 547$ m/s。逐差法是实验单元与计算题两栖的技能，这里的雷达数据表和纸带是同一套逻辑。
:::

### 条件变化后怎么调整

- 变式 1：等时间但非从静止。先算第一段末速，或用 $\Delta x = aT^2$ 只求 a。应对：比例 1:3:5 不可用，逐差仍可用。主讲篇练习三的 $x = 5t + t^2$ 就是初速度不为零的例子。
- 变式 2：逆向化归。减速到停的问题倒过来读成"初速为零的加速"（刹车倒放、上抛倒放、水球里的子弹）。应对：末态当初态，时间轴翻转。
- 变式 3：等位移切段。通过连续相等位移（2024 山东卷 T3 木板型）：各段末速比 = $1 : \sqrt{2} : \sqrt{3}$，时间用 $t = \sqrt{\frac{2x}{a}}$ 逐段差。应对：回到 $x \propto t^2$ 的原始关系解。
- 变式 4：纸带缺段。连续六段用逐差法分组求 a（$(x_4+x_5+x_6) - (x_1+x_2+x_3) = 9aT^2$）。应对：实验单元正式推，本单元先记结构。

### 常见错误与适用边界

- 错因（条件）：初速不为零硬套 1:3:5。比例前先查 $v_0$。
- 错因（概念）："前 n 秒位移比"与"第 n 秒位移比"混用（1:4:9 对 1:3:5）。
- 错因（数学）：$\sqrt{2}-1 \approx 0.41$、$2-\sqrt{3} \approx 0.27$ 这些数值要熟，考场现推费时间。
- 边界：比例只服务初速为零的匀加速（或其逆过程）；$\Delta x = aT^2$ 服务一切匀变速。

## 题型四：刹车位移——停车时间+位移卡

### 如何识别

刹车/减速到停的问题里问"多远停住""某段时间内滑行多远"，是《速度公式》单元停车时间卡的位移版。

### 为什么用这个方法

两步走：先算 $t_{\text{停}} = \frac{v_0}{|a|}$，再算位移：问的时间没超 $t_{\text{停}}$ 就正常代公式，超了就只算到停为止。刹车位移有一条速算路：平均速度法 $x = \frac{v_0}{2} \cdot t_{\text{停}}$。反过来，已知刹车距离求初速，就用位移公式与 $v = v_0 + at$ 联立；学过"没有 t 的公式" $v^2 = v_0^2 + 2ax$ 后一行收工（主讲篇第 3 题备注埋过这颗种子）。

适用条件：模型边界与 K005 相同：停后不动。上抛过顶不是刹车，上抛的位移要用完整公式让 x 自己变负，不套"截断"。

### 完整示范

:::problem
<span class="prob-grade">示范 1【提升题·易错题·计算题】</span><span class="prob-source">（题库《高中物理题型全总结》专题 1.1 第 5 题，主讲篇第 2 题）</span>汽车 20 m/s 行驶，急刹车加速度大小 5 m/s²，求刹车后 2 s 与 5 s 的位移之比。先算停车时间 $t_{\text{停}} = \frac{20}{5} = 4$ s：2 s 没超，$x_1 = 20 \times 2 - \frac{1}{2} \times 5 \times 4 = 30$ m；5 s 超了，只算到停为止，$x_2 = \frac{20}{2} \times 4 = 40$ m。比值 30 : 40 = 3 : 4，选 C。问"5 s 内滑行多远"，多出来的 1 s 车没动——截断在 $t_{\text{停}}$。
:::

:::problem
<span class="prob-grade">示范 2【提升题·经典题·选择题】</span><span class="prob-source">（2022 全国甲卷 T15）</span>长为 l 的列车以速率 $v_0$ 行驶，前方一长为 L 的隧道规定：列车任一部分在隧道内时速率不得超过 v（$v < v_0$）。列车加速和减速的加速度大小分别为 a 和 2a，求从减速开始至回到 $v_0$ 的最短总时间。减速段：$t_1 = \frac{v_0 - v}{2a}$；匀速段：从车头进洞到车尾出洞，位移是 L + l，$t_2 = \frac{L + l}{v}$；加速段：$t_3 = \frac{v_0 - v}{a}$。合计 $t = \frac{3(v_0 - v)}{2a} + \frac{L + l}{v}$，选 C。两个易混点：减速用 2a、加速用 a，系数别装反；"任一部分在隧道内"对应的匀速位移是 L + l，车长 l 不能丢。
:::

### 条件变化后怎么调整

- 变式 1：两段刹车。反应距离（匀速）+ 刹车距离（匀减速）。应对：切段相加，这是"安全距离"类题的标准结构。
- 变式 2：减速到目标速度再匀速（限速区、进站）。应对：减速段单独用卡，匀速段 $x = vt$，本题型示范 2 的列车过隧道就是完整版；别把"减速到限速 v"当"减到停"。
- 变式 3：问"最后 1 s 内滑行多远"。应对：倒过来读成初速为零的匀加速，最后 1 s 就是逆向的第 1 s，位移 $x = \frac{1}{2}|a| \times 1^2$；总滑行时间也可以这样逆向求出。

### 常见错误与适用边界

- 错因（建模）：不查 $t_{\text{停}}$ 直接代"6 s 内位移"。负位移或超量位移都是模型越界。
- 错因（概念）：刹车位移用 $v_0 t - 0.5|a|t^2$ 代了超过 $t_{\text{停}}$ 的 t。截断在 $t_{\text{停}}$。
- 边界：只管"减速到停停住不动"；冰面倒滑、上抛越顶另立模型。

## 题型五：v–t 图像面积——面积分块卡

### 如何识别

给 v–t 图像求位移，或多段折线图求全程位移、路程。

### 为什么用这个方法

v–t 图线与时间轴围成的面积 = 位移。倾斜直线下面积是梯形/矩形+三角形，即位移公式 $x = v_0 t + \frac{1}{2}at^2$ 的图像版（主讲篇推导用的就是它）。三条使用规则：

1. 分块：复杂折线按"每段一个几何图形"切块，各块面积相加。
2. 正负：t 轴下方的面积算负位移（速度为负在往回走）；路程则把绝对值全加。代数面积与路程的分野在图像题里最直观。
3. 方向：总位移正负即总位移方向；"回到出发点"对应正负面积互相抵消（x = 0）。

适用条件：面积法对任何 v–t 图成立（包括曲线，高中曲线面积用数格近似）；匀变速直线用几何公式精确算。

### 完整示范

:::problem
<span class="prob-grade">示范 1【提升题·经典题·计算题】</span><span class="prob-source">（2022 湖北卷 T6，主讲篇第 19 题）</span>两站间 1080 km、中间均匀分布 4 站，普通列车最高 108 km/h、高铁最高 324 km/h，进出站加速度大小都是 0.5 m/s²，停车时间相同，求高铁省下的时间。把全程想成 v–t 图：每个加、减速段是一块三角形，其余是矩形。普通列车 $v = 30$ m/s：每段加（减）速 60 s、位移 $\frac{30}{2} \times 60 = 900$ m，10 个加减速段共 9 km、600 s，匀速段 $\frac{1071\,000}{30} = 35\,700$ s，合计 36 300 s。高铁 $v = 90$ m/s：每段 180 s、8 100 m，10 段共 81 km、1 800 s，匀速段 $11\,100$ s，合计 12 900 s。省下 $36\,300\ \text{s} - 12\,900\ \text{s} = 23\,400$ s = 6 小时 30 分钟，选 B。分块时数清"有几段"是关键：始发站只加速、终点站只减速，中间 4 站各一减一加。
:::

:::problem
<span class="prob-grade">示范 2【提升题·易错题·选择题（多选）】</span><span class="prob-source">（2008 上海卷 T11）</span>以 30 m/s 初速度竖直上抛一物体，不计空气阻力，g 取 10 m/s²，判断 5 s 内的路程与位移。上升段：$t_1 = \frac{30}{10} = 3$ s，上升高度 $h_1 = \frac{30 + 0}{2} \times 3 = 45$ m（v–t 图上方的三角形面积）；后 2 s 下落 $h_2 = \frac{1}{2} \times 10 \times 2^2 = 20$ m（图线下方）。总位移 $45\ \text{m} - 20\ \text{m} = 25$ m，方向向上；总路程 $45\ \text{m} + 20\ \text{m} = 65$ m。故：

- A 对。
- B 对。
- C 错。5 s 末速度 20 m/s 向下，速度改变量大小 $|-20 - 30| = 50$ m/s。
- D 错。平均速度 $\frac{25}{5} = 5$ m/s。

“位移带符号、路程取绝对值”在竖直上抛里一样成立。
:::

### 条件变化后怎么调整

- 变式 1：梯形直接算。匀加速段就是梯形 $\frac{v_0+v}{2} \times t$，平均速度法的图像解释，两卡联动。
- 变式 2：判追及。两车 v–t 同图：面积差 = 距离变化；交点（速度相等）常是距离极值点。本单元点到为止，追及专题在主题⑩。
- 变式 3：a–t 图迁移。a–t 图的面积是 $\Delta v$ 不是位移，是另一张牌，别混。

### 常见错误与适用边界

- 错因（概念）：把 t 轴下方面积也加正。位移带符号、路程取绝对值。
- 错因（读图）：把 x–t 图当 v–t 图求面积。先看纵轴。
- 边界：面积法只配 v–t 图；x–t 图没有"面积=位移"的属性。
