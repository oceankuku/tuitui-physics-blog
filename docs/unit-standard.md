# 单元内容与排版规范（2026-10-24 第二章实验试点定稿）

> 本规范从"第二章实验"三篇重构中提炼，供后续单元（K008 起）复用；与《AI_WRITING_GUIDE》冲突时以后者为准，本文件是其单元级细化。

## 一、三篇职责与结构

**主讲篇（建立物理理解）**
- 以核心问题组织全篇，按实验/教学的本来逻辑推进：研究目标 → 情境 → 对象与假设 → 物理量与测量方式 → 规律推导 → 物理解释 → 适用条件 → 基础应用。逻辑顺序不必做成标题。
- 全单元的公式推导只落在主讲篇；方法篇、练习篇引用不重复。推导每步有依据，禁用"显然""同理""整理可得"跳过影响理解的过程；近似关系必须明示（严格等式 / 理想模型下成立 / 实验近似）。
- 开篇交代核心问题、前置知识与学习目标；结尾回答开篇问题并指向配套篇。

**方法篇（建立分析能力）**
- 按测量任务分类（问题实质优先），题面问法只作辅助，不按问法建类。
- 每类任务固定走：问题实质 → 已知量与目标量 → 路径选择及理由 → 完整示范 → 条件变化 → 方法边界。
- 条件变化必须是条件真实变化后方法适用性的分析，不得只换数字。

**练习篇（检验与反馈）**
- 按学习目标分层：概念辨析 / 基础应用 / 条件变化 / 综合评估。题量由覆盖需求决定，不凑数；同层不设重复考点。
- 每题标注检测目标，答案区按题号逐题"答案 — 依据 — 检查"；计算题必须包含量级、互验或自洽检查中的至少一种。

## 二、题卡与配色

- 题卡首行格式：`编号 + 分级 + 来源 + 题干`；分级【难度·功能·形式】（基础题/提升题 · 常考/易错/经典 · 选择/计算/实验/简答）；来源只在核实后标注，查不到的写（经典题）。
- 标签双色（2026-10-24 起）：分级用 `<span class="prob-grade">`，来源用 `<span class="prob-source">`；样式由主题变量提供（深浅主题各自成立），公众号复制由管线内联计算后的具体色值。
- 题目卡（灰底）与答案卡（绿底）为题、答两色；备注卡琥珀，只在有深度延伸时使用。
- 答案卡首行 `**答案：X。**`；选择题逐选项给错因，错因必须能复现出该选项的数值。

## 三、公式与图

- 公式规范沿用主规范（MathJax，`\frac` 竖式，单位留在 `$` 外）。
- 图四要素：编号、图注、正文显式引用、与正文符号一致。示意图由数据或函数生成（SVG + playwright 管线，源在 `workspace/figs-questions.html`）；装饰性插画不得替代物理示意图；alt 描述内容、不得泄露答案。

## 四、语言

- 禁承诺词（必拿满分、秒杀、万能、闭眼套用等）；口诀只能在原理讲清之后作为记忆辅助，不得作为论证依据。
- 保留教师口吻；段落之间写明逻辑联系，不连续堆放方法卡、提示框和结论清单；表格用于比较与对应关系。
