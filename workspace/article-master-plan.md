# 三大硬核高考模型 · 完整分类与方法（专节）

> 以下三类是高考力学综合题的"常客"，必须讲全分类、讲透方法。每类都会单开（或并入对应章节的"经典题型"大节）成篇。

## A. 晾衣架模型（落在 K012 共点力的平衡）

**本质**：两根绳对称吊起横梁（或衣物），求绳拉力、横梁受力；推广到一切"对称双拉力 + 中间载荷"的平衡结构。

### 完整分类
1. **按约束类型分**
   - 轻绳约束：只能拉、不能压，力沿绳方向，结点无摩擦 → 拉力方向固定。
   - 轻杆约束：可拉可压，力不一定沿杆（铰链端自由）→ 要按平衡方程解，不能想当然沿杆。
   - 轻弹簧约束：弹力 F=kx，方向沿弹簧，有伸长/压缩两态。
2. **按几何分**
   - 两绳等长的对称晾衣架（最常见）：两拉力等大，与竖直夹角 θ 随载荷位置/绳长变化。
   - 两绳不等长 / 载荷偏置：两拉力不等，用正交分解或相似三角形。
   - 横梁自重不可忽略：横梁受重力 + 两端拉力 + 中间载荷，整体法优先。
3. **按问题分**
   - 求绳拉力大小（随夹角 θ 变化：F = G/(2cosθ)，θ 越大 F 越大）。
   - 求横梁/杆受力（受压还是受拉）。
   - 动态问题：缓慢移动载荷或改变绳长 → 拉力如何变（图解法/解析法）。

### 对应方法（破题动作）
- **第一步**：找"结点"，明确每个结点的受力（重力、绳张力、杆力），标清方向。
- **第二步**：对称先看对称（等大反向），不对称用正交分解列 x、y 平衡方程。
- **动态平衡三法**：
  - 图解法（三力平衡且一力恒定、一力方向不变 → 画力矢量三角形转）。
  - 解析法（列 F 与 θ 的函数，看单调性）。
  - 相似三角形法（几何相似 → 力三角形 ∽ 结构三角形）。
- **口诀**："晾衣架，看结点；对称等大先写出来，不对称就正交分解；动态慢变画图 triangle。"

## B. 传送带分类（落在 K016 牛顿定律应用）

**本质**：物体在传送带上受摩擦，经历"加速/减速 → 共速"过程，考相对运动、划痕、能量。

### 完整分类
1. **按放置分**
   - **水平传送带**：
     - 工件从静止释放（初速 0，传送带匀速 v）→ 先匀加速到 v，再匀速。
     - 工件以初速 v₀ 滑上（v₀ < v 或 v₀ > v）→ 加速或减速到 v。
     - 能否共速？若传送带不够长，未共速就离开 → 全程变速。
   - **倾斜传送带**（向上/向下送料）：
     - 物块沿带向上：摩擦向上帮一把 vs 重力分力向下，看谁大。
     - 物块沿带向下：摩擦向上阻碍，可能减速到 0 再反向，或一直加速。
     - 摩擦方向可能**阶段性反向**（先加速后共速，或先减速后反向）。
2. **按问题分**
   - 求物体到达末端的末速度 / 时间。
   - 求**划痕长度**（划痕 = 两者相对位移，注意相对运动方向，划痕不叠加要取净相对位移）。
   - 求**摩擦生热** Q = f · s_相对。
   - 求电动机多做的功（能量：物体动能增量 + 生热）。
3. **按组合分**
   - 纯牛顿过程（高一）。
   - 加能量视角（动能定理/功能关系，高二复习）。

### 对应方法（破题动作）
- **第一步**：判"共速否、何时共速"。算 a = μg（水平）或 a = g(sinθ ± μcosθ)（倾斜），算共速所需时间 t₁ 与位移 s₁，和传送带长度 L 比。
- **第二步**：分段。未共速段（变速）写牛顿第二定律；共速后段（匀速或相对静止）摩擦消失（水平共速后 f=0）。
- **第三步**：划痕 = |s_物 − s_带| 在该段内的累积；生热 Q = f·s_相对。
- **第四步**：能量守恒兜底（物体能量变化 + 生热 = 电机做功）。
- **口诀**："传送带，先判共速；共速前摩擦在，共速后摩擦没（水平）；划痕算相对，生热乘相对。"

## C. 板块问题（滑块—木板，落在 K014/K016 牛顿版，选择性必修动量能量版）

**本质**：滑块在木板上滑动，两者加速度不同产生相对位移；考临界、相对位移、摩擦生热、动量能量综合。

### 完整分类
1. **按地面分**
   - 木板置于**光滑地面**：系统水平方向不受外力，动量守恒可用。
   - 木板置于**粗糙地面**：地面摩擦参与，动量不守恒，要算总受力。
2. **按施力对象分**
   - **拉力作用在木板上**（最常见）：板加速快，块靠摩擦带 → 先相对滑动，后共速。
   - **拉力作用在滑块上**：块加速快，板靠摩擦带。
   - **滑块以初速滑上静止木板**：纯初速驱动，摩擦使两者趋近共速。
3. **按过程分**
   - 一直相对滑动到分离（板不够长）。
   - 先滑后共速（板够长），之后一起匀速/匀加速。
   - 含外力持续作用（恒力/变力）。
4. **按知识层次分**
   - 牛顿版（高一）：两物体各自牛顿第二定律 + 位移关系 s_块 − s_板 = L（板长）或 = d（相对位移）。
   - 动量能量版（选择性必修）：相对滑动阶段动量守恒（光滑地）+ 机械能损失 = 摩擦生热 Q = f·s_相对。

### 对应方法（破题动作）
- **第一步**：判"是否相对滑动"——求临界：若两者间静摩擦能提供所需加速度则一起动（a 相同）；否则滑动（各算各的 a）。
  - 临界条件：f_max = μ·m_块·g ≥ |m_块·a_所需|。
- **第二步**：给两块分别列牛顿第二定律，标清摩擦方向（块相对板向哪滑，摩擦就阻碍哪）。
- **第三步**：写位移关系。相对滑动阶段：s_块 − s_板 = 相对位移 Δx；判断是否 Δx 达到板长 L（分离条件）。
- **第四步**：共速后若仍受外力，按整体一起算；若光滑地面+无外力，共速即匀速。
- **第五步（动量能量版）**：相对滑动全程用动量守恒（水平合外力为零时）+ Q = f·s_相对 算能量损失，再用动能定理收尾。
- **口诀**："板块题，先判滑不滑（看临界摩擦）；各算各的 a，位移差等于板长；光滑地面动量守，生热乘相对移。"
