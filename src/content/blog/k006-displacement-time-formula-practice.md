## 题型库加练答案（第 31–35 题）

**31.** $a = \frac{\Delta x}{3t^2}$。两段的中间时刻速度分别是 $v_1 = \frac{\Delta x}{2t}$、$v_2 = \frac{\Delta x}{t}$，两个中间时刻相隔 $\frac{2t + t}{2} = \frac{3t}{2}$，所以 $a = \frac{v_2 - v_1}{3t/2} = \frac{\Delta x}{3t^2}$。（典型错误：把两个中间时刻的间隔当成 $t$ 或 $2t$。）

**32.** $a = \frac{4}{3} \approx 1.33$ m/s²。两段中间时刻速度 $v_1 = \frac{16}{4} = 4$ m/s、$v_2 = \frac{16}{2} = 8$ m/s，中间时刻相隔 $\frac{4 + 2}{2} = 3$ s，$a = \frac{8 - 4}{3} = \frac{4}{3}$ m/s²。

**33.** 加速度 5 m/s²，加速阶段通过 10 m。匀加速第 2 s 内的位移为 $\frac{1}{2}a(2^2 - 1^2) = 1.5a = 7.5$，得 $a = 5$ m/s²。设加速时间为 $t_1$，全程 $100 = \frac{1}{2} \times 5 \times t_1^2 + 5t_1(11 - t_1)$，整理得 $t_1^2 - 22t_1 + 40 = 0$，解出 $t_1 = 2$ s（另一根 20 s 超过总时长，舍去），加速段位移 $\frac{1}{2} \times 5 \times 2^2 = 10$ m。

**34.** $OA = \frac{(3l_1 - l_2)^2}{8(l_2 - l_1)}$。相邻相等时间位移差 $l_2 - l_1 = aT^2$；B 是 AC 段中间时刻，$v_B = \frac{l_1 + l_2}{2T}$；由 $v_B^2 = 2a \cdot OB$ 得 $OB = \frac{(l_1 + l_2)^2}{8(l_2 - l_1)}$，故 $OA = OB - l_1 = \frac{(l_1 + l_2)^2 - 8l_1(l_2 - l_1)}{8(l_2 - l_1)} = \frac{(3l_1 - l_2)^2}{8(l_2 - l_1)}$。

**35.** (a) 最大速度 $v_m = a_1 t_1$（也等于 $a_2 t_2$），全程位移 $x = \frac{v_m(t_1 + t_2)}{2}$（两段都是均匀变化，各占一个三角形），所以 $\bar{v} = \frac{x}{t_1 + t_2} = \frac{a_1 t_1}{2}$。(b) 平均速度只由"速度从 0 均匀升到 $v_m$ 再均匀降回 0"决定：峰值 $v_m$ 和总时间定了，$\bar{v}$ 就定了；$a_2$、$t_2$ 只在保证 $a_2 t_2 = v_m$ 的前提下参与，不改变"三角形面积"这个结果。
