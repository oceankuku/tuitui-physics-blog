## 用法与分层说明

:::usage

- 第 1–10 题 基础理解。
- 第 11–20 题 典型应用。
- 第 21–26 题 变化迁移。
- 第 27–30 题 综合提升。
- 题型分布：选择题 18 道（其中多选 3 道：第 8、9、14 题）、计算题 12 道（每题题号后已标注；第 31–35 题为题型库加练，另有 1 道多选：第 32 题）。
- 必做与选做：第 1–20 题必做，第 21–26 题推荐完成，第 27–30 题选做。
- 知识边界：可用 $x = v_0 t + \frac{1}{2}at^2$、$v = v_0 + at$、平均速度推论（中间时刻速度等于这段的平均速度）、初速为零的比例推论（含"减速到停倒过来看"的逆向化归）；不使用 $v^2 = v_0^2 + 2ax$，也不使用 $\Delta x = aT^2$ 逐差——那是实验单元的工具。个别题以自由下落为情境，都按 $a = g$ 的匀加速直线运动处理，g 取 10 m/s²。
- 使用规则：先做题再翻答案（前 30 题答案收在下一篇《自由落体运动》练习篇文末「上一单元答案区」）；每题标 ✓、△、✗；计算题写公式原形再代数。

:::

## 题型库加练答案（第 31–35 题）

31. (1) $9 : 7$；

　　(2) 2.1 m/s。$AB$ 段从静止开始匀加速，平均速度

:::formula
\bar{v}_{AB} = \frac{0+3}{2} = 1.5 \text{ m/s}
:::

　　$BC$ 段平均速度

:::formula
\bar{v}_{BC} = \frac{3+4}{2} = 3.5 \text{ m/s}
:::

　　两段等长，所以

:::formula
t_{AB} : t_{BC} = \frac{1}{1.5} : \frac{1}{3.5} = 7 : 3
:::

　　加速度 $a_{AB} = \frac{3}{t_{AB}}$，$a_{BC} = \frac{4-3}{t_{BC}}$，故

:::formula
a_{AB} : a_{BC} = \frac{3}{1.5} : \frac{1}{3.5} = 9 : 7
:::

　　全程平均速率

:::formula
\bar{v}_{AC} = \frac{2x}{t_{AB}+t_{BC}} = \frac{2}{\frac{1}{1.5}+\frac{1}{3.5}} = \frac{2}{\frac{20}{21}} = 2.1 \text{ m/s}
:::

　　（典型错误：$BC$ 段平均速度直接用 3 或 4 m/s——它是匀变速段，必须用首末平均。）

32. BCD。

　　B 对。中间时刻速度等于首末速度的平均

:::formula
\frac{v+7v}{2} = 4v
:::

　　A 错。位移中点的速度要更大——按推论三（本单元认识即可）

:::formula
v_{\frac{x}{2}} = \sqrt{\frac{v^2 + (7v)^2}{2}} = 5v \neq 4v
:::

　　C 对。加速度 $a = \frac{6v}{t}$，前 $\frac{t}{2}$ 位移

:::formula
x_1 = v \cdot \frac{t}{2} + \frac{1}{2} \cdot \frac{6v}{t} \cdot \frac{t^2}{4} = \frac{5vt}{4}
:::

　　后半位移

:::formula
x_2 = 4vt - \frac{5vt}{4} = \frac{11vt}{4}
:::

　　少了 $\frac{6vt}{4} = 1.5vt$。

　　D 对。等位移的两段，平均速度分别为 $\frac{v+5v}{2} = 3v$ 和 $\frac{5v+7v}{2} = 6v$，时间与平均速度成反比，$t_1 : t_2 = 2 : 1$。

33. (1) $v_0 = \sqrt{gh}$；

　　(2) $v_a = 0$，$v_b = \sqrt{gh}$（方向竖直向下），a 球恰好到达最高点；

　　(3) 同时落地。解法：b 球落到 $\frac{h}{2}$ 处用时 $t_0$，由

:::formula
\frac{h}{2} = \frac{1}{2}gt_0^2
:::

　　得 $t_0 = \sqrt{\frac{h}{g}}$；a 球在同一时间内上升 $\frac{h}{2}$：

:::formula
\frac{h}{2} = v_0 t_0 - \frac{1}{2}gt_0^2
:::

　　代入 $\frac{1}{2}gt_0^2 = \frac{h}{2}$ 得 $v_0 t_0 = h$，所以 $v_0 = \frac{h}{t_0} = \sqrt{gh}$。相遇时 a 球速度

:::formula
v_a = v_0 - gt_0 = 0
:::

　　恰好到达最高点；b 球速度

:::formula
v_b = gt_0 = \sqrt{gh}
:::

　　方向向下。相遇后 a 球从 $\frac{h}{2}$ 处自由下落，用时

:::formula
\sqrt{\frac{2 \times (h/2)}{g}} = \sqrt{\frac{h}{g}}
:::

　　b 球继续下落剩下的 $\frac{h}{2}$，用时同为 $\sqrt{\frac{h}{g}}$——两球同时落地。（原卷多选的正确项"两球同时落地"与本结论一致。）

34. (1) $T = \frac{t}{n+1}$；

　　(2) $\frac{2t}{n+1}$；

　　(3) $g = \frac{(n+1)^2 h}{2t^2}$。一滴刚落地、一滴刚出发、空中还有一滴，说明相邻两滴的出水间隔为 $T$，且第 1 滴落地时已在空中下了 $2T$：

:::formula
h = \frac{1}{2}g(2T)^2 = 2gT^2
:::

　　第 $k$ 滴在时刻 $(k+1)T$ 落地，由 $t = (n+1)T$ 得 $T = \frac{t}{n+1}$；每滴的下落时间为 $2T = \frac{2t}{n+1}$；代回得

:::formula
g = \frac{h}{2T^2} = \frac{(n+1)^2 h}{2t^2}
:::
