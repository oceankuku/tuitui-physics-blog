原理在①、路径在②，这篇检验两件事：题目换了条件你还会不会分析，答案对不对你能不能自己检查出来。24 道题按学习目标分四层，做完再翻文末答案区，每题都按"答案—依据—检查"给全。

- 对应教材：人教版必修第一册 第二章 实验节。
- 本篇类型：第二章实验单元练习篇。
- 前置知识：主讲篇《第二章实验①》的器材原理与推导，方法篇《第二章实验②》的四类任务。
- 学习目标：按层检验——概念是否清楚（A）、标准流程是否熟练（B）、条件变了会不会分析（C）、综合问题能否评估（D）。
- 使用规则：先独立完成再对答案；每题给自己标 ✓、△、✗，△ 和 ✗ 回到对应讲解位置重做一遍。

## 用法与分层说明

- 第 1–5 题　概念辨析（必做）：计时原理、定理依据、判据。
- 第 6–13 题　基础应用（必做）：点速、逐差、双门、完整流程。
- 第 14–20 题　条件变化（推荐完成）：装置、数据、环境变了，方法还成立吗。
- 第 21–24 题　综合与评估（选做）：大题流程、误差链、方案比较。
- 题型分布：选择题 7 道、实验题 12 道、简答题 5 道（每题标签已注明）。
- 知识边界：打点计时器 50 Hz、计数点间隔、中间时刻速度、逐差法（4 段/6 段）、光电门 $v = \frac{d}{\Delta t}$、$\frac{v_B^2 - v_A^2}{2L}$、误差方向；未注明时 g 取 10 m/s²。

## 本单元答案区（按题号逐题）

**1. B。**依据：打点周期由交流电频率决定，$T = \frac{1}{f} = 0.02$ s。A 错，电磁打点计时器用 4–6 V 低压交流，220 V 是电火花计时器；C 错，拉得快只改变点间距；D 错，必须用交流电。检查：抓住"计时靠频率"这一条即可排掉全部干扰项。

**2. A。**依据：匀变速中一段时间的平均速度等于中间时刻的瞬时速度，左右两段相加除以 $2T'$ 正是 AC 段平均速度。检查：D 的"位移中点"是另一个推论（中间位置速度），与中间时刻不是一回事。

**3. B。**依据：隔 3 段相减每位差 $3aT'^2$，三差相加得 $9aT'^2$，$3 \times 3 = 9$。检查：忘记来历就回到"两组求和再相减"的图（主讲篇图 3）。

**4. B。**依据：匀加速的定义性质 $\Delta x = aT'^2$ 恒定。A 只说明轨迹是直的（变速直线运动也是直线）；C 是加速的表现但不是判据（匀减速也变间距）；D 无关。顺带一提：点距均匀只说明速度大小不变，要下"匀速直线运动"的结论还需点迹在同一直线上。检查：判据必须能区分"是"与"不是"，单看现象不行。

**5. B。**依据：图像法的规范动作是让数据点均匀分布在直线两侧，斜率即加速度。强行穿每个点是过拟合，折线无意义，只取首尾两点浪费了其余数据。检查：图像法的价值在"用上全部数据 + 暴露异常点"。

**6. 0.14 m/s。**依据：$v = \frac{0.012 + 0.016}{0.2} = 0.14$ m/s（毫米换米）。检查：数量级应与小车速度相符，1.4 m/s 偏大一个量级。

**7. 0.40 m/s。**依据：$v = \frac{0.0080}{0.020} = 0.40$ m/s。检查：厘米已换米；若得 0.016 或 4.0，回查单位链。

**8. 0.60 m/s²。**依据：先体检，$\Delta x = 0.6$ cm 恒定；4 段逐差 $a = \frac{(0.032 + 0.038) - (0.020 + 0.026)}{4 \times 0.01} = \frac{0.024}{0.04} = 0.60$ m/s²。检查：与 $\frac{\Delta x}{T'^2} = 0.60$ m/s² 互验一致。

**9. 0.48 m/s²。**依据：$a = \frac{v_B^2 - v_A^2}{2L} = \frac{0.64 - 0.16}{1.0} = 0.48$ m/s²（$L = 0.50$ m）。检查：题给速度已带单位，唯一要换的是 L。

**10. 参考答案（两点齐即可）：**①振针通电后有起动过程，先通电让打点稳定，开头一段点迹规律才可靠；②释放前小车靠紧打点计时器，先通电再释放能让有限长的纸带尽量多记录有效运动，不浪费纸带。检查：答成"防止仪器损坏""更省电"都没有回答物理目的。

**11. (a) 匀加速直线运动；(b) 0.18 m/s；(c) 0.40 m/s²。**依据：$\Delta x = 0.40$ cm 恒定 → 匀加速；$v_3 = \frac{0.016 + 0.020}{0.2} = 0.18$ m/s；逐差 $a = \frac{(0.020 + 0.024 + 0.028) - (0.008 + 0.012 + 0.016)}{9 \times 0.01} = \frac{0.036}{0.09} = 0.40$ m/s²。检查：与 $\frac{\Delta x}{T'^2} = 0.40$ m/s² 互验一致。

**12. 3.0 m/s²。**依据：相邻速度差恒为 0.30 m/s，即 $aT' = 0.30$，$a = \frac{0.30}{0.1} = 3.0$ m/s²。逐差验证：$(v_4 + v_5) - (v_1 + v_2) = 6aT'$，$\frac{1.8}{0.6} = 3.0$ m/s²，一致。检查：$\Delta v = 0.30$ 是 $T'$ 时间内的变化量，直接当加速度就差了一个 $T'$。

**13. (a) 0.08 s；(b) 0.64 倍，偏小；(c) 10 倍。**依据：5 个点只有 4 个间隔，$T' = 4 \times 0.02 = 0.08$ s；误按 0.1 s 算，$a_{\text{测}} = \frac{\Delta x}{0.1^2}$，$a_{\text{真}} = \frac{\Delta x}{0.08^2}$，比值 $= \frac{0.08^2}{0.1^2} = 0.64$，分母偏大结果偏小；毫米当厘米，长度放大 10 倍，加速度数值放大 10 倍。检查：两问都是"代错一个量，看 $\frac{\text{代}}{\text{真}}$ 出现在分子还是分母"。

**14. B（向右减速）。**依据（结合图 1）：纸带向右被拉出，先打的点被拉得最远、落在右端，后打的点留在左端计时器附近。右端疏＝先打时快，左端密＝后打时慢——先快后慢，向右减速。检查：方向感不确定时回到一句话"先打的点跑得最远"；若把图中的小车放在计时器左侧，答案就不同——方位必须先看图。

**15. 匀速：不变。加速：测得速度略大。**依据：测得速度是遮光片的平均速度，匀变速下等于遮光片中点经过门位置的速度。匀速时速度处处相同，片宽不影响读数；加速时宽片的中点位置更靠前，对应的瞬时速度更大，所以宽片测得的数略大。检查：这不是"误差变大变小"的问题，而是"测的是哪个位置的速度"。

**16. 0.60 m/s²。**依据：弃最短的开头段 $x_1$（点最密、估读相对误差最大），用剩余 4 段：$a = \frac{(x_4 + x_5) - (x_2 + x_3)}{4T'^2} = \frac{(0.028 + 0.034) - (0.016 + 0.022)}{0.04} = \frac{0.024}{0.04} = 0.60$ m/s²。检查：$\Delta x = 0.6$ cm 恒定，与 $\frac{\Delta x}{T'^2}$ 互验一致。

**17. 弃 $x_1$，用 $x_2$ 到 $x_6$ 五段中的后四段做逐差。**依据：异常段必须能说明原因才可弃——$x_1$ 点迹异常密集且偏离等差，符合"开头段点密、易出异常"的已知规律，舍弃理由充分；其余段健康。检查：没有原因的异常不能删，先查操作和读数。

**18. 点距变小（更密）；逐差法照样适用。**依据：月面 g 小，相同时间内位移小，点距整体变小；逐差法只依赖"匀加速 + 相等时间间隔"两条，与 g 的数值无关，算出的结果就是月面 g。检查：公式换环境不换本质，先问公式依赖什么前提。

**19. 偏大，约 1.04 倍。**依据：实际打点周期 $T_{\text{真}} = \frac{1}{49}$ s 大于代入的 0.02 s，$a_{\text{测}} = \frac{\Delta x_{\text{真}}}{T_{\text{代}}^2} = a_{\text{真}}\left(\frac{T_{\text{真}}}{T_{\text{代}}}\right)^2 = a_{\text{真}} \times \left(\frac{50}{49}\right)^2 \approx 1.04\,a_{\text{真}}$。检查：分母被代小，结果必然偏大，方向与倍数都能由原理式定出。

**20. 减小偶然误差：多次测量取平均；消除装置姿态带来的系统偏差：检查挡光片是否平行。**依据：偶然误差靠平均摊薄；平行度问题来自 $d\cos\theta < d$ 的几何关系，靠重新校正消除。"更换更窄的挡光片"减小的是遮光近似带来的偏差，两问都不选它。检查：先分清偏差属于偶然还是系统，再对号入座。

**21. (a) 匀加速直线运动；(b) $v_2 = 0.49$ m/s，$v_5 = 0.67$ m/s；(c) 0.60 m/s²；(d) 0.37 m/s。**依据：段位移 4.00、4.60、5.20、5.80、6.40、7.00 cm，$\Delta x = 0.60$ cm 恒定 → 匀加速。$v_2 = \frac{x_2 + x_3}{2T'} = \frac{0.046 + 0.052}{0.2} = 0.49$ m/s；$v_5 = \frac{x_5 + x_6}{2T'} = \frac{0.064 + 0.070}{0.2} = 0.67$ m/s（注意求点 5 的速度必须用紧邻它的第 5、6 两段，不能用 $x_4 + x_5$，那是计数点 4 的速度）。逐差 $a = \frac{(5.80 + 6.40 + 7.00) - (4.00 + 4.60 + 5.20)}{9 \times 0.01} \times 10^{-2} = \frac{5.40}{0.09} \times 10^{-2} = 0.60$ m/s²；$v_0 = v_2 - 2aT' = 0.49 - 0.12 = 0.37$ m/s。检查：$v_5 - v_0 = 0.30$ m/s，恰等于 $5aT' = 5 \times 0.60 \times 0.1 = 0.30$，全链自洽。

**22. C。**依据：代错数据是计算错误，可避免；A、D 是方向明确的系统误差，B 是不可避免的偶然误差。检查：判断标准是"能不能靠规范操作消除"。

**23. 偏大；$a_{\text{测}} = \frac{a_{\text{真}}}{\cos^2\theta}$，偏大。**依据（对照图 2）：遮光期间小车实际前进 $d\cos\theta < d$，真实速度 $v_{\text{真}} = \frac{d\cos\theta}{\Delta t}$，而计算用 $v_{\text{测}} = \frac{d}{\Delta t} = \frac{v_{\text{真}}}{\cos\theta}$，偏大；两门速度都放大 $\frac{1}{\cos\theta}$ 倍，$a_{\text{测}} = \frac{v_{B\text{测}}^2 - v_{A\text{测}}^2}{2L} = \frac{a_{\text{真}}}{\cos^2\theta}$。主修正：重新安装平行。检查：误差链每一环都写了"为什么"，没有靠结论跳步。

**24. 开放题，合格标准：三个维度齐全、结论自洽。**参考要点——原理误差：甲受限位孔摩擦与空气阻力（系统误差，g 偏小），乙主要是挡光/安装的系统偏差，无接触测量；操作难度：甲器材简单、但纸带处理繁琐，乙对调平、对准和挡光片姿态敏感；数据处理：甲有成熟的逐差/图像法，乙数据少、靠公式直接算。任选一套并给出与三方面一致的理由即可。检查：比较必须有维度，单说"哪个好"不算完成。
